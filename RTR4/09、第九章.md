# 基于物理的着色

## 章节内容

本章建立基于物理着色的理论基础：先从光与物质的交互出发，定义相机、BRDF 和反射方程，再介绍菲涅尔反射、微表面几何、Cook–Torrance 模型以及漫反射、布料、薄膜干涉和分层材质等扩展。工程上的 PBR 并不是完全复制真实世界，而是在能量守恒、互易性、参数可控和实时成本之间取得平衡。

### 1. 光与物质的交互

光到达表面后，可能发生：

- **反射**：光线在表面返回外部。
- **折射**：光线进入材质内部，传播方向因折射率变化而改变。
- **吸收**：不同波长被材质吸收，造成颜色和能量衰减。
- **散射**：光线在内部或表面微结构中改变方向。
- **自发光**：表面自身向外发出辐射度。

金属通常具有较高的表面反射率，进入内部的光很快被吸收，因此几乎没有传统意义上的漫反射；非金属会让一部分光进入内部，经过散射和吸收后从表面重新出来，形成局部次表面散射和漫反射。透明材质的吸收和散射较低，进入内部的光可以穿过物体并从另一侧折射出来。

次表面散射是否必须使用全局模型，取决于散射距离与当前着色尺度的关系：

- 如果光线从进入点到离开点的距离小于一个像素或着色样本覆盖范围，可以把它近似为同一点的局部漫反射。
- 如果散射距离跨越了多个像素，光线在一个点进入、另一个点离开，就需要屏幕空间、纹理空间或路径追踪等全局次表面散射方法。
- 同一种材质在远景中可以使用局部模型，在特写中则可能需要全局模型。

### 2. 相机和观察射线

渲染的目标是计算从表面沿观察方向进入相机的 radiance。传统实时渲染通常使用针孔相机模型：相机位置和屏幕上的每个采样点定义一条观察射线，射线击中表面后计算该点向相机发出的辐射度。

真实镜头具有光圈和透镜。较大的光圈会让传感器接收到更多光，同时导致有限景深：不在焦平面上的物体会形成弥散圆而变得模糊。实时渲染中通常先使用理想针孔模型，景深等效果则作为额外的后处理或多采样过程实现。

抗锯齿也可以从相机角度理解为：一个像素传感器不应只接收单个无限小点的信号，而应当重建其覆盖区域内的连续图像信号。MSAA、超采样和时间采样都在近似这个过程。

### 3. BRDF 和反射方程

BRDF（双向反射分布函数）描述一个表面把来自入射方向的光，按多大比例反射到出射方向。它记为：

    fr(l, v)

其中 l 是指向光源的入射方向，v 是指向相机的出射方向，n 是表面法线。BRDF 的单位可以理解为每单位立体角的反射比例。

局部反射的反射方程为：

    Lo(p, v) = ∫Ω fr(p, l, v) Li(p, l) max(n · l, 0) dl

也就是说，出射 radiance 等于半球内所有方向的入射 radiance、BRDF 和余弦投影项的积分。实时渲染通常不会真的对整个半球连续积分，而是使用方向光、点光源、环境贴图、预积分和重要性采样等方法近似。

BRDF 的方向参数通常有四个自由度：入射方向和出射方向各需要两个角度。各向同性材质绕法线旋转后外观不变，因此可以减少一个方位角参数；各向异性材质还需要切线方向来描述拉丝金属、头发和织物等方向性。

可信的 BRDF 通常应满足：

- **Helmholtz 互易性**：交换入射方向和出射方向，BRDF 结果不变。
- **能量守恒**：反射出的总能量不能超过入射能量。
- **非负性**：BRDF 不应产生负的反射能量。

实时近似有时会违反严格互易性或能量守恒，但明显违反会让材质看起来异常发亮，并可能影响离线路径追踪的收敛。

### 4. 菲涅尔反射

菲涅尔效应描述反射率如何随入射角变化。垂直入射时反射率通常较低；观察方向越接近掠射角，反射率越接近 1。因此几乎所有材质在掠射角附近都会出现更强的反射。

非金属的垂直入射反射率主要由折射率决定，可近似为：

    F0 = ((η - 1) / (η + 1))²

其中 η 是材质相对于外部介质的折射率。绝缘体的 F0 通常较低且接近无色；金属的反射率更高，并且因为复折射率和吸收特性而呈现带颜色的反射。

精确菲涅尔方程需要使用折射率，金属还需要使用复数形式的折射参数。实时渲染常用 Schlick 近似：

    F = F0 + (1 - F0)(1 - cosθ)⁵

在微表面模型中，cosθ 通常取 v · h 或 l · h，其中 h 是入射方向与出射方向的半角向量；在更简化的解释中，也常用 n · v 来说明掠射角反射增强。菲涅尔项描述的是反射能量比例，不是透明度，也不等同于高光贴图颜色。

当光线从高折射率介质射向低折射率介质时，还可能发生全反射：入射角超过临界角后，光线不再折射到外部，反射率变为 1。

### 5. 微表面几何

真实表面在宏观上可能是平的，但在微观上由大量朝向不同的微小平面组成。光线会分别与这些微表面发生反射或折射，最终形成宏观上的高光和粗糙外观。

粗糙度描述微表面法线分布的离散程度：

- 表面较光滑时，微表面方向集中，高光较窄、较亮。
- 表面较粗糙时，微表面方向分散，高光较宽、较暗。
- 粗糙表面上的微表面还会互相遮挡，产生 masking 和 shadowing。
- 微表面越多方向不一致，反射和折射的细节也越模糊。

半角向量 h 是 l 和 v 的中间方向。如果某个微表面法线正好朝向 h，那么入射光可以沿该微表面反射到观察方向，这就是微表面高光的几何基础。

### 6. Cook–Torrance 微表面 BRDF

Cook–Torrance 模型把镜面反射写成三个核心项：

    f_spec(l, v) = D(h) F(l, h) G(l, v, h)
                  / (4 (n · l)(n · v))

- **D：法线分布函数 NDF**，表示朝向 h 的微表面比例。
- **F：菲涅尔项**，表示微表面反射率随角度的变化。
- **G：几何遮蔽项**，表示微表面之间的 masking 和 shadowing。
- 分母中的 n · l 与 n · v 用于投影和微表面几何的归一化。

常见 NDF 包括 Beckmann 和 GGX。GGX 在长尾方向保留更多高光，通常更适合实时材质中自然的粗糙高光。常见几何项包括 Smith 模型及其近似。

完整的着色还需要加上漫反射或局部次表面散射项，并乘以光源 radiance、可见性、n · l 和其他材质参数。BRDF 方程本身不是最终颜色，也不包含光源强度、阴影、曝光和显示编码。

### 7. 漫反射、能量分配和多次反弹

最简单的漫反射模型是 Lambert：

    f_diff = ρ / π

其中 ρ 是漫反射反照率。它假设光线在表面上均匀地向各个方向重新发射，成本低，至今仍广泛用于实时渲染和烘焙光照。

表面反射与内部散射共享同一份入射能量，因此不能同时把镜面和漫反射都设得很高。常见做法是根据菲涅尔项让更多能量在掠射角进入镜面反射，同时降低漫反射部分。

单次微表面模型在粗糙表面上可能损失能量：光线第一次反射后还可能继续撞击其他微表面并再次反射。多次散射补偿可以恢复一部分这类能量，避免粗糙材质看起来异常发暗。实时实现通常通过解析近似、预计算 LUT 或经验参数完成。

Disney diffuse、Oren–Nayar 等模型进一步考虑了粗糙漫反射、局部次表面散射和艺术控制。工程上选择 Lambert 还是更复杂的漫反射模型，要看目标材质、镜头距离、间接光方案和预算。

### 8. 表面反射模型的扩展

本章还讨论了多种专用材质模型：

- **布料**：纤维会产生方向性高光、粗糙散射、边缘发亮和颜色随观察方向变化等现象。可使用经验性的 wrap/rim 光照、sheen，或使用微表面和微圆柱体模型。
- **天鹅绒**：可以使用逆高斯类法线分布，表现掠射角附近的柔和边缘高光。
- **微圆柱体布料模型**：把表面近似为大量纤维线段，利用切线方向和纤维分布描述丝绸、绒布等外观。
- **各向异性材质**：用切线和副切线控制高光拉伸方向，常用于拉丝金属、头发和织物。

这些模型不是简单给标准 PBR 增加一个颜色，而是改变了微观几何假设、法线分布、遮蔽函数和反射方向。

### 9. 波动光学：衍射与薄膜干涉

普通微表面 BRDF 多使用几何光学，把光当作射线处理。但当结构尺寸接近光波长时，波动性质会影响外观。

- **衍射**：光波通过狭缝、细小结构或规则周期结构时发生弯曲和方向性扩散，常见于光盘、细密纹理、羽毛和某些织物。
- **薄膜干涉**：光在薄膜的上下表面反射后相互叠加，不同波长因为路径差产生增强或抵消，从而形成随观察角度变化的彩色效果。油膜、肥皂泡、氧化金属和部分涂层都可能出现这种现象。

薄膜干涉不是普通 Fresnel 高光，也不是简单的彩虹贴图。工程实现通常会根据膜厚、折射率、入射角和相位差计算或查表得到 RGB 反射率，再与基础材质混合。

### 10. 分层材质、混合与过滤

真实材质通常由多个层组成，例如透明涂层、金属基底、油膜、织物纤维和表面污渍。分层模型需要处理：

- 上层反射和透射对下层能量的影响。
- 各层的折射率、粗糙度和颜色。
- 层与层之间的能量守恒。
- 上层法线、下层法线以及微表面分布的组合。

材质混合可以按遮罩混合参数，也可以混合更完整的 BRDF/BSDF。直接线性插值最终颜色通常便宜，但不一定保持能量守恒；更物理的做法是混合反射率、粗糙度、法线分布和层间能量。

法线贴图和粗糙度贴图还涉及过滤问题。缩小纹理时，直接平均法线可能得到长度不足或方向错误的结果；对法线分布进行过滤，通常比简单平均 RGB 更合理。粗糙度、法线和高光的过滤应当考虑它们描述的是统计分布，而不是普通颜色。

## 讨论与补充

### 1. 菲涅尔项

常见的 Schlick 菲涅尔近似：

    F = F0 + (1 - F0)(1 - cosθ)^5

其中 cosθ 表示入射方向与微表面法线之间夹角的余弦。在微表面 BRDF 中，半角向量 H 是入射方向与视线方向的中间方向，因此通常使用 saturate(dot(V, H))；在只讨论宏观表面角度的简化解释中，也常用 N·V 来帮助理解菲涅尔效应。当视线越贴近表面时，相关余弦值越小，反射率越接近 1，因此掠射角下几乎所有材质都会更容易出现反射。

- F0 表示垂直观察表面时的反射率。
- 绝缘体的 F0 通常较低，而且 RGB 差异小，所以接近无色反射。
- 金属的 F0 较高，并且带有金属本身的颜色，因此金属反射通常是有色的。

菲涅尔项并不是“透明度”或单纯的高光颜色，而是在描述光线被表面反射的比例。剩余能量才可能进入材质内部，形成折射、吸收或漫反射等效果。

### 2. 微表面 BRDF

Cook-Torrance 微表面 BRDF 常简写为：

    BRDF = DFG / (4 · (N·V) · (N·L))

这里：

- D：微表面法线分布函数，描述有多少微表面朝向合适的方向；粗糙度越高，高光通常越宽、越暗。
- F：菲涅尔项，描述反射率随观察角度变化的情况。
- G：几何项，描述微表面之间的遮蔽和阴影。
- N·V 与 N·L：视线、光线与宏观法线的夹角余弦；分母用于补偿投影和几何项带来的影响。

因此，BRDF 是“材质如何响应入射光”的函数，不是光源本身，也不是最终颜色。最终结果还要结合入射光、法线、可见性、曝光以及颜色空间等因素。

### 3. Mipmap 与材质语义

Mipmap 通常在贴图导入阶段由引擎自动生成，我们一般只需要勾选对应开关。引擎会根据贴图的导入类型决定部分处理方式，但它不能可靠地猜出所有自定义通道的语义：

- 普通颜色贴图通常按 sRGB 纹理处理，采样后转入线性空间参与光照计算。
- 法线贴图应标记为 Normal Map，导入器会按法线数据处理；采样后还需要保证法线方向有效，不能把它当普通颜色贴图使用。
- Metallic、Roughness、AO 以及各种遮罩通常是数据纹理，应关闭 sRGB，按线性数据采样。
- 如果把多个数据打包进不同通道，具体哪个通道代表什么仍由 Shader 约定，不能只依赖贴图文件本身的名字。

所以“自动生成 Mipmap”不等于“自动理解所有材质语义”。自动化主要解决不同缩小级别的纹理数据生成和过滤；贴图是颜色、法线还是线性材质参数，仍需要正确设置导入选项和 Shader 约定。
