# 阴影

## 章节内容

本章讨论实时渲染中的阴影：阴影不仅能表现光照方向和遮挡关系，还能帮助观察者判断物体与地面的距离、接触关系和空间位置。原书重点比较了平面投影阴影、阴影体、阴影贴图及其软阴影扩展，并强调实时算法需要在画质、稳定性和可预测的性能之间取舍。

### 1. 阴影的作用和基本术语

阴影可以理解为光源可见性的问题：如果从接收物表面向光源观察时，中间有其他物体遮挡，那么该位置就处于阴影中。

- 光源（light source）：发出光线的物体或方向。
- 遮挡物（occluder）：挡住光线并投射阴影的物体。
- 接收物（receiver）：接受阴影的表面。
- 本影（umbra）：光源完全不可见、完全被遮挡的区域。
- 半影（penumbra）：只能看到光源一部分的区域。

阴影首先提供的是空间感和接触感。一个不完全准确但位置合理的阴影，通常也比完全没有阴影更能帮助观察者理解场景。

点光源或其他没有面积的精确光源，通常产生硬阴影；面光源或体积光源能够产生软阴影。软阴影不是单纯把硬阴影边缘统一模糊，而是由光源的部分可见性决定的：遮挡物越靠近接收物，半影越窄；距离越远，半影越宽。本影的大小也会随光源面积和遮挡物、接收物之间的距离变化，甚至可能完全消失。

### 2. 平面投影阴影

当物体只需要向一个平面投射阴影时，可以使用投影阴影。基本做法是：

1. 正常绘制物体。
2. 使用由光源位置和平面方程构造的投影矩阵，将物体顶点投影到接收平面。
3. 再绘制一遍投影后的几何体，将它作为深色阴影，并关闭光照。

投影矩阵可以理解为让光源、原始顶点和投影点共线，并让投影点落在平面上。对于任意平面 n · x + d = 0，都可以构造对应矩阵，因此不必局限于水平地面。

这种方法需要处理一些特殊问题：

- 投影后的三角形可能因为深度精度问题落到接收平面下方；可以偏移平面，或先绘制接收平面，再关闭 Z 测试绘制投影几何体。
- 如果接收平面有边界，需要使用模板缓冲或投影纹理限制阴影范围。
- 光源位于遮挡物下方、遮挡物位于接收平面下方时，可能产生方向错误的“反阴影”。实际系统需要剔除或裁剪不符合条件的投影几何体。
- 投影几何体也可以先渲染为纹理，再作为光照贴图或投影纹理应用到平面上；若光源与遮挡物的相对关系不变，这张纹理可以重复使用。

平面投影阴影速度快、实现简单，但只能适用于已知的接收平面，不能自然处理任意曲面、自阴影和复杂遮挡关系。

### 3. 平面软阴影和投影纹理

一种直接近似面光源的方法，是在面光源表面取多个采样点，把每个采样点当作一个点光源，分别生成硬阴影，再将多张结果累积平均。采样数越多，越接近面光源的结果，但每个采样点都需要一次阴影计算，实时成本很高，更多适合离线生成参考图或验证其他算法。

更快的近似包括：

- 对硬阴影纹理进行模糊，并把结果作为带透明度的阴影纹理合成。
- 从光源方向把遮挡物绘制到纹理，再将这张纹理投影到地面或其他接收物。
- 使用从阴影中心到轮廓的渐变，生成看起来合理但不严格物理正确的半影。
- 将遮挡物的水平切片保存为纹理层或 Mipmap，距离接收物越远时选择越模糊的层级。

这些方法通常需要应用程序明确区分遮挡物和接收物，也难以正确处理自阴影、复杂曲面和遮挡物顺序，因此更适合作为特定对象、特定平面或增强感知的辅助阴影。

投影纹理还可以表达光照模式，例如聚光灯的 cookie/gobo 纹理、百叶窗效果和预定义的光照衰减遮罩。动态阴影纹理可以与这些静态光照模式相乘。

### 4. 阴影体

阴影体把遮挡物相对于光源投射出的无限延伸区域建模成几何体。以点光源和一个三角形为例，将光源与三角形顶点连接并向远处延伸，就能形成一个截断的无限棱锥；其中的空间就是该三角形对应的阴影体。

阴影体的典型模板测试流程是沿相机到表面的视线统计进入和离开阴影体的次数：

- 穿过朝向观察者的面，计数增加。
- 穿过背面，计数减少。
- 到达最终可见表面时，计数大于零表示位于阴影体内部。

常见实现有从相机到表面计数的 z-pass，以及从无限远处开始计数的 z-fail。后者能处理相机位于阴影体内部等情况，但通常需要更完整的阴影体几何和额外处理。

阴影体不依赖阴影贴图的离散采样，因此可以得到精确、锐利的几何阴影；缺点是需要生成和光栅化额外几何体，成本会随遮挡物复杂度和场景关系变化，难以预测。它还天然偏向硬阴影，薄衣物褶皱等几何细节可能产生过于尖锐的阴影。由于性能和软阴影问题，现代实时项目中通常较少把它作为通用阴影方案。

### 5. 阴影贴图的基本流程

阴影贴图是最常用的通用阴影方法。它把光源视角下的遮挡信息存入纹理，再在相机视角的着色过程中查询。

    Pass 1：从光源视角绘制可能投射阴影的物体，记录最近深度

    Pass 2：从相机视角绘制接收物
            将当前表面转换到光源空间
            用光源空间坐标采样阴影贴图
            比较当前深度与阴影贴图深度

如果当前表面在光源空间中的深度大于阴影贴图中的最近深度，说明光源到当前表面之间已经有遮挡物，该表面处于阴影中。这里的阴影贴图是光源视角的深度纹理，不是把相机深度图再处理成另一张“相机阴影图”。

阴影贴图的实际生成通常还会做光源视锥裁剪和剔除：只绘制可能影响相关接收区域的投射物，减少阴影 Pass 的成本。点光源需要覆盖各个方向，常用立方体阴影贴图；聚光灯的视锥是透视投影，因此使用平面阴影贴图；方向光则通常使用正交投影。

### 6. 阴影贴图的误差和稳定性

阴影贴图把连续的遮挡关系离散到有限分辨率纹素中，因此会出现：

- 走样和锯齿：阴影贴图分辨率不足，或光源与相机的采样位置不匹配。
- 远处分辨率不足：同样大小的阴影贴图覆盖更大的世界范围时，每个纹素代表的面积更大。
- 闪烁和游移：相机或光源移动时，阴影投影在纹素网格中的位置变化。
- Shadow Acne：接收物与自己生成的深度之间存在精度误差，导致表面出现条纹状自阴影。
- Peter Panning：偏移量过大，阴影看起来与投射物分离。

Bias 的目的就是让接收物的深度比较避开数值误差，但它只能在两种错误之间取平衡：

    Bias 太小 → Shadow Acne
    Bias 太大 → Peter Panning 和漏光

常见手段包括常量深度偏移、根据表面斜率变化的 slope-scale bias、法线偏移、调整光源投影范围，以及让投射物和接收物的几何关系尽量可靠。阴影贴图还要求正确处理投射物的背面、透明度和裁剪，否则单一最近深度不能表达复杂的遮挡情况。

### 7. 透视、级联和多张阴影贴图

由于方向光覆盖的场景范围很大，单张阴影贴图很难同时保证近处和远处的质量。透视阴影贴图、梯形阴影贴图和 LiSPSM 等方法会改变光源投影，使更多纹素集中到相机更关注的区域；它们可以改善分辨率分配，但会引入投影变换、稳定性和实现复杂度问题。

更常见的工程方案是 CSM（Cascaded Shadow Maps，级联阴影贴图）：

1. 沿相机视线把可见视锥分成多个深度区间。
2. 为每个区间单独构造方向光阴影贴图。
3. 近处分配更高的纹素密度，远处分配相对较低的纹素密度。
4. 在级联交界处进行重叠或平滑过渡。

CSM 需要多次渲染投射物，成本高于单张阴影贴图；同时还需要处理级联边界、光源移动时的稳定性、正交投影包围范围和纹素对齐。它的价值在于把有限分辨率分配给不同距离，而不是凭空增加阴影信息。

### 8. PCF 与 PCSS

原始阴影贴图的单次比较通常只有“受光”或“遮挡”两种结果。PCF（Percentage-Closer Filtering）不是直接把深度纹理先做普通颜色模糊，而是对阴影贴图附近多个纹素分别执行深度比较，然后统计通过比较的比例：

    shadow = 通过深度比较的采样数 / 总采样数

因此，PCF 得到的是一个可见性比例。它可以产生柔和边缘，但如果采样半径固定，远近不同的遮挡关系通常会得到相对统一的软化范围。

PCSS（Percentage-Closer Soft Shadows）在 PCF 前增加遮挡物搜索：

1. 在当前阴影贴图位置附近寻找可能的遮挡物深度。
2. 根据遮挡物和接收物之间的距离估计半影宽度。
3. 使用这个动态半径进行 PCF 过滤。

遮挡物越靠近接收物，半影越窄，阴影更硬；二者距离越远，半影越宽，阴影更软。这就是接触硬化。PCSS 比 PCF 更符合面光源的几何趋势，但需要更多采样，仍会受到阴影贴图分辨率、搜索范围和偏移误差的影响。

### 9. 可过滤的阴影贴图和透明体阴影

PCF 需要多次进行深度比较，另一类思路是让阴影贴图本身更容易被滤波。

- VSM（Variance Shadow Maps）存储深度的一阶矩和二阶矩，例如 E(z) 与 E(z²)，利用方差和概率不等式估计当前深度被遮挡的概率。由于矩可以被普通纹理过滤，VSM 能较快地产生软阴影，但可能出现 light bleeding，即本应被遮挡的区域出现漏光。
- Moment Shadow Maps 存储更多深度矩，以提高对深度分布的表达能力，但会增加存储、滤波和数值稳定性的要求。
- 指数阴影贴图等方法通过变换深度改善过滤效果，但也需要注意漏光和参数范围。

普通单深度阴影贴图只记录一个最近深度，难以表示头发、烟雾、树叶或其他半透明体。深度阴影贴图、Opacity Shadow Maps 和自适应体积阴影贴图会在每个纹素中保存多个深度—不透明度样本，近似光线沿深度方向的衰减函数。这样可以让光线逐渐穿过头发或烟雾，而不是只能选择“完全遮挡”或“完全可见”。代价是数据结构更复杂，并且需要处理可变长度数据、内存写回和线程发散。

### 10. 不规则 Z 缓冲和其他方向

不规则 Z 缓冲（Irregular Z-Buffer，IZB）反过来存储相机可见表面的位置，而不是只存储光源视角下的最近遮挡深度。随后从光源视角光栅化遮挡物，并对这些表面点做三角形相交测试，判断每个可见点是否被遮挡。它可以减少阴影贴图采样偏移，得到很精确的硬阴影，但需要列表、保守光栅化和额外的相交计算，也需要控制每个纹素列表的长度以避免线程发散。

本章还讨论了几种特殊应用：

- 将阴影贴图视为空间体积或高度场，用于地形阴影和区域遮挡高度估计。
- 使用相机深度缓冲进行屏幕空间光线步进，在特写镜头中补充阴影贴图的小尺度错误；这种方法只对相机可见表面有效，采样成本也较高。
- 将阴影信息体素化，再用体素锥形追踪等方法近似面光源软阴影。
- 使用稀疏纹理、压缩体素结构等技术，降低大范围静态阴影的存储成本。

总体上，实时阴影的选择取决于场景尺度、静态或动态物体、光源类型、材质是否透明、是否需要软阴影，以及目标平台对性能和内存的限制。阴影贴图之所以长期流行，是因为它的成本和 GPU 光栅化流程相对容易预测；光线追踪则直接从接收物向光源发射射线，概念更直接，但需要加速结构和更高的计算预算。

## 讨论与补充

### 1. 阴影贴图的基本原理

阴影贴图的核心是从光源视角记录遮挡信息：

```text
Pass 1：从光源视角渲染场景，记录每个纹素看到的最近深度

Pass 2：从相机视角渲染场景
        将当前表面位置转换到光源空间
        与阴影贴图中的深度进行比较
```

如果当前表面在光源空间中的深度大于阴影贴图记录的深度，说明光源到当前表面的途中已经有其他物体遮挡：

```text
当前深度 > 光源视角记录的深度
→ 当前表面处于阴影中
```

这里不是生成一张“相机空间阴影贴图”，而是使用光源空间中的深度纹理，对相机看到的表面进行光源可见性测试。

### 2. 阴影贴图的常见问题

由于阴影贴图是有限分辨率的离散纹理，容易出现：

- 阴影锯齿；
- 阴影闪烁；
- 远处细节丢失；
- Shadow Acne，自阴影条纹；
- Bias 过大导致的 Peter Panning，阴影与物体分离。

其中 Bias 需要在两类错误之间取平衡：

```text
Bias 太小 → Shadow Acne
Bias 太大 → Peter Panning
```

### 3. CSM、PCF 与 PCSS

CSM（Cascaded Shadow Maps，级联阴影贴图）将相机视锥体分成多个区域：

```text
近处区域：分配更高阴影分辨率
远处区域：分配较低阴影分辨率
```

它主要用于方向光的大范围阴影，让有限的贴图分辨率优先用于更重要的近处区域。

PCF（Percentage-Closer Filtering）会对阴影贴图周围多个纹素分别进行深度比较，再统计其中有多少采样点被遮挡，从而得到一个阴影比例。它可以把阴影边缘软化，但通常会让所有阴影边缘使用比较统一的软化范围。

PCSS（Percentage-Closer Soft Shadows）会根据遮挡物与接收物之间的距离估计半影大小：

```text
遮挡物靠近接收物 → 接触处阴影较硬
遮挡物远离接收物 → 阴影边缘较软
```

因此 PCSS 比 PCF 更接近真实软阴影，但需要更多采样，成本更高。

### 4. 本影与半影

```text
本影 Umbra：光源完全不可见，完全被遮挡
半影 Penumbra：只能看到光源的一部分，部分被遮挡
```

点光源没有面积，可以近似为一个光点：

```text
完全被挡 → 完全处于阴影
没有被挡 → 完全受光
```

因此理想点光源通常只产生硬阴影。

面光源有二维面积。接收物上的不同位置，可能看到面光源的不同部分：

```text
看到整个光源 → 完全受光
看到部分光源 → 半影
完全看不到光源 → 本影
```

所以真实软阴影来自面光源的部分可见性，而不是简单把硬阴影边缘模糊一下。

### 5. 面光源、体积光源和聚光灯

需要区分：

```text
面光源：有二维面积
体积光源：有三维发光范围
```

产生软阴影的关键是光源具有面积或角度范围，不是必须具有体积。

普通聚光灯通常可以理解为：

```text
点光源 + 一个照射圆锥
```

它的圆锥表示光线传播范围，不代表光源本身具有面积，因此普通聚光灯通常仍然产生硬阴影。聚光灯边缘的平滑衰减只是光照强度的渐变，不等于真实的半影。

真实软阴影可以通过对面光源的不同区域分别测试可见性，再按照可见光源比例合成：

```text
阴影亮度 ≈ 可见光源面积 / 光源总面积
```

在实时渲染中，通常无法采样整个面光源，因此会用多次采样、PCF、PCSS、阴影滤波等方式近似。

### 6. 阴影算法的取舍

```text
平面投影阴影：简单快速，但只能处理特定平面

阴影体：几何上精确，但成本不稳定，软阴影较难处理

阴影贴图：性能可预测、适用范围广，但存在分辨率和采样问题

PCF：简单软化阴影，但软化范围比较统一

PCSS：可以表现接触硬化，但采样成本更高

光线追踪阴影：直接测试光源可见性，但需要加速结构和更多计算
```

### 我之前的总结

```text
阴影本质：判断接收物表面是否能被光源看到

阴影贴图：从光源视角记录深度，再进行可见性比较

硬阴影：光源没有面积，只有完全受光或完全被遮挡

软阴影：光源有面积，不同位置看到的光源比例不同
```
