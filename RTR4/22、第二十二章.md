# 相交测试方法

## 本章核心

相交测试用于回答“两个几何对象是否相交”，也可以进一步求出最近交点、穿透深度、碰撞法线等信息。它的应用包括：

- 射线拾取和射击检测；
- 角色与地面、墙壁的碰撞；
- 物体之间的碰撞检测；
- 视锥体剔除；
- 光线追踪中的射线与包围体、三角形测试；
- 判断物体是否应该继续进入渲染管线。

相交测试通常不是直接对复杂模型的全部三角形进行，而是采用分层结构：

```text
粗略包围体
    ↓
快速排除不可能相交的对象
    ↓
更紧的碰撞代理
    ↓
必要时执行精确图元测试
```

## 1. 凸物体与凹物体

### 凸物体

如果任取物体内部的两个点，连接这两个点的线段始终完全位于物体内部，则物体是凸的。

```text
凸：任意两点之间的线段都不会穿出物体
凹：某些内部点之间的线段会穿过外部空间
```

对于凸多面体，也可以理解为：对每个面，其余顶点都位于该面的同一侧。如果某个面的两侧都有其他顶点，那么物体通常是凹的。

### 实际项目如何处理

运行时通常不会每帧重新判断渲染模型是凸还是凹。碰撞体一般在导入或设计阶段就已经确定：

- 使用 Box、Sphere、Capsule 等简单凸体；
- 生成低面数凸包；
- 将凹物体分解成多个凸体；
- 静态场景直接使用三角形网格，并为它建立 BVH。

因此，SAT 等凸体算法的前提是：输入数据已经是凸的，而不是由 SAT 自己负责判断凸性。

## 2. 包围体不是精确模型

包围体（Bounding Volume，BV）是包住真实物体的简化几何体，例如：

- Sphere；
- AABB；
- OBB；
- k-DOP；
- Capsule；
- Convex Hull。

包围体的主要目的不是得到最终精确结果，而是快速完成拒绝测试：

```text
两个物体的包围体不相交
        ↓
真实物体一定不相交
```

如果两个包围体相交，并不能说明真实物体一定相交，因为包围体可能包含空白区域。这种结果叫保守误报，通常需要下一阶段继续确认。

## 3. AABB 与 OBB

### AABB

AABB 是轴对齐包围盒（Axis-Aligned Bounding Box）。它的边始终平行于世界坐标轴，可以用最小点和最大点表示：

```text
min = (xmin, ymin, zmin)
max = (xmax, ymax, zmax)
```

优点是表示简单、测试便宜，因此经常用于：

- BVH 节点；
- Broad Phase；
- 视锥剔除；
- 射线的快速排除；
- 粗略碰撞。

缺点是物体旋转后会变得松散，包含更多空白空间。

### OBB

OBB 是定向包围盒（Oriented Bounding Box）。它是可以旋转的盒子，通常由以下信息组成：

```text
中心点 C
三个正交局部轴 U、V、W
三个半尺寸 hx、hy、hz
```

OBB 可以更紧地贴合旋转物体，但相交测试更复杂。

OBB 不是渲染模型，而是碰撞或加速用的代理。例如 Unity 的 BoxCollider 在物体旋转后，在世界空间中就表现为一个 OBB。

## 4. 射线检测与 AABB 的关系

AABB 和射线检测不是互相替代的概念：AABB 是被测试的形状，射线检测是测试方式。

典型的模型拾取或射击检测流程是：

```text
Ray
 ↓
BVH 根节点 AABB
 ↓
只进入被射线穿过的子节点
 ↓
叶节点 AABB
 ↓
Ray-Triangle
```

因此，AABB 的作用是快速排除大量不可能被射线击中的部分，最终命中结果通常仍然由 Ray-Triangle 给出。

Ray-OBB 也不一定要直接使用 SAT。常见做法是将射线变换到 OBB 的局部空间，在局部空间中 OBB 就变成 AABB，然后复用 Ray-AABB 测试。

## 5. 分离轴测试 SAT

SAT 是分离轴测试（Separating Axis Test），主要用于判断两个凸物体是否相交。

### 分离轴的含义

将两个物体投影到某条轴上，得到两个一维区间：

```text
A → [minA, maxA]
B → [minB, maxB]
```

如果存在一条轴使两个区间分离：

```text
maxA < minB
```

或者：

```text
maxB < minA
```

那么这条轴就是分离轴，两个物体一定不相交。

如果所有候选轴上的投影区间都重叠，则两个凸物体相交。

```cpp
bool SAT(Shape A, Shape B)
{
    for (Axis axis : GetCandidateAxes(A, B))
    {
        Interval a = Project(A, axis);
        Interval b = Project(B, axis);

        if (a.max < b.min || b.max < a.min)
            return false;
    }

    return true;
}
```

投影通常通过点积计算：

```cpp
projection = dot(vertex, axis);
```

### 候选轴不是固定的 XYZ 轴

候选轴取决于物体类型：

| 物体 | 常见候选轴 |
|---|---|
| AABB | 世界 X、Y、Z 轴 |
| 2D 凸多边形 | 两个多边形所有边的法线 |
| 3D OBB | 两个物体各自的 3 个局部轴，以及 9 个边叉积轴 |
| 一般凸多面体 | 面法线，以及不同物体边之间的叉积 |

两个 OBB 最多需要检查：

```text
3 + 3 + 3×3 = 15 条轴
```

SAT 中的“分离轴”不是预先固定保存的特殊轴，而是当前测试中能够使两个投影区间分离的候选方向。

### SAT 还能用于碰撞响应

如果所有轴都重叠，可以计算每条轴上的重叠量：

```text
overlap = min(maxA, maxB) - max(minA, minB)
```

最小重叠量对应的轴，通常可以作为解除穿透的近似方向。不过要得到完整的接触点、接触面和稳定的物理响应，还需要额外算法。

## 6. 高面数凸多面体为什么不直接用 SAT

你的判断是正确的：如果两个凸多面体面数和边数都很高，直接做完整 SAT 会很昂贵。

一般凸多面体的候选轴包括：

- A 的所有面法线；
- B 的所有面法线；
- A 的每条边与 B 的每条边的叉积。

如果边数分别为 `Ea` 和 `Eb`，边叉积候选轴最多接近：

```text
Ea × Eb
```

每条轴还需要将顶点投影到轴上，因此高面数模型会产生很大开销。

实际项目通常采用以下方案：

### 方案一：AABB/OBB 粗筛

```text
AABB Broad Phase
    ↓
OBB 或其他简单凸体
    ↓
只有少数候选对象进入精确测试
```

OBB 本身也可以使用 SAT，但两个 OBB 只有最多 15 条候选轴，因此远比两个高面数凸多面体直接做 SAT 便宜。

### 方案二：GJK/EPA

动态凸体常使用 GJK，而不是枚举所有 SAT 轴。GJK 通过支持函数寻找某个方向上的最远点，逐步判断 Minkowski Difference 是否包含原点。

实际实现还可以使用：

- 上一帧的 Simplex 或方向作为初始值；
- 凸体邻接关系加速寻找最远点；
- 时间一致性缓存；
- EPA 计算穿透深度和碰撞方向。

### 方案三：简化碰撞模型

渲染网格和碰撞网格通常不相同：

```text
高面数渲染网格
        ↓
低面数碰撞凸包 / 多个简单凸体
```

例如汽车可以用多个 Box、Cylinder 和 Convex Hull 近似，而不是直接使用几万三角形的渲染网格。

### 方案四：静态网格使用 BVH

对于建筑、地形等静态凹模型，可以保留三角形网格，但提前建立 BVH：

```text
移动物体
    ↓
测试静态 BVH 的 AABB
    ↓
只访问少量候选节点
    ↓
最终进行 Capsule-Triangle 或 Ray-Triangle 测试
```

## 7. 项目中的实际组合

| 场景 | 常见方案 |
|---|---|
| FPS 射击 | Ray + BVH + AABB + Ray-Triangle |
| 鼠标拾取 | CPU Raycast 或 GPU ID Buffer |
| 角色碰撞 | Capsule + AABB Broad Phase + 三角形/凸体测试 |
| 旋转箱子 | OBB + SAT |
| 动态刚体 | 简化凸体 + GJK/EPA |
| 静态建筑地形 | 三角形网格 + BVH |
| 简单触发器 | Sphere、AABB、Capsule |
| 视锥剔除 | Sphere/AABB 与视锥平面测试 |

因此，实际项目中不是“只用射线和 AABB”，而是：

> AABB、Sphere 等便宜包围体负责快速缩小候选范围；OBB、SAT、GJK、Ray-Triangle 等算法负责对少量候选对象进行更精确的判断。

## 本章总结

```text
AABB：最便宜的第一道门
OBB：更紧的旋转盒代理
SAT：凸体之间基于投影区间的相交测试
GJK：动态凸体常用的迭代式相交测试
BVH：组织大量几何并减少候选数量
Ray-Triangle：射线检测的最终精确测试
```

最重要的性能思想是：

```text
不要一开始就做精确测试。
先用便宜的包围体拒绝绝大多数不可能相交的对象，
只有真正可能相交的少数对象才进入昂贵算法。
```
