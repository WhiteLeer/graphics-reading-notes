# 光与颜色

## 章节内容

本章建立“从场景光量到屏幕颜色”的基础。它先介绍辐射度量学、光度学和色度学，再解释为什么实时渲染通常用 RGB 近似光谱计算，最后讨论 HDR 显示、色调映射、曝光和颜色分级。

### 1. 为什么要区分光量和颜色

渲染器中常见的 RGB 数值，既可能表示物理光量的近似，也可能表示已经编码、准备显示的颜色。二者不能混为一谈：

- 场景中的光照计算应尽量在线性空间、场景参考状态中进行。
- 显示器接收的是经过显示编码的显示参考颜色。
- 从场景到屏幕通常不是简单复制，而是要经过曝光、色调映射、色域转换和显示编码。

本章的重点不是要求实时渲染器完全采用光谱计算，而是说明 RGB 三元组与真实光谱、物理光量以及人眼感知之间的关系。

### 2. 辐射度量学

辐射度量学研究电磁辐射的物理测量。可见光只是整个电磁波谱中很窄的一段，大约从 400 纳米的紫光延伸到 700 多纳米的红光。不同波长的能量分布可以用光谱功率分布（SPD）表示。

几个重要的辐射量如下：

- **辐射通量 Φ（radiant flux）**：单位时间流动的辐射能量，也就是功率，单位为瓦特 W。
- **辐照度 E（irradiance）**：单位面积接收到的辐射通量，E = dΦ/dA，单位为 W/m²。
- **辐射强度 I（radiant intensity）**：单位立体角方向上的辐射通量，I = dΦ/dω，单位为 W/sr。
- **辐射度 L（radiance）**：单位投影面积、单位立体角上的辐射通量，单位为 W/(m²·sr)。

立体角是二维角度在三维空间中的扩展，单位为球面度 sr。完整球面的立体角是 4π sr。

辐射度对渲染特别重要，因为相机或眼睛沿某条方向直接接收到的就是辐射度。在没有雾等参与介质的情况下，辐射度沿传播方向不会因为距离增加而自动衰减；距离增加时，表面覆盖的像素数量会减少，但每个可见像素对应的辐射度不因此降低。相反，点光源照到表面的辐照度会随距离平方衰减。

严格来说，光量是随波长变化的函数。例如两个 RGB 看起来相同的光源，可能有完全不同的 SPD。实时渲染通常用 RGB 三元组压缩表示光谱信息，以换取存储和计算效率。

### 3. 光度学

辐射度量学只描述物理能量，不考虑人眼对不同波长的敏感程度。光度学在辐射量的基础上乘以 CIE 光度曲线，对人眼感知更敏感的波长赋予更高权重。

常见光度学量包括：

- 光通量，单位流明 lm。
- 发光强度，单位坎德拉 cd。
- 照度，单位勒克斯 lux。
- 亮度，单位 cd/m²，也常用 nit 表示。

光度学中的亮度更接近显示设备和照明工程描述的“看起来有多亮”，而辐射度则是渲染和能量传输中更基础的物理量。HDR 显示器的峰值亮度、天空和太阳的亮度，都可以用 nit 进行描述。

### 4. 色度学和颜色空间

光谱功率分布与颜色感知不是一一对应的。人眼视网膜中有三类主要视锥细胞，它们对不同波长有不同响应，因此大多数正常颜色感知可以用三个刺激量近似表示。

不同的 SPD 可能产生相同的三刺激值和相同的颜色感知，这种现象叫同色异谱（metamerism）。这意味着 RGB 颜色并没有完整保存光谱信息：在普通场景中这种近似通常足够好，但在特殊光源或需要预测真实外观的应用中可能产生错误。

CIE XYZ 是常用的颜色表示基础。对 XYZ 进行归一化，可以得到色度坐标：

    x = X / (X + Y + Z)
    y = Y / (X + Y + Z)
    z = 1 - x - y

x、y 描述色度，Y 描述亮度。CIE 1931 色度图展示了可见光谱以及不同显示设备的色域。显示系统通常用三个原色和一个白点定义颜色空间：

- sRGB 与 Rec. 709：实时渲染和普通显示器中最常见，白点通常为 D65。
- DCI-P3：比 sRGB 更宽，电影和许多现代设备常用。
- Rec. 2020：面向 UHD/HDR 的更宽色域规范。
- ACEScg：主要作为电影和渲染中的工作颜色空间，不是直接显示空间。

需要区分“线性 sRGB 颜色空间”和“sRGB 非线性编码”。前者描述颜色空间的原色和白点，可以用于线性光照计算；后者是为了适应显示编码和有限位深而使用的传输曲线。纹理中的 sRGB 颜色通常需要先解码到线性值，完成光照计算后再编码到显示空间。

从一个颜色空间转换到另一个颜色空间，通常使用由原色和白点决定的 3×3 矩阵。转换后可能出现小于 0 或大于 1 的值，这表示颜色落在目标色域之外，需要进行色域映射或裁剪。

### 5. RGB 渲染与光谱渲染

严格的光谱渲染应该：

1. 保存光源在各个波长上的 SPD。
2. 保存材质在各个波长上的反射率或透射率。
3. 在每个波长上计算光与材质的相互作用。
4. 将最终 SPD 积分并转换为目标颜色空间中的 RGB。

普通实时渲染器则通常直接将光源 RGB 与材质 RGB 相乘，或者在 RGB 空间中运行 BRDF。这在大多数自然光源和表面上效果很好，因为自然光源和常见材料的光谱曲线通常比较平滑，RGB 三元组已经足够表达主要视觉效果。

但在窄带激光、特殊投影屏幕、荧光材料和需要预测换光源后颜色变化的应用中，RGB 近似可能失败：两个材料在一个光源下看起来相同，换一个光源后却会产生不同的颜色。游戏和一般实时渲染通常接受这种近似；汽车涂装预测、科学可视化和某些高精度离线渲染则可能需要光谱方法。

### 6. 从场景到屏幕

基于物理的渲染首先计算场景中的场景参考辐射度，但显示器无法直接显示无限动态范围和任意色域的场景值。因此需要经过以下过程：

    线性场景参考值
        → 曝光
        → 色调映射或色调再现
        → 色域转换
        → 显示编码
        → 显示器发光

需要区分两种图像状态：

- **场景参考（scene-referred）**：数值表示场景中的光量，适合进行光照、混合和其他物理运算。
- **显示参考（display-referred）**：数值表示目标显示设备应该发出的光量，已经受到显示器动态范围和色域限制。

显示编码不是色调映射。显示编码主要负责把线性显示值转换为适合传输和显示的非线性值，例如 sRGB OETF 或 PQ；色调映射则负责把场景动态范围和感知外观转换到显示设备能够表现的范围。

### 7. HDR 显示编码

SDR 显示通常使用 sRGB 或 Rec. 709/Rec. 1886 相关标准。HDR 显示通常涉及 Rec. 2020 色域和 Rec. 2100 标准，其中 PQ（Perceptual Quantizer）是实时 HDR 中常见的非线性编码，HLG 是另一种编码方案。

常见 HDR 传输路径包括：

- **HDR10**：常见于 PC 和主机系统，通常使用每像素 32 位的 RGB10A2 格式、PQ 编码和 Rec. 2020 色域。
- **scRGB**：线性 RGB 格式，每个通道通常为 16 位，允许小于 0 和大于 1 的值，主要在 Windows 路径中使用。
- **Dolby Vision**：专有 HDR 格式，具有更高位深和自己的显示映射流程。

Rec. 2020 是编码规范，并不代表所有实际 HDR 面板都能覆盖完整 Rec. 2020 色域或达到规范峰值亮度。显示设备和驱动仍可能执行色调映射与色域映射。应用程序还需要考虑 HDR UI 的可读性和舒适亮度，不能简单把所有 UI 当作场景光照处理。

### 8. 色调映射

色调映射（tone mapping）或色调再现，是把场景参考辐射度转换为显示参考辐射度的过程。它不是把场景中的每一个数值无损塞进显示器，也不是保证显示器上的结果与真实场景的绝对辐射度完全相同；它的目标是，在显示设备和观看条件有限的情况下，尽量再现原场景的感知印象。

现实场景的亮度范围可能远大于显示器。直接裁剪会造成：

- 高光全部变成白色。
- 暗部全部变成黑色。
- 颜色和对比度发生突变。
- 细节丢失。

色调映射通常让暗部保持相对稳定，使高光逐渐压缩到白色附近，并通过 S 形曲线保留部分阴影和高光层次。曝光通常是色调映射前对场景参考值进行的线性缩放。全局色调映射对所有像素使用同一个曝光和曲线，实时应用中最常见；局部色调映射会根据邻域像素使用不同映射，成本和稳定性更复杂。

常见曲线包括：

- Reinhard：暗部基本保持，亮部渐进地压缩到白色。
- Drago：在类似 Reinhard 的基础上增加显示亮度控制。
- Hable/Filmic：通过胶片风格 S 曲线提供更有控制力的高光压缩。
- ACES：将场景到屏幕拆成参考渲染转换 RRT 和输出设备转换 ODT，可针对不同显示设备和观看条件选择输出变换。

色调映射可以逐通道处理，也可以先作用于亮度再恢复色度。逐通道非线性处理可能引起色相和饱和度变化；基于亮度处理通常更容易保持色相，但结果仍可能超出显示色域，需要额外进行色域映射。色调映射还可能影响抗锯齿和透明混合，因此应放在合适的渲染阶段，并确保此前的颜色仍处于正确的线性、场景参考状态。

### 9. 曝光

曝光是色调映射前对场景参考图像进行线性缩放的过程。常见实现会分析前一帧的亮度，避免当前帧突然变化造成停顿或闪烁。

曝光估计方式包括：

- 对亮度做多级下采样，计算对数平均亮度。
- 使用亮度直方图，取中位数或某个百分位，降低少量极亮像素对结果的影响。
- 根据场景光照而不是最终像素亮度估计曝光，使材质反照率不会错误地改变曝光。
- 在已知照明区域中由美术手动设置曝光，避免动态自动曝光出现意外变化。

很多实时项目仍会使用静态或半自动曝光；完整的基于光照的物理曝光在工程上更准确，但需要更多场景信息和稳定的时域处理。

### 10. 颜色分级和 LUT

颜色分级是对图像颜色进行创造性调整，以获得目标风格、对比度、色温和饱和度。游戏中常见的颜色分级通常通过 3D LUT 实现：

1. 准备一张表示所有输入颜色的规则 LUT 图像。
2. 在图像编辑或调色工具中对这张图像应用颜色变换。
3. 将结果重新打包为三维 GPU 纹理。
4. 渲染时以输入 RGB 作为三维坐标查询 LUT。

3D LUT 可以快速实现复杂的逐颜色映射，但会受到 LUT 分辨率、采样和边界处理的限制。模糊、锐化等空间操作不能简单烘焙进颜色 LUT，因为 LUT 只描述单个颜色输入到输出颜色的映射，不包含邻域信息。

颜色分级有两种重要位置：

- **显示参考分级**：先完成色调映射，再对显示参考颜色调色，直观易用，但可能丢失场景高光信息。
- **场景参考分级**：在色调映射前对场景参考颜色处理，再进行显示变换，通常能保留更多动态范围和更高保真度，也可以把部分色调映射一起烘焙到 LUT 中。

因此现代管线需要明确每个后处理效果处于场景参考还是显示参考阶段，不能只把所有颜色操作都简单堆在最后。
