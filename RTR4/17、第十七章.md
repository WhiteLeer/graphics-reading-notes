# 曲线和曲面

## 章节内容

曲线和曲面用方程或控制点描述连续形状，再在需要渲染时转换为三角形。相比直接保存高密度网格，它们更紧凑、可缩放、表面连续，也便于动画、碰撞和路径计算；代价是运行时需要评估、细分和三角化。

### 1. 曲线表示

曲线可以用参数方程 P(t) 描述。最常见的 Bézier 曲线由控制点决定：线性 Bézier 在两个端点之间插值，二次 Bézier 使用两个端点和一个控制点，三次 Bézier 使用两个端点和两个控制点。控制点不一定落在曲线上，但会控制曲线的切线、弯曲方向和整体形状。

多段 Bézier 可以把多条低阶曲线连接起来。只要求位置连续是 C0，连接处切线和速度连续是 C1，曲率也连续则是 C2。工程上通常使用多段低阶曲线，而不是一条控制点很多的高阶曲线，因为高阶曲线的控制点会互相影响，局部修改容易牵动整个形状。

### 2. B 样条和 NURBS

B 样条使用基函数和节点向量组合控制点。与 Bézier 不同，一个控制点通常只影响曲线的一段局部区域，因此可以在不破坏其他部分的情况下修改局部形状。通过调整节点向量，还可以改变控制点的影响范围和连续性。

Bézier 可以视为 B 样条的特殊情况：使用单个区间并适当重复端点节点时，B 样条会退化为 Bézier。B 样条更适合拼接多段曲线、保持局部控制和构造复杂路径。NURBS 再加入权重，可以精确表示圆、椭圆、圆柱和其他二次曲线曲面，因此广泛用于 CAD 和 DCC。

### 3. 曲线求值与 GPU 渲染

曲线可以在 CPU 上预先离散为线段，也可以把控制点传到 GPU，在顶点或计算着色器中实时求值。评估密度应根据曲率、屏幕占比和相机距离决定：近处或弯曲剧烈的区段需要更多采样，远处可以减少采样。

直接把曲线渲染为线通常会受到线宽和 API 支持限制。常见做法是把曲线细分为带状四边形、圆柱段、粒子或面向相机的 ribbon。头发、草、道路中心线和粒子轨迹都可以用曲线控制点生成几何。

### 4. 曲面与细分

曲面可以通过参数 P(u,v) 求值。双线性曲面、Bezier 曲面、B 样条曲面和 NURBS 曲面都可以在运行时采样。细分过程会把一个粗粒度 patch 转为更多三角形，再交给普通光栅化管线。

细分有两个重要用途：提高表面和 silhouette 的几何质量，以及让位移、碰撞或逐顶点操作拥有足够密度。细分数量应与屏幕误差相关，过少会出现块状轮廓，过多则浪费带宽和顶点着色器计算。

### 5. 裂缝与连续性

多个曲面拼接时，如果相邻 patch 的边界采样点数量或位置不一致，就会出现裂缝。边缘缝合要求共享边生成完全一致的顶点；自适应细分还需要处理相邻区域细分等级不同的问题。常见方案包括边界顶点共享、特殊过渡 patch、调整细分因子和 stitch pattern。

### 6. 工程权衡

曲线和曲面并不意味着最终不需要三角形。多数实时 GPU 最终仍通过细分、计算着色器或 CPU 预处理生成三角形。它们的价值在于以更紧凑的控制数据生成可伸缩的几何，并把细节生成延迟到真正需要的视角和分辨率。

## 讨论与补充

### 既有整理

### Bézier 曲线

Bézier 曲线由一组控制点定义。起点和终点通常位于曲线上，中间控制点一般不在曲线上，而是控制曲线的切线方向和弯曲程度。

如果控制点越多，Bézier 曲线的阶数就越高。高阶曲线的问题是：

- 计算成本会增加；
- 控制点之间的关系变得不直观；
- 修改任意一个控制点，都会影响整条曲线。

因此实践中通常使用多段低阶 Bézier，而不是一条包含大量控制点的高阶 Bézier。

### 多段 Bézier 与连续性

多段三次 Bézier 可以表示为：

```text
第 1 段：P0 P1 P2 P3
第 2 段：Q0 Q1 Q2 Q3
```

为了让两段连接自然，需要手动满足连续性条件：

- `C0` 连续：两段端点重合，即 `Q0 = P3`；
- `C1` 连续：连接处切线方向和长度关系连续；
- `C2` 连续：曲率也连续。

如果只共享端点而不约束控制柄，就可能出现方向突变或明显折角。

### B 样条曲线

B 样条也使用控制点，但通常使用一套连续的控制点序列和节点向量，将曲线分成多个低阶区间。

三次 B 样条的某个局部区间可能由附近的四个控制点共同影响：

```text
区间 1：P0 P1 P2 P3
区间 2：P1 P2 P3 P4
区间 3：P2 P3 P4 P5
```

因此 B 样条具有局部控制能力：一个控制点只影响附近的一部分曲线，不会影响整条曲线。三次 B 样条中，一个控制点最多通常影响附近的几个区间，而不是整条曲线。

节点向量决定了每个控制点的影响范围，以及不同区间之间的连续性。节点重复次数越高，连接处的连续性通常越低，因此也可以用来制造折角或边界。

### 二者的实现区别

多段低阶 Bézier 和 B 样条在表达能力上可以互相转换，区别主要在数据组织方式：

- 多段 Bézier：每一段有自己的一组控制点，段与段之间的连续性需要显式维护；
- B 样条：所有区间共享一组控制点，通过基函数和节点向量自动组织连接关系。

多段 Bézier 的局部控制范围更直观，单段计算也更简单；B 样条的控制点和数据更紧凑，更适合大量控制点和复杂编辑。

可以把二者理解为：

```text
多段 Bézier：每段独立存储局部曲线
B 样条：     用一套控制点和节点规则生成多个局部曲线
```

一个单区间、端点节点重复 `n+1` 次的 `n` 次 B 样条，就是 `n` 次 Bézier 曲线。因此 Bézier 曲线确实是 B 样条曲线的特殊情况。

### 曲面与细分

曲线使用一个参数 `t`，参数化曲面使用两个参数：

```text
p = p(u, v)
```

运行时可以根据距离、曲率和屏幕占用等因素，对曲面采样并生成不同数量的三角形。因此曲面表示天然适合动态 LOD 和自适应曲面细分。

PN 三角形、Phong 曲面细分、Loop 细分和 Catmull-Clark 细分，都是用较少的控制数据生成更加平滑或更加密集的曲面的方法。

需要区分：凹凸贴图只改变法线，位移细分则会实际改变表面位置和轮廓。
