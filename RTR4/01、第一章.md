# 实时渲染简介

## 章节内容

本章是全书导论，介绍实时渲染的定义、帧率与刷新率等基本概念，并统一后续章节会使用的数学符号、几何术语和“着色”相关概念。它本身不深入讨论具体算法，主要负责建立阅读全书所需的基础语言和知识地图。

### 1. 实时渲染的定义

实时渲染是快速生成三维场景图像，并根据观察者的操作持续更新画面的过程：

```text
生成图像
   ↓
观察者观察、反馈和操作
   ↓
影响下一张图像
   ↓
持续循环
```

实时渲染的关键不只是生成图像，还包括交互性、三维场景到二维图像的转换、图形加速硬件，以及有限的帧时间预算。

书中用 FPS 或 Hz 描述图像显示速率。速率很低时，用户会明显意识到每一张图像是独立的；达到一定速率后，画面才会逐渐具有连续的交互感。游戏常见目标包括 30、60、72 FPS 或更高，VR 设备通常需要更高且更稳定的帧率来降低延迟。

电影放映机通常以 24 FPS 显示画面，但快门系统会将每一帧重复照亮多次，以减少闪烁。因此需要区分：

```text
显示速率：每秒显示多少张不同的图像
刷新率：显示设备每秒刷新或照亮屏幕多少次
```

LCD 显示器的刷新率和游戏实际生成的 FPS 同样不是一个概念。

### 3. 数学符号

书中使用以下基本符号约定：

| 类型 | 常见表示 | 含义 |
| --- | --- | --- |
| 角度 | 小写希腊字母 | 角度、相位等标量量 |
| 标量 | 小写斜体字母 | 单个实数 |
| 向量、点 | 粗体小写字母 | 具有多个分量的量 |
| 矩阵 | 大写粗体字母 | 线性或仿射变换等 |
| 平面 | 法线和常数 | 用方程描述的平面 |
| 三角形 | 三个顶点 | 常见的渲染图元 |
| 几何实体 | 大写斜体字母 | 一组几何数据或几何对象 |

向量通常使用列向量表示。矩阵元素使用行、列下标访问；矩阵的行向量和列向量也可以单独取出，用于描述变换或坐标基。

### 4. 点、向量和齐次坐标

在三维图形学中，点表示位置，向量表示方向或位移。使用齐次坐标时，可以通过第四个分量区分二者：

```text
向量：v = (x, y, z, 0)
点：  p = (x, y, z, 1)
```

`W` 分量的意义是：向量不应受到平移影响，所以 `W=0`；点可以被平移，所以 `W=1`。这使得点和向量可以使用相同的矩阵形式参与运算，同时保留不同的几何语义。

### 5. 常用数学运算

本章回顾了后续章节经常使用的运算：

- 点积：判断方向关系、计算投影和夹角；
- 叉积：得到垂直于两个向量的向量；
- 转置：在行向量和列向量之间转换；
- 范数：计算向量长度；
- 行列式：描述矩阵的缩放、方向和可逆性等性质；
- 标量绝对值；
- 将负数限制为 0 的函数；
- 将数值限制到 `[0, 1]` 的 Clamp 函数；
- 阶乘和组合数；
- `atan2(y, x)`：处理方向和象限；
- `log`：本书中通常表示自然对数。

书中还约定了区间表示，例如 `[a,b]` 表示包含两端点的区间，`(a,b)` 表示不包含两端点的区间。

### 6. 平面、坐标轴和几何定义

平面可以表示为：

```text
π : n · x + d = 0
```

其中 `n` 是平面法线，`d` 是标量。平面会将空间分成正半空间、负半空间以及位于平面上的点。

坐标轴方向通常使用标准基向量表示。`x=0`、`y=0`、`z=0` 等平面称为坐标平面或轴对齐平面。

实时渲染中常见的基本图元包括点、线段和三角形。三角形由三个顶点定义。多个几何实体可以组成模型或物体；场景则通常包含模型、材质、灯光和观察信息。

物体不一定只能由三角形组成，也可以使用更高层次的几何表示，例如 Bézier 曲线、Bézier 曲面、细分曲面，或者由其他物体嵌套组成。

### 7. 颜色表示

颜色可以使用三维向量表示：

```text
color = (red, green, blue)
```

在本章的约定中，各颜色分量通常位于 `[0, 1]` 范围内。后续章节会进一步讨论颜色空间、光照计算和显示转换。

### 8. “着色”的两种含义

计算机图形学中，“着色”和“着色器”可能指两个相关但不同的概念。

第一种是物体外观的计算模型，例如着色模型、着色方程、卡通着色和材质外观计算。

第二种是渲染系统中的可编程组件，例如顶点着色器、像素着色器和着色器语言。需要根据上下文判断“着色”是在说外观模型，还是在说 GPU 程序。

## 讨论与补充

### 1. 24 FPS 与电影感

24 FPS 常用于制造电影感，但低帧率本身并不自动等于电影感。还需要结合运动模糊、快门、镜头运动、构图、动画节奏、景深和色彩等因素。

180° 快门可以近似为每帧曝光半个帧周期：

```text
曝光时间 ≈ 1 / (2 × FPS)
```

在实时渲染中，通常通过运动模糊参数来近似这种效果，而不是使用真实的机械快门。

### 2. 游戏过场的帧率选择

游戏过场不一定必须使用 24 FPS。是否锁定 24 FPS，需要综合考虑目标设备刷新率、过场是否允许输入、运动模糊和动画节奏，以及性能预算和画面复杂度。

如果只是想获得电影感，可以保持较高帧率，再通过运动模糊、镜头语言和动画设计模拟电影效果。

### 3. FPS、刷新率和锁帧

- FPS：程序或渲染系统生成新画面的速率；
- 刷新率：显示设备刷新屏幕的速率；
- 锁帧：限制程序生成新帧的速率。

锁帧可以降低 CPU/GPU 负载和功耗，也可以减少帧时间波动。垂直同步和可变刷新率则用于协调程序生成帧与显示器刷新之间的关系。

### 4. 点和向量的工程意义

`W=0` 和 `W=1` 不只是记号区别，而是后续矩阵变换正确处理平移的基础：

```text
M × 向量：不产生平移
M × 点：可以产生平移
```

因此，顶点位置、法线、切线、速度和方向等数据不能只看它们都是 `float3`，还需要理解它们在几何上的语义。
