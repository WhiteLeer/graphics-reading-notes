# 纹理

## 章节内容

本章介绍纹理化：使用图像、函数或其他数据，修改表面不同位置的外观。内容包括纹理坐标、纹理投影、纹理采样和过滤、Mipmap、各向异性过滤、纹理数组、纹理压缩、程序化纹理、Alpha 映射、法线映射、视差映射和纹理化光源。

### 1. 纹理化的基本流程

纹理化可以理解为：为表面位置生成纹理空间坐标，再使用这个坐标取得纹理值，最后将纹理值输入着色模型。

```text
表面位置
    ↓
纹理坐标生成或投影
    ↓
纹理采样
    ↓
过滤和 Mipmap 选择
    ↓
参与材质和光照计算
```

纹理不一定只能保存颜色，也可以保存法线、粗糙度、遮罩、高度、光照、对象 ID 或其他计算数据。

### 2. 纹理坐标和投影

最常见的纹理坐标是二维 `u、v` 坐标，也可以使用一维、三维或更高维坐标。纹理坐标通常在模型制作阶段生成并存储在顶点中，但也可以在顶点着色器或像素着色器中实时计算。

常见的纹理投影方式包括：

- 平面投影；
- 球面投影；
- 柱面投影；
- 盒状投影；
- 基于世界空间或模型空间的位置投影。

纹理展开需要在纹理空间中安排网格表面，同时尽量减少拉伸、重叠和接缝。良好的展开能够让纹理分辨率得到更合理的利用，也方便后续绘制和烘焙。

纹理坐标还可以通过变换矩阵进行平移、旋转、缩放和剪切，从而实现滚动纹理、旋转纹理和程序化变化。

### 3. 纹理地址模式和采样坐标

当纹理坐标超出 `[0,1]` 时，可以使用不同的地址模式：

- Repeat：重复纹理；
- Mirror：镜像重复；
- Clamp：限制到边缘纹素；
- Border：超出范围时使用固定边框颜色。

不同 API 对纹理坐标原点和纹理坐标方向的约定可能不同，迁移渲染代码时需要特别注意。

### 4. 放大过滤

当一个纹素覆盖多个屏幕像素时，属于纹理放大。常见过滤方式包括：

- Nearest / Point：选择最近纹素，结果锐利但可能出现块状边缘；
- Bilinear：对相邻四个纹素进行插值，结果更平滑；
- Bicubic 等更高阶过滤：使用更多邻近纹素，质量更高但计算更复杂。

双线性过滤本质上是先在一个方向上插值，再在另一个方向上插值。

### 5. 缩小过滤与 Mipmap

当一个屏幕像素覆盖多个纹素时，属于纹理缩小。如果只取一个纹素，就容易出现：

- 闪烁；
- 摩尔纹；
- 高频细节混叠；
- 纹理随距离变化而跳动。

Mipmap 会为原始纹理预先生成多级低分辨率版本：

```text
Mip 0：原始分辨率
Mip 1：约一半宽度和高度
Mip 2：继续降低分辨率
...
```

采样时根据一个屏幕像素覆盖的纹理区域选择合适的 Mipmap 层级。三线性过滤还会在两个相邻 Mipmap 层之间进行插值，以减少层级切换造成的跳变。

Mipmap 的生成质量依赖于下采样过滤和颜色空间。颜色纹理通常需要在线性空间进行正确的平均；法线、高度、Alpha 和其他数据纹理则可能需要专门的处理方式。

### 6. 各向异性过滤和 SAT

屏幕像素在纹理上的投影区域不一定是正方形，斜视表面上的投影可能是很长的椭圆或四边形。普通 Mipmap 通常用一个近似的正方形区域进行过滤，因此在地面和掠射角表面上容易变模糊。

各向异性过滤会沿纹理投影的主要方向进行多次采样，从而在保持远处清晰度的同时减少锯齿。

Summed-Area Table（SAT）可以快速计算轴对齐区域内的纹素总和，用于更大范围的过滤，但需要额外存储空间和较高精度。它适合某些大范围过滤场景，但现代硬件通常更多使用 Mipmap、各向异性采样和专用过滤机制。

### 7. 纹理类型和组织方式

常见纹理类型包括：

- 一维纹理；
- 二维纹理；
- 三维体积纹理；
- 立方体贴图；
- 纹理数组；
- 多级纹理。

纹理数组可以保存尺寸和格式一致、但内容不同的多个纹理层，并通过额外的层索引采样。它不会像纹理图集那样在子纹理边界处发生跨图采样，适合粒子、材质集合和数组化资源。

纹理图集将多个小纹理放入一张大纹理，可以减少资源切换，但需要处理子纹理边缘、UV 范围和 Mipmap 串色问题。

三维纹理可以直接使用三维坐标采样，适合体积数据、烟雾、噪声和程序化效果，但存储和过滤成本更高。

### 8. 纹理压缩

GPU 纹理压缩的目标是减少显存和带宽占用，同时保持可以接受的视觉质量。块压缩格式通常将固定大小的纹素块独立编码，使 GPU 可以直接对局部块进行解码。

常见格式家族包括：

- BC/DXTC；
- ETC；
- ASTC。

不同格式在颜色、Alpha、法线、HDR 和移动平台支持方面各有取舍。法线贴图通常需要专门的通道组织和压缩方式，不能直接按照普通颜色纹理处理。

### 9. 程序化纹理

程序化纹理通过函数或噪声生成纹理值，不一定需要完整保存一张图像。常见方法包括：

- 噪声函数；
- 蜂窝或 Voronoi 类特征点距离；
- 纹理坐标变换；
- 图像扭曲和变形；
- 查找表。

程序化纹理可以节省存储并产生连续变化，但运行时计算成本、重复模式和过滤质量需要额外处理。

### 10. Alpha 映射

Alpha 贴图可以表达树叶、草、灌木、栅栏等非矩形形状。常见方式包括：

- Alpha Blend：支持连续透明度和边缘抗锯齿，但需要排序；
- Alpha Test / Alpha Clip：根据阈值保留或丢弃片元，不需要半透明排序，但边缘可能锯齿明显。

使用 Alpha Clip 时，Mipmap 可能改变纹理的覆盖率，导致远处的树叶或草地变薄、消失。因此需要对 Alpha Mipmap 进行覆盖率修正，或者在 Shader 中根据层级进行补偿。

透明纹理过滤还会受到 RGB 与 Alpha 分离存储的影响。预乘 Alpha 可以减少透明边缘的黑边和颜色泄漏，但必须配合正确的混合公式。

### 11. 法线映射和凹凸映射

凹凸映射通过高度或法线信息改变光照计算中的表面方向，而不一定改变真实几何体。

法线贴图通常在切线空间中保存法线方向。为了将其转换到世界空间，需要使用由切线、副切线和法线构成的 TBN 基：

```text
TBN = [T, B, N]
```

法线贴图的 RGB 通道通常表示切线空间法线的三个分量。由于法线的过滤和归一化不是线性的，直接对法线纹素进行普通平均可能产生误差，需要在采样后重新归一化，某些场景还需要专门的法线过滤方式。

### 12. 视差映射和视差遮挡映射

视差映射根据观察方向和高度贴图偏移 UV，使表面产生随视角变化的深度错觉：

```text
观察方向 + 高度信息
    ↓
调整 UV
    ↓
采样不同位置
    ↓
产生表面深度感
```

基础视差映射计算便宜，但在掠射角度下偏移可能过大，近似容易失效。视差遮挡映射会沿观察方向进行光线步进，寻找高度场的近似交点，因此能够表现遮挡和自阴影，但需要更多采样。

法线映射和视差映射都不会改变物体真实轮廓；在模型边缘仍然会暴露出原始平面几何的轮廓。

### 13. 纹理化光源

纹理不仅可以描述物体表面，也可以控制光源的强度分布和聚光范围。

常见方式包括：

- 使用二维投影纹理控制聚光灯；
- 使用一维纹理定义距离衰减；
- 使用二维纹理定义角度衰减；
- 使用立方体贴图控制全方向光源；
- 使用三维纹理控制体积光照。

## 讨论与补充

### 1. 纹理缩放与过滤

当一个纹素（Texel）覆盖多个屏幕像素时，属于纹理放大，需要根据纹理采样方式生成更多屏幕像素：

```text
Point / Nearest：取最近的 Texel
Bilinear：对相邻 Texel 进行插值，结果更平滑
```

当多个 Texel 共同覆盖一个屏幕像素时，属于纹理缩小。此时如果只取一个 Texel，容易出现：

- 闪烁；
- 摩尔纹；
- 高频细节混叠；
- 纹理随距离变化而跳动。

因此通常使用 Mipmap，根据纹理在屏幕上的覆盖范围选择合适的低分辨率纹理层级。

### 2. 不同纹理的 Mipmap 生成方式不一定相同

Mipmap 并不是简单地对所有纹理都使用同一种平均方式。

```text
颜色纹理：通常可以进行颜色下采样
法线纹理：需要考虑方向和归一化
高度纹理：有时需要保留最大值等特征
Alpha / Mask：需要避免边缘信息被错误过滤
```

因此，纹理类型不同，Mipmap 的生成和过滤逻辑也可能不同。尤其是法线、高度、Alpha 等数据纹理，不能完全按照普通颜色纹理处理。

### 3. 凹凸贴图和视差贴图

凹凸贴图的核心是修改着色时使用的法线：

```text
模型几何形状不变
        ↓
修改法线
        ↓
光照变化产生凹凸视觉
```

因此凹凸贴图不会真正改变：

- 模型轮廓；
- 三角形位置；
- 真实遮挡关系；
- 几何体的实际高度。

视差贴图除了修改法线或使用高度信息，还会根据观察方向调整 UV：

```text
观察方向 + 高度贴图
        ↓
偏移 UV
        ↓
从不同位置采样纹理
        ↓
产生表面深度变化的错觉
```

所以二者的主要区别是：

```text
凹凸贴图：主要改变法线
视差贴图：还会改变纹理采样位置（UV）
```

视差贴图的立体感更强，但仍然没有改变真实几何体，因此在轮廓边缘和极端掠射角度下会暴露限制。
