# 纹理

## 核心理解

### 1. 纹理缩放与过滤

当一个纹素（Texel）覆盖多个屏幕像素时，属于纹理放大，需要根据纹理采样方式生成更多屏幕像素：

```text
Point / Nearest：取最近的 Texel
Bilinear：对相邻 Texel 进行插值，结果更平滑
```

当多个 Texel 共同覆盖一个屏幕像素时，属于纹理缩小。此时如果只取一个 Texel，容易出现：

- 闪烁；
- 摩尔纹；
- 高频细节混叠；
- 纹理随距离变化而跳动。

因此通常使用 Mipmap，根据纹理在屏幕上的覆盖范围选择合适的低分辨率纹理层级。

### 2. 不同纹理的 Mipmap 生成方式不一定相同

Mipmap 并不是简单地对所有纹理都使用同一种平均方式。

```text
颜色纹理：通常可以进行颜色下采样
法线纹理：需要考虑方向和归一化
高度纹理：有时需要保留最大值等特征
Alpha / Mask：需要避免边缘信息被错误过滤
```

因此，纹理类型不同，Mipmap 的生成和过滤逻辑也可能不同。尤其是法线、高度、Alpha 等数据纹理，不能完全按照普通颜色纹理处理。

### 3. 凹凸贴图和视差贴图

凹凸贴图的核心是修改着色时使用的法线：

```text
模型几何形状不变
        ↓
修改法线
        ↓
光照变化产生凹凸视觉
```

因此凹凸贴图不会真正改变：

- 模型轮廓；
- 三角形位置；
- 真实遮挡关系；
- 几何体的实际高度。

视差贴图除了修改法线或使用高度信息，还会根据观察方向调整 UV：

```text
观察方向 + 高度贴图
        ↓
偏移 UV
        ↓
从不同位置采样纹理
        ↓
产生表面深度变化的错觉
```

所以二者的主要区别是：

```text
凹凸贴图：主要改变法线
视差贴图：还会改变纹理采样位置（UV）
```

视差贴图的立体感更强，但仍然没有改变真实几何体，因此在轮廓边缘和极端掠射角度下会暴露限制。
