# 超越多边形

## 章节内容

本章讨论如何用图像、粒子、点和体素等表示替代或补充三角形网格。三角形适合从任意角度表示物体，但当物体距离较远、屏幕占比很小，或者对象本身是云、烟、毛发、植被和点云时，继续使用完整几何体往往会浪费大量顶点处理和光栅化开销。图像化表示的成本更多取决于最终覆盖的像素数量，因此可以在不同距离和用途下选择不同表示，并通过 LOD 在它们之间切换。

### 1. 渲染频谱与表示选择

渲染没有唯一正确的表示方式。一个物体可以从完整三角形模型，逐步简化为低模、广告牌云、单张 impostor、分层图像、粒子、点云，最后甚至只保留体素或其他图像数据。表示越靠近几何体，通常越容易支持任意视角、真实遮挡和光照；表示越靠近图像，通常越容易快速显示，但越依赖视角、分辨率和预处理。

LOD 不只是“减少三角形数量”，也可以是表示类型的切换：近处使用完整网格，中距离使用简化网格或广告牌云，远处使用单张或多视角 impostor。选择时要综合考虑屏幕尺寸、视角变化、物体是否运动、是否需要投影和接受阴影，以及切换时能否隐藏视觉跳变。

### 2. 固定视图、缓存与渐进细化

如果相机和场景中的大部分内容都不动，可以将静态内容预先渲染成颜色缓冲和 Z 缓冲。之后每帧先用这些缓存初始化画面，再只绘制动态对象；缓存的深度还能继续遮挡动态对象。若动态对象会影响静态场景，也可以只重新计算它影响到的局部区域。

固定视图还允许把物体 ID、法线、纹理坐标等附加信息保存下来。例如，三维绘图工具可以根据 ID 和 UV 将屏幕上的交互转换为对原始纹理的修改。

另一个相关概念是自适应细化或渐进细化：相机和场景静止后，系统持续生成更多样本，逐步改善抗锯齿、景深、阴影、光线追踪或路径追踪结果。它可以直接切换到更高质量的图像，也可以在多帧中逐渐混合。这里与延迟渲染都使用了“先保存中间结果、后继续计算”的思想，但固定视图方法主要是把昂贵成本分摊到多帧，而延迟渲染主要是加速同一帧中的光照计算。

### 3. 天空盒

环境贴图不仅可以用于反射，也可以直接表示远处的环境。将一个足够大的盒子或其他网格放在场景外围，并把环境贴图映射到其表面，就得到天空盒。由于远处物体的视差很小，天空盒通常跟随相机平移，只保留相机的旋转，从而避免观察者移动时暴露出环境图像的平移误差。

立方体贴图是常见实现，因为六个面的纹素密度比较均匀；也可以使用全景图或穹顶。所需分辨率与视场角和屏幕分辨率有关：视场角越小，同样的屏幕范围对应立方体贴图上越小的区域，因此需要更高的贴图分辨率。

天空盒本身位于其他物体之后，一般不需要写入 Z 缓冲。常见顺序是先绘制不透明物体，再绘制天空盒，最后绘制透明物体。这样天空盒可以利用已经写入的深度跳过被不透明物体覆盖的像素，减少像素着色器工作量。

### 4. 光场渲染

光场或 Lumigraph 通过在多个观察位置、观察方向，甚至不同时间和光照条件下采集 radiance，记录物体的图像表示。渲染新视角时，可以在邻近的已采样视图之间插值。

它的优点是可以捕获几何形状、材质和光照都很复杂的真实物体，并以接近恒定的显示成本生成新视图；缺点是需要存储大量视图，并且视角范围、遮挡变化和动态内容会使插值困难。光场在交互式通用渲染中的应用有限，但在计算摄影、VR 和支持正确视觉聚焦的显示研究中仍有价值。

### 5. Sprite 与分层图像

Sprite 是直接显示或映射到始终面向观察者的四边形上的图像。Alpha 可以表示完全透明、半透明和抗锯齿边缘，Sprite 也可以通过播放一系列纹理帧形成动画，并携带深度或其他附加信息。

复杂场景可以拆成多个带深度的 Sprite 图层。例如，前景物体、角色、车辆和背景分别处于不同层。按照从后往前的画家算法绘制时，可以不使用 Z 缓冲完成遮挡合成。相机前后移动时，可以根据每层深度调整其缩放和位置；相机横向或纵向移动时，也可以根据深度产生视差。

也可以用多张不同视角的 Sprite 表示一个小物体，视角改变时切换或变形图像。该方案适合屏幕占比小的对象，但视角变化过大时会出现新的表面无法显示、图像变形和遮挡错误。

### 6. 广告牌与 Impostor

广告牌是根据观察方向旋转纹理矩形的技术，常用于草、烟、火、雾、爆炸、云、能量盾和远处植被。广告牌通常由表面法线 (n) 和 up 向量 (u) 定向：先计算 (r = normalize(u \times n))，再用叉乘重新求得与其正交的向量，组成正交基。实际实现还要处理两个向量平行或几乎平行时的退化情况。

常见类型包括：

#### 屏幕对齐广告牌

四边形始终平行于屏幕，法线指向相机，up 方向采用相机的 up。它等价于常见的二维 Sprite，适合粒子、HUD 和近似对称的物体，但从上方或侧面观察时容易暴露其平面性质。

#### 面向世界广告牌

广告牌尽量朝向相机，同时尝试让 up 方向与世界 up 对齐。它适合烟雾、云和一般粒子，因为物体会面对观察者，但不会随着相机俯仰完全躺倒。

#### 轴向广告牌

固定一个世界空间轴，只允许广告牌绕该轴旋转并尽可能朝向相机。远处树木通常固定世界 up 轴，使其始终直立；激光束等具有圆柱对称性的对象也适合这种表示。缺点是从树木上方俯视时，树会像一张被切出来的纸片，可以加入水平横截面、十字树或在更近距离切换到真实网格。

#### Impostor

Impostor 是把复杂物体从某个视点预渲染成带 Alpha 的图像，再映射到广告牌上。它可以把大量三角形压缩成一次简单的图像绘制，适合远处物体、重复实例和静止角色。图像还可以额外保存深度、法线、材质 ID 等数据，以改善光照、遮挡和与场景的融合。

Impostor 的问题是没有真实厚度，视角改变或物体运动时容易出现拉伸、穿插和 pop。常见策略是根据视角变化、物体运动距离或屏幕占比决定是否更新；物体移动时使用真实几何，静止后切换到 impostor。也可以将四肢、躯干等拆成多个 impostor，形成介于单张图像和完整网格之间的 polypostor。

#### 广告牌云

广告牌云用一组互相交叉的镂空四边形表示复杂模型，例如用少量广告牌近似数万个三角形的树。它可以附加法线贴图、位移贴图和不同材质，通常比单张 impostor 更能适应视角变化，但会产生较多 overdraw，交叉半透明广告牌也难以严格排序。若过度绘制成本高于几何处理成本，就应改用简化网格或专门的植被表示。

#### 软粒子与体积广告牌

烟尘广告牌与实体几何相交时，会出现明显的矩形边缘或条带。软粒子可以采样场景深度：当广告牌片元接近底层实体深度时，逐渐降低 Alpha，而不是写入自己的深度，从而让交界处柔和。靠近近裁剪面或穿过广告牌时，还可以对 Alpha 做距离淡出以避免突然消失。

更复杂的球形或盒形体积广告牌不把自己当作薄平面，而是让像素着色器估算视线穿过体积的入口、出口和传播距离，再据此计算透明度。这种方法更接近真正的体积，但像素计算成本更高。

### 7. 深度 Sprite、分层深度与浮雕映射

在 impostor 图像中加入深度偏差，就得到深度 Sprite 或 nailboard。纹理除了 RGB 外还保存一个观察空间高度场，像素着色器据此修改片元深度，使图像与附近几何体的遮挡关系更合理，尤其能改善广告牌穿入墙体或地面的情况。

单个像素只有一个深度时，视点变化会使原本被遮挡的区域暴露出来，产生空洞。分层深度图像为同一像素保存多个深度，能够在扭曲和视角变化时提供更多后方表面。浮雕纹理映射则把高度场放在世界空间四边形上，通过沿视线步进高度场来寻找可见表面；浮雕 impostor 可以在盒子的各个面上保存颜色、法线和高度，并支持刚性整体动画。

这些方法都不是把真实网格恢复出来，而是用一个简单几何体触发像素着色器，再在着色器中用深度或高度数据近似表面。它们可以提高遮挡和轮廓质量，但仍存在有限视角、去遮挡信息不足、步进成本和边缘误差等问题。

### 8. 粒子系统

粒子用大量轻量元素表示火花、烟、火焰、雨、雪、尘埃、云、液滴和其他难以直接建模的现象。一个粒子通常包含位置、大小、朝向、颜色、生命周期、速度、纹理帧和其他自定义属性，可以渲染为屏幕对齐广告牌、轴向广告牌、带状粒子或小型网格。

粒子着色除了普通纹理和 Alpha 混合，还要处理动画序列、软粒子、深度测试、边缘淡出、颜色和尺寸随生命周期变化，以及大量半透明粒子的排序和 overdraw。粒子自阴影比较困难，因为普通不透明阴影贴图只记录一个深度，不能表示沿光线方向的累积透光率。原书列举了傅里叶不透明度映射、深度阴影、透光率函数映射和消光体素等方法，用来近似粒子和体积之间的阴影及自阴影。

粒子模拟可以在 CPU 或 GPU 上执行。GPU 可以通过计算着色器、UAV、流式输出或间接绘制更新粒子的位置、生命周期、创建和销毁，并进行一定的碰撞检测；这样可以支持大量粒子，但复杂排序、稀疏创建、跨系统交互和调试会更困难。粒子并不等于简单的序列帧，序列帧只是粒子外观的一种来源，粒子的运动和交互仍可以由实时模拟系统控制。

### 9. 点渲染与点云

点渲染用大量点而不是连续三角网格表示表面，特别适合激光扫描、摄影测量、RGB-D 设备和超大点云。点可以被渲染为带半径的 splat、方形广告牌、圆形或模糊圆形；通过过滤和填补相邻点之间的空隙，使离散点看起来像连续表面。

QSplat 使用包围球层次结构组织点云：遍历可以在任意层级停止，节点被渲染为代表该区域的 splat，因此可以根据屏幕占比和可用时间渐进提高质量。Surfel 是带法线的表面元素，通常还包含位置、半径和过滤后的纹理信息。分层点云则让父节点和子节点各自保存不同密度的点，避免为层次结构重复生成平均点，更适合 GPU 批量加载和渲染。

点云数据可能达到数十亿甚至更多，几乎必须使用四叉树、八叉树或其他层次结构进行流式加载和 LOD。它的主要困难是点之间存在空隙、半透明 splat 排序成本高，以及没有法线时难以进行可靠光照。可用深度缓冲加屏幕空间 AO，或用 EDL 检查相邻像素的深度差来增强表面轮廓。若点中已经包含颜色或强度，显示结果实际上已经带有采集时的光照，视角变化时不会像真实材质那样重新响应。

### 10. 体素：数据与应用

Voxel 是三维网格中的体积元素。它与像素和纹素对应，但不再表示二维图像位置，而表示规则三维网格中的一个体积。体素可以只保存一个 bit 来表示内外，也可以保存密度、不透明度、颜色、法线、符号距离、材质、流量或其他属性。

体素适合表达表面以外的体积和内部结构，可用于烟雾、云、流体、侵蚀、体积测量、碰撞、雕刻、科学和医疗可视化、3D 打印、地形、全局光照和阴影。它的代价是分辨率为 (N^3) 时数据量按三维立方增长，因此实际系统通常利用空体素很多、邻域值相似等特点做稀疏存储。

最简单的存储方式是密集三维纹理或体素块。稀疏体素八叉树（SVO）利用八叉树跳过空区域，并合并相同或相似的子树，同时天然提供类似三维 Mipmap 的 LOD。VDB 或基于索引块的层次结构更适合稀疏数据、流式加载和动态变化；如果不同区域高度重复，还可以用有向无环图共享相同子树，进一步减少存储。

### 11. 体素生成

体素化就是把点云、三角网格或其他表示转换为体素占用和属性。常见方法包括：

- 从顶部、底部和四个侧面做六个正交视图，将深度结果组合起来判断内外。这种方法简单快速，但可能漏掉六个视角都看不到的细节，复杂模型上也可能误判。
- 将模型切片渲染，每次只处理一个或多个深度层。Slice map 可以把多个深度层编码到位图中，在较少的渲染 pass 内生成表面体素，但它主要识别边界，不一定能判断完全位于模型内部的体素。
- 使用计算着色器、图像读写和保守光栅化，直接标记与三角形重叠的所有体素，并累积颜色、法线等属性。这种方法更准确，也能直接构建稀疏结构。

保守体素化会把所有与三角形接触的体素都标记出来，以避免漏掉表面；6-separating 和 26-separating 等定义控制内部、外部体素之间允许共享面、边或顶点的关系。动态体素化是难点，因为每帧重新体素化成本很高。也可以根据相机深度和阴影贴图逐步清除、设置可见区域，但这会产生视角依赖：当前相机看不到的区域状态可能未知，适合有容错性的动态 GI 等次级效果。

### 12. 体素渲染

体素可以直接射线投射，沿光线寻找最近的占用体素或等值面；也可以先转换为多边形网格。对于不透明体素，相邻实体体素之间的内部面可以删除，再通过合并相邻面减少网格数量。

如果直接显示方块外壳，表面会呈现明显的块状结构。Marching Cubes 把相邻 (2 \times 2 \times 2) 个采样点的内外状态编码成 0–255 的索引，根据查表结果生成三角形，并可使用符号距离在边上插值得到更平滑的顶点。Level set 或 SDF 则直接表示到表面的距离，可以提取零等值面，也可以沿光线追踪等值面，并自然得到较好的表面和法线。

体素锥形追踪把体素层次结构视作类似 Mipmap 的预过滤数据：随着光线传播，锥体半径逐渐增大，采样更高层级、更大范围的体素。它用区域采样近似可见性，因此可以较快地计算软阴影、景深、抗锯齿、法线过滤和全局光照，但必然会引入分辨率、过滤、遮挡和漏光误差。体素通常更适合阴影、间接光等次级效果，因为人眼对这些效果中的小误差更宽容。

SVO 的缺点是射线追踪需要较多树遍历和中间节点访问。VDB、索引块和其他 GPU 友好的层次结构可以减少遍历开销，并支持两 pass 流式流程：第一 pass 找到可见块并加载数据，第二 pass 渲染当前驻留的块。体素表示还可以被多个光源共享，不必为每个光源都单独生成完整的几何阴影贴图。

### 13. 本章要点

“超越多边形”不是要完全抛弃三角形，而是根据屏幕占比、距离、视角变化、动态程度和效果需求，在几何、图像、广告牌、粒子、点云和体素之间选择合适的表示。真实项目通常采用混合方案：近处保留几何细节，远处换成图像或点，复杂体积用粒子或体素，次级光照再使用更粗糙的体素近似，并通过 LOD、淡出和交叉混合隐藏表示切换。
