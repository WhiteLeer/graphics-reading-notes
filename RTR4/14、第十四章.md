# 体积与半透明渲染

## 章节内容

本章把渲染对象从“表面”扩展到参与光线传播的体积。空气、雾、水、烟、云、皮肤、蜡和头发都可能发生吸收、发射和散射。实时渲染通常不能完整追踪所有光路，因此会在光线步进、阴影贴图、体素、LUT、屏幕空间滤波和预计算之间做近似。

### 1. 参与介质与光线散射

参与介质是充满粒子的体积，并且会影响穿过其中的光线。介质可以是均匀的，例如空气和清水；也可以是不均匀的，例如云、烟和蒸汽。即使看起来像实体表面的物体，也可以从高密度参与介质的角度理解：所有材质都在不同程度上发生散射。

沿光线传播时，主要有四类事件：

- **吸收**：光子被介质吸收，能量转化为热或其他形式。
- **外散射**：光子被粒子偏转到当前光路之外。
- **发射**：高温介质，例如火焰，向外发射光线。
- **内散射**：其他方向来的光子被偏转到当前光路中。

吸收系数记为 `sigma_a`，散射系数记为 `sigma_s`，消光系数为：

`sigma_t = sigma_a + sigma_s`

散射相对于吸收的比例可以用反照率近似表示：

`rho = sigma_s / (sigma_a + sigma_s)`

反照率接近 0 时，大部分光被吸收，介质容易显得浑浊、暗；接近 1 时，大部分光被散射，介质更容易显得明亮，例如空气和云。实际这些参数通常是 RGB 向量，因为不同波长的光可能具有不同的吸收和散射概率。

### 2. 透光率与 Beer–Lambert 定律

透光率表示一段路径中仍能通过的光线比例。对于均匀介质：

`T = exp(-sigma_t * d)`

其中 `d` 是传播距离；对于不均匀介质，则需要沿路径积分消光系数：

`T = exp(-integral(sigma_t(x) dx))`

距离越长、密度越大，透光率越低。这个衰减需要同时应用在：

1. 不透明表面到相机之间的表面辐射；
2. 体积内部散射到相机的路径；
3. 光源到散射点之间的路径。

第三项就是体积阴影的重要来源：即使光源到体积采样点之间没有不透明物体，沿途的雾、烟或粒子也会吸收和散射光线，使体积产生自阴影或向其他物体投射阴影。

### 3. 单次散射、光线步进与相位函数

实时体渲染通常先沿相机主光线进行采样，再在每个采样点上估计光源到该点的散射贡献。光线步进就是将一段连续路径离散为若干采样点，在每个点上计算密度、透光率、光照和散射，然后进行累积。

如果同时对每个采样点到每个光源的路径进行步进，计算量会随主光线采样数和光源数快速增长。因此实际系统会使用阴影贴图、体积纹理、低分辨率缓冲、预计算透光率或时域重投影来降低成本。

相位函数描述光线在介质中向不同方向散射的概率分布，并且应在单位球面上积分为 1，以保持能量守恒。常见类型包括：

- **各向同性散射**：所有方向的散射概率相同，简单但不够真实。
- **瑞利散射**：粒子远小于波长，短波长的蓝光比红光更容易被散射，是天空呈蓝色、日落偏红的重要原因。
- **米氏散射**：粒子大小与波长相近，常出现明显的前向散射和光源周围的光晕，适合雾、尘埃和云。
- **几何散射**：粒子远大于波长，需要考虑粒子内部的反射和折射，彩虹等现象与此类复杂散射有关。

Henyey–Greenstein（HG）相位函数用参数 `g` 控制方向性：`g < 0` 偏后向散射，`g = 0` 近似各向同性，`g > 0` 偏前向散射。Schlick 相位函数用更便宜的近似替代 HG，适合实时计算。多个 HG 或 Schlick 函数还可以混合，同时表达前向和后向散射波瓣。

### 4. 大尺度雾、局部雾与体积光

最简单的深度雾根据相机到表面的距离估计透光率，再将雾颜色与场景颜色混合。它虽然不是完整的体积积分，但可以提供真实感、深度暗示和大气遮挡；当远处物体已经完全被雾遮住时，还可以跳过这些物体的渲染。

高度雾会根据世界空间高度改变密度，例如山谷底部浓、山顶稀。深度雾和高度雾可以分别计算后组合。局部雾则使用球体、椭球体、盒体或任意网格限定影响范围，并根据观察射线与体积的入口、出口距离计算覆盖长度。原书还介绍了使用两个通道保存最近入口和最远出口的单 pass 方法，以便之后恢复射线在体积内部的长度。

体积光或光束可以用多种近似实现：

- 将相机对齐的透明切片从后往前叠加；
- 将光源影响体积渲染到低分辨率缓冲，再进行光线步进；
- 对均匀介质使用单次散射的解析积分，避免大量切片；
- 用屏幕空间泛光近似短距离、无明显遮挡的散射；
- 使用光源阴影贴图判断不透明遮挡，再结合体积透光率计算体积阴影。

切片方法简单直观，但透明切片会带来 overdraw 和带宽开销；解析方法速度快，却通常不能正确处理非均匀介质和复杂阴影。低分辨率光束常使用随机步进、蓝噪声、双边模糊和双边上采样来减少条带与边缘泄漏。

### 5. 通用体渲染与 Froxel

医学 CT、MRI、科学可视化和流体数据通常把标量场存储为三维体素。最基本的体渲染方式是将体积切成一系列与观察平面平行的切片，并从后往前进行透明合成。

体素的密度可以通过传输函数映射为颜色和 Alpha。仅使用一维“密度到颜色”的传输函数时，难以区分密度相近但材质不同的组织；二维传输函数还可以使用密度梯度长度作为索引，从而突出组织边界和材质转变。

半角切片将切片方向设置在观察方向和光源方向之间，可以在累积观察辐射的同时保留光源方向的遮挡信息，用于近似体积阴影和前向多次散射，但每个切片都要光栅化，带宽成本很高。

游戏中的动态体积常映射到相机视锥体，形成 froxel（frustum voxel）。它是相机视锥体空间中的三维低分辨率网格，通常保存每个体素的散射、吸收、相位函数参数、发射量和光照信息。这个结构相当于体积材质的三维 G-Buffer：先把雾、粒子和其他介质体素化，再在体积网格中累积光源和阴影，最后沿相机射线合成。

为了让粒子、雾和其他参与介质共享体积阴影，可以围绕相机建立级联消光体积（extinction volume）。不透明物体的阴影贴图提供光源方向的遮挡，消光体积则提供介质沿光线的透光率，因此它们可以统一处理体积自阴影、粒子互相投影的阴影，以及投射到不透明和透明物体上的体积阴影。

### 6. 大气散射与天空

大气的主要组成包括高空稀薄分子造成的瑞利散射，以及地面附近较大粒子造成的米氏散射。前者决定天空的蓝色和空气透视，后者决定太阳周围的光晕、雾霾和银边。

实时大气渲染常采用两类方案。分析模型使用太阳高度、浑浊度和地面反照率等少量参数，快速拟合天空辐射；物理参数化模型则把视点高度、观察方向、太阳方向和大气边界等参数映射到 LUT 中，预计算透光率和不同阶次的散射，再在运行时采样。

Bruneton–Neyret 一类方法会使用多维 LUT 记录透光率和多次散射；为了降低存储和更新成本，也可以减少参数维度，使用较小的三维 LUT，代价是忽略部分效果，例如行星本身对大气的阴影。LUT 更新和多次散射计算还可以分摊到多帧，并用上一帧结果重投影和 EMA 混合。

### 7. 云

云是高散射、复杂相位函数的参与介质。原书介绍了三种主要表示：

1. **粒子或 impostor 云**：把云表示为带视角信息的体积粒子或四边形，渲染成本低，但旋转视角时容易暴露离散化和层状瑕疵。
2. **网格加超纹理**：网格定义云的整体轮廓，超纹理在边缘和内部增加高频体积细节，可以对边缘进行精细光线步进，对内部采用均匀近似。
3. **程序化参与介质**：用基础噪声定义云的大尺度形状，再用另一层噪声腐蚀和补充细节。Perlin–Worley 等混合噪声适合生成积云等形状，再沿观察光线步进计算密度、透光率和散射。

云的多重散射非常重要。只计算单次散射时，厚云内部容易变黑，无法表现真实云层的明亮和白色。实时系统通常用若干散射阶次的近似、预计算传输函数或艺术家可控的多重散射项来补足内部光照，同时约束权重以避免能量凭空增加。

为了控制成本，云经常使用低分辨率光线步进、每帧只更新部分像素、随机步进、前一帧重投影和 EMA。云还必须与大气散射保持一致：云会遮挡太阳和天空，对云下的空气透视和太阳散射也有影响，否则云层和天空会显得割裂。

### 8. 半透明表面、覆盖率与透射率

本章区分了几个容易混淆的概念：

- **透光率（transmittance）**：光谱能量穿过材质后的比例；
- **透明（transparent）**：允许光线通过，但内部散射不明显，通常主要表现为折射和透射；
- **半透明（translucent）**：允许光线通过，并在内部发生明显散射，使入射点和出射点不再简单对应；
- **不透明（opaque）**：光线基本无法穿过。

覆盖率适合描述织物、纤维或镂空贴图：它表示当前像素有多少比例被表面覆盖。玻璃、水和有颜色的介质则更适合使用 RGB 透光率。半透明表面的输出可以理解为表面反射与背景经过透光率过滤后的组合：

`C_out = C_surface + T * C_background`

如果同时存在几何覆盖率和体积透射，还需要使用同时考虑两者的混合公式；现代 API 可以用双源颜色混合分别提供表面贡献和透光率。对于厚度为 `d` 的均匀材质，可以用 `T = exp(-sigma_t * d)` 求透光率，也可以根据目标透光率反推消光系数 `sigma_t = -log(T) / d`。

玻璃和水还需要折射。实时方法经常忽略进入材质时的完整折射路径，只计算离开表面时的折射方向或用深度贴图估计入射位置，这是因为从折射采样点反向找到对应入口点很困难。更精确的方法需要在材质内部步进或进行光线追踪。

### 9. 焦散

焦散是反射或折射后的光线在空间中聚集或稀疏，形成局部明暗图案。水面把太阳光折射到水底形成的光斑是折射焦散，玻璃或水晶把光线聚集到附近表面也可以形成焦散。它不是色散：焦散描述能量的空间分布，色散描述不同波长因折射率不同而发生颜色分离，二者可以同时出现。

严格的焦散需要追踪光线或记录光子在接收表面上的聚集位置，成本较高。实时近似包括：

- 预烘焙或离线生成动态焦散纹理，并叠加到水底或受影响表面；
- 根据水面法线和折射方向，将水面状态投影到水底的 radiance 贡献；
- 从光源视角保存折射后的位置和方向，再沿折射方向光栅化线段并累积，最后用模糊掩盖采样不足；
- 使用分层深度和光子 splat，把折射后的光子以带衰减的四边形投射回场景。

这些方法通常把焦散作为附加光照项，而不是让所有接收物体重新完整求解水面和光线传播。

### 10. 次表面散射 SSS

SSS 发生在皮肤、蜡、牛奶等高散射固体中。光线进入表面后，在内部经历一次或多次散射，再从附近位置重新出射。由于入射点和出射点不同，影响范围可能跨越多个像素，因此普通 BRDF 不能完整描述它；BSSRDF 是将 BRDF 推广到这种空间非局部散射的模型。

实时 SSS 的常见近似包括：

#### 环绕光照

将光照范围从表面法线的一侧扩展到背面，并加入颜色偏移，模拟光线从附近位置泄漏而来的效果。它成本低、容易控制，但物理准确性有限。

#### 法线模糊与曲率 LUT

多次散射可以近似为扩散过程，因此漫反射辐照度会产生空间模糊，而镜面反射仍保留表面细节。常见做法是镜面使用细节法线，漫反射使用平滑法线。也可以根据散射率、透光率和曲率预积分到二维 LUT 中，以较低成本估计局部散射。

#### 纹理空间扩散

在纹理空间中对光照进行多尺度扩散，再映射回模型。多个不同半径的模糊结果可以按 RGB 权重组合，得到更接近真实散射剖面的效果。它质量较高，但需要额外纹理空间渲染和多个模糊 pass；更少样本的滤波核可以降低成本，但会损失细节和真实感。

#### 屏幕空间扩散

先把需要扩散的 irradiance 保存到屏幕缓冲，再进行水平和垂直的双边模糊。双边过滤会参考线性深度和法线，避免把光线泄漏到不相连或朝向差异很大的表面。实际应只模糊 irradiance，不应把 albedo 和镜面高光一起模糊；最终将模糊后的 irradiance 与 albedo 相乘，再叠加镜面项。

屏幕空间方案可以在一次后处理中处理多个角色，但它只能看到当前屏幕上的信息，背面、遮挡区域和屏幕外的散射无法正确处理。可使用模板测试限制 SSS 区域，并通过时域重投影降低随机采样噪声。背光 SSS 还可以使用反向法线采样，并用阴影贴图和厚度信息限制背面贡献。

### 11. 头发与皮毛

头发和皮毛可以视为沿曲线分布的大量细长体积。单根纤维通常包含角质层、皮质层和髓质：角质层形成表面反射，皮质层中的色素决定颜色，髓质在人类头发中通常可以忽略，但在动物皮毛中可能很重要。

经典毛发 BSDF 会区分几条主要光路：表面反射产生偏向毛根的无色高光；光线进入纤维、穿过并从另一侧离开，产生带有吸收颜色的透射高光；光线进入纤维后在内部反射，再离开，形成另一组有色的次级高光。毛发横截面通常不是完美圆形，因此高光会产生偏心和闪烁，这种变化对真实感很重要。更复杂的模型会加入多重散射，并用能量守恒的参数化粗糙度和颜色供艺术家控制。

实际几何可以是曲线、带状四边形或由少量引导毛发实例化出的大量毛发。Alpha 混合需要排序，静态短发可以使用预排序索引；动态、交错的长发则可使用 Alpha Test、MSAA 或顺序无关透明技术。毛发阴影可以从现有阴影贴图估算，但仅使用第一个遮挡深度会让毛发团块阴影过于平滑，更好的方案是深度阴影、体积阴影或对透明度累积进行更丰富的表示。

皮毛还可以通过多层 shell、轮廓 fin、几何着色器挤出折线毛发，或使用体积纹理近似。Shell 方法成本低，但轮廓处容易断裂，因此通常需要 fin 或真实几何补足轮廓。

### 12. 统一方法

本章最后的方向是把表面、体积、粒子、毛发和半透明材质放到统一的散射框架中理解。它们的差别主要在于：散射发生在哪里、介质是否连续、是否需要方向性和空间非局部信息，以及数据是以表面参数、体素还是微结构表示。

统一表示可以让相同的光照、阴影和透光率数据服务于多种材质，但代价是更高的存储、采样和积分成本。工程上通常仍会根据平台和效果选择不同精度的近似：直接可见的表面要求更高精度，阴影、间接光和体积内部细节则可以接受较粗糙的体素、LUT 和时域近似。

## 讨论与补充

### 透明、半透明与不透明

- 透明材质主要考虑折射和透光，例如清玻璃和水。
- 半透明材质主要考虑内部散射，例如皮肤、蜡、牛奶和磨砂玻璃。
- 因此半透明不是简单的“透明度较低”，而是光线进入材质后在内部传播，并从附近位置重新出射。

### 焦散与色散

焦散主要指水面折射后在水底形成的光斑，也可以泛指反射或折射导致的光线聚集。色散则是不同波长发生不同程度的折射，产生颜色分离。普通水面焦散不一定有色散，水晶可以同时产生彩色焦散。

### SSS 的工程实现

不使用光线追踪时，SSS 通常用环绕光照、厚度图、散射贴图、LUT、法线模糊、纹理空间扩散或屏幕空间双边模糊近似。它们不是对整张画面无条件模糊，而是会根据深度、法线、材质遮罩、厚度和散射半径限制扩散范围；镜面项一般不参与模糊。
