# 变换

## 核心理解

### 1. 变换矩阵的组合顺序

在列向量约定下，如果模型变换为：

```text
M = T × R × S
```

则：

```text
P1 = M × P0
   = T × R × S × P0
```

实际作用顺序是从右到左：

```text
temp0 = S × P0
temp1 = R × temp0
temp2 = T × temp1
P1    = temp2
```

因此这里是先缩放，再旋转，最后平移。

矩阵乘法不满足交换律，所以：

```text
T × R ≠ R × T
```

变换顺序不同，最终结果也不同。

### 2. 刚体变换

刚体变换只包含平移和旋转，不包含缩放：

```text
M = T × R
```

刚体变换不会改变物体的长度、角度和形状。

### 3. 为什么法线不能直接使用模型矩阵

模型矩阵可以写成：

```text
M = [ A  t ]
    [ 0  1 ]
```

其中：

- `M` 是 `4×4` 矩阵；
- `A` 是左上角的 `3×3` 矩阵，包含旋转、缩放和剪切；
- `t` 是平移部分。

法线是方向，不是位置，因此不需要平移。使用 `A` 可以忽略平移部分。

但如果存在非均匀缩放，不能简单使用：

```text
N' = A × N
```

因为这样可能导致变换后的法线不再垂直于变换后的表面。

### 4. 法线的逆转置变换

设原来的法线和切线满足：

```text
N · T = 0
```

切线是表面上真实存在的方向，因此直接变换：

```text
T' = A × T
```

我们需要让变换后的法线继续满足：

```text
N' · T' = 0
```

由此可以得到：

```text
N' = (A⁻¹)ᵀ × N
```

Shader 中通常写成：

```hlsl
float3x3 normalMatrix = transpose(inverse((float3x3)M));
float3 worldNormal = normalize(mul(normalMatrix, normal));
```

这里的关键不是“法线和切线都是顶点数据”，而是二者的几何语义不同：

```text
切线：表面上的方向，跟随表面直接变换
法线：描述垂直关系的约束，需要使用逆转置保持垂直
```

### 5. 也可以变换切线后重新计算法线

如果有两条独立的表面切线 `T1` 和 `T2`，也可以：

```text
T1' = A × T1
T2' = A × T2
N'  = normalize(cross(T1', T2'))
```

这种结果与使用逆转置变换法线在理想情况下是等价的。逆转置方法更常用，是因为模型通常已经保存了顶点法线，不需要每帧根据三角形重新计算。

需要注意，只有一条切线不足以唯一确定一个表面法线，通常需要两条独立切线或完整的切线空间。

如果 `A` 只有旋转，或者是旋转加均匀缩放，直接使用 `A × N` 通常也可以；非均匀缩放和剪切则需要逆转置。

### 6. 欧拉角

欧拉角可以用多个轴的旋转来表示物体朝向，但有几个问题：

- 旋转轴的顺序会影响结果；
- 插值时旋转速度可能不均匀；
- 可能出现万向节锁问题。

因此骨骼动画、相机动画等场景经常使用四元数来表示和插值旋转。

### 7. 透视除法与深度精度

透视投影后，顶点会带有与深度相关的 `w` 分量。进行透视除法时：

```text
z_ndc = z_clip / w_clip
```

由于 `w_clip` 通常与观察空间深度 `d` 相关，最终深度大致具有这样的形式：

```text
z_ndc = A + B / d
```

因此深度不是在线性距离上均匀分布的：

```text
近处：距离变化一点，深度值变化明显
远处：距离变化很大，深度值变化很小
```

远处不同表面可能被映射到非常接近的深度值，有限精度的 Z-Buffer 无法区分它们，就可能出现：

- Z-Fighting；
- 表面抖动；
- 深度排序不稳定。

常见解决方式包括：

- 合理设置 Near 和 Far，尤其不要把 Near 设置得过小；
- 提高深度缓冲精度；
- 使用 Reversed-Z；
- 避免让两个几何表面过于接近。

## 本章总结

```text
模型变换：M = T × R × S，实际从右到左执行
刚体变换：只包含平移和旋转
切线变换：T' = A × T
法线变换：N' = (A⁻¹)ᵀ × N
透视除法：产生非线性的深度分布
```
