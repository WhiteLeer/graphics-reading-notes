# 图像空间特效

## 章节内容

本章讨论在场景几何已经渲染完成后，如何把颜色、深度、法线、速度等缓冲作为图像输入，使用 GPU 进行后处理和重建。图像空间方法的优势是与屏幕像素数量相关，能够高效实现模糊、降噪、景深、运动模糊、泛光和镜头光晕；缺点是只能使用当前帧或保存下来的有限信息，容易受到屏幕边界、遮挡和缺失数据的影响。

### 1. 全屏后处理

后处理通常先把场景渲染到离屏颜色缓冲、深度缓冲和其他 G-buffer，再把这些缓冲作为纹理输入，通过一个覆盖全屏的几何体执行像素着色器。

常见实现是全屏四边形或覆盖屏幕的单个大三角形：

- 每个屏幕像素运行一次后处理着色器。
- 着色器根据 UV 读取颜色、深度、法线、速度或其他缓冲。
- 结果写入另一个渲染目标。
- 多个后处理之间使用 ping-pong 缓冲交替读写。

覆盖屏幕的大三角形可以避免四边形两个三角形在边界处的重复处理，并可能改善缓存一致性。对于较复杂或较大范围的图像处理，也可以使用计算着色器，让线程组共享邻域数据、使用 UAV，并减少重复纹理读取。

后处理 Pass 的数量、输入输出分辨率和缓冲格式都会影响带宽。很多效果会在半分辨率或更低分辨率上计算，再上采样到全分辨率；这对泛光、粒子、雾和大范围模糊通常很有效，但会损失细节。

### 2. 图像滤波和模糊

图像滤波会读取当前像素周围的邻域样本，用滤波核对样本加权求和。滤波核可以用于：

- 模糊和平滑。
- 边缘检测和锐化。
- 降噪。
- 重建抗锯齿后的图像。
- 生成泛光、景深和运动模糊。

高斯滤波器是常见的模糊核。二维高斯核可以分解为水平和垂直两个一维核，因此一次二维滤波所需的样本数可以从 d² 降到约 2d，其中 d 是核的直径。这种可分离滤波是实时模糊的基础。

其他常见优化包括：

- 使用硬件双线性插值，一次采样近似合并多个相邻纹素。
- 先下采样，在低分辨率图像上执行更大范围的模糊，再上采样。
- 使用 Mipmap 或多级缩小图像快速获取不同尺度的模糊。
- 在计算着色器的共享内存中复用线程组邻域数据。
- 对水平和垂直滤波使用移动平均，降低大半径滤波的开销。

滤波时必须处理屏幕边界。最简单的方式是采样器 clamp 到边缘，也可以额外扩大输入图像，避免边缘像素采样到不存在的数据。

### 3. 双边滤波和边缘保持

普通高斯模糊只考虑空间距离，可能把不同物体、不同深度或不同材质的颜色混在一起。双边滤波还会根据样本与中心像素的相似程度调整权重：

- 颜色差异大，降低权重。
- 深度差异大，降低权重。
- 法线差异大，降低权重。
- 物体 ID、速度或其他属性不一致，降低权重。

使用额外引导数据的双边滤波也叫联合双边滤波或交叉双边滤波。它常用于：

- SSAO 降噪。
- 低分辨率光照上采样。
- 阴影软化。
- 光线追踪结果降噪。
- 保持几何边缘的后处理。

双边滤波通常不可分离，因为每个邻域样本是否参与取决于中心像素和样本本身的值。因此它比普通高斯滤波更昂贵，也不容易直接使用双线性采样合并多个纹素。工程上常使用近似的可分离双边滤波、深度引导上采样和时域累积来降低成本。

### 4. 重投影和时域复用

重投影是把上一帧或其他视角已经计算出的结果，重新映射到当前帧。基本流程是：

1. 取得当前像素的深度或世界空间位置。
2. 使用当前帧和上一帧的相机矩阵，将该位置投影到上一帧屏幕。
3. 根据得到的上一帧 UV 读取历史颜色、光照或其他结果。
4. 与当前帧结果进行混合，并根据可信度限制历史贡献。

重投影可以复用昂贵的光照、阴影、反射、抗锯齿和降噪结果，减少每帧所需的样本数。它也是时间抗锯齿、时空降噪和低帧率重建的重要基础。

重投影并不总是可靠：

- 相机或物体移动后，历史像素可能已经不对应当前表面。
- 新暴露区域在上一帧没有数据，称为 disocclusion 或空洞。
- 动态物体需要物体运动矢量，而不仅是相机矩阵。
- 透明、粒子和屏幕空间效果通常缺少稳定的历史对应关系。
- 错误历史会产生拖影、鬼影和滞后。

因此需要使用深度、法线、速度、材质 ID、邻域一致性和历史长度等信息进行历史拒绝与权重控制。

### 5. 镜头光晕和泛光

镜头光晕和泛光是把强亮区域扩散到周围像素的图像空间效果。

典型泛光流程是：

1. 从 HDR 场景颜色中提取超过阈值的高亮区域。
2. 对高亮图像进行下采样。
3. 在多个分辨率上进行模糊或卷积。
4. 将不同尺度的结果混合回场景颜色。
5. 在色调映射前或合适的场景参考阶段进行合成。

多级下采样可以用较低成本产生大范围光晕。阈值和柔和阈值决定哪些亮度参与泛光；如果在已经经过 SDR 裁剪的图像上提取，就会丢失 HDR 高光信息。

镜头光晕还可以使用一系列更具体的光学近似：

- 由镜片内部反射产生的多个 ghost 形状。
- 与镜头光圈形状有关的光斑。
- 横向或纵向 streak。
- 镜头污渍、灰尘和光圈纹理。
- 色散和色彩偏移。
- 由亮点位置生成的屏幕空间光斑。

这些效果通常不是严格模拟真实镜片，而是用纹理、缩放、翻转、模糊和加法混合得到具有摄影感的结果。

### 6. 景深

真实相机的有限光圈会让不在焦平面上的物体形成弥散圆。实时景深首先根据深度和焦距、光圈等参数计算每个像素的 CoC（Circle of Confusion，弥散圆）大小：

- CoC 接近 0，表示像素位于焦平面附近，应保持清晰。
- CoC 较大，表示像素处于前景或背景失焦区域，应进行更强模糊。
- CoC 的正负可以区分焦平面前方和后方的失焦区域。

景深的理想定义是对一组不同焦点或镜头采样结果进行平均。实时实现通常使用屏幕空间的 gather 或 scatter 近似：

- gather：当前像素根据自身 CoC 从邻域采样。
- scatter：每个清晰像素根据自己的 CoC 向周围贡献，但需要处理重叠和排序。
- 分层模糊：按 CoC 大小划分多个范围，分别处理前景和背景。
- 半分辨率和多级 Mipmap：降低大范围散焦的成本。

景深的主要困难是遮挡和缺失信息。一个前景物体失焦时，它应该覆盖背景；一个背景物体失焦时，不能错误地把模糊颜色溢出到前景清晰物体上。单张相机图像没有被遮挡表面的完整信息，因此常见瑕疵包括边缘泄漏、前景光晕、背景穿透和模糊区域断裂。

高质量景深还会考虑真实光圈形状，使弥散圆呈现圆形、多边形或其他 bokeh 形状。圆盘滤波通常不可分离，样本量和带宽成本较高。

### 7. 运动模糊

运动模糊是相机快门打开期间，不同时刻的图像在传感器上累积的结果。它可以来自：

- 相机旋转。
- 相机平移。
- 物体平移。
- 物体旋转或形变。

最直接的方法是在快门时间内渲染多帧并平均，但实时成本很高。更常见的方法是使用速度缓冲区。

速度缓冲区通常在顶点阶段同时计算当前帧和上一帧的位置：

1. 使用当前模型矩阵和当前相机矩阵得到当前屏幕位置。
2. 使用上一帧模型矩阵和上一帧相机矩阵得到上一帧屏幕位置。
3. 两者相减得到屏幕空间速度。
4. 在三角形内部插值到片元。

后处理阶段沿速度方向采样颜色，采样长度由速度和快门时间决定。为了让快速移动物体的影响扩展到邻近像素，常见系统会：

- 先按 tile 计算最大速度。
- 再在更大的邻域内传播或查询最大速度。
- 最后沿主导速度方向采样和混合。

运动模糊必须处理遮挡关系。静态前景物体后面的快速物体不能把模糊错误地涂到前景上；快速物体内部、外部和边缘区域也可能缺少正确的背景颜色。深度比较、速度分层、抖动采样和邻域重建可以降低这些错误，但不能从单帧数据中完全恢复被遮挡的历史。

运动模糊可以根据艺术需求调整：

- 只模糊物体，不模糊相机旋转。
- 只在过场动画中启用。
- 对角色、武器或粒子使用独立强度。
- 用径向模糊强化速度感。
- 使用目标跟踪或眼动信息，让被关注物体保持清晰。

因此它既是摄影模拟，也是强烈的艺术控制工具。

### 8. 图像空间方法的共同限制

图像空间效果的输入通常只有当前颜色、深度、法线和少量历史数据，因此无法自动获得：

- 屏幕外物体。
- 被前景遮挡的表面。
- 完整的三维几何和材质信息。
- 透明物体背后的可靠历史。
- 所有时间采样和光线路径。

工程上通常通过多种方式弥补：

- 额外渲染深度、法线、速度、ID 或透明层。
- 使用历史帧和重投影。
- 使用双边滤波保持边缘。
- 使用邻域填充和 fallback。
- 将关键效果转移到更高分辨率或单独的几何 Pass。
- 用光线追踪、反射探针或预计算数据补充屏幕空间缺失内容。

图像空间方法的价值不在于物理完整，而在于能用固定且可预测的屏幕像素成本，近似大量复杂的摄影和光照现象。
