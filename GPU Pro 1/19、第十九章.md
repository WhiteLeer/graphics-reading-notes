# Real-Time Screen-Space Cloud Lighting（实时屏幕空间云层光照）

## 章节内容

作者：Kaori Kubota

本章介绍一种面向实时游戏场景的云层和天空光照近似方法。它不尝试严格求解云体中的多次散射，而是把云层密度渲染到屏幕空间纹理，再沿太阳方向进行模糊，用模糊后的密度近似光在云层中的传播和散射。

该方法适合玩家位于地面、从远处观察天空的场景。它重点追求经验上可信的云层外观，而不是物理精确的体积光照。

## 为什么云层光照昂贵

真实云层由大量粒子或体积密度组成。太阳光进入云层后会发生：

- 吸收；
- 前向散射；
- 多次间接散射；
- 云层内部遮挡；
- 从面向观察者的一侧重新出射。

如果沿光线和视线同时积分体积散射，通常需要大量步进和多次光照计算，难以在普通游戏帧预算内完成。

本章抓住一个视觉现象：靠近太阳方向的云往往更亮，因为太阳光在云层背部进入，并经过散射后从面向观察者的一侧出射。只要沿太阳方向对云密度做适当模糊，就能重现这一主要视觉线索。

## 三个主要 Pass

方法大致分为三个阶段：

```text
Pass 1：渲染云层密度
        ↓
Pass 2：向太阳方向模糊密度
        ↓
Pass 3：使用密度、模糊结果和大气散射公式渲染天空与云
```

## Pass 1：云密度图

首先把云层的密度写入离屏 Render Target。密度是一个标量，可以来自：

- 艺术家绘制的云纹理；
- 多层云纹理混合；
- 程序化噪声；
- 按天气参数选择的不同云层。

密度图可以同时作为：

- 云层的遮挡强度；
- 云层透明度；
- 后续散射模糊的输入。

书中示例使用屏幕空间的云平面或规则网格，云的形状和光照相互解耦，因此云纹理可以滚动，也可以由程序动态生成。

## Pass 2：朝太阳方向的屏幕空间模糊

太阳方向被投影到屏幕，得到当前像素对应的模糊方向。然后沿这个方向采样密度图：

```text
当前像素
  ← 太阳方向附近的密度样本
  ← 更远的密度样本
  ← 更远处的密度样本
```

模糊权重随距离衰减，因为距离较远的云层对当前点的入射散射贡献较小。

如果光线方向与视线方向接近，投影到屏幕上的方向可能接近点模糊；如果两者近似垂直，则形成明显的定向模糊。太阳位于观察者背后时，模糊方向需要反转。

模糊长度还会根据世界空间距离进行调整：距离相机越远，屏幕投影关系不同，需要限制和缩放采样步长，避免模糊过长。

## 模糊结果代表什么

模糊后的密度不是严格的体积光照积分，而是一个屏幕空间近似：

- 云密度高的区域会向邻近区域传播较强影响；
- 靠近太阳方向的云更容易获得亮度；
- 多个云层之间会产生近似的光照扩散；
- 低频云层可以用较低分辨率处理。

因此它更准确地说是“用方向性密度滤波模拟散射外观”。

## Pass 3：大气与云层散射

最终阶段把天空、云和其他几何放到统一的日光散射模型中。章节使用类似：

`L(s,θ) = exp(−sβex)L0 + (βsc(θ)/βex · Esun)(1 − exp(−sβex))`

其中：

- `s` 是视线距离；
- `βex` 是消光参数；
- `βsc(θ)` 是与角度有关的散射项；
- `Esun` 是太阳光；
- `L0` 是来自表面或云层的基础光照。

对于天空，`L0` 可以设为零或使用环境项。对于云层，`L0` 由模糊密度图缩放后得到，同时密度图也参与透明度计算。

## 云影项

仅使用云层亮度会产生一个问题：地面可能仍然很亮，即使上方有一大片厚云。

因此方法会用不同衰减参数再计算一个 shadow term，用于近似云层投射到地面的阴影：

`L(s,θ) = exp(−sβex)L0 + (βsc(θ)/βex · Esun · shadow + C)(1 − exp(−sβex))`

其中：

- `shadow` 表示云造成的遮挡或变暗；
- `C` 是可调常量，可以作为艺术家控制的雾或环境补偿项。

这样即使普通 shadow map 产生了不理想的地面结果，也可以用额外的屏幕空间阴影项压低云下地面亮度。

## 大气距离近似

为了估计光线穿过大气层和云层的距离，本章把大气看成地球表面上方的球冠。对于垂直角度 `θ`，光线穿过大气的距离可以近似为：

`d(θ) = −R sinθ + sqrt(R² sin²θ + h² + 2h)`

其中 `R` 是地球半径，`h` 是大气厚度。使用更小的 `h'` 可以近似得到到云层的距离。

这个公式让太阳接近地平线时的光程变长，产生更强的散射和更厚重的天空颜色变化。

## 低分辨率处理

云本身通常是低频、柔软的视觉元素，因此密度图和模糊 Render Target 可以使用屏幕四分之一分辨率。

这样可以降低：

- 密度渲染成本；
- 多次模糊采样成本；
- 带宽和临时纹理大小。

最终再在全分辨率中合成云层与天空。

## 云层分层

单张密度图进行二维模糊会导致云层之间相互污染：靠近太阳的云可能把不应该传播到另一层的亮度或阴影扩散过去。

一种扩展是把不同云层或交替云条存储到不同通道：

```text
R 通道：第一组云层
G 通道：第二组云层
```

分别对不同通道进行模糊，再在最终阶段合成。这样可以降低云层之间的错误混合，尤其适合层状的 stratocumulus 云。

## 它和真实体积云的区别

本方法没有完整模拟：

- 每个体素中的真实粒子分布；
- 光线在云内部的多次反弹；
- 方向相关的真实相函数；
- 不同波长光的散射颜色；
- 云层前后和内部的完整遮挡关系。

它主要利用：

```text
屏幕空间密度
→ 朝太阳方向模糊
→ 经验散射公式
→ 透明度与云影合成
```

因此它是远景云层的外观近似，而不是物理体积渲染。

## 适用场景

- 玩家主要在地面观察天空；
- 云层距离较远；
- 云的细节较低频；
- 需要实时动画和天气变化；
- 可以接受近似的多次散射外观；
- 目标是自然的户外氛围，而不是近距离穿云。

它不适合：

- 玩家进入云体内部；
- 需要近距离体积云细节；
- 云层与复杂建筑、山体频繁交错；
- 需要严格物理一致的日落、日出和多波长散射。

## 代价与限制

1. **屏幕空间限制**：当前屏幕外的云不会参与模糊和散射。
2. **遮挡关系不完整**：二维密度图不能完整表达云层前后关系。
3. **太阳方向依赖**：模糊方向来自投影太阳方向，极端视角下可能变形。
4. **厚云会过暗或过亮**：简单密度累积无法严格控制能量守恒。
5. **云层互相污染**：单通道模糊会让邻近云层产生错误光照传播。
6. **颜色近似不足**：本章基本忽略进入云层的光色变化，日出日落时不够真实。

## 本章结论

本章用一个非常工程化的方式近似云层多次散射：先把云层表示为屏幕空间密度，再沿太阳方向对密度进行加权模糊，最后将模糊结果放入大气散射和云影公式中。

它牺牲了严格物理正确性，换来了低成本、低分辨率、易于与程序化云层和天气系统结合的实时效果。对于远景天空，这种“正确抓住视觉线索”的方法往往比完整体积光照更符合游戏帧预算。
