# Real-Time Multi-Bounce Ray-Tracing with Geometry Impostors（使用几何代理的实时多次反弹光线追踪）

## 章节内容

作者：Péter Dancsik、László Szécsi

本章研究如何在传统光栅化管线中，近似实现反射、折射、焦散和多次光线反弹。核心做法不是直接遍历原始三角形，而是为环境和物体建立几何 impostor，将复杂几何压缩成适合 GPU 查询的距离、法线、纹理坐标或高度数据。

## 核心思路

普通光线追踪需要对每条射线寻找三角形交点：

`射线 → 加速结构 → 三角形求交 → 命中点、法线、材质`

本章将中间的三角形求交替换为：

`射线 → 查询几何 impostor → 近似命中点、法线、材质`

因此保留了光线追踪的基本流程，但把昂贵的几何求交改成纹理采样、二分搜索或有限次数的距离查询。

## 几何 impostor 保存的信息

几何 impostor 不是普通颜色贴图，而是面向几何查询的预计算表示。根据类型不同，可以保存：

- 从参考点到表面的距离；
- 命中表面的法线；
- 表面的颜色或材质参数；
- 表面的纹理坐标；
- 高度场或几何图像中的表面位置。

例如距离 impostor 可以把射线方向映射到 cubemap 方向，再从纹理中读取该方向上的表面距离：

`HitPosition ≈ ReferencePoint + RayDirection × Distance`

这样就能得到一个近似交点，再根据对应的法线和材质继续进行着色。

## 环境距离 impostor

环境距离 impostor 类似环境 cubemap，但不只保存颜色，而是保存从某个参考位置向外观察时的表面距离。它适合表示静态环境：墙壁、地面、房间和远处物体等。

当反射或折射射线离开当前物体时，可以查询环境距离 impostor，得到它在环境中的近似命中位置。若 impostor 同时保存法线或纹理坐标，就能继续计算光照，甚至继续发射下一次反射或折射射线。

它与普通环境 cubemap 的区别是：

- 普通 cubemap 主要回答“这个方向的颜色是什么”；
- 距离 impostor 还回答“这个方向的表面在哪里”；
- 有了近似表面位置，射线就可以继续进行多次反弹。

## 物体距离 impostor

对于场景中的玻璃、镜面和液体等反射/折射物体，可以为每个物体建立独立的 object impostor。

渲染某个反射物体时，二次射线可以分别查询：

1. 静态环境 impostor；
2. 场景中其他动态物体的 object impostor；
3. 当前物体自身的 impostor，用于处理光线进入和离开物体的折射。

最后选择沿射线方向最近的有效交点。

如果命中另一个反射物体，还可以从新的命中点继续发射射线，形成多次反射或折射。

## 距离 impostor 的几何限制

距离 impostor 对星形凸物体尤其有效。所谓星形凸，直观上是指从参考点向任意方向发射射线时，可以比较稳定地得到一个主要表面交点。

复杂凹形物体会带来问题：

- 同一个方向上可能有多个表面；
- 洞穴内部可能无法被单层距离记录；
- 参考点变化后，原有距离数据可能不再适用；
- 物体内部的折射射线可能需要找到第二个、第三个交点。

因此距离 impostor 不是完整几何，而是针对特定参考位置和查询方式的压缩表示。

## 高度图 impostor

高度图 impostor 用一个或两个高度场表示物体相对于参考平面的厚度。射线与高度场的求交不再是直接读取一个距离，而是在射线参数区间中进行搜索：

1. 先计算射线进入和离开物体包围盒的范围；
2. 判断射线与参考平面的关系；
3. 在近侧或远侧高度图中确定搜索区间；
4. 使用二分搜索寻找射线高度和几何高度相交的位置。

它比单一距离纹理更适合表示某些凹陷和厚度结构，也能用于液体、玻璃棋子等近似二维或旋转对称的模型。

但它本质上仍是 2.5D 表示，复杂任意拓扑和多层遮挡仍然可能失败。

## Geometry Image

Geometry Image 将模型表面参数化到纹理中，在纹理中保存表面位置、法线以及其他属性。与单个距离值相比，它可以表达更复杂的表面结构。

代价是求交过程更复杂，需要在纹理参数空间或层次结构中寻找合适的表面区域。它的优势是表示能力更强，限制不完全依赖“从一个参考点看出去每个方向只有一个表面”。

因此可以粗略理解为：

- 距离 impostor：查询非常快，但形状限制较强；
- 高度图：适合 2.5D、液体和规则物体；
- Geometry Image：表达能力更强，但查询更复杂。

## 多次折射

对于玻璃等透明物体，第一条折射光线进入物体后，还需要找到离开物体的第二个交点。使用 impostor 的表面距离和法线，可以重复执行：

1. 在物体表面计算折射方向；
2. 查询物体内部的下一次交点；
3. 在出口处重新计算折射方向；
4. 继续查询环境或其他物体。

实际项目中通常只需要有限次数的折射，因为反弹次数越多，计算量越大，而且近似误差会不断累积。

## 静态与动态场景分离

本章最重要的工程优化之一，是把静态环境和动态物体分开处理。

### 静态环境

静态环境的 impostor 可以在加载时或低频更新，不必每帧重建。这样可以把构建成本摊薄到较长时间内。

### 动态物体

动态液体、移动玻璃物体或变形表面需要更新自己的 object impostor。由于动态物体通常数量较少，可以只更新这一小部分，而不是重新渲染整个环境。

最终的次级射线可以同时查询静态环境和动态物体，并取最近交点：

`NearestHit = min(StaticEnvironmentHit, DynamicObjectHit)`

这比每帧重新生成所有反射环境图更划算。

## 环境 impostor 的延迟多次反弹

如果环境 impostor 每帧重新渲染，并且生成 impostor 时也使用上一帧的反射结果，那么它可以逐帧积累反弹：

- 第一帧主要包含漫反射环境；
- 第二帧开始包含一次反射；
- 后续帧逐渐包含更多反射层次。

这种方式可以近似多次反弹，但存在时间延迟，而且更新完整 cubemap 的成本很高。因此它更适合静态或变化缓慢的环境，不适合完全动态的复杂场景。

## 焦散与阴影

焦散可以从光源方向反向追踪光线路径：

1. 将相机放到光源位置；
2. 使用 impostor 追踪多次反射和折射；
3. 记录光线最终击中漫反射表面的位置；
4. 将这些命中点 splat 到焦散光照图；
5. 在普通物体渲染时使用焦散光照图。

阴影仍然可以结合传统 shadow mapping。动态物体造成的阴影或焦散可能使静态环境 impostor 失效，因此可以：

- 把潜在接收面当作动态对象处理；
- 或者在 impostor 中保存静态表面的纹理坐标，而不是直接保存颜色，在最终命中时重新读取当前材质和焦散光照。

## 示例场景

书中使用了两个典型场景：

### 玻璃国际象棋

棋子种类很少，只有少量网格类型，且通常只有一个棋子移动。静态棋子可以复用 impostor，移动棋子单独更新环境和焦散信息，因此适合展示多次折射和动态焦散。

### Alien Pool

场景包含液体、冰块、浮动物体和容器。液体用 ripple height map 生成动态表面，再用高度图 impostor 表示；浮动物体使用距离 impostor。静态墙面通过纹理坐标而不是固定颜色参与后续焦散计算，从而减少重建静态环境的需要。

## 和 SSR、SDF、硬件光追的区别

- **SSR**：只查询当前屏幕深度，便宜但看不到屏幕外内容；
- **SDF**：按空间位置查询距离，需要多次步进；
- **几何 impostor**：按方向、纹理参数或高度场查询近似表面，查询快但表示限制更强；
- **硬件光追/BVH**：直接对真实几何求交，通用性和准确性更高，但需要更高的硬件与构建成本。

几何 impostor 的定位是：在不使用完整硬件光追的情况下，为特定场景和特定类型的反射/折射效果提供廉价近似。

## 代价与限制

1. **表示误差**：impostor 不是原始网格，复杂凹面、多层表面和内部结构可能丢失。
2. **参考点依赖**：距离 impostor 通常绑定参考位置，物体移动、旋转或尺度变化时需要重新处理或转换。
3. **动态更新成本**：动态物体和动态环境需要重新渲染 impostor，更新过多会抵消性能收益。
4. **多物体查询成本**：如果每条射线都与大量 object impostor 求交，也会产生高开销，需要场景规模较小或额外的空间组织。
5. **反弹误差累积**：每一次近似命中都会影响下一次射线，多次反弹后误差和能量偏差会变得明显。
6. **不是完整 GI**：它主要解决反射、折射、焦散等特定路径，并不自动得到完整的漫反射全局光照。

## 本章结论

几何 impostor 光追的本质，是把真实网格求交替换成对预计算几何表示的查询。通过距离、法线、高度和纹理坐标等数据，GPU 可以近似找到反射或折射射线的命中点，再继续进行有限次数的光线反弹。

它真正可行的关键不是“用一张图表示所有几何”，而是：选择适合场景的 impostor 类型，并把静态环境和少量动态物体分开维护。这样可以在玻璃棋子、液体、镜面物体等特定场景中，以远低于完整光追的成本得到可信的多次反射、折射和焦散效果。
