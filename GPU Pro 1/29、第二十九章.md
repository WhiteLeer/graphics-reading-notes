# Multi-Fragment Effects on the GPU Using Bucket Sort（使用桶排序实现 GPU 多片元效果）

作者：Meng-Cheng Huang、Fang Liu、Xue-Hui Liu、En-Hua Wu  
来源：GPU Pro 1，Part VIII，Chapter 1，pp. 495–507。

## 核心问题

透明、景深、折射和 CSG 等效果需要保留同一像素的多个片元并按深度处理，而普通光栅化和深度测试通常只保留最终可见片元。

## Bucket Sort

先估计每像素实际深度范围 `[zNear,zFar]`，再把范围划分为多个深度桶。片元按深度写入对应桶，并用位图/直方图记录哪些桶非空。随后把非空桶压缩成连续层，按深度顺序恢复片元。

该方法用固定容量和多 Pass 处理超过容量的深度层，避免为每个像素动态分配无限长度链表。除深度外，还可以打包颜色、法线等属性。

## 应用与限制

可用于 OIT、景深、折射、阴影、体积渲染和 CSG。代价是 MRT、纹理带宽、桶量化误差和固定层数限制；复杂度高时需要多轮扫描。

## 总结

它是 GPU 端的多片元组织框架，介于重复 Depth Peeling 与动态 A-buffer 之间，重点是用深度分桶降低排序和存储成本。
