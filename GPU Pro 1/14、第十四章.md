# Anisotropic Kuwahara Filtering on the GPU（GPU 上的各向异性 Kuwahara 滤波）

## 章节内容

作者：Jan Eric Kyprianidis、Henry Kang、Jürgen Döllner

本章介绍一种面向 GPU 的图像抽象方法。它从普通 Kuwahara 滤波开始，通过局部均值和方差保留结构边缘，再使用结构张量估计图像方向，把固定的圆形或扇形滤波区域变成沿特征方向旋转和拉伸的椭圆，从而产生绘画化、油画化的效果。

## 核心思路

普通模糊会把邻域中所有颜色混合，容易让边缘变软。Kuwahara 滤波把邻域分成多个子区域，分别计算每个区域的平均颜色和方差，优先选择方差较小的区域。

如果一个子区域跨过物体边缘，它通常同时包含两种明显不同的颜色，方差较大；如果一个子区域位于同一材质或同一色块内部，方差较小。于是算法会倾向于在区域内部平滑，而避开跨越轮廓的区域。

各向异性版本进一步回答了一个问题：局部区域应该沿哪个方向平滑？它通过结构张量得到局部方向和各向异性程度，再让滤波核沿图像特征方向拉伸。

## 普通 Kuwahara 滤波

普通 Kuwahara 可以把滤波邻域划分成四个矩形或多个扇形区域。对第 `k` 个区域计算：

- 平均颜色 `m_k`；
- 颜色方差 `σ_k²`。

最简单的版本直接选择方差最小的区域：

`output(P) = m_argmin(σk²)`

更平滑的版本会根据方差对各个区域进行加权，方差越小，权重越高。

它可以保留边缘，但固定区域容易产生块状伪影，尤其是在斜线、弯曲轮廓和方向性纹理附近。

## 结构张量与局部方向

首先使用类似 Sobel 的卷积估计图像梯度：

`fx = Sx * f`，`fy = Sy * f`

然后构造结构张量：

`J = [[fx², fx·fy], [fx·fy, fy²]]`

结构张量的特征值和特征向量描述局部图像结构：

- 较大的特征值表示颜色变化强的方向；
- 较小的特征值表示颜色变化弱的方向；
- 特征向量表示对应方向。

在一条边缘附近，梯度方向通常垂直于边缘，而变化较小的方向沿着边缘切线。滤波器使用局部特征方向，让平滑更多发生在边缘方向上，而不是穿过边缘。

为了减少方向场中的突变，章节会先对结构张量做高斯平滑，再重新计算特征值和特征向量。这样比直接平滑方向角更稳定。

## 各向异性程度

各向异性程度由两个特征值计算：

`A = (λ1 − λ2) / (λ1 + λ2)`

其中：

- `A ≈ 0`：局部区域没有明显方向，使用接近圆形的滤波核；
- `A ≈ 1`：局部区域方向非常明显，使用细长的椭圆滤波核。

滤波核的长轴沿局部结构方向，短轴垂直于该方向。平坦区域因此得到较均匀的平滑，而毛发、边缘和线状结构会产生方向性笔触。

## 椭圆滤波核与扇区

各向异性 Kuwahara 仍然会把滤波核划分成多个方向扇区。区别是这些扇区位于旋转后的椭圆中，而不是固定圆形中。

滤波半径为 `r`，调节参数为 `α` 时，长短轴可以根据各向异性程度调整为类似：

`a = ((α + A) / α) r`

`b = (α / (α + A)) r`

当 `A` 较小时，`a` 和 `b` 接近，滤波核近似圆形；当 `A` 增大时，长轴变长，短轴变短。

随后通过旋转矩阵和缩放矩阵，把椭圆中的采样位置映射到预计算的圆形权重纹理中。这样可以复用扇区权重，而不必为每种方向重新生成完整核。

## 均值、方差与最终合成

对每个扇区 `k`，计算加权颜色均值和二阶矩：

`m_k = Σ w_i c_i / Σ w_i`

`s_k = Σ w_i c_i² / Σ w_i`

方差可以由二阶矩减去均值平方得到：

`σ_k² = s_k − m_k²`

最终不是简单选择某一个扇区，而是让低方差区域获得更高权重。这样比硬切换到最小方差区域更平滑，也更适合视频或实时画面。

直观上：

- 跨越眼睛轮廓、鼻子边缘的扇区方差高，权重低；
- 位于同一片毛发内部的扇区方差低，权重高；
- 这些低方差扇区的颜色沿毛发方向被拉伸成笔触。

## GPU 实现流程

章节中的实现可以拆成以下阶段：

1. 输入图像；
2. 用 Sobel 卷积计算梯度；
3. 构造结构张量；
4. 对结构张量进行高斯平滑；
5. 求特征值和特征向量；
6. 得到局部方向 `φ` 和各向异性 `A`；
7. 根据 `φ`、`A` 构造椭圆采样核；
8. 读取椭圆内的邻域颜色；
9. 按多个扇区累计均值和方差；
10. 根据方差合成输出颜色。

它可以使用多个 fragment pass，也可以把部分步骤合并，具体取决于 GPU、分辨率和允许的纹理带宽。

## 采样优化

各向异性滤波的主要成本来自邻域采样和多个扇区的统计。章节中使用了几种优化：

- 预计算扇区权重纹理；
- 将多个权重打包到 RGBA 通道；
- 利用椭圆关于原点的对称性减少采样；
- 对 `N = 8` 的扇区进行专门展开；
- 使用 GPU fragment shader 对像素并行处理。

这类优化降低了纹理查找次数，但大半径滤波仍然会带来明显的带宽和算力成本。

## 示例效果

GPU Pro 中使用狮子等图像展示了：

- 原图中的毛发细节被抽象成较大的绘画笔触；
- 笔触沿局部毛发和轮廓方向排列；
- 眼睛、鼻子、嘴巴等高对比轮廓仍然清晰；
- 平坦区域被平滑成更统一的色块。

因此它不是简单的 Gaussian Blur，而是“方向感知的保边抽象”。

## 和其他滤波方法的区别

### Gaussian Blur

对固定空间邻域做平均，成本低但会跨越边缘，导致轮廓变软。

### Bilateral Filter

同时考虑空间距离和颜色差异，主要目标是保边降噪；它通常不会主动产生明显的方向性笔触。

### 普通 Kuwahara

通过多个子区域的方差选择较稳定区域，能产生绘画化效果，但固定区域容易出现块状伪影。

### 各向异性 Kuwahara

先分析局部方向，再旋转和拉伸滤波核，因此更适合表达毛发、边缘、线条等方向性结构。

## 适用场景

- 油画或绘画风格后处理；
- 卡通化和图像抽象；
- 水彩、手绘背景的基础滤镜；
- 低频化但仍需保留轮廓的画面处理；
- 需要对视频保持一定时间稳定性的艺术化效果。

它本质上是屏幕空间后处理，不会修改真实几何、材质或光照，也不能替代专门的 NPR 几何和笔刷系统。

## 代价与限制

1. **邻域采样成本高**：半径越大、扇区越多，纹理读取和统计量越多。
2. **方向估计依赖输入图像**：弱纹理、重复纹理和噪声可能产生不稳定方向。
3. **过强参数会丢失细节**：长轴过长或方差权重过强，会把重要的小结构合并掉。
4. **可能出现伪影**：方向场不连续时，笔触方向可能突然改变；固定扇区也可能产生轻微聚集。
5. **屏幕空间性质**：只处理最终图像，不理解场景中的真实材质和几何关系。
6. **不等于真实油画**：它生成的是方向性颜色抽象，并没有真正模拟画笔、颜料叠加或纸张纹理。

## 本章结论

各向异性 Kuwahara 的关键不是“更复杂地做平均”，而是把局部图像结构转换成滤波核的方向和形状：

`结构张量 → 局部方向与各向异性 → 旋转椭圆核 → 分区统计 → 低方差加权合成`

这样可以沿图像特征方向平滑并生成绘画笔触，同时避免跨越重要轮廓。它是一个典型的 GPU 图像空间风格化后处理方案，适合实时艺术化效果，但不应被理解为完整的材质或 NPR 渲染系统。
