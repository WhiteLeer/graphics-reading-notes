# Edge Anti-aliasing by Post-Processing（通过后处理实现边缘抗锯齿）

## 章节内容

作者：Hugh Malan

本章介绍一种面向实时渲染的轮廓边缘抗锯齿方法。它不依赖高倍 MSAA，而是在几何渲染阶段写入少量边缘提示信息，然后在后处理阶段只对接近 silhouette edge 的像素进行局部混合。

目标不是模糊整张图，而是让轮廓边缘产生类似超采样覆盖率的渐变，同时尽量不增加额外几何、不改变绘制顺序，也能够应用于延迟渲染后的阴影、局部光照和 decal 等效果。

## 为什么需要这种方法

MSAA 能够对一个像素保存多个覆盖样本，但代价包括：

- 多份颜色、深度和其他 framebuffer 数据；
- 更高的显存占用和带宽；
- 延迟效果读取和处理多重样本时成本更高；
- 在某些平台上难以对所有 deferred effect 提供完整支持。

普通后处理抗锯齿可以检测深度或法线不连续并进行模糊，但这只能说明“这里可能有边缘”，不能准确知道像素覆盖了多少前景和背景。

本章的方法尝试额外保存一个子像素级的边缘提示，使后处理能够近似回答：

```text
当前像素距离轮廓边缘有多远？
轮廓位于哪个方向？
应该从哪个邻居读取背景颜色？
```

## 基本概念：silhouette edge

Silhouette edge 是相邻三角形中，一个朝向相机、一个背向相机的轮廓边。它是物体与背景之间最重要的可见边缘。

传统光栅化只会写入像素中心位于三角形内部的像素，但理想抗锯齿应该考虑所有与三角形有覆盖交集的像素。于是可能出现：

- 像素中心在三角形外；
- 但像素面积的一部分被三角形覆盖；
- 普通单采样光栅化完全不写它；
- 最终轮廓出现阶梯。

## 轮廓外扩

为了让轮廓附近的像素也获得处理机会，本章在顶点着色阶段对部分顶点做屏幕空间外扩。

当一个顶点连接到至少一个背向三角形时，将它沿屏幕空间外法线方向移动约 `k` 个像素。这样会形成一个略大于原物体的边缘区域：

```text
原始几何：       ─────
外扩后的几何：  ─────────
```

外扩不是为了改变最终物体轮廓，而是为了让轮廓附近的像素被额外三角形覆盖，从而可以在后处理阶段得到提示。

几何本身仍然用背面剔除等方式进行控制，真正的颜色结果仍来自原始图像和邻居混合。

## silhouetteParameter

顶点程序输出一个 `silhouetteParameter`：

- 普通内部顶点为 `1`；
- 外扩或接近轮廓的顶点为 `0`；
- 光栅化插值后，像素得到 `0` 到 `1` 之间的值。

它不是精确的真实距离，但可以作为一个近似的轮廓距离提示。为了估计屏幕空间距离，使用像素着色器的导数：

`hdist = -silhouetteParameter / ddx(silhouetteParameter)`

`vdist = -silhouetteParameter / ddy(silhouetteParameter)`

这里的 `hdist` 和 `vdist` 分别近似表示当前像素在水平、垂直方向上距离轮廓还有多少像素。

该估计不是数学上严格的轮廓求交，特别是在复杂三角形、透视插值和鞍点附近会产生误差，但对于一像素左右的边缘混合通常足够。

## 后处理混合

对当前像素，定义：

- `colbase`：当前像素的前景颜色；
- `colneb`：根据边缘方向选择的邻居颜色，近似背景颜色；
- `blendfactor`：根据距离轮廓的程度估计覆盖率。

核心逻辑可以概括为：

```text
colbase = 当前像素颜色
colneb  = 沿轮廓方向选取的邻居颜色
blend   = min(abs(hdist), abs(vdist))
output  = lerp(colneb, colbase, blend)
```

越靠近轮廓，越需要混入邻居颜色；离开轮廓一像素以上时，不再处理。

邻居方向通常取：

`(sign(hdist), sign(vdist))`

因此可能选择上、下、左、右或对角邻居。使用最近邻居是为了避免采样距离过远导致背景颜色相关性迅速下降，也能控制后处理成本。

## 为什么能模拟 MSAA

MSAA 的边缘颜色来自多个子采样点的覆盖率混合：

```text
前景覆盖 30% + 背景覆盖 70%
```

本章没有真的保存多个子采样点，而是通过：

1. 外扩几何产生边缘覆盖提示；
2. 导数估计轮廓位置；
3. 读取邻居近似背景颜色；
4. 用距离近似覆盖率；

模拟一个类似的结果。

所以它不是严格意义上的 MSAA，而是利用场景几何和邻居颜色推断子像素覆盖。

## 帧缓冲中的提示编码

为了减少额外带宽，本章将边缘提示压缩到额外的少量通道中。示例中可以使用 8-bit alpha：

- 低位编码邻居采样方向；
- 剩余位编码 blend factor。

这样后处理只需要读取一个紧凑的提示值，再恢复：

```text
邻居偏移量
边缘覆盖率
```

这说明本方法的成本不只是 shader 指令，还包括额外 framebuffer 存储、写入和读取带宽。

## 特殊情况与失败模式

### 材质颜色边界

如果物体内部存在红蓝材质分界，它不一定是 silhouette edge。若错误地把它当作轮廓处理，像素会被不正确地混合到另一侧颜色。

### 三个顶点都被判为外扩

某些正方形、立方体面或复杂曲面会出现整个三角形的参数都接近零，导致导数无法提供有效的边缘距离。

### 小三角形

当三角形尺寸接近一个像素时，单采样方法仍然受 Nyquist 限制，无法像高倍 MSAA 那样可靠地重建覆盖率。

### 小间隙

外扩可能把非常细的几何间隙填掉，例如角色手指之间的空隙。`k` 越大，这种问题越明显。

### 透明和 Alpha 混合

透明 billboard、玻璃或半透明物体的边缘不能简单套用不透明轮廓规则，否则可能破坏其后方物体的边缘抗锯齿。需要单独控制提示写入。

### 深度相交表面

如果多个表面在深度缓冲中发生复杂相交，本方法无法获得足够的背景层信息，抗锯齿结果会退化。

## 对蒙皮角色的处理

静态网格可以更准确地检查顶点相邻的背面三角形，但蒙皮角色更困难：

- 姿态变化后轮廓不断变化；
- 鞍点和复杂曲率更常见；
- 顶点法线可能不适合作为统一外扩方向；
- 保存多个相邻三角形法线会增加顶点数据。

实际实现可能使用较简单的锥体测试或近似阈值，以减少顶点着色器成本，但会牺牲一部分边缘覆盖率和稳定性。

## 性能与实现成本

主要成本包括：

- 顶点外扩和相邻背面测试；
- 顶点中额外的法线或测试数据；
- 额外的 edge hint framebuffer 通道；
- 一个 resolve pass；
- 一个全屏后处理 pass。

章节给出的旧平台测试中，后处理成本与屏幕内容复杂度无关，主要取决于分辨率，因为它是固定的全屏处理。

## 其他应用

### 阴影图放大

如果阴影图中也保存轮廓距离和方向提示，就可以在采样阴影图时判断真实的阴影边缘，而不是单纯对深度做双线性插值。这可以改善低分辨率阴影图的边缘。

### 保边上采样

低分辨率图像上采样时，普通双线性插值会保留明显的阶梯边缘。若低分辨率图像携带边缘距离函数，就可以在高分辨率像素中重建更准确的轮廓位置，并按覆盖率混合两侧颜色。

这使它成为一种介于“直接提高渲染分辨率”和“普通图像放大”之间的方案。

## 和 FXAA、SMAA、MSAA 的区别

- **MSAA**：真实保存多个几何覆盖样本，质量稳定但带宽和存储成本高；
- **FXAA**：主要从最终颜色中寻找高对比边缘，再进行方向性模糊，不需要修改几何，但无法得到真正的几何覆盖率；
- **SMAA**：结合颜色、边缘和预计算模式，重建能力通常比 FXAA 更好；
- **本章方法**：在几何阶段写入轮廓提示，因此比单纯颜色后处理更了解几何边缘，但需要修改顶点阶段和 framebuffer，并且对几何特殊情况更敏感。

## 本章结论

本章的本质是：用少量几何边缘提示，换取一个针对轮廓的后处理混合 pass。

它不真正增加 MSAA 子样本，也不需要完整深度剥离，而是通过外扩轮廓、屏幕导数、邻居颜色和覆盖率近似，生成像素宽度的平滑边缘。

它适合延迟渲染、低 MSAA 或无法承担高倍 MSAA 的场景，也能扩展到阴影图放大和保边上采样。但它无法解决所有采样问题：小三角形、小间隙、透明表面和复杂材质边界仍然需要单独处理。
