# Parallelized Light Pre-Pass Rendering with the Cell Broadband Engine（Cell 上的并行 Light Pre-Pass 渲染）

作者：Steven Tovey、Stephen McAuley  
来源：GPU Pro 1，Part VIII，Chapter 2，pp. 509–526。

## 核心问题

针对 PlayStation 3 的 Cell Broadband Engine，本章研究如何把 Light Pre-Pass Renderer 的部分光照工作分配到 GPU 和多个 SPE，降低动态光源场景的瓶颈，同时避免额外帧延迟。

## 流程

1. GPU 生成法线、深度和材质相关的几何缓冲；
2. SPE 并行处理光源影响、光源列表和屏幕区域；
3. GPU 执行材质与最终合成；
4. 使用双缓冲和明确的 GPU/SPE 同步维持流水线。

## 重点

Cell 的局部存储和 DMA 传输要求数据分块、预取和同步非常明确。Light Pre-Pass 减少了复杂材质对大量动态光源的重复处理，但增加了额外几何 Pass 和数据管理成本。

## 当代意义

具体 SPE API 已过时，但“按屏幕/光源分块、将光照与材质解耦、用并行任务填满 CPU/GPU 流水线”的思想仍对应现代 clustered/deferred lighting。
