# Accelerating Virtual Texturing Using CUDA（使用 CUDA 加速虚拟纹理）

作者：Charles-Frederik Hollemeersch、Bart Pieters、Peter Lambert、Rik Van de Walle  
来源：GPU Pro 1，Part X，Chapter 2，pp. 623–641。

## 核心问题

虚拟纹理将超大纹理拆成页面，只加载当前视角真正需要的页面。页面请求、映射和更新本身可能成为 CPU 瓶颈。

## GPU 加速流程

- 生成或读取页面请求；
- 在 GPU 上处理可见页面和地址映射；
- 更新 Page Table；
- 将物理纹理页上传到缓存；
- Shader 通过虚拟坐标查表获得实际物理页坐标；
- 对缺页区域使用低级别或占位纹理。

CUDA 主要用于页面分析、请求整理、映射更新和数据搬运，目标是减少 CPU 参与和大规模页面管理成本。

## 限制

必须处理页面边界、Mip 级别、反馈延迟、缓存淘汰、纹理上传和缺页闪烁。虚拟纹理不是“无限显存”，而是用可见性和分页把工作限制在当前需求上。
