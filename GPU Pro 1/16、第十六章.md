# Environment Mapping with Floyd-Steinberg Halftoning（使用 Floyd-Steinberg 半色调的环境映射）

## 章节内容

作者：László Szirmay-Kalos、László Szécsi、Anton Penzov

本章研究环境光照中的重要性采样问题。核心观点是：数字半色调和重要性采样都在把连续的权重分布转换成离散点分布，因此可以借用 Floyd-Steinberg 误差扩散来生成更均匀、更符合重要性分布的光照采样方向。

## 环境映射中的采样问题

环境贴图可以表示来自各个方向的光照。对一个表面点 `x`，反射辐射需要对环境方向进行积分：

`L(x,ω) = ∫ Lenv(ω') · fr(ω',x,ω) · cosθ' · V(x,ω') dω'`

其中：

- `Lenv` 是环境光照；
- `fr` 是 BRDF；
- `cosθ'` 是余弦项；
- `V` 是可见性，表示环境光方向是否被遮挡。

逐个遍历环境贴图的所有 texel 太昂贵，因此需要用少量方向样本近似积分。

最耗时的部分往往是可见性判断，也就是从表面点发射射线并判断环境光是否被物体遮挡。因此采样数量有限时，采样分布是否合理会直接影响噪声和误差。

## 重要性采样

蒙特卡洛估计通常写成：

`Integral ≈ (1/M) Σ f(ωi) / p(ωi)`

其中 `p(ω)` 是采样概率密度。理想情况下，采样概率应该尽量接近被积函数的分布：贡献大的方向多采样，贡献小的方向少采样。

环境映射中常见的 importance function 包括：

- **Light-Source Sampling**：根据环境光亮度采样；
- **BRDF Sampling**：根据表面 BRDF 的贡献采样；
- **Product Sampling**：根据环境光与 BRDF 的乘积采样；
- **Triple Product Sampling**：进一步加入廉价的可见性近似。

由于真实可见性计算很昂贵，importance map 通常只使用较便宜的光照、BRDF 或代理几何信息，而不会在生成采样分布时完整计算所有遮挡。

## 环境贴图参数化

本章将环境方向映射到二维纹理坐标 `(u,v)`。以球面环境贴图为例，方向可以表示为：

`ω'(u,v) = (cos(2πu) sin(πv), sin(2πu) sin(πv), cos(πv))`

但二维 texel 面积并不对应均匀的立体角。不同纬度的 texel 覆盖的球面面积不同，需要考虑：

`Δω = sin(πv) Δu Δv`

因此环境图的 importance map 不应只看原始亮度，还应考虑参数化造成的立体角变形，否则两极和赤道区域会被不正确地加权。

## 随机重要性采样的问题

最直接的方法是：

1. 计算每个环境 texel 的重要性；
2. 根据重要性建立概率分布；
3. 生成随机数；
4. 按概率选择环境 texel。

它能保证统计意义上的重要性分布，但有限样本下可能出现：

- 重要区域之间出现大块空洞；
- 多个样本聚集在同一小块区域；
- 样本在空间上分布不均匀；
- 低采样数时产生明显噪声。

也就是说，随机采样虽然“平均上正确”，但单次采样的空间分层性不一定好。

## 半色调与重要性采样的等价性

半色调的目标是把灰度图转换成黑白点阵，同时让局部白点密度近似灰度值：

```text
亮区域：白点多
暗区域：白点少
```

如果把：

- 灰度值看作 importance map；
- 白点位置看作采样位置；

那么半色调就等价于生成符合重要性密度的离散采样点。

因此，Floyd-Steinberg 半色调中的白点位置可以直接作为环境光采样方向。

这不是说把环境图变成黑白图来显示，而是把半色调过程当作一个确定性的采样点生成器。

## Floyd-Steinberg 误差扩散

Floyd-Steinberg 的基本过程是：

1. 按行扫描图像；
2. 当前像素根据累积值判断是否生成一个采样点；
3. 如果生成采样点，则减去一个采样单位；
4. 将剩余误差分配给尚未访问的邻居；
5. 邻居在后续判断时吸收这部分误差。

其经典误差分配权重是：

```text
        当前   7/16
  3/16  5/16  1/16
```

在本章中，当前 texel 的重要性不是简单地被量化成黑或白，而是通过阈值和误差传播决定是否生成一个光照样本。

## 采样阈值

设 importance map 所有 texel 的重要性总和为 `S`，期望生成 `M` 个样本，则章节使用类似：

`threshold = S / (2M)`

扫描过程中：

- 如果当前累积重要性不超过阈值，则不生成样本；
- 如果超过阈值，则在当前环境方向生成样本；
- 生成样本后扣除相应重要性，并把剩余误差传播给邻居。

这样最终生成的样本数量和空间分布会近似 importance map，同时比独立随机采样更均匀。

## GPU 实现

章节给出的实现使用 geometry shader 生成采样点。流程可以概括为：

1. 遍历 importance map，计算总重要性 `S`；
2. 按扫描顺序访问 texel；
3. 读取原始重要性和邻域传播过来的误差；
4. 判断当前值是否超过阈值；
5. 若超过阈值，输出对应的环境方向和采样权重；
6. 将剩余误差写入下一行和邻近位置的缓存；
7. 交替改变行扫描方向，避免误差长期向一个方向偏移。

为了减少临时数组，代码把下一行的误差以 `float4` 打包保存，并以四个 texel 为一组处理。固定期望采样数时，还可以把输出数量限制为例如 32 个方向。

## 光源采样应用

在 light-source sampling 中，importance function 主要由环境光亮度和立体角修正构成：

`I(u,v) = luminance(E(u,v))`

采样点只依赖环境光方向，不依赖具体着色点，因此可以对整张环境图预计算一次，再供多个物体和像素使用。

这是一种很适合预计算的情况：

- 环境图不变；
- 所有表面共享同一组重要方向；
- 每个像素只需要执行可见性和 BRDF 计算。

## Product Sampling

Product Sampling 会把更多积分因子加入 importance map，例如环境光和 BRDF 的乘积：

`I(u,v) = E(u,v) · R(u,v,x,ω) · Ṽ(u,v,x)`

其中 `Ṽ` 是廉价的可见性近似，不是真实的完整遮挡测试。

优点是样本更贴近当前像素真正的光照贡献；缺点是 importance map 依赖当前着色点 `x`，因此不能像纯光源采样那样只预计算一次，而需要为不同着色点重复生成或更新。

如果场景中很多方向最终都会被遮挡，加入代理几何的可见性近似可以减少明显无效的光线样本，但构建代理几何本身也有成本。

## 采样结果与噪声

本章的比较表明，Floyd-Steinberg 采样相比独立随机采样具有更好的空间分布：

- 重要光照区域较少出现空洞；
- 样本聚集现象减少；
- 低样本数下的积分结果更平滑；
- 在完全可见表面上可以显著降低噪声。

在部分遮挡区域，噪声仍然存在，因为真实可见性仍需要有限数量的射线或查询来估计。它主要改善的是采样位置分布，而不是消除所有光追成本。

## 和抖动、蓝噪声的关系

Floyd-Steinberg 半色调和随机 dithering 都是在连续权重上生成离散点，但机制不同：

- **随机抖动**：独立加入随机扰动，简单但容易形成局部聚集和空洞；
- **有序抖动**：使用固定矩阵，分布稳定但可能产生周期性图案；
- **Floyd-Steinberg**：把量化误差传播给邻居，利用局部历史信息改善分层；
- **蓝噪声采样**：追求低频空洞、均匀点间距和较好的频谱性质。

本章的重点不是追求现代意义上的蓝噪声，而是利用误差扩散以很低的额外开销获得比独立随机更好的采样分布。

## 代价与限制

1. **扫描存在顺序**：误差扩散依赖访问顺序，GPU 上不如完全独立采样容易并行。
2. **状态管理复杂**：需要保存下一行和邻域的误差，几何 shader 实现也有输出限制。
3. **样本数量太少时会预热**：误差扩散在扫描初期可能还没有形成稳定分布。
4. **importance map 必须便宜**：如果构建 importance map 已经接近真实积分成本，就失去采样优化意义。
5. **真实可见性仍然昂贵**：方法改善的是方向选择，不会自动消除遮挡射线的成本。
6. **动态环境需要更新**：环境光或材质快速变化时，importance map 和采样方向需要重新生成。

## 本章结论

本章的关键转换是：

`连续重要性分布 → 半色调量化 → 离散采样方向`

Floyd-Steinberg 的误差扩散让采样点不再完全独立随机，而是利用邻域误差保持更好的空间分层。因此在环境光照、反射和可见性积分中，同样数量的样本可以得到更稳定、更低噪声的结果。

它并没有减少光照积分本身的复杂度，也不是新的 BRDF 或 GI 模型，而是一个采样分布优化方法：在有限样本预算下，让样本更集中于重要方向，并尽量避免聚集和空洞。
