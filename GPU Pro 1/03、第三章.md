# As Simple as Possible Tessellation for Interactive Applications（面向交互式应用的简化细分）

## 章节内容

本章提出 Phong Tessellation：一种在 GPU 上对粗粒度三角形或四边形进行运行时细分的方法。它不追求像 Subdivision Surface 那样重建整体光滑曲面，而是以很低的计算成本，把顶点位置和法线定义的局部切平面组合成一个弯曲的几何片面，用来隐藏低模在轮廓和内部边界上的明显多边形痕迹。

作者：Tamy Boubekeur。

## 核心目标

实时细分的基本作用是：应用层只保存较粗的网格，渲染时由 GPU 动态生成更多顶点。生成的高分辨率网格可以用于：

- 让表面看起来更平滑；
- 继续进行位移贴图或向量位移；
- 改善模型轮廓上的 polygonization；
- 减少需要从 CPU 传输和维护的几何数据。

本章的重点不是优化某个已有 Tessellation Shader 的指令数，而是选择一个足够简单的几何细分算子，使它适合交互式渲染。

## Phong Tessellation 的基本方法

对于一个三角形，每个顶点包含位置 `p` 和法线 `n`。普通线性细分只是在原三角形平面上插值，因此增加了三角形数量，却没有真正改变几何曲面。

Phong Tessellation 的处理过程可以概括为：

1. 先按照重心坐标，在三角形平面上得到一个线性插值点；
2. 将这个点分别正交投影到三个顶点的切平面上；
3. 对三个投影结果再次插值，得到一个弯曲方向；
4. 用形状因子 `alpha` 在平面位置和弯曲位置之间混合。

每个顶点的切平面由“顶点位置 + 顶点法线”定义，因此不需要额外的控制点或邻域查询。该方法隐式地产生一个二次曲面片，并且是局部的：每个多边形只依赖自己的顶点数据。

## 为什么它比普通线性细分更有用

普通线性细分只会把一个大平面切成更多小平面，轮廓依然可能呈现明显折线。Phong Tessellation 会根据顶点法线让几何位置向曲面方向弯曲，因此可以在不改变输入网格拓扑的前提下，改善：

- 物体外轮廓；
- 内部曲面过渡；
- 低模表面和 Phong 光照之间的不一致。

它的目标不是把整个模型变成严格意义上的高质量光滑曲面，而是优先处理最容易被看见的轮廓和连续性问题。

## 自适应细分与视角关系

本章也使用 Adaptive Instanced Tessellation。细分等级可以根据摄像机位置、顶点法线和观察方向估计 silhouette 程度：

- 越接近轮廓的区域，越需要真实几何弯曲，细分等级可以更高；
- 面向屏幕内部、且 Phong 法线插值已经足以掩盖几何不足的区域，可以少细分；
- 形状因子也可以随区域变化，让几何从平面逐渐过渡到弯曲形状。

因此，本章中的“细分方法”和“细分等级控制”是两个层面：Phong Tessellation 决定怎么生成弯曲几何，Adaptive Instanced Tessellation 决定哪里生成多少几何。

## 四边形扩展

对于四边形，作者没有简单地先把它拆成两个三角形，而是将三角形中的重心插值替换为双线性插值，并对四个顶点的切平面投影进行组合。

这样做有两个好处：

- 四边形的曲面定义不会受到任意对角线方向影响；
- 相邻三角形或四边形在共享边上可以得到一致的位置，从而避免裂缝。

虽然最终仍可以用三角形方式采样四边形，但几何算子本身保留了四边形的整体结构。

## 与 Subdivision Surface 的区别

Phong Tessellation 并不是完整的 Subdivision Surface，也不是试图从低模重建一个全局光滑模型。

| 方案 | 主要特点 |
| --- | --- |
| 线性细分 | 只增加三角形数量，几何仍在原平面上 |
| Phong Tessellation | 利用顶点法线局部弯曲几何，成本较低 |
| Subdivision Surface | 通常需要邻域信息并重建更完整的光滑曲面 |

因此它更适合动态变形的粗网格、实时预览和对轮廓质量要求较高但不需要严格曲面重建的场景。

## 性能与结果

书中给出的典型场景是几千个多边形的动态粗网格，在 GPU 上进行较高等级的细分。相较于 Curved PN Triangle，Phong Tessellation 在视觉效果相近时可以获得更好的帧率和更低的带宽使用。

它的额外开销主要在顶点生成和曲面位置计算。片元着色开启时，这部分开销占整帧的比例会进一步降低，因此整体上属于成本较低的实时几何平滑方案。

## 代价与限制

- 它依赖输入顶点法线，法线质量差时，几何弯曲方向也可能不理想；
- 它是局部算子，不会像完整细分曲面那样全局修正模型形状；
- 高细分等级仍会带来顶点处理和光栅化压力；
- 对硬表面、尖角和需要严格保持形状的模型，不能盲目使用；
- 它主要隐藏 polygonization，不等于生成高精度原始几何。

## 本章结论

本章的核心不是“把 Tessellation Shader 写得更快”，而是提出一个简单、局部、适合 GPU 实时执行的几何细分算子：

> 用粗网格顶点的位置和法线定义局部切平面，再通过投影和插值生成弯曲几何；必要时只在轮廓附近提高细分等级。

它在质量、实现复杂度和性能之间做了务实取舍，适合动态粗网格和实时交互应用，但不能替代完整的 Subdivision Surface 或高质量离线建模。
