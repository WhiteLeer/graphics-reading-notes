# NPR Effects Using the Geometry Shader（使用 Geometry Shader 的非真实感渲染）

## 章节内容

本章利用 Geometry Shader 实时生成风格化轮廓，并进一步实现铅笔绘制效果。核心不是普通的光照卡通化，而是把轮廓这种几何实体显式提取出来，再生成可纹理化、可控制宽度的描边几何。

作者：Pedro Hermosilla、Pere-Pau Vázquez。

## 主要目标

本章解决两类 NPR 问题：

1. 在单次渲染过程中同时绘制物体和它的 silhouette；
2. 使用曲率、光照和铅笔纹理模拟手绘效果。

相比单纯的后处理边缘检测，几何方法可以更明确地控制轮廓的宽度、纹理坐标和线条风格。

## 轮廓检测

一个三角形是否朝向摄像机，可以通过三角形法线和观察方向的点积判断。真正的 silhouette edge 位于一个朝向摄像机的三角形和一个背向摄像机的相邻三角形之间。

```text
front-facing triangle + back-facing triangle
                    ↓
              silhouette edge
```

因此，Shader 必须同时知道当前三角形和共享边的相邻三角形。实现上需要：

- 对索引重新排序；
- 使用带 adjacency 的三角形输入；
- 或预先把邻接信息打包到顶点数据中。

本章使用 Geometry Shader 的邻接输入，使 GS 可以在处理当前三角形时访问相邻三角形。

## 描边几何生成

发现轮廓边后，GS 会沿屏幕空间方向把边扩张成带状几何。扩张方向通常与边方向和视线方向共同决定，也可以加入顶点法线投影来处理边端点。

生成的不是单纯的一条线，而是由多个三角形组成的窄带。这样可以：

- 控制描边宽度；
- 使用纹理；
- 处理线条端点和连接处；
- 避免普通线段宽度受硬件限制。

使用屏幕空间扩张的一个好处是描边宽度更容易保持稳定，不会因为物体离摄像机远近而变化得过于明显。

## 单 Pass 绘制

传统方案可能需要：

```text
Pass 1：绘制模型
Pass 2：绘制轮廓
```

本章让 GS 同时输出普通三角形和描边三角形。Pixel Shader 通过额外的纹理坐标分量区分当前片元属于普通几何还是 silhouette 几何，再选择对应的着色方式。

这样可以避免把同一个模型完整送入渲染管线两次，但 GS 需要生成更多几何，实际收益取决于模型复杂度和硬件。

## 描边纹理

为了让轮廓线不只是纯色，章节还为整个 silhouette 构造连续的纹理坐标。它使用轮廓相对于模型包围盒中心的位置计算极坐标：

- 角度决定纹理沿轮廓方向的坐标；
- 到包围盒中心的距离作为额外的长度参数；
- 最终形成连续的 `u` 坐标。

这样可以沿完整轮廓使用笔刷、墨线或其他艺术纹理，而不是每条边都从头开始采样，减少纹理断裂。

## 铅笔渲染

铅笔效果不是简单地把物体变黑，而是根据表面曲率和光照方向改变笔触纹理。

流程大致是：

1. 为顶点计算最小曲率方向；
2. 通过 GS 把三角形三个顶点的曲率信息复制给输出三角形；
3. Pixel Shader 根据屏幕坐标生成铅笔纹理坐标；
4. 按三个顶点曲率方向旋转并采样笔触纹理；
5. 混合三组笔触结果；
6. 根据 `dot(L, N)` 选择或调整明暗和笔触强度。

这里 GS 的一个重要用途不是生成新三角形，而是把“每个三角形需要的三组曲率数据”传递给片元阶段，从而避免复制原始顶点数据。

## 与后处理边缘检测的区别

| 方案 | 特点 |
| --- | --- |
| GS 几何轮廓 | 使用真实网格边和相邻面，轮廓具有几何意义 |
| Sobel 等后处理 | 根据深度、法线或颜色边缘检测，适合全屏统一处理 |
| 反向膨胀壳体 | 复制模型并沿法线扩张，实现简单但可能有重叠和宽度问题 |

GS 方法的优势是能直接生成纹理化、可控宽度的轮廓；缺点是依赖邻接信息，并且会增加几何阶段压力。

## 性能特点

轮廓算法的成本主要受顶点和三角形数量影响，因为每个三角形都可能需要检查相邻面，并且可能生成额外三角形。复杂模型即使屏幕覆盖不大，也可能因为几何阶段工作量很高而变慢。

铅笔渲染相对便宜，主要是把曲率数据传给 Pixel Shader 并采样纹理；但其效果依赖曲率估计和屏幕空间纹理稳定性。

## 代价与限制

- 需要正确的三角形邻接信息；
- 动态拓扑或蒙皮模型的邻接处理更复杂；
- 轮廓扩张可能出现裂缝、重叠和端点不连续；
- GS 输出几何过多时可能成为瓶颈；
- 极端宽描边下，轮廓带容易发生自相交；
- 视角变化时，轮廓集合会发生离散变化，可能产生闪烁；
- 铅笔纹理需要处理屏幕空间缩放和时间稳定性。

## 本章结论

本章确实是用 Geometry Shader 做描边，但完整思路是：

> 用邻接三角形识别 silhouette edge，用 GS 生成有宽度的轮廓几何，再用 Pixel Shader 进行轮廓纹理和铅笔风格着色。

因此它不仅是“画一圈黑边”，而是把几何轮廓提取、描边几何生成、纹理化和手绘风格统一到实时 GPU 管线中。
