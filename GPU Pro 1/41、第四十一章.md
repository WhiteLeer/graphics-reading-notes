# Real-Time Interaction between Particles and the Dynamic Mesh on the GPU（粒子与动态网格的实时 GPU 交互）

作者：Vlad Alexandrov  
来源：GPU Pro 1，Part X，Chapter 5，pp. 693–706。

## 核心问题

本章讨论粒子系统如何与动态三角形网格实时交互，并尽量避免把大量粒子和三角形数据回读 CPU。

## 主要流程

1. 对三角形按空间或屏幕区域排序；
2. 构建 Buffer Map，记录粒子或网格元素对应的缓冲区位置；
3. 使用 GPU 地址和索引访问候选三角形；
4. 计算粒子与动态网格的接触或碰撞；
5. 更新粒子状态和动态网格缓存。

排序和 Buffer Map 的作用是把大量不规则的几何查询转换为可并行访问的规则缓冲区。重点不在单个碰撞公式，而在于如何组织数据、减少随机访问和避免 CPU/GPU 往返。

## 限制

动态网格更新、三角形排序、缓冲区重建和碰撞精度之间需要平衡。候选集合过大时，GPU 仍会受到带宽和局部存储压力。

## 总结

这是 GPU 驱动粒子-几何交互的早期案例，核心思想与现代 GPU 粒子、GPU 碰撞和空间加速结构相通。
