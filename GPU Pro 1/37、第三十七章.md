# Parallelized Implementation of Universal Visual Computer（通用视觉计算器的并行实现）

作者：Tze-Yui Ho、Ping-Man Lam、Chi-Sing Leung  
来源：GPU Pro 1，Part X，Chapter 1，pp. 613–622。

## 核心内容

本章将 GPU 当作通用并行计算设备，实现 Universal Visual Computer，主要使用卷积神经网络等高度数据并行的视觉计算任务作为案例。

## 方法

将输入图像、卷积核和中间特征图组织成 GPU 可访问纹理/缓冲区，并把每个像素、神经元或卷积位置映射为并行线程。重点处理局部邻域访问、内存布局、Pass 间数据传递和 CPU/GPU 同步。

## 启示

GPU 适合规则、独立、数据量大的运算；不规则控制流、频繁同步和小规模任务可能抵消收益。这是早期 GPGPU 与现代 Compute Shader/ML 推理的连接点。
