# Porting Code between Direct3D9 and OpenGL 2.0（Direct3D9 与 OpenGL 2.0 之间的移植）

作者：Wojciech Sterna  
来源：GPU Pro 1，Part VIII，Chapter 3，pp. 529–540。

## 核心问题

Direct3D9 与 OpenGL 2.0 都支持可编程渲染，但在坐标系、资源、Shader、状态机、纹理、帧缓冲和错误处理上存在差异。直接逐 API 翻译很容易产生坐标翻转、深度范围和资源生命周期问题。

## 主要内容

- 抽象窗口、上下文和设备初始化；
- 统一顶点/索引缓冲、纹理、Render Target 和 Shader 接口；
- 处理矩阵、纹理坐标、深度范围和正反面约定；
- 区分 D3D 的显式资源绑定与 OpenGL 的全局状态；
- 统一 Debug、错误检查和资源释放；
- 用一个小型示例验证跨 API 的渲染结果。

## 总结

跨 API 移植的关键不是复制函数名，而是先定义引擎层语义，再为各 API 实现后端；尤其要明确资源所有权、状态缓存和坐标约定。
