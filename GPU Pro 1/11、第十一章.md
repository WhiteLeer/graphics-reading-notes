# Fast, Stencil-Based Multiresolution Splatting for Indirect Illumination（基于模板缓冲的多分辨率间接光照 Splatting）

## 章节内容

本章针对 Reflective Shadow Maps（RSM）产生的大量虚拟点光源（VPL），提出一种多分辨率 Splatting 方法。它让每个 VPL 仍然可以影响整个屏幕，但根据局部光照变化选择不同的采样分辨率，从而减少 Fill Rate 和像素计算。

作者：Chris Wyman、Greg Nichols、Jeremy Shopf。

## 从 Instant Radiosity 到 RSM

Instant Radiosity 的基本思路是：

1. 从光源发射光子；
2. 光子与表面相交；
3. 将相交位置视为虚拟点光源 VPL；
4. 从摄像机视角计算这些 VPL 对场景的光照。

RSM 对它做了简化：

- 只考虑一次间接反弹；
- 从光源的 Shadow Map 中直接获得位置、法线和反射光颜色；
- 通常忽略 VPL 到接收点之间的可见性。

这样可以在 GPU 上实现，但 VPL 数量仍然可能很多。

## 普通 RSM 的性能问题

如果每个 VPL 都通过全屏 Splat 影响所有像素：

```text
VPL 1 → 全屏
VPL 2 → 全屏
VPL 3 → 全屏
...
```

在 1024×1024 屏幕上，即使只使用几百个 VPL，也会产生巨大的片元数量。

直接降低整个光照 Buffer 的分辨率虽然能减少 Fill Rate，但会导致：

- 物体轮廓被模糊；
- 法线突变区域被混合；
- 阴影和间接光跨越不连续边界；
- 低分辨率结果无法恢复高频细节。

只在 VPL 附近绘制小 Splat 又会漏掉本应影响该像素的其他 VPL，使结果偏暗。

## 多分辨率 Splatting

本章的方案让每个 VPL 仍然贡献到全屏，但每个屏幕区域使用不同分辨率：

- 光照缓慢变化的区域使用粗采样；
- 深度边缘和法线剧烈变化区域使用细采样；
- 不能接受模糊的区域继续细分。

```text
全屏 VPL Splat
      ↓
判断局部是否存在不可接受的模糊
      ↓
平滑区域：保留粗片元
边缘区域：细分为 4 个子片元
      ↓
多分辨率光照 Buffer
      ↓
逐级上采样并合并
```

这不是简单地把整张光照图缩小，而是对每个区域分别决定分辨率。

## 为什么检测深度和法线不连续

低分辨率采样最大的风险是跨越不应混合的边界。

### 深度不连续

通常对应物体轮廓、前景与背景的边界。如果跨越这种区域进行低分辨率插值，前景和背景的间接光会互相污染。

### 法线不连续

通常对应硬边、折角和表面方向快速变化。即使深度连续，法线突变也可能导致光照高频变化，因此需要更高的采样分辨率。

对于漫反射间接光，深度和法线检测通常已经足够；如果处理高光或 SSAO，还可能需要额外检测光照变化或空间邻近关系。

## 初始迭代式实现

最直接的方法是先生成粗粒度 Patch，然后用 Geometry Shader 递归细化：

```text
粗 Patch
  ↓
检测 discontinuity
  ↓
通过：保留
不通过：拆成 4 个子 Patch
  ↓
重复若干轮
```

但是这个实现存在问题：

- Geometry Shader 输出数量动态变化；
- GPU 可能无法走高效的固定吞吐路径；
- 每轮细化都可能需要新的 Pass；
- CPU 需要参与循环控制，产生同步点；
- 顶点和片元阶段都会处理这些中间 Patch。

## Stencil-Based 并行细化

作者观察到，大多数 discontinuity 检测不依赖同一轮其他 Patch 的结果，因此可以并行判断所有层级，而不必真的一轮一轮生成几何。

实现方法是把不同分辨率的采样区域放在一个扁平化的多分辨率 Buffer 中，用一个全屏 Pass 并行检查：

1. 当前片元是否属于某个有效多分辨率层级；
2. 当前层级是否仍然存在 discontinuity；
3. 父级区域是否需要继续细分；
4. 当前片元是否应该被保留。

如果片元满足最终保留条件，就设置 Stencil。后续 Splat Pass 只处理 Stencil 标记的片元。

Stencil 在这里相当于一个 GPU 内部的有效区域列表，避免了显式生成和管理大量动态 Patch。

## 上采样与合并

多分辨率 Buffer 中有不同大小的有效区域和空白区域，因此需要逐级上采样：

```text
最粗分辨率
  ↓ 双线性上采样
与下一层有效数据合并
  ↓
继续上采样
  ↓
最终完整屏幕分辨率
```

插值时只使用有效的邻近 texel，不能把空区域当作黑色参与平均，否则会产生不必要的暗边。

## 和普通降分辨率的区别

普通降分辨率是全局统一的：

```text
整张光照图 → 256×256
```

本章方案是空间自适应的：

```text
平滑区域 → 粗分辨率
边缘区域 → 细分辨率
```

因此它可以在保留边缘质量的同时，获得接近低分辨率渲染的成本。

## 和 VRS / Tile-Based 光照的关系

- VRS 改变的是光栅化或片元着色频率；
- Tile-based Lighting 通常决定某个屏幕 Tile 受哪些光源影响；
- 本章决定每个 VPL 的间接光照在屏幕上用什么分辨率计算；
- Stencil 负责标记哪些多分辨率片元有效。

它们都在做空间自适应计算，但优化对象不同，理论上也可以组合使用。

## 适用范围

它适合：

- RSM 一次反弹间接光；
- 大量 VPL 的屏幕空间累积；
- 光照大部分区域平滑、但边缘需要高质量的场景；
- 可以接受近似和一定模糊的漫反射 GI。

它不适合直接解决：

- 多次反弹的完整 GI；
- 需要严格 VPL 可见性的场景；
- 高频镜面反射；
- 需要精确阴影边界的光照。

## 代价与限制

- RSM 本身会产生 VPL 选择和光照近似误差；
- 忽略 VPL 可见性会产生漏光；
- discontinuity 检测过弱会造成边缘模糊；
- 检测过强会过度细分，失去性能收益；
- 多分辨率 Buffer、Stencil 和上采样会增加显存带宽；
- VPL 数量、屏幕分辨率和间接光复杂度仍然影响总体成本；
- 主要针对漫反射间接光，高光和复杂材质需要更细的检测。

## 本章结论

本章的核心是：

> 不降低整个间接光照 Buffer 的分辨率，而是根据深度和法线不连续性，在屏幕上自适应选择光照采样分辨率；再用 Stencil 并行标记有效区域，避免 Geometry Shader 迭代细化的同步和动态输出成本。

它本质上是对 RSM/VPL 间接光的空间自适应采样优化，而不是新的 GI 理论，也不是完整的无偏光照求解。
