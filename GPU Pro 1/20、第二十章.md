# Screen-Space Subsurface Scattering（屏幕空间次表面散射）

## 章节内容

作者：Jorge Jimenez、Diego Gutierrez

本章介绍一种直接在屏幕空间执行的次表面散射算法。它以已经渲染完成的颜色缓冲、深度和模板缓冲为输入，用多个 Gaussian 近似材质的 diffusion profile，再对屏幕图像做受深度和轮廓约束的水平、垂直模糊。

目标是用后处理的形式，为皮肤、大理石、蜡、纸张、树叶等半透明材质提供实时的柔和透光效果，同时避免传统 Texture-Space SSS 为每个对象建立 Irradiance Map 的成本。

## 次表面散射是什么

普通表面反射可以近似为：

```text
光到达表面点 P
→ 在 P 处反射或散射
```

次表面散射则允许光进入物体内部，在内部传播后从附近的另一个点重新出射：

```text
光在 P 进入
→ 在材质内部传播
→ 在 Q 出射
```

因此它会让表面出现：

- 边缘透光；
- 柔和的颜色扩散；
- 皮肤的红润感；
- 蜡、玉石和大理石的内部光感。

## Diffusion Profile

均匀材质的次表面散射可以用一维径向函数描述：

`R(r)`

其中 `r` 是入射点与出射点之间的表面距离，`R(r)` 表示光照强度随距离的衰减。

大部分光能通常集中在入射点附近，随着距离增加迅速衰减。不同材质使用不同 profile：

- 皮肤：较近距离内的红色和浅色扩散；
- 大理石：传播距离更长；
- 蜡：柔和且范围较大的散射；
- 纸张或叶片：可能具有更明显的透射和薄片效应。

真实二维卷积成本较高，因此实际实现通常把 diffusion profile 拟合成多个 Gaussian 的加权和：

`R(r) ≈ Σ wi Gi(r,σi)`

二维 Gaussian 可以拆成水平和垂直两个一维 Gaussian，从而大幅降低采样成本。

## Texture-Space SSS 的传统流程

传统实时 SSS 通常在纹理空间执行：

1. 将对象渲染到 Irradiance Texture；
2. 在纹理空间对光照做多个 Gaussian 模糊；
3. 将模糊后的结果重新映射回模型表面；
4. 在最终渲染中合成散射结果。

这种方法质量较高，但有明显成本：

- 每个对象通常需要自己的 irradiance map；
- 需要额外渲染对象和转换顶点；
- UV 接缝会影响空间扩散；
- 纹理空间相邻的 texel 不一定对应世界空间相邻点；
- 很难充分利用最终屏幕的 Early-Z 和可见性剔除；
- 多个对象、树叶或大量实例会带来大量额外 pass。

## Screen-Space SSS 的基本流程

本章把 diffusion convolution 从纹理空间移到最终图像空间：

```text
主渲染
  ↓
颜色缓冲 + 深度/模板缓冲
  ↓
受深度控制的水平 Gaussian
  ↓
受深度控制的垂直 Gaussian
  ↓
与原图合成
```

所有屏幕中属于相同 SSS 材质的像素可以一起处理，不需要每个对象单独生成 irradiance map。

## 为什么不能直接普通模糊

如果直接对整张颜色图做 Gaussian Blur，会出现明显错误：

- 物体背景颜色扩散到前景皮肤；
- 不同物体之间发生错误颜色传播；
- 轮廓外出现光晕；
- 深度差异很大的像素被错误混合。

因此屏幕空间 SSS 必须结合深度和模板信息，对模糊区域进行限制。

## 深度与模板缓冲

本章使用：

- 线性深度缓冲：用于计算模糊宽度；
- 原始深度/模板缓冲：用于限制哪些像素需要 SSS；
- 颜色缓冲：作为被卷积的光照结果。

模板测试可以快速排除不属于 SSS 材质的像素。相比在每个像素着色器中进行动态分支，硬件模板测试在大面积屏幕被排除时通常更高效。

## 深度相关的模糊宽度

屏幕空间中固定的像素半径并不对应固定的世界空间距离：

- 近处物体的一个像素代表很小的世界距离；
- 远处物体的一个像素代表更大的世界距离；
- 斜向观察的表面在屏幕上还会发生投影压缩。

因此本章根据深度和深度导数调整水平、垂直方向的拉伸系数：

`sx = sssLevel / (d + correction · min(|ddx(d)|, maxdd))`

`sy = sssLevel / (d + correction · min(|ddy(d)|, maxdd))`

再将每个 Gaussian 的原始宽度乘以 `sx`、`sy`，得到最终屏幕采样宽度。

这样可以让：

- 近处、正对相机的表面使用较宽的屏幕模糊；
- 远处物体使用较窄的模糊；
- 深度变化剧烈的轮廓附近自动收窄模糊，减少背景泄漏。

## 轮廓保护

物体轮廓处的深度导数通常很大。通过深度导数影响模糊宽度，轮廓附近的 kernel 会自动变窄，减少：

- 背景颜色向皮肤内部泄漏；
- 物体外部出现亮边；
- 鼻子、脸颊和背景之间出现过强的混合。

这不是严格的几何光线传播，而是利用深度不连续作为边界提示。

## 多 Gaussian 合成

皮肤和大理石的 diffusion profile 通常用多个 Gaussian 拟合。每个 Gaussian 会执行：

1. 水平模糊；
2. 垂直模糊；
3. 按材质 profile 权重累加到最终目标。

为了减少 Render Target 数量，本章使用 MRT 和 Alpha Blending 在计算 Gaussian 的同时逐步累积最终结果，而不是为每个 Gaussian 都保存独立的完整纹理。

对于不同颜色通道，Gaussian 权重也可能不同，因为红、绿、蓝光在材质内部的传播距离不同。

## 深度 LOD 优化

当物体距离相机很远时，窄 Gaussian 的屏幕宽度可能小于半个像素。此时大部分采样都会落回当前像素，继续执行模糊几乎没有效果。

因此可以根据：

```text
Gaussian 宽度 × SSS Level / 深度
```

判断该 Gaussian 是否已经小到可以跳过。

这带来一个重要特点：物体越远，SSS 成本越低；当对象已经很小到屏幕上几乎不可见时，可以自动关闭细窄的散射层。

## 直接光照与高光处理

理论上 SSS 主要应该作用于漫反射部分，因为镜面高光通常不在材质内部传播。但本章发现，把 SSS 同时应用到漫反射和镜面部分也能产生有吸引力的结果：

- 高光被轻微软化；
- 镜面边缘锯齿减少；
- 产生类似柔和 bloom 的效果。

实际项目中可以根据材质需求，将漫反射和镜面分开存储，再决定哪些部分进入 SSS。

## 材质局部控制

角色的头发、胡须、眼睛或金属饰品通常不应该使用和皮肤相同的散射强度。

一种方法是在漫反射纹理 Alpha 通道中保存局部 SSS 强度：

```text
Alpha = 0：不进行 SSS
Alpha = 1：使用完整 SSS
```

后处理阶段用该值乘到水平、垂直 stretch factor 上，就可以局部关闭或减弱散射。

## 与 Texture-Space SSS 的比较

### Screen-Space SSS 优势

- 不需要特殊 UV 展开；
- 没有 UV seam 造成的扩散断裂；
- 所有屏幕中的同类材质可以一起处理；
- 更容易利用 Early-Z 和模板测试；
- 对多个对象和大量实例扩展更好；
- 接入现有后处理管线较简单。

### Screen-Space SSS 劣势

- 只能看到屏幕中当前可见的表面；
- 看不到物体背面的散射贡献；
- 薄耳朵、鼻子等高曲率区域可能缺失背面光照；
- 深度不连续处仍可能出现 halo；
- 不是真实的三维内部传播。

## 典型伪影

### 鼻子到脸颊的错误扩散

如果鼻子和脸颊在屏幕上相邻，但实际深度关系不适合传播，屏幕模糊可能产生小光晕。

### 薄结构缺少背面信息

真实 SSS 可以让光从耳朵背面穿到正面，但屏幕空间方法只看到当前可见的一侧，因此无法完整重建这种传播。

### 过宽 Gaussian 的边缘泄漏

对于大理石等宽散射 profile，深度边缘处更容易产生颜色污染，需要深度导数限制、模板遮罩或更复杂的深度感知采样。

## 适用场景

- 实时角色皮肤；
- 大理石、蜡和纸张的柔和材质；
- 大量树叶或半透明物体；
- 需要简单接入后处理管线的游戏；
- 对远处物体自动降低 SSS 成本的场景。

## 代价与限制

1. 需要颜色、深度、线性深度和模板信息。
2. 多个 Gaussian 仍然需要多次水平/垂直模糊。
3. 屏幕外和背面几何无法贡献散射。
4. 深度不连续处可能出现光晕或错误颜色传播。
5. 真实的内部厚度、折射和光路没有被完整模拟。
6. SSS 强度、深度修正和 Gaussian profile 需要按材质调参。

## 本章结论

屏幕空间 SSS 的关键是把材质的 diffusion profile 近似成多个 Gaussian，然后直接对最终颜色缓冲做深度感知的水平和垂直模糊。

它不是简单的全屏 Gaussian Blur，而是结合了：

```text
材质 diffusion profile
→ 多 Gaussian 近似
→ 深度和模板遮罩
→ 深度相关的 kernel 宽度
→ 水平/垂直分离卷积
→ MRT 与 Alpha 累积
```

它牺牲了背面和屏幕外的真实传播，换来了比 Texture-Space SSS 更简单、更适合多对象实时渲染的实现。
