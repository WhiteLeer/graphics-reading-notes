# Screen Space Soft Shadows（屏幕空间软阴影）

作者：Jesus Gumbau、Miguel Chover、Mateu Sbert  
来源：GPU Pro 1，Part VII，Chapter 4，pp. 477–490。

## 1. 本章解决的问题

标准 Shadow Map 能生成硬阴影，PCF 可以把边缘平滑化，但都不能直接表达面积光源产生的真实半影：阴影会随着遮挡物和接收面之间的距离变大，也会随着光源面积增大而变软。

本章提出一种屏幕空间近似方法：先得到硬阴影，再根据每个像素的遮挡距离估计半影大小，用可变大小的各向异性 Gaussian Filter 在屏幕空间模糊阴影。

## 2. 基本流程

```text
标准 Shadow Map
    + 膨胀 Shadow Map
        → 硬阴影、深度、法线、距离图
            → 每像素估计半影大小
                → 各向异性 Gaussian Filter
                    → 屏幕空间软阴影
```

它不是重新计算完整面积光照，而是用 Shadow Map 和屏幕空间信息近似光源可见范围。

## 3. 半影宽度估计

本章使用平行平面近似估计半影宽度：

```text
w_penumbra = (d_receiver - d_blocker) / d_blocker * w_light
```

其中：

- `d_receiver`：接收点到光源的距离；
- `d_blocker`：遮挡物到光源的距离；
- `w_light`：面积光源大小；
- `w_penumbra`：估计得到的半影宽度。

它表达了三个规律：光源越大，半影越宽；接收面离遮挡物越远，半影越宽；遮挡物越靠近光源，半影相对越窄。

## 4. 为什么需要膨胀 Shadow Map

普通 Shadow Map 只记录硬阴影区域。如果直接在硬阴影区域内做模糊，通常只能得到内部半影，阴影无法自然向外扩展。

因此本章先生成一个膨胀版本的 Shadow Map，用来覆盖潜在的外部半影区域。膨胀图并不是最终阴影，而是为了告诉后续屏幕空间算法：哪些区域可能受到半影影响。

## 5. Distance Map

Distance Map 是一张屏幕对齐纹理，每个像素保存与软阴影计算相关的信息，例如：

- 像素到潜在遮挡物的距离；
- 像素到观察者的距离；
- 是否可能落在阴影或半影区域的遮罩。

它通过全屏四边形生成：将屏幕像素转换到光源空间，再和粗粒度遮挡物深度比较，得到接收点与遮挡物之间的距离。

其中遮罩可以排除绝不可能受阴影影响的像素，减少后续滤波采样。

## 6. 各向异性 Gaussian Filter

滤波核的大小不是全屏统一的，而是逐像素变化，主要取决于：

- 遮挡物与接收点之间的距离；
- 光源与遮挡物之间的距离；
- 光源大小；
- 当前像素到观察者的距离；
- 表面法线方向。

使用各向异性 Gaussian Filter，是因为阴影半影在屏幕空间中不一定是圆形，可能沿表面或投影方向拉长。法线可以帮助确定滤波方向和纵横比。

## 7. Gaussian Filter 的可分离性

二维 Gaussian 可以写成两个一维函数的乘积：

```text
G(x, y) = Gx(x) * Gy(y)
```

所以可以拆成水平和垂直两个 Pass，而不是对二维邻域逐点采样。

这使大范围软化更可行。例如直接执行 11×11 核需要大量采样，而可分离实现可以拆成两次一维采样。但本章的核半径和方向是逐像素变化的，因此仍需要控制最大半径、采样步长和屏幕空间边界。

## 8. 与 PCF、PCSS 的区别

### 与 PCF

PCF 通常使用固定或有限变化的邻域对 Shadow Map 进行多次比较并平均，重点是平滑硬阴影边缘。

本章方法则先估计遮挡距离和半影大小，再对硬阴影进行屏幕空间可变滤波，更强调半影宽度的变化。

### 与 PCSS

PCSS 通常先搜索 blocker，再根据 blocker 深度计算滤波半径，最后执行可变 PCF。

本章把距离信息先做成屏幕空间 Distance Map，再使用 Gaussian Filter。二者都属于面积光源的近似，但数据准备和最终滤波方式不同。

## 9. 质量与性能

书中比较了不同滤波核：

- 5×5：成本低，但半影容易出现离散伪影；
- 11×11：大多数场景可以接受；
- 23×23：近距离观察半影时质量更高，但成本更大。

方法的性能优势来自：

- Gaussian 的可分离性；
- 只有潜在阴影区域参与计算；
- 每个像素根据距离选择滤波范围；
- 不需要为面积光源生成大量独立点光源 Shadow Map。

## 10. 局限

- 仍然受 Shadow Map 分辨率和深度偏移影响；
- 屏幕空间方法缺少屏幕外遮挡信息；
- 遮挡物和接收面关系复杂时，平行平面近似会失真；
- 半影区域很大时，Distance Map 与滤波本身仍然昂贵；
- 阴影边界、遮挡物重叠和屏幕边缘可能出现漏光或不连续；
- 不是严格的光源可见性积分，也不等价于光线追踪。

## 11. 总结

本章的核心是：

```text
硬阴影
  → 根据遮挡关系估计半影大小
  → 生成逐像素可变的屏幕空间滤波
  → 用可分离各向异性 Gaussian 近似软阴影
```

它比固定半径 PCF 更能表现半影随距离和光源大小变化的特征，同时比多光源采样或完整光线追踪便宜。代价是依赖屏幕空间信息，并且需要额外的膨胀 Shadow Map、Distance Map 和滤波 Pass。
