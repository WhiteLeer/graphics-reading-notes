# Practical Thread Rendering for DirectX 9（DirectX 9 的实用线程渲染）

作者：David Pangerl  
来源：GPU Pro 1，Part VIII，Chapter 4，pp. 541–546。

## 核心问题

在 DirectX 9 时代，渲染命令提交和场景更新可能让单线程 CPU 成为瓶颈。本章讨论如何将渲染准备工作放到工作线程，同时保持图形 API 调用与资源生命周期安全。

## 方法

将场景遍历、可见性判断、排序和命令准备与真正的 API 提交拆开，使用线程间队列或双缓冲交换 Render Packet。主渲染线程负责上下文相关调用，工作线程生成下一帧所需的不可变数据。

## 注意事项

线程化不会自动提升性能：同步、锁竞争、资源创建和 GPU 阻塞都可能抵消收益。必须区分 CPU 准备阶段、API 提交阶段和 GPU 执行阶段，并避免线程直接访问不安全的图形对象。

## 总结

本章的核心是把“场景准备”和“图形 API 提交”分离，用可预测的数据交换隐藏 CPU 工作，但不能把线程安全问题简单交给驱动。
