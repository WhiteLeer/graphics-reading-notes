# 动态环境光遮蔽与间接光照

## 章节内容

本章提出一种完全在 GPU 上近似计算动态 Ambient Occlusion（AO）和漫反射间接光照的方法。它把网格转换成许多带位置、法线和面积的表面元素，用这些元素之间的近似遮挡和光能传递代替昂贵的逐元素可见性测试，从而支持每帧更新的变形和动画物体。

### 1. 方法目标与核心思想

传统预计算 AO 或 Precomputed Radiance Transfer 通常要求物体保持刚性，物体之间不能发生相对运动。本章的方法直接使用当前帧的表面元素数据，因此可以处理动画和变形网格。

它不严格计算“一个表面元素是否能看见另一个表面元素”，而是用两个表面元素之间的距离、方向、面积和法线，估计遮挡或光能传递量。

```text
网格
  ↓
表面元素
  ↓
近似元素之间的遮挡/光能传递
  ↓
GPU 多 Pass 累积
  ↓
AO、Bent Normal 或间接光照
```

### 2. 表面元素

本章把每个网格顶点近似为一个带方向的圆盘。一个表面元素包含：

- 位置；
- 法线；
- 面积；
- 朝向正面和背面。

正面用于发射和反射光，背面用于透射和投射阴影。顶点位置和法线通常已经存在，只需要计算每个顶点对应的面积。

三角网格中，一个顶点的面积可以取与它相邻的每个三角形面积的三分之一并累加；四边形则可以按每个相邻四边形面积的四分之一累加。

由于后续使用 Fragment Program 计算元素之间的关系，元素的位置、法线和面积会存入纹理。每个纹理像素对应一个表面元素，像素着色器把它当成通用计算单元使用。

如果物体在动画中发生变形，元素数据也需要更新。可以从一开始就把顶点数据放在纹理中，用 Fragment Program 做动画和空间变换，再通过 render-to-vertex-array 生成普通渲染管线需要的顶点；也可以由 CPU 更新顶点并每帧上传元素纹理，但效率更低。

### 3. Ambient Occlusion 与可见性

AO 用一个 accessibility 值表示表面点上方半球有多少比例没有被几何体遮挡：

```text
accessibility = 未被遮挡的环境方向比例
AO             = 1 - accessibility
```

遮挡越严重，accessibility 越低，表面越暗。AO 特别适合补充环境光下的接触阴影和缝隙阴影，因为单纯的环境漫反射容易让物体显得扁平。

除了 accessibility，本章还计算 bent normal。Bent normal 指向相对不容易被遮挡的环境方向，可以代替普通法线去采样环境光，使环境光方向更符合当前局部遮挡情况。

### 4. 两个表面元素之间的遮挡近似

计算时把一个元素视为 receiver，把另一个元素视为 emitter。根据 emitter 的面积、两者距离、emitter 法线与连线的夹角、receiver 法线与连线的夹角，近似 emitter 在 receiver 处覆盖的立体角。

影响遮挡结果的因素包括：

- emitter 面积越大，遮挡影响越强；
- 两者距离越近，影响越强；
- emitter 朝向 receiver 时影响更强；
- receiver 朝向 emitter 时影响更强；
- 位于 receiver 背面或下半球的 emitter 应被忽略。

示意性的计算可以写成：

```hlsl
shadow = SolidAngleApproximation(
    emitterArea,
    distanceSquared,
    receiverNormal,
    emitterNormal,
    direction
);
```

该方法没有计算中间几何体造成的真正可见性，因此不是严格的光线追踪；它用快速的几何近似换取 GPU 上的大量并行计算。

### 5. 多 Pass AO 计算

第一遍中，对每个 receiver 累加所有 emitter 带来的遮挡量，然后从 1 中减去得到初步 accessibility。

直接这样做会产生一个问题：已经处于阴影中的 emitter 仍然会继续对其他元素投射同样强的阴影，导致重复计算阴影，结果过暗。

第二遍会使用第一遍得到的 emitter accessibility 调制遮挡贡献：

```text
已经处于阴影中的 emitter
    ↓
投射更少的二次阴影
```

第二遍还可以同时计算 bent normal。对每个 emitter，先用元素间方向向量乘以对应 form factor，再从 receiver 的原始法线中减去这些被遮挡方向，最后归一化得到 bent normal。

GPU 实现中可以绘制一个覆盖所有元素的四边形，每个片元对应一个表面元素。第一遍结果写入纹理的 Alpha，第二遍读取上一遍结果，并把 bent normal 写入 RGB、更新后的遮挡值写入 Alpha。

### 6. 层次化元素与性能优化

如果每个元素都遍历所有其他元素，复杂度接近 `O(n²)`，只能处理很少的元素。为此，本章把相邻的元素分组为更大的父元素，形成层次结构：

```text
叶子元素
    ↓
较大的局部元素
    ↓
更大的区域元素
    ↓
整个物体的粗略元素
```

父元素的位置和法线由子元素平均得到，面积为子元素面积之和。距离较远时，直接使用一个较大的父元素近似其全部子元素；只有 receiver 距离较近时，才继续遍历父元素的子节点。

这种层次遍历类似于对元素进行空间和尺度上的粗粒度近似，可以将实际表现从 `O(n²)` 改善到接近 `O(n log n)`。由于远处环境遮挡本来就比较柔和，使用粗元素通常不会产生明显的视觉损失。

元素面积在很多动画物体中变化不大，因此可以预先计算并复用，减少每帧更新量。

### 7. 间接光照与面光源

在 AO 之后，本章进一步计算漫反射表面之间的一次间接光照。一个元素既可以：

- 接收环境光；
- 接收点光源或方向光；
- 反射来自其他元素的漫反射光；
- 作为面光源发光。

首先计算每个元素能够反射或发出的光，再使用元素之间的 disk-to-disk form factor 估计光能传递：

```text
发光/反射元素
    ↓
方向、面积、距离计算
    ↓
接收元素得到间接光
    ↓
再用遮挡 Pass 修正被挡住的部分
```

元素反射的光还要乘以自身表面颜色，因此红色表面反射出的间接光会偏红，黄色表面反射出的光会偏黄。环境光和直接光都可以作为间接光照的初始来源。

面光源可以按照特殊的发光表面元素处理：它们不是由其他光照得到能量，而是直接带有需要发出的光值。

### 8. 方法特点与限制

优点包括：

- 可以处理动画和变形物体；
- 每帧在 GPU 上更新 AO 和间接光照；
- 不需要逐元素计算严格可见性；
- 可以通过层次元素处理较多顶点；
- 能得到接触阴影、Bent Normal 和一次漫反射间接光照。

限制包括：

- 这是近似算法，不是严格光线追踪；
- 省略真实可见性会产生漏光或错误遮挡；
- 多次间接反射需要额外 Pass，成本会增加；
- 主要适合漫反射、低频、柔和的环境光照；
- 不适合高频镜面反射、精确阴影和复杂透明/折射；
- 元素数量过多时仍然需要层次结构和多 Pass 优化。

## 讨论与补充

### 1. 与 SSAO、接触阴影的区别

本章的方法和现代常见的 SSAO、接触阴影都可以用于补充局部遮蔽，但数据空间和采样方向不同：

```text
本章方法：表面元素之间的几何空间近似
SSAO：围绕当前像素在屏幕空间深度上采样
接触阴影：沿具体光源方向进行短距离遮挡检测
```

SSAO 通常需要深度和法线。对当前像素重建观察空间位置后，在法线半球内生成采样点，将采样点重新投影到屏幕并查询深度。如果深度图中的几何体位于采样点前方，则认为该方向被遮挡，最后将遮挡比例转换为 AO：

```hlsl
float3 P = ReconstructViewPosition(uv, depth);
float3 N = SampleNormal(uv);
float3 samplePos = P + TBN * kernel[i] * radius;
float2 sampleUV = ProjectToScreen(samplePos);
float sceneDepth = SampleDepth(sampleUV);

occlusion += IsOccluded(sceneDepth, samplePos);
AO = 1 - occlusion / sampleCount;
```

实际实现还会加入深度 Bias、距离衰减、随机旋转、蓝噪声、半分辨率计算、时域累积和边缘感知模糊。SSAO 主要调制环境光或间接漫反射，不应该无条件把所有直射光都乘黑。

接触阴影则从当前表面点朝光源方向做短距离步进：

```hlsl
float3 P = ReconstructWorldPosition(uv, depth);
float3 L = GetDirectionToLight(P);

for (int i = 1; i <= stepCount; i++)
{
    float3 rayPoint = P + L * (i * stepLength);
    float2 rayUV = ProjectToScreen(rayPoint);
    float sceneDepth = SampleDepth(rayUV);

    if (HitsOccluder(sceneDepth, rayPoint))
    {
        contactVisibility = 0;
        break;
    }
}
```

接触阴影通常是普通阴影贴图的补充：阴影贴图负责大范围阴影，接触阴影负责脚底、贴地、贴墙等短距离细节。两者可以相乘或取更严格的可见性结果，但需要控制强度，避免同一遮蔽被 AO、阴影贴图和接触阴影重复加深。

| 项目 | SSAO | 接触阴影 |
| --- | --- | --- |
| 采样方向 | 法线半球的多个方向 | 朝某个光源的方向 |
| 主要影响 | 环境光、间接光 | 特定光源的直射光 |
| 典型效果 | 缝隙、褶皱、局部环境变暗 | 脚底、贴墙、贴地的接触阴影 |
| 主要缺点 | 屏幕外遮挡不可见，容易漏光 | 步进有限、屏幕外遮挡不可见 |

因此本章算法更像动态几何 AO 和漫反射间接光照的早期探索；现代游戏通常使用 SSAO/GTAO、接触阴影、阴影贴图和光追 AO 的组合，而不是直接照搬本章的逐元素遍历方案。
