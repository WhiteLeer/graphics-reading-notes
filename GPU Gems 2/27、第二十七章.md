# 高质量图像过滤

## 章节内容

本章讨论如何在 GPU 上实现比硬件默认双线性、三线性和各向异性过滤更高质量的图像过滤。重点包括卷积过滤、子像素过滤、纹理抗锯齿、图像重建、去模糊以及运动图像的时间插值。这些方法能够改善放大、缩小、扭曲和纹理映射的质量，但通常需要大量纹理采样和 Shader 指令，因此更适合高质量优先的图像处理、视频、影视和离线预处理，而不是直接用于高帧率游戏的全屏实时渲染。

### 在 GPU 上实现图像过滤

最直接的实现方式是使用一个与输入图像尺寸一致的屏幕对齐四边形，将输入图像作为纹理，在像素着色器中计算每个输出像素。需要保持图像尺寸时，通常只需绘制同尺寸的全屏 Quad。

#### 访问离散纹素

图像过滤通常需要访问当前纹素周围的多个离散纹素，但普通 Shader 的纹理坐标是归一化的实数坐标，而不是直接的整数索引。需要在纹素坐标和归一化纹理坐标之间转换：

```hlsl
sampleCoord  = floor(textureCoord * texSize);
textureCoord = (sampleCoord + 0.5) / texSize;
```

加上 `0.5` 是为了访问纹素中心，减少边界和浮点舍入造成的误差。如果只访问紧邻的上下左右像素，也可以直接使用 `1 / textureSize` 作为纹理坐标步长。使用最近点采样时，硬件会自动选择对应的离散纹素，不一定需要手动把坐标对齐到纹素中心。

### 卷积过滤与子像素过滤

普通离散卷积可以把卷积系数放在常量或 Uniform 中。为了实现更灵活的子像素过滤，本章把连续卷积核存储为纹理：

```text
FilteredColor = Σ Kernel(s - s0, t - t0) × Texture(s, t)
```

其中 `(s0, t0)` 是当前纹理坐标，卷积核的中心可以落在纹素之间，而不必固定在某个纹素中心。这样可以得到更平滑、更准确的放大结果，例如子像素 Gaussian 过滤。

为了避免卷积改变图像整体亮度，希望卷积核的系数和为 1。但连续卷积核采样到离散网格后，实际采样系数和可能随位置变化，因此需要把累加后的颜色除以实际采样系数和。原章中的实现把颜色累加放在 RGB 通道，把系数和临时累加在 Alpha 通道，以减少额外指令；如果 Alpha 本身也需要被处理，则需要单独保存系数和。

这种高质量子像素过滤的代价是每个输出像素需要多次纹理访问，可能使片元阶段成为整个管线的瓶颈。

### 旋转不变卷积核与可分离卷积

如果卷积核具有旋转不变性，例如只依赖样本到中心的距离，就不必把完整的二维核存成 2D 纹理，只保存一条径向截面的 1D 纹理即可。运行时根据距离查表，这样可以节省纹理内存，但需要额外计算距离。

另一种常见优化是利用卷积核的可分离性。若一个二维卷积等价于先对每一行做一维卷积，再对每一列做一维卷积，就可以把一次二维大卷积拆为两个一维 PASS。Gaussian Blur 和 Box Filter 都具有这种性质。代价是需要两个 PASS 和一个中间结果，只有当卷积核较大时，节省的采样量通常才足以抵消额外 PASS 的成本。

### 大卷积核与多 PASS 累积

当卷积核很大时，单个 Shader 可能超过硬件的指令或采样限制。可以把卷积核划分成多个 Tile，每个 PASS 只计算一部分样本，再把各 PASS 的结果累加到浮点渲染目标或累加缓冲区中。

此时不能在每个 PASS 中立即除以卷积系数和，因为最终结果还没有累加完整。正确做法是先累加所有颜色和权重，最后再使用一个后处理 PASS 做统一归一化。中间目标最好使用浮点格式，否则多次累积会受到 8 位量化误差影响。

## 数字图像重采样

屏幕像素通常不能与原始图像像素一一对应，因此需要进行重采样。可以将屏幕坐标 `(i, j)` 映射到纹理坐标 `(u, v)`：

```text
P(i, j) = I(f(i, j))
```

其中 `f` 描述屏幕空间到图像空间的映射。图像缩小时属于欠采样，容易产生锯齿和纹理闪烁；图像放大时属于过采样，需要在离散样本之间重建连续信号。

硬件通常提供双线性、三线性、各向异性过滤以及 Mipmap 来缓解这些问题，但它们是速度和质量之间的折中，不一定是信号意义上的最优重建。

### 抗锯齿与采样区域

根据 Nyquist 采样定理，采样频率不足以覆盖信号中的高频成分时，就会产生频谱混叠。传统抗锯齿的基本思路是在采样之前滤掉超出采样带宽的高频信号，使剩余低频部分不被错误地折叠到低频区域。

理想的纹理抗锯齿应该计算当前屏幕像素对应的纹理采样区域的平均值，而不是只在一个纹理坐标上采样。为了近似这个区域，本章在每个像素处使用纹理坐标映射的局部一阶 Taylor 展开，并利用纹理坐标 Jacobian：

```text
f(i, j) ≈ f(i0, j0) + J0 · (i - i0, j - j0)
```

在局部线性假设下，屏幕像素的正方形采样区域会映射为纹理空间中的四边形。Shader 可以遍历该四边形包围盒内的候选纹素，再判断候选纹素是否落在映射后的四边形内，只累加真正属于采样区域的纹素。

实际实现可以利用 `ddx`、`ddy` 或 `fwidth` 得到纹理坐标变化，快速估计采样包围盒。`fwidth` 得到的包围盒通常略大于真实区域，因此会产生一些额外的无效采样。该方法主要对纹理本身抗锯齿，不能代替多重采样等几何边缘抗锯齿；四边形外轮廓的锯齿仍需要硬件 MSAA 等方法处理。

## 图像重建与放大

图像放大时，目标不是简单复制像素，而是根据已有离散样本重建一个连续信号，再在更高分辨率处重新采样。双线性过滤速度快，但容易使图像模糊。

### Shannon-Nyquist 重建

对于满足采样条件的信号，Shannon-Nyquist 理论可以用 sinc 核进行理想重建。sinc 本质上是理想低通滤波器，能够保留原始采样信号带宽内的频率，同时抑制带宽之外的成分。

但 sinc 的理论响应范围无限且衰减缓慢，无法直接用有限数量的纹理样本实现。工程上通常使用窗口函数，例如 Gaussian，对 sinc 进行截断，使其变成有限大小的卷积核。这样会失去理想低通滤波的严格性质，但能够控制采样数量。

Shannon-Nyquist 重建对自然图像通常效果较好，但在合成图像的锐利边缘附近可能出现振铃，即边缘周围产生明暗波纹。对这类图像，Gaussian 核通常更稳定，但会损失更多高频细节。

## Shock Filtering 去模糊

普通锐化通常通过放大高频分量增强边缘。本章介绍另一种 Shock Filter，它试图把纹理插值产生的平滑过渡重新变成更陡峭的边缘。

该方法根据局部梯度和二阶导数的符号判断区域的凸性，并沿相应方向扩散邻域能量：在不同的二阶导数区域，扩散方向相反，从而逐渐压缩模糊边缘。通常需要多次 PASS 才能产生明显效果。

Shock Filtering 对 2D 图像中较均匀的模糊比较有用，但不适合直接处理 3D 场景纹理，因为透视投影、深度和各向异性会使不同区域的模糊方向和程度不同，而该算法本身并不知道这些信息。

## Shader 中使用查找表的实现建议

复杂函数不一定要在 Shader 中逐像素计算，可以预先计算并保存为纹理查找表，用一次纹理读取和插值代替复杂数学运算。设计这类 LUT 时需要注意：

- 根据函数范围和所需精度选择纹理格式；
- 缩放函数范围，使有效数据落在纹理坐标范围内；
- 周期函数使用 Wrap，具有渐近线的函数使用 Clamp；
- 线性过滤可以利用插值提高有效精度；
- LUT 分辨率需要在精度、纹理内存和采样成本之间取平衡；
- 并非所有 GPU 都支持浮点纹理的线性过滤，无法过滤时可能需要提高 LUT 分辨率；
- 可以把多个函数分别存入纹理的不同颜色通道，同时完成查表。

## 高级应用

### 时间扭曲

如果把一段图像序列看作三维数据，第三维表示时间，就可以在相邻帧之间进行类似空间重建的时间插值，从而生成更流畅的慢动作。输入可以使用 3D 纹理，也可以使用多张 2D 纹理。

这种方案比简单地混合前后两帧质量更好，但比基于运动估计的完整视频插帧简单。对于快速运动的物体，需要更大的重建核才能得到更好的结果。

### 运动模糊去除

时间重建可能把原始序列中的曝光模糊也插值出来。如果需要减弱这种模糊，可以把 Shock Filter 改造成只沿时间方向扩散的形式，用于衰减时间维度上的模糊。

### 自适应纹理过滤

一个完整的高质量纹理过滤 Shader 可以把抗锯齿和图像重建结合起来，根据当前映射属于缩小还是放大来选择不同的过滤器：缩小时使用抗锯齿和低通处理，放大时使用重建和插值处理。

## 总结

本章的高质量过滤方法本质上是用更多样本、更大的卷积核以及更准确的采样区域估计，换取比硬件默认过滤更好的图像质量。它们可以处理纹理缩放、透视映射、抗锯齿、去模糊、慢动作和运动模糊等问题，但计算量通常很高。

因此，这些方法更适合医学和科学成像、照片和电影处理、图像合成、视频格式转换、专业渲染以及游戏中的离线纹理预处理。对于要求高帧率的实时游戏，通常仍需使用 Mipmap、双线性/三线性过滤、各向异性过滤、MSAA、TAA 等成本更低的近似方法。
