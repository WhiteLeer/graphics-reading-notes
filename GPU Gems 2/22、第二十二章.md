# 快速预过滤线段

## 章节内容

本章介绍一种面向线段的高效抗锯齿方法。它先把线段与滤波器在不同距离下的卷积结果预计算到一张小型 1D 查找纹理中，运行时只需计算片元到线段边缘的距离并查询 LUT，即可用固定成本得到平滑的线段边缘和端点。该方法支持任意对称滤波器，并且不依赖不同 GPU 厂商具体的硬件线段抗锯齿实现。

### 1. 线段为什么容易产生锯齿

数学上的线段没有厚度，但屏幕上的线必须具有宽度，例如 1 像素或 3 像素。锐利线段可以看作一个阶跃信号：线段内部为高强度，外部为低强度。阶跃边缘包含非常高的频率，而有限分辨率的屏幕无法准确表示这种突变，因此会出现：

- 斜线呈阶梯状；
- 线段运动时闪烁；
- 细线时有时无；
- 近水平和近垂直线段出现明显不稳定。

提高屏幕分辨率只能减轻问题，不能彻底消除理想锐利线段的采样误差。

### 2. 通过低通滤波进行抗锯齿

更实际的方案不是无限提高分辨率，而是去除最终分辨率无法表示的高频信息。具体来说，就是用低通滤波器与线段信号做卷积：

```text
锐利线段
    ↓ 低通滤波
边缘平滑的线段
```

抗锯齿后的边缘不再是完全锐利的阶跃，而是具有一定宽度的平滑过渡。滤波核越宽，边缘越平滑，但线段也越容易显得模糊。

### 3. 预过滤的核心思路

如果滤波核是对称的，那么线段与滤波核的卷积结果主要取决于滤波核中心到线段的距离，而不依赖于线段的具体方向。

因此可以在预处理阶段完成昂贵的卷积：

```text
将滤波核放在线段不同距离处
        ↓
计算每个距离下的卷积强度
        ↓
保存到 1D 查找纹理
```

运行时流程变成：

```text
计算当前片元到线段的归一化距离
        ↓
查询 1D LUT
        ↓
得到当前片元的抗锯齿强度
```

这样滤波器的复杂度被转移到了预处理阶段，运行时只需要少量边缘函数、点积和纹理查询。

### 4. 预计算表的参数化

假设线段宽度为 `w`，滤波器半径为 `R`。当滤波器中心位于线段中心时，线段与滤波器的重叠最大，强度为 1；当距离达到 `w / 2 + R` 时，滤波器完全离开线段，强度为 0。

因此可以使用归一化参数 `d`：

```text
d = 1：滤波器中心位于线段中心附近
d = 0：距离足够远，完全没有覆盖
```

将不同 `d` 对应的强度存入一张 1D 纹理。原章认为 32 个条目通常已经足够，必要时可以使用 64 个条目。

### 5. 滤波器选择

理论上，Sinc 滤波器适合消除混叠，但它具有无限支持范围，无法直接用于实时实现。因此实际可以选择有限范围的滤波器：

- Box Filter：简单、边缘较硬，适合较细线段；
- Gaussian Filter：边缘更平滑，适合较粗线段；
- Cubic 等有限支持滤波器：可以在锐度和平滑度之间折中。

滤波器半径太小，抗锯齿效果不足；半径太大，线段会过度模糊。由于卷积结果已经预计算，因此运行时成本与所选滤波器的复杂程度基本无关。

### 6. CPU 端的线段准备

线段由两个端点定义：

```text
P0 = (x0, y0)
P1 = (x1, y1)
```

CPU 先将端点从对象空间变换到窗口空间：

```text
对象空间
    ↓ Model/View/Projection
裁剪空间
    ↓ 透视除法
NDC
    ↓ 视口变换
屏幕像素坐标
```

随后根据线段宽度和滤波器半径构造一条更宽的辅助线。它的覆盖范围至少需要达到：

```text
线段半宽 + 滤波器半径
```

这样光栅化器才会生成所有可能受到滤波影响的片元。

### 7. 四条边缘函数

有限线段可以看作一个加宽的矩形，并额外考虑两个端点。围绕它可以构造四条边：

```text
E0：线段一侧的边
E2：线段另一侧的边
E1：第一个端点的边
E3：第二个端点的边
```

每条边都可以表示为线性函数：

```text
E(x, y) = ax + by + c
```

CPU 预先计算四组 `(a, b, c)`，并将它们作为常量参数传入像素 Shader。

### 8. 像素 Shader 中的运行时计算

对于当前片元的屏幕位置 `(x, y)`，Shader 计算四个边缘函数：

```hlsl
d0 = dot(edge0, float3(x, y, 1));
d1 = dot(edge1, float3(x, y, 1));
d2 = dot(edge2, float3(x, y, 1));
d3 = dot(edge3, float3(x, y, 1));
```

如果任意一个值小于 0，表示当前片元已经超过线段的滤波影响范围，可以直接丢弃。

接着分两组处理：

```hlsl
sideIntensity = LUT(min(d0, d2));
endIntensity  = LUT(min(d1, d3));
intensity = sideIntensity * endIntensity;
```

其中：

- `min(d0, d2)` 控制线段左右两侧的衰减；
- `min(d1, d3)` 控制线段两个端点的衰减；
- 两次查表结果相乘，得到有限线段的最终覆盖强度。

因此该方法同时平滑了线段的侧边和端点，而且每个片元只需要少量点积和两次 1D 查表。

### 9. 保守光栅化与宽线绘制

普通光栅化器只会生成线段本身覆盖的片元，但抗锯齿滤波会影响线段外部的一圈区域。因此需要先绘制一条足够宽的辅助线，让所有位于滤波范围内的片元都被生成。

像素 Shader 再根据边缘函数：

- 对滤波范围外的片元执行丢弃；
- 对边缘片元写入较低透明度；
- 对线段中心区域写入较高强度。

这相当于用较宽的几何覆盖潜在影响范围，再由 Shader 恢复真实的平滑线段形状。

### 10. 多条线段的混合

如果所有线段颜色相同，使用 Alpha 混合时顺序通常不重要，因为相同颜色的覆盖可以近似交换。

如果线段颜色不同，Alpha 混合不满足交换律：

```text
A over B ≠ B over A
```

此时需要从后向前绘制。对于相互交叉的线段，标准 Z-Buffer 无法完成每个像素级别的精确排序，因此可以使用线段中点深度等启发式排序。该方法不能保证完全正确，但错误通常只出现在少数交叉区域。

### 11. 用于多边形边缘抗锯齿

本章还将预过滤线段用于多边形边缘：

1. 先正常绘制多边形；
2. 找出轮廓边、材质边界等不连续边；
3. 将这些边重新作为预过滤线段绘制；
4. 将抗锯齿线覆盖在原始多边形上。

这种方法可以改善轮廓线和非真实感描边，但需要显式识别模型中的不连续边。复杂模型的边界提取可能有额外成本，而且多个不同颜色的边仍然要处理透明混合排序。

### 12. 方法特点与适用范围

本章的核心流程可以概括为：

```text
线段与滤波器的复杂卷积
        ↓ 离线预计算
距离 → 强度的 1D LUT
        ↓ 运行时
线性边缘函数 + 两次查表
        ↓
得到平滑线段
```

优点：

- 运行时成本固定；
- 支持 Box、Gaussian、Cubic 等对称滤波器；
- 不依赖具体 GPU 厂商的线段抗锯齿实现；
- 只需要少量 CPU 和 GPU 运算；
- 适合电线、栅栏、电缆、细长结构和轮廓线。

## 讨论与补充

### 1. 这里的线段不等于屏幕边缘检测

本章中的线段首先是已经知道几何信息的线段，而不是 FXAA、SMAA 那种从最终颜色图中检测出来的边缘。它的输入可以是：

```text
端点 P0
端点 P1
线宽 w
```

运行时根据片元到线段的距离查询预过滤 LUT。

边缘检测得到的轮廓线可以使用本章方法，但需要先把检测结果转换为可绘制的线段。原章提到的多边形应用就是先找出轮廓边、材质边界等不连续边，再将这些边重新作为抗锯齿线绘制。

### 2. 线状表示与管状网格的区别

电线、电缆、栅栏横杆、激光线和 `LineRenderer` 等对象可以用“中心线 + 宽度”表示。曲线或不规则线也可以拆成多段折线：

```text
P0 → P1 → P2 → P3 → P4
```

但段与段之间还需要处理连接、端点、尖角、圆角和斜接，否则容易出现断裂或接缝。若曲线需要很高精度，可以增加折线段数，或改用曲线距离函数和专门的曲线渲染方案。

真正的圆柱形水管或电线网格则由顶点、三角形、法线和 UV 构成，本质上仍是普通三角形模型。它需要使用普通几何抗锯齿、TAA、MSAA 或专门的管线渲染方法，而不是直接套用本章的线段预过滤。

线段表示适合远距离 LOD、风格化效果、不需要真实圆形截面和复杂光照的对象。需要真实截面、自阴影、反射、金属高光或复杂法线时，应使用管状网格或更完整的曲线几何方案。

### 3. 线段上的花纹材质

线段上的颜色花纹可以在覆盖率之外继续采样纹理或程序材质：

```hlsl
float pattern = SamplePattern(alongLineUV);
float coverage = SampleLineLUT(distanceToLine);
color = pattern * coverage;
```

预过滤 LUT 只负责线段边缘的覆盖率，不负责花纹本身的纹理抗锯齿、法线、高光或阴影。如果花纹只是颜色变化，可以使用沿线 UV、程序纹理或普通贴图；如果花纹表现为凹凸、金属反射、复杂法线或真实几何结构，则需要真正的管状网格或更复杂的曲线材质方案。
