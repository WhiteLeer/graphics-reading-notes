# 用 FFT 进行医学图像重建

## 章节内容

本章介绍如何在 GPU 上实现快速傅里叶变换，并将其应用于 MRI 和超声图像重建。重点是把 FFT 的蝶形运算、复数数据布局和多阶段内存访问映射到早期 GPU 的顶点处理器、光栅化器和片元处理器，同时减少纹理访问和均匀分布各阶段负载。

### 医学图像重建背景

MRI 和超声设备通常先采集频域或其他原始信号，再通过数学重建得到空间图像。FFT 是从频域和空间域之间转换的关键工具，但二维或三维数据规模大，CPU 重建可能成为瓶颈。

### FFT 基础

离散傅里叶变换把有限序列分解为不同频率的复数分量。直接计算需要 `O(N²)`，Cooley-Tukey 等 FFT 算法把问题递归拆成更小的变换，通过蝶形运算将复杂度降到 `O(N log N)`。

一个蝶形通常读取两个复数值，乘以旋转因子后做加减，生成两个输出。二维 FFT 可以先对所有行做一维 FFT，再对所有列做一维 FFT，并在需要时进行中心化、缩放和频域数据校正。

### GPU 数据表示

复数可以把实部和虚部打包到纹理的两个通道。FFT 的每个阶段通过片元程序并行执行大量蝶形运算，使用纹理查找获得配对元素和旋转因子。由于早期 GPU 缺少方便的整数索引和任意 Scatter，需要精心设计纹理坐标、步长和 Ping-Pong 缓冲。

### 性能优化

本章的优化包括：

- 根据数据规模选择顶点、光栅化和片元阶段的工作分配；
- 将多个标量或复数分量打包到 RGBA 通道；
- 预计算或缓存旋转因子；
- 尽量让相邻线程访问连续纹理位置；
- 使用多个 PASS 表达 FFT 的不同蝶形阶段；
- 减少纹理切换、地址计算和不必要的中间复制；
- 对二维数据采用行列分解，并处理转置或布局变化。

### MRI 与超声重建

MRI 重建通常需要对采集的频域数据进行校正、填充和逆 FFT，再得到空间图像。超声重建也可以把采集信号组织为适合 FFT 的二维或一维数据，并在 GPU 上执行频域处理和反变换。实际管线还包括幅度缩放、中心频率处理、滤波和显示映射。

### 总结

FFT 是非常适合 GPU 的数据并行算法，但它包含多轮阶段依赖，不能一次 Kernel 完成。高效实现的关键是把每轮蝶形运算组织成规则纹理访问，合理分配 GPU 各阶段，并尽量减少中间数据搬运。该思路同样适用于图像处理、信号处理和海洋等频域模拟。
