# 用渐进细化辐射度实现全局光照

## 章节内容

本章介绍完全在 GPU 上计算渐进细化辐射度的方法。场景表面被划分为许多元素，元素之间的能量传递由形状因子和可见性决定；辐射度和残差能量被存储在纹理中，片元程序负责计算能量传递。

### 辐射度基础

辐射度是一种有限元全局光照方法，把场景表面离散成许多小面元，并计算面元之间传输的能量。两个面元之间的形状因子由距离、相对朝向和可见性共同决定：被遮挡时可见性为零，完全可见时为一。

使用无限小面元时公式较简单；为了减少元素数量，可以使用较大的面元，并用定向圆盘等近似它们的面积积分。

### 渐进细化

经典辐射度需要建立并求解巨大的线性方程组。渐进细化方法不一次性构造完整矩阵，而是每次选择残差能量最大的 Shooter，把它向其他 Receiver 传递，逐步减少系统中的剩余能量。

### GPU 中的表示

本章把每个场景多边形的纹理 texel 当作一个辐射度元素，并为每个多边形保存辐射度纹理和残差纹理。纹理分辨率决定辐射度解的空间粒度。

直接从 Shooter 视角渲染并把能量 Scatter 到所有可见多边形，要求 GPU 向多个纹理的任意位置写入，早期硬件难以高效完成。于是本章反转计算：遍历 Receiver 元素，判断它们是否能看到当前 Shooter，并由 Receiver Gather 应接收的能量。这样输出位置规则，适合片元程序。

### 可见性与能量更新

对于每个 Receiver，GPU 通过投影、深度测试和纹理访问判断 Shooter 是否可见，再根据形状因子、反射率和 Shooter 的残差更新 Receiver 的辐射度。完成一次传递后，更新残差并选择下一个需要细化的 Shooter。

### 总结

本章最重要的 GPU 思路是把难以实现的 Scatter 改为规则的 Gather：不是把一个面元的能量任意写向很多接收面元，而是让每个接收元素主动查询自己应接收的能量。这样牺牲了一部分直观性，却获得了 GPU 友好的访问模式，可以计算漫反射间接光照、软阴影和物体间反射。
