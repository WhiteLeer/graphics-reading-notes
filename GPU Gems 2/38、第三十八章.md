# 用光栅化实现高质量全局光照

## 章节内容

本章介绍一种利用 GPU 光栅化硬件进行高质量全局光照离线渲染的方法。它不是把传统 CPU 光线追踪直接搬到 GPU，而是利用光栅化一次处理大量同方向射线的能力，执行最终聚集，从而计算间接光照、软阴影和物体间反射。

### 全局光照与最终聚集

局部光照只考虑光源直接照射到表面的贡献；全局光照还要考虑物体之间的遮挡、漫反射和间接反射。路径追踪可以直接计算这些效果，但通常需要大量射线才能降低噪声。

常用的两阶段方法是：第一阶段用较低成本的方法计算粗略的全局光照表示，例如光子图或辐射度；第二阶段在每个可见点上发射半球方向的射线，从第一阶段结果中获取间接光照，这就是 Final Gathering。

### 用光栅化实现射线求交

传统 GPU 光线追踪需要在 GPU 上维护场景和加速结构，受到随机访问、内存容量和 CPU 构建加速结构的限制。本章的方法利用光栅化器把大量射线或射线束转化为图元，再通过深度和遮挡关系完成射线与场景的求交。

核心思想是把“查找射线第一次命中的物体”改写成 GPU 擅长的投影、光栅化和深度测试。光栅化硬件可以同时处理很多方向相近的射线，避免为每条射线执行完整的通用遍历。

### 第一阶段与第二阶段

第一阶段使用 CPU 上的网格光子映射构建粗略光照，并将辐照度作为顶点颜色或其他场景数据保存。第二阶段对目标点进行半球采样，使用 GPU 光栅化得到各方向可见性和命中信息，再从预计算光照中进行积分。

本章为了说明方法，主要使用 Lambert 材质，并支持软阴影、间接反射、抗锯齿、景深和图像环境光等离线渲染效果。最终聚集也可以作用于 Lightmap texel、顶点颜色或其他离散点集。

### 性能与限制

该方案针对高质量离线渲染，不以实时帧率为目标。它减少了 CPU 光线追踪中维护加速结构的压力，但仍需要大量光栅化工作和样本。复杂材质、镜面多次反射以及动态场景会增加实现难度。

### 总结

本章不是“光栅化天然等于全局光照”，而是把最终聚集中的大量射线求交重新编码成光栅化任务。它利用 GPU 对规则射线束和深度测试的优势，为离线全局光照提供了另一种 GPU 加速路线。
