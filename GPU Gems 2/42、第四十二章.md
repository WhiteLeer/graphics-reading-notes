# 保守光栅化

## 章节内容

本章介绍一种通过顶点和片元程序实现的保守光栅化方法，用于保证几何图元与像素网格之间的覆盖关系不会因采样分辨率而漏判。它适合 GPU 碰撞检测、遮挡剔除、可见性测试和其他离散化算法。

### 标准光栅化的问题

标准光栅化只根据采样点判断像素是否被三角形覆盖。因此两个几何上相交的三角形，可能因为它们都没有覆盖同一个采样点而被判定为不相交。提高分辨率可以降低错误概率，但不能保证完全正确。

### 两种保守光栅化

- 过估计：只要像素单元和多边形有任何交集，就把该像素包含进来；
- 欠估计：只有像素单元完全位于多边形内部时，才把该像素包含进来。

本章主要关注过估计，因为它对碰撞和遮挡测试更有用：它宁可产生候选误报，也不能漏掉潜在相交对象。

### GPU 实现方法

第一种算法在顶点程序中计算多边形的最优包围多边形，使填充区域尽量紧凑，减少无效片元。但它需要复制和处理更多顶点，几何阶段成本较高。

第二种算法在顶点程序中生成一个包围三角形，再在片元程序中裁剪多余区域。它减少了几何处理，但对尖锐三角形的包围范围较松，会产生更多无效片元。

两种方法都通过沿像素半对角线方向扩大原始三角形，使任何与原始图元相交的像素单元都能被光栅化覆盖。

### 保守深度

除了覆盖关系，还可以为每个像素单元计算保守的最小或最大深度。以碰撞检测为例，可以先用物体 B 的保守最小深度写入深度缓冲，再用物体 A 的保守最大深度进行测试。如果 A 有片元被深度测试剔除，则说明两个物体可能发生遮挡关系，需要在 CPU 上进行精确相交测试。

### 总结

保守光栅化不直接给出精确碰撞结果，而是提供“不会漏掉真实相交”的候选集合。它可以把低成本的粗筛放到 GPU，再把少量候选交给 CPU 或更精确算法，从而在正确性和性能之间取得平衡。
