# 使用像素 Shader 分支高效实现软边阴影

## 章节内容

本章介绍一种基于单张阴影贴图和自适应 PCF 采样的实时软阴影方法。它不为面光源的每个采样点重复生成阴影贴图，而是在像素 Shader 中对当前阴影贴图坐标附近进行抖动采样，并根据当前片元是否可能处于半影区域，决定是否执行高成本的完整过滤。

### 1. 阴影体与阴影贴图

阴影体通过光源与物体轮廓构造遮挡体，再使用模板缓冲判断像素是否位于阴影体内。它适合点光源和方向光，但依赖物体轮廓复杂度，消耗较多填充率，通常还需要多 Pass 和 CPU 参与构建轮廓。

阴影贴图则把场景从光源视角渲染成深度图：

```text
光源视角渲染场景深度 → Shadow Map
当前片元转换到光源空间
比较当前深度与 Shadow Map 深度
→ 判断是否被遮挡
```

阴影贴图能够覆盖可以产生深度的各种几何体，三角形数量增加时扩展性较好，但会受到分辨率、投影和重采样的影响，产生锯齿、走样和阴影 Acne。

### 2. 用一张阴影贴图近似软阴影

真实面光源软阴影需要对光源表面进行多点采样，每个采样点可能都要得到一份阴影结果，再将结果累积，成本很高。

本章改为使用一张阴影贴图，并在当前阴影贴图坐标附近进行多次采样：

```hlsl
float shadow = 0;
for (int i = 0; i < sampleCount; i++)
{
    float2 offsetUV = uv + offsets[i] * filterRadius;
    shadow += Compare(currentDepth, shadowMap(offsetUV));
}
shadow /= sampleCount;
```

如果周围样本有些处于光照区、有些处于阴影区，平均值就落在 `0～1` 之间，形成软边缘。PCF 不是直接模糊阴影贴图中的深度，而是先分别比较深度，再平均比较结果。

### 3. 抖动采样与条带

固定采样位置较少时，半影会出现多条重叠的硬边缘，形成明显条带。为此，每个像素使用略有不同的抖动偏移，使误差从规则条带变成高频噪声，再通过空间或时间滤波减弱噪声。

采样点通常分布在阴影贴图坐标周围的圆盘中，圆盘半径控制软阴影的宽度。为了提高效率，估计样本优先分布在圆盘边缘，因为那里最容易遇到光照和阴影的转换区域。

### 4. 自适应 PCF

高质量 PCF 可能需要几十次甚至 64 次阴影贴图采样，但大部分像素并不位于半影：

```text
完全受光区域 → 少量采样即可
完全阴影区域 → 少量采样即可
半影区域     → 才需要大量采样
```

因此先进行少量估计采样：

```text
所有估计样本为 0 → 很可能完全阴影
所有估计样本为 1 → 很可能完全受光
结果处于中间值   → 可能位于半影
```

只有第三种情况才进入完整 PCF：

```hlsl
float shadow = CheapSamples();

if (shadow > 0 && shadow < 1)
    shadow = RefineWithManySamples(shadow);
```

这样可以跳过大量不需要高质量过滤的片元。

### 5. 动态分支的一致性

像素 Shader 的动态分支并不一定总能带来收益。GPU 会让相邻片元以线程组方式执行，如果相邻片元进入不同分支，硬件可能仍需要分别执行两条路径，分支收益就会降低。

因此需要让空间上相邻的片元尽量作出相同判断。阴影区域通常具有较大连续性，相邻片元往往同时处于受光区、阴影区或半影区，比较适合进行这种自适应分支。

### 6. Jitter Map

运行时生成抖动偏移会增加成本，因此本章预先生成 Jitter Map。它使用三维纹理保存多组采样序列：

- `s、t` 方向根据屏幕坐标平铺；
- `r` 方向表示采样序号；
- RGBA 可以存储两组二维偏移。

运行时根据屏幕坐标和当前采样序号读取偏移：

```hlsl
float2 offset = SampleJitterMap(screenUV, sampleIndex);
shadowUV = baseShadowUV + offset * penumbraRadius;
```

偏移被归一化到 `[-1, 1]`，因此可以使用较低精度的纹理格式保存，减少带宽。

### 7. 深度比较与阴影 Acne

阴影贴图可以使用硬件深度比较和硬件 PCF，减少手动比较的开销。阴影 Acne 是当前表面深度和阴影贴图深度存在误差造成的自阴影条纹，常见处理包括：

- 深度 Bias；
- 在阴影贴图中渲染背面；
- 法线偏移；
- 中点阴影贴图。

本章还会利用 `NdotL` 排除背向光源的表面，避免阴影 Acne 干扰半影估计和动态分支判断。

### 8. 方法特点与限制

优点包括：

- 只需要一张阴影贴图；
- 不需要为面光源的每个采样点重复生成阴影贴图；
- 通过自适应分支减少完全受光和完全阴影区域的采样；
- 抖动采样可以减弱 PCF 条带。

限制包括：

- PCF 是视觉近似，不是严格的面光源积分；
- 半影很大时仍需要大量采样；
- 分支不一致会降低性能收益；
- 阴影贴图分辨率和投影方式仍会限制最终质量；
- 透视阴影贴图等特殊投影需要额外调整过滤半径。

## 讨论与补充

### 1. 降低采样数量与抖动的关系

标准 PCF 可以对当前阴影贴图坐标周围采样 64 次，但也可以直接降低到 8 次或 16 次。这样会减少带宽和 Shader 计算，但固定采样位置容易产生明显的条带和重叠硬边。

加入抖动后，每个像素使用略有不同的采样偏移，规则条带会转化为高频噪声：

```text
64 次固定 PCF
    ↓
8/16 次采样，出现条带
    ↓
抖动采样，条带变成噪声
    ↓
时域累积或滤波后，视觉上更平滑
```

抖动并没有恢复原本缺少的采样，也没有让结果变得物理准确，而是把规律性错误换成随机性误差。静态画面或没有 TAA 时仍可能看到噪点；阴影贴图分辨率、过滤半径和 Bias 的问题也不能靠抖动彻底解决。

### 2. 自适应 PCF 的预估

自适应 PCF 不是直接把所有片元都从 64 次改成 8 次，而是先用少量样本判断当前片元是否可能处于半影：

```text
先采样 4～8 次
    ↓
全部为阴影 → 很可能完全在阴影中
全部为受光 → 很可能完全在受光区
两者混合   → 可能位于半影
```

如果估计结果接近 0 或 1，就直接使用少量样本的结果；只有结果位于中间区域时，才继续补采样到 32 或 64 次。因此它减少的是平均采样成本，半影区域仍然会承担高采样成本。

这种判断只是概率估计，并不保证绝对正确。估计样本通常放在过滤圆盘边缘，以提高遇到阴影/受光过渡的概率；抖动则把误判分散成噪声。

### 3. Jitter Map 不只是随机灰度图

普通二维噪声图通常只提供一个随机值：

```text
Noise(x, y) → 一个随机数
```

本章的 Jitter Map 保存的是每个像素的一整组二维采样偏移：

```text
Jitter(screenX, screenY, sampleIndex)
    → 第 sampleIndex 个二维偏移
```

因此使用三维纹理：

- `s、t` 方向对应屏幕位置；
- `r` 方向对应采样序号；
- RG 和 BA 可以各保存一组二维偏移。

现代实现也可以使用二维蓝噪声来选择或旋转固定的 Poisson Disk 采样核，但本质上仍然是在为不同像素提供不同的采样模式。
