# GPU 上的期权定价

## 章节内容

本章使用 GPU 并行计算金融期权价格，介绍 Black-Scholes 模型和格点模型两种方法。前者对大量独立期权参数执行相同公式，后者包含时间和价格方向的依赖，需要通过适当的遍历方向和纹理布局映射到 GPU。

### 期权与定价

期权是一种价值依赖于其他资产的衍生工具。看涨期权给予未来以约定执行价买入标的的权利，看跌期权给予卖出的权利。定价的目标是根据标的价格、执行价、到期时间、利率和波动率等参数估计公平价值。

### Black-Scholes 模型

Black-Scholes 模型使用解析公式计算欧式期权价格。每个期权的参数可以独立处理，因此非常适合把大量期权编码成纹理或流，让 GPU 同时计算。

本章还利用 GPU 的四分量向量运算优化多项式和幂运算：预先计算与执行价有关的幂，把系数打包到向量中，再利用点积一次完成多个乘加。

### 格点模型

格点模型把标的价格和时间离散成网格，从到期日向当前时刻反向计算期权价值。节点值依赖下一时间层的相邻节点，因此存在阶段间依赖，但同一层中的多个节点可以并行计算。

可以把每一层保存为纹理，并通过 Ping-Pong 纹理从后往前迭代。为了增加并行度，GPU 同时为大量独立期权执行格点计算。

### Monte Carlo

Monte Carlo 和准 Monte Carlo 也适合 GPU，因为每条随机路径可以独立模拟，最后只需做归约求平均。早期 GPU 缺少方便的整数指令和随机数生成器，因此可以由 CPU 生成随机数并上传；只要每个样本承担足够多的计算，传输成本不一定成为瓶颈。

### 总结

期权定价展示了两类 GPU 计算：公式型、完全独立的 Black-Scholes；以及需要按时间层推进的格点模型。只要把阶段依赖保留在 PASS 序列中，把每一层的大量节点并行化，就能利用 GPU 的吞吐量。
