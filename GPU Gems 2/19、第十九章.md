# 通用折射模拟

## 章节内容

本章介绍一种非常高效但非物理准确的屏幕空间折射方法。它先把非折射物体渲染到一张场景纹理中，再使用折射表面的法线贴图扰动屏幕投影坐标，采样这张场景纹理，从而模拟水、玻璃、热浪和狙击镜片等效果。为了减少前方物体被错误折射进来的问题，本章还在场景纹理的 Alpha 通道中保存折射物体遮罩。

### 1. 真实折射与实时近似

光线从一种介质进入另一种介质时，会根据折射率改变方向。严格计算需要考虑：

- 入射方向；
- 表面法线；
- 两种介质的折射率；
- 物体厚度；
- 光线进入和离开表面的两次交点；
- 被折射后真正看到的场景物体。

实时渲染中，为了避免为每个折射物体生成复杂环境图或进行多次场景渲染，本章使用屏幕空间的纹理坐标扰动近似折射。

原章特别强调，这个方法是对 Far Cry 中水面、热浪和狙击镜片等效果的归纳。它的工程目标不是恢复真实的折射光路，而是避免每个折射表面都单独生成环境图，尤其避免传统水面方案中额外渲染完整折射场景的成本。

### 2. 基础方案

首先渲染场景中所有非折射物体，得到场景纹理 `S`：

```text
非折射物体 → 场景纹理 S
```

然后绘制折射物体。对于折射物体上的每个片元：

1. 采样法线贴图；
2. 取法线的 XY 分量作为屏幕坐标偏移；
3. 将偏移乘以折射强度；
4. 使用扰动后的屏幕 UV 采样 `S`。

```hlsl
float2 screenUV = screenPos.xy / screenPos.w;
float2 offset = SampleNormal(uv).xy * refractionScale;
float3 refractedColor = SampleSceneColor(screenUV + offset);
```

它并没有真正追踪折射后的光线，而是用法线贴图制造图像错位，因此特别适合水面、热空气和轻微玻璃扭曲。

这里的场景纹理可以理解为绘制折射物体之前的当前 back buffer 快照，而不是一张预先制作的固定贴图。折射物体本身必须从这张纹理的生成阶段排除，否则会把尚未正确处理的自身颜色或其他折射表面写入输入。

### 3. 为什么需要折射遮罩

如果场景纹理 `S` 包含了折射物体前方的几何体，直接扰动 UV 可能把前方物体错误地采样进折射结果：

```text
实际关系：前方物体遮挡折射物体
错误采样：折射偏移后采到了前方物体的其他位置
```

这种现象表现为折射内容“穿过”不应该被折射的物体，称为折射泄漏。

本章的改进方法是在 `S` 的 Alpha 通道中保存折射遮罩：

```text
Alpha = 1 → 当前像素不属于折射物体
Alpha = 0 → 当前像素属于折射物体
```

渲染折射表面时，同时采样原始 UV 和扰动后的 UV：

```hlsl
float4 refracted = Sample(S, screenUV + offset);
float4 original  = Sample(S, screenUV);

color = lerp(refracted, original, refracted.a);
```

如果扰动坐标落到了不属于折射区域的位置，就使用未扰动的颜色，减少明显的错误采样。这个方案不完全正确，因为真实折射确实可能看到非正后方的物体，但视觉上更稳定。

原章的实现细节是：先把 `S` 的 Alpha 清为白色，再只把折射网格写成黑色到 Alpha；折射 Shader 采样扰动坐标得到 `vRefrA`，同时采样未扰动坐标得到 `vRefrB`，并依据 `vRefrA.w` 在两者之间选择。这里的遮罩不是深度意义上的完整可见性判断，而是检查扰动采样是否越过屏幕上的折射区域边界。

### 4. 水面折射与反射

水面通常使用以下数据：

- 场景颜色纹理，用于折射；
- 折射遮罩；
- 反射纹理；
- 多层动画凹凸/法线贴图；
- 深水颜色；
- Fresnel 参数。

水面渲染流程可以写成：

```text
渲染普通场景和水面遮罩
        ↓
从反射视角渲染 Reflection Map
        ↓
采样多层动画 Bump Map
        ↓
扰动折射和反射 UV
        ↓
使用 Fresnel 混合反射与折射
```

本章使用多层凹凸图来模拟不同尺度的水波，并对每层使用不同的缩放和移动速度。折射和反射可以使用不同强度的法线扰动。

原章的水面示例具体使用四层凹凸采样：每层在顶点阶段准备不同的 UV 缩放和时间平移，片元阶段采样后平均并重新归一化。随后同一组波纹分别乘以不同的 XY 缩放，得到折射扰动和反射扰动；折射通常需要更明显的扰动，反射则使用更小的扰动，避免反射图被扭曲得过度破碎。

水面反射图不是从普通相机直接采样，而是把场景从水面反射后的视角重新渲染，并裁剪水面以下的几何体。这样得到的反射图和场景纹理 `S` 扮演不同角色：`S` 负责提供水下或水面后方的折射颜色，Reflection Map 负责提供镜像方向上的反射颜色。

Fresnel 近似控制观察角度对反射/折射的影响：

```hlsl
float facing = 1 - NdotV;
float fresnel = fresnelBias
              + (1 - fresnelBias) * pow(facing, fresnelPower);
```

掠射角下反射增强，正视水面时折射和水体颜色占比更高。距离较远或水体较深时，还可以逐渐混入深水颜色。

原章示例使用水面顶点到相机的距离作为一个衰减因子，在折射采样颜色和预设的深水蓝绿色之间插值。这个步骤不是物理上的体积吸收积分，而是用距离控制透明水面逐渐变成深色水体，避免远处水面持续显示清晰的背景。

### 5. 玻璃模拟

玻璃可以使用相同的场景纹理折射方案，再叠加环境贴图反射：

```text
场景纹理 + 法线扰动 → 折射
环境贴图/反射纹理   → 反射
Fresnel              → 混合二者
```

玻璃颜色可以用基础颜色贴图调制折射结果。通过改变凹凸贴图、漫反射颜色和环境贴图，可以得到不同类型的玻璃和染色玻璃效果。

玻璃示例中，环境图使用由反射方向得到的二维环境映射坐标；折射部分仍然从 `S` 的投影坐标采样，并继续使用 Alpha 遮罩排除明显的遮挡物泄漏。基础颜色先对折射结果进行染色，再根据 Fresnel 项把它与环境反射混合。这样不需要修改片元程序，就可以通过替换基础颜色、凹凸图和环境图来改变玻璃外观。

原章还指出，若希望表现色散，可以让不同颜色通道使用不同的折射偏移；但该章的玻璃示例主要展示的是环境反射、屏幕空间折射和 Fresnel 混合，并没有把完整色散作为核心方案。

### 6. 方法特点与限制

优点包括：

- 实现非常简单；
- 只需要场景颜色纹理和法线贴图；
- 不需要为每个折射物体单独生成环境图；
- 水面可以少一次专门的折射场景重渲染；
- 可以用于水、玻璃、热浪和镜片等效果。

限制包括：

- 不是真实折射，不计算完整光路和折射率；
- 不处理物体厚度和进入/离开表面的双重折射；
- 屏幕外物体无法被采样；
- 折射物体重叠时可能互相污染；
- 前后关系复杂时仍可能出现折射泄漏；
- 大幅 UV 扰动会把错误区域采样进来。

如果场景中有多个不同颜色的折射表面，可以按从后到前排序，并在每个折射物体绘制后更新场景纹理；或者使用 Alpha 混合进行更便宜但更不准确的近似。

该限制非常重要：单张 `S` 只代表某一个时刻和某一层场景状态。当不同颜色的折射表面互相重叠时，后绘制的表面会继续使用之前的折射输入，颜色和遮挡关系可能不再正确。按从后到前排序并逐个更新输入纹理能改善结果，但会增加额外绘制；单纯从后到前做 Alpha 混合则更便宜，却只是近似叠加。

原章最后还说明，这一类操作在当时的低端硬件上也可以向较低版本像素 Shader 适配。其核心依赖只是凹凸图采样、投影坐标扰动、场景纹理采样和简单混合，并不要求现代计算着色器或光线追踪硬件。
