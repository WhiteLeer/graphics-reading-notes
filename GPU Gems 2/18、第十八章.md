# 使用顶点纹理置换实现写实水面

## 章节内容

本章介绍《Pacific Fighters》中使用的一种实时海水渲染方法：用多张随时间和空间平铺的高度图合成水面波形，用低频、大振幅高度图在顶点阶段进行几何位移，再用高频法线细节完成像素级光照。它试图在简单法线贴图水面和高质量 FFT 海洋之间取得平衡，并通过顶点纹理采样、径向网格、手动过滤和动态分支实现较大范围的实时水面。

### 1. 简单水面与 FFT 水面的取舍

只使用法线贴图的水面速度快，但只能改变光照细节，不能真正改变轮廓、遮挡和波峰位置。基于流体动力学或 FFT 的海洋模型效果更真实，但计算量较大，不一定适合当时的交互式应用。

本章采用混合方案：

```text
低频、大振幅波形 → 顶点位移，真正改变水面几何
高频、小尺度波形 → 法线/像素光照，补充细节
```

### 2. 多张高度图合成波面

每张高度图表示一个空间和时间尺度的波形，可以理解为一个频率层或 octave。多张高度图在空间和时间上平铺，再按照不同系数相加：

```text
H(x, t) = A0 H0(x, t) + A1 H1(x, t) + A2 H2(x, t) + ...
```

不同高度图使用不同的移动速度、缩放和振幅，可以减少单张纹理平移造成的周期感。书中的实现使用四张高度图参与光照，其中两张尺度最大的高度图用于顶点位移。

高度图对艺术家也比较友好：直接绘制灰度图就可以控制某一层波浪的形状和动画。

### 3. 径向网格与距离 LOD

为了让顶点纹理采样集中在摄像机附近，水面使用以摄像机为中心的径向网格。网格在近处更密，远处更稀：

```text
摄像机
  ↓
近处：高密度顶点
远处：低密度顶点
```

径向位置可以用半径和角度生成：

```text
r = a0 + a1 * i^4
x = r * cos(2πj / M)
y = r * sin(2πj / M)
```

使用 `i^4` 让采样密度快速向外降低，天然形成距离相关的 LOD。书中示例覆盖从约 10 厘米到 40 千米的水面范围。

### 4. 顶点纹理置换

顶点 Shader 根据当前顶点的世界坐标计算高度图 UV，然后读取高度值并修改顶点高度：

```hlsl
float height = SampleHeightMap(uv);
position.y = waterLevel + (height - 0.5) * amplitude;
```

这是真正的几何位移，会影响：

- 水面轮廓；
- 深度关系；
- 遮挡关系；
- 波峰和波谷的位置。

它与只在像素 Shader 中修改法线不同。像素法线只改变光照，不能改变水面的实际几何形状。

### 5. 顶点纹理过滤

当时的硬件顶点纹理采样存在限制：顶点纹理通常只能使用浮点格式，而且不支持普通纹理采样器的双线性或三线性过滤。因此需要在 Shader 中手动完成过滤。

朴素双线性过滤需要读取四个 texel：

```text
A B
C D
```

再进行两次线性插值。如果每个顶点都执行四次读取，成本较高。

本章把四个高度值预先打包到一个 RGBA texel 中，使一次纹理读取即可得到四个值，再在 Shader 中完成插值：

```hlsl
float4 h = SamplePackedHeight(tex, uv);
float2 ab = lerp(h.xz, h.yw, frac.x);
float  h0 = lerp(ab.x, ab.y, frac.y);
```

三线性过滤还需要在相邻 Mipmap 层之间插值。书中根据摄像机距离估计 LOD，并只在两个 Mipmap 层影响相近时执行两次过滤，否则直接选择影响更大的层，从而减少顶点纹理读取。

### 6. 顶点 Shader 中的分支优化

水面网格通常以大批量几何体提交，其中有些三角形完全在视锥体外，但它们的顶点 Shader 仍可能被执行。为了避免对这些顶点进行昂贵的高度图采样，Shader 先将顶点投影到裁剪空间，并用扩大的 Guard Band 视锥判断其是否可能可见：

```text
顶点是否明显位于扩大的视锥外？
    是 → 跳过昂贵的顶点纹理采样
    否 → 执行置换和过滤
```

顶点 Shader 无法直接知道三角形的完整拓扑，因此只能逐顶点判断。如果同一个三角形的不同顶点采取不同路径，理论上可能产生裂缝或错误；本章认为网格足够细且位移幅度有限，这类伪影不明显。

### 7. 预先合成高度图

为了减少顶点 Shader 中多张高度图的采样，可以先用一个像素 Shader 把多张高度图合成为一张浮点纹理：

```text
Pass 1：像素 Shader 合成高度图 → 浮点 RT
Pass 2：顶点 Shader 采样合成结果 → 顶点位移
```

这样可以把多张高度图的求和和过滤从顶点阶段转移到像素阶段。动画高度图也可以作为 3D 纹理的不同层保存，再按时间进行采样或插值。

### 8. 水面光照与波背面伪影

本章将较细的水面光照放在像素 Shader 中，因为顶点阶段计算光照会在远处产生明显欠采样。高频法线细节由法线贴图或其他像素级数据提供。

几何位移后，水面可能出现实际朝向摄像机背面的波面，但原本的平面光照假设仍会把它当成正面，导致波峰出现异常明亮区域。书中通过把光照使用的法线稍微向摄像机方向倾斜，近似修正这种背面波光伪影。

### 9. 局部波浪、泡沫与交互

本章还讨论了爆炸、船迹和物体落水等局部扰动。由于基础高度图模型不容易直接加入严格的流体相互作用，因此采用近似方法：

- 在顶点 Shader 中加入基于距离的解析波函数；
- 把局部位移写入高度纹理，再由后续水面 Pass 使用；
- 使用元胞自动机等方式逐帧传播局部扰动；
- 沿风向模糊局部位移以模拟风的影响。

如果局部波峰高度超过阈值，可以生成泡沫：

```text
波高低于 H0 → 无泡沫
波高超过 H0 → 泡沫逐渐出现
达到 Hmax    → 泡沫强度最大
```

泡沫通常使用预制纹理或动画序列，并根据波高计算透明度。

### 10. 方法特点与限制

优点包括：

- 比单纯法线贴图有更真实的波形和几何轮廓；
- 比完整 FFT 海洋更容易控制，计算成本更低；
- 通过径向网格提供距离 LOD；
- 顶点纹理可以把高度计算和部分数据处理交给 GPU；
- 可以覆盖从近距离到远距离的大范围水面。

限制包括：

- 高度图叠加不是真实流体模拟；
- 周期性和重复图案仍需要通过多尺度纹理缓解；
- 顶点纹理采样和手动过滤会带来成本；
- 顶点位移不能表达任意复杂的波形拓扑变化；
- 局部交互主要是解析或纹理近似，不是完整的水体物理求解；
- 水面反射、折射、泡沫和 HDR 还需要额外的光照与后处理方案。

## 讨论与补充

### 1. 不是 FFT，而是多尺度高度图近似

本章没有真正执行 FFT。它借鉴了 FFT 海洋中的多尺度波形叠加思想，但实际使用的是预先制作或生成的高度图：

```text
多张高度图
    ↓ 不同缩放、速度、方向和振幅
平移并叠加
    ↓
当前水面高度
```

这里的 `harmonic` 或 `octave` 更接近不同尺度的波形层，不代表运行时根据频谱执行了 FFT 或 IFFT。它比 FFT 更容易由艺术家控制，但不是严格的流体或频域海洋模拟。

### 2. 高度图和法线图可以逐层对应

如果每个波层都有对应的高度图和法线/坡度图，并且使用相同的 UV 缩放、移动速度、时间相位和权重，那么几何波形与光照法线可以保持更好的对应关系：

```text
Wave 0：HeightMap0 + NormalMap0
Wave 1：HeightMap1 + NormalMap1
Wave 2：HeightMap2 + NormalMap2
```

但本章的重点是低频高度图负责顶点位移，高频纹理负责像素级光照，因此法线细节不一定严格来自同一组几何位移。法线纹理独立滚动时，可能出现法线和实际波峰不完全对齐的情况，这是用视觉近似换取性能和艺术控制的结果。

### 3. 法线混合不能简单理解为颜色相加

如果总高度为：

```text
h = w0 * h0 + w1 * h1 + w2 * h2
```

更一致的法线应由总高度的梯度计算：

```text
∂h/∂x = w0 * ∂h0/∂x + w1 * ∂h1/∂x + w2 * ∂h2/∂x
∂h/∂z = w0 * ∂h0/∂z + w1 * ∂h1/∂z + w2 * ∂h2/∂z
```

然后：

```hlsl
float3 N = normalize(float3(-dhdx, 1, -dhdz));
```

工程上也可以把每层高度图预先转换成坡度，再按权重混合坡度，最后重建法线。直接归一化相加多个法线只能算近似，并不严格等价于高度场叠加。

### 4. 低频真实几何与高频假几何

更常见的分工是：

```text
低频波：高度 → 顶点位移，并计算低频法线
中频波：高度/法线 → 像素级细节
高频波：法线、粗糙度和闪烁高光
```

高频波没有足够的几何顶点承载，因此只能改变光照，不能改变真实轮廓、深度和遮挡。只有低频部分能够真正改变水面几何。
