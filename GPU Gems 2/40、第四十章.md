# GPU 上的计算机视觉

## 章节内容

本章把 GPU 当作图像分析设备，而不是图像生成设备，介绍如何用片元程序和纹理管线实现径向畸变校正、Canny 边缘检测、全景拼接、特征点与特征向量计算等计算机视觉任务。

### 视觉算法的 GPU 映射

计算机视觉通常要对整张图像执行重复的滤波和数学运算，这与 GPU 的 SIMD、流式模型非常匹配。输入图像被上传为纹理，屏幕对齐四边形保证输入像素和输出片元近似一一对应，片元程序执行一个过滤阶段，结果再保存为下一阶段的纹理。

完整算法可以由多个过滤 PASS 组成。需要汇总时，可以通过逐级缩小纹理、加法归约等方式实现；更复杂的特征跟踪也可以通过 GPU 处理部分图像和特征数据。

### 径向畸变校正

广角和低成本镜头可能产生桶形等径向畸变。校正时，对输出像素反向计算其在原始图像中的位置，再通过纹理采样获取颜色。由于每个输出像素可以独立计算，这类变换适合片元程序。

### Canny 边缘检测

Canny 检测器可以拆为多个 GPU PASS：

1. 用可分离 Gaussian 滤波计算水平和垂直梯度；
2. 计算梯度幅值，并把梯度方向量化为八个方向之一；
3. 沿梯度方向进行非极大值抑制；
4. 根据高低阈值执行滞后阈值连接，保留真正的边缘。

可分离滤波把二维大卷积拆成两个一维 PASS，减少纹理访问；多阶段结果保存在中间纹理中。

### 全景与特征处理

多帧视频可以通过几何变换、颜色校正和融合生成全景图。特征点检测后，只对少量特征区域计算特征向量，而不是像普通逐像素滤波那样处理整张图。此时需要调整 GPU 数据组织，使稀疏特征点也能被有效处理。

### 多 GPU

多个视觉算法可以分配到不同 GPU 并行执行，也可以让多个 GPU 共同处理不同图像区域。早期实现需要显式管理多块 PCI 显卡，后续 SLI 等技术可以隐藏一部分多 GPU 分配细节。

### 总结

GPU 计算机视觉的基本框架是“纹理输入—片元过滤—中间纹理—下一阶段过滤”。它非常适合规则、密集、逐像素的视觉操作；全局汇总、稀疏特征和复杂控制流仍需要额外的数据结构和归约设计。
