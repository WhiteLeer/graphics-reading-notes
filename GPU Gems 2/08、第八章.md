# 基于距离函数的逐像素置换

## 章节内容

本章介绍一种在像素着色器中实现小尺度置换贴图的方法：Distance Mapping。它不通过增加真实顶点来生成细节，而是把置换表面看作一个需要求交的隐式表面。像素着色器从基础表面的纹理坐标出发，沿观察方向在切线空间中步进，通过预计算的三维距离图快速找到视线与置换表面的交点，再使用交点纹理坐标采样颜色和法线。

这种方法结合了置换贴图的遮挡效果和像素着色器的局部计算成本，可以表现比普通法线贴图更强的表面深度细节，但它并不真正改变模型的屏幕轮廓。

### 1. 与其他表面细节方法的区别

置换贴图会改变表面实际位置，因此可以表现：

- 表面特征之间的相互遮挡；
- 更真实的凹凸深度；
- 某些普通 Bump/Normal Mapping 无法表现的内部遮挡。

传统的几何置换通常需要不断细分基础网格，再沿顶点法线移动顶点。第七章讨论的是这种方向的自适应几何细分。本章则把问题转移到像素着色器中，用逐像素的视线求交来避免生成大量新顶点。

与普通 Parallax Mapping 相比：

- Parallax Mapping 通常只根据一个位置的高度偏移 UV；
- Relief Mapping 会沿视线搜索高度表面，再使用二分搜索精确定位；
- Distance Mapping 使用距离函数决定每一步最多可以前进多远，从而跳过远离表面的空区域，减少固定步长搜索的浪费。

### 2. 为什么使用像素着色器

像素着色器方案有几个优势：

- 当时的 GPU 通常拥有更多像素处理能力；
- 像素着色器更适合访问纹理；
- 像素计算量随屏幕覆盖范围变化，远处物体只处理较少像素；
- 可以把计算集中在近处、真正需要细节的区域。

但像素着色器不能改变已经确定的屏幕坐标，因此不能像真实几何置换那样处理任意大的位移，也不能真正改变物体的外轮廓。它更适合有界的小尺度表面细节。

### 3. 把置换渲染转化为光线求交

以一个平面为例，普通置换会绘制基础平面，再把顶点沿法线推出去。本章采用相反的思路：先绘制包围置换表面的上方平面，然后对每个像素寻找观察射线真正碰到的置换表面位置。

两种问题可以这样对比：

```text
普通光栅化：给定几何，计算它覆盖哪些像素
距离映射：  给定像素，反过来计算它看到表面的哪个位置
```

顶点着色器把基础纹理坐标和切线空间观察方向传给像素着色器。像素着色器从基础纹理坐标开始，沿切线空间观察射线搜索表面交点。

### 4. 三维距离图

如果只按照固定间隔采样高度图，步长太大可能跳过表面，产生裂缝和锯齿；步长太小又会需要大量采样。

因此，书中预计算一张三维距离图。对纹理空间中的每个点 `p`，距离图保存它到置换表面 `S` 的最近距离：

```text
dist(p, S) = p 到表面 S 的最短距离
```

距离图是一个三维纹理，每个体素保存对应位置到最近表面的距离。它不仅可以表示普通高度场，还能表示更复杂的体素化表面数据。

### 5. Sphere Tracing 步进

设当前射线位置为 `p`，观察方向为单位向量 `d`。距离函数给出了当前位置到表面的安全距离，因此下一步可以直接前进这个距离：

```text
p_next = p + dist(p, S) × d
```

只要当前点在表面外，这一步就不会越过表面。不断重复查询和步进，位置会逐渐收敛到射线与表面的交点。

与固定步长搜索相比，这种方法有两个特点：

- 远离表面时可以大步前进，快速跳过空区域；
- 接近表面时自动减小步长，避免错过细节。

因此它在保证不越过表面的同时，减少了不必要的采样。

### 6. 任意网格上的距离映射

对于平面，纹理空间和表面空间关系比较直接。要应用于一般网格，本章假设表面在局部范围内近似平面，并使用每个顶点的切线空间进行计算：

1. 将视线方向变换到当前表面的切线空间；
2. 在切线空间中执行与平面相同的距离步进；
3. 使用得到的纹理坐标采样颜色和法线。

高曲率区域会因为局部平面假设产生失真，这是该方法的限制之一。

### 7. 距离图的预计算

距离图可以通过距离变换算法生成。书中采用的思路是：

1. 为每个体素保存指向最近表面的三维位移向量；
2. 通过多次连续扫描，根据邻居信息更新这些位移向量；
3. 计算位移向量的长度，得到最近距离；
4. 将距离归一化到适合纹理存储的范围。

对于包含 `n` 个体素的地图，书中引用的 Danielsson 距离变换算法可以在线性复杂度下完成预计算。

### 8. Shader 实现

顶点着色器主要负责：

- 将顶点变换到屏幕空间；
- 传递基础纹理坐标；
- 将观察方向和光照方向变换到切线空间；
- 根据位移深度调整射线方向。

像素着色器主要负责：

1. 读取当前纹理坐标处的距离值；
2. 沿切线空间观察射线前进对应距离；
3. 重复执行若干次，直到接近置换表面；
4. 使用最终纹理坐标采样颜色和法线；
5. 在切线空间中执行法线贴图光照。

由于逐步偏移后的纹理坐标在遮挡边界附近可能不连续，书中使用基础纹理坐标的 `DDX` 和 `DDY` 来计算纹理过滤导数，而不是直接使用偏移后的坐标。距离图则采用线性过滤但不使用 Mipmap，以避免不连续坐标选择过粗的 Mipmap 层级而产生错误距离。

### 9. 限制与结果

该方法的主要限制包括：

- 只能表现有限大小的表面位移；
- 像素着色器不能改变真实轮廓；
- 三维距离图需要额外的预处理和纹理存储；
- 每个像素需要进行多次依赖型纹理读取；
- 高曲率网格上的局部平面近似可能产生失真；
- 早期硬件对依赖型纹理读取和动态控制能力有限。

它的主要价值是：使用较少的基础几何，通过像素级光线步进获得带有遮挡关系的细节表面。

## 讨论与补充

### 1. 它与 POM 的关系

本章可以理解为一种使用三维距离图和 Sphere Tracing 的 POM 变体：

```text
POM 思路
    + 三维距离图
    + Sphere Tracing 自适应步进
    = Distance Mapping
```

它与普通 POM 都是在像素着色器中沿视线步进、修改采样 UV，并模拟局部视差和遮挡；区别是普通 POM 通常直接使用高度图，以固定步长或分层步长搜索表面，而本章的距离图保存当前位置到表面的安全距离，可以让射线在远离表面时大步前进、接近表面时自动减小步长。

这里的 3D 纹理不是普通颜色体积纹理，而是距离场：每个体素保存该位置到置换表面的最近距离。它仍然是像素级假象，不会真正增加网格或改变物体轮廓。
