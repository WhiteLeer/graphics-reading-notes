# 用 GPU 预测蛋白质结构

## 章节内容

本章以核磁共振实验中的蛋白质结构预测为例，展示如何把全源最短路径问题映射到 GPU。NMR 通常只能提供部分原子间距离上下界，需要通过距离界平滑得到更一致的约束，随后用于生成蛋白质三维结构。

### 距离界平滑与 Floyd-Warshall

把原子看作图节点，把距离上下界看作边权，就可以使用全源最短路径算法逐步收紧距离界。Floyd-Warshall 算法对每个中间节点 `k` 更新所有节点对：

```text
D[i, j] = min(D[i, j], D[i, k] + D[k, j])
```

它的时间复杂度是 `O(n³)`，存储复杂度是 `O(n²)`，但每次更新可以并行处理大量 `(i, j)` 对。

### GPU 数据表示

上下界分别保存为二维纹理，纹理坐标 `(i, j)` 表示一对原子。虽然矩阵具有对称性、会造成一定存储浪费，但这种布局减少了纹理访问和索引转换，更适合 GPU。

由于第 `k` 次迭代的输出是第 `k+1` 次迭代的输入，不能在同一纹理上同时读写。算法使用 Ping-Pong 缓冲，在两张纹理之间交替渲染。

GPU 片元程序对每个矩阵元素执行相同更新，依赖纹理读取当前值、与第 `k` 行和第 `k` 列相关的值，然后输出更新后的上下界。

### 向量化与性能

GPU 以四分量向量工作，可以把多个距离值打包到 RGBA 通道中，减少纹理查找和指令数量。虽然使用独立纹理保存对称矩阵会占用更多内存，但通常能换取更规则的访问和更高吞吐量。

### 总结

本章展示了一个典型的 GPU 迁移模式：把 `O(n³)` 的算法拆成大量独立的矩阵元素更新，用纹理保存状态，用 Ping-Pong 处理迭代依赖，并用通道打包降低访问成本。它的关键是把串行的外层迭代保留为 PASS 序列，把内层大规模更新并行化。
