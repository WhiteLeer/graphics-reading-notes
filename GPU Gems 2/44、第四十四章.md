# GPU 线性方程组求解框架

## 章节内容

本章构建一个在 DirectX 9 级 GPU 上执行线性代数运算的框架，用向量和矩阵纹理表示数据，并实现向量运算、矩阵-向量乘法、归约以及共轭梯度求解器。最后用隐式方法求解二维波动方程，展示 GPU 数值模拟的完整流程。

### 向量和标量表示

GPU 上的标量可以表示为单元素纹理，向量则重排为二维纹理。为了减少纹理尺寸和提高访问效率，可以把连续的 `2 × 2` 标量块打包到一个 RGBA texel 中。

### 矩阵表示

稠密矩阵可以拆成多个列向量，并按向量纹理布局保存。由规则网格离散得到的矩阵通常是带状稀疏矩阵，非零元素集中在若干条对角线上；如果直接保存成完整矩阵，会浪费大量空间和计算，因此可以只保存带状数据及其偏移。

一般稀疏矩阵的非零元素位置不规则，需要额外索引纹理。矩阵表示应根据非零模式选择，不能把所有矩阵都强行编码成同一种纹理。

### GPU 线性代数操作

框架提供向量加减、缩放、点积、归约求和、矩阵-向量乘法和除法等基本操作。每个操作都通过全屏 Quad 和片元程序执行，结果写入新的纹理，再作为下一步的输入。

### 共轭梯度求解器

对于对称正定系统，可以使用共轭梯度法。每次迭代包含矩阵-向量乘法、点积归约、标量更新、向量加法和残差更新。需要在多个纹理之间交换中间向量，并把归约得到的标量保存为单元素纹理。

### 隐式二维波动方程

显式有限差分方法在时间步长较大时可能不稳定。章节使用 Crank-Nicolson 离散，将当前时刻和下一时刻平均，从而构造更稳定的隐式系统。这个系统可以交给 GPU 共轭梯度求解器，模拟浅水表面或振动薄膜。

### 总结

本章不是只实现某一个方程，而是建立可复用的 GPU 数值计算抽象：用纹理表示向量和矩阵，用片元程序实现基础线性代数，再在其上组合迭代求解器和 PDE 模拟。
