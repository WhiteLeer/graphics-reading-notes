# 基于 GPU 几何 Clipmap 的地形渲染

## 章节内容

本章介绍使用 GPU 几何 Clipmap 渲染大规模地形。它把地形看作高度图，并在观察者周围维护多层嵌套的规则网格：近处使用高分辨率，远处使用低分辨率。通过顶点纹理、固定的网格缓冲区和增量更新，将地形高度采样、层级过渡、法线更新以及部分细节合成工作交给 GPU。

### 1. 几何 Clipmap 的基本结构

- 将地形表示为二维高程图，并预处理为多层分辨率的 mipmap 金字塔；
- 每一层只缓存观察者附近的 `n × n` 高度样本，而不是把完整地形全部放入内存；
- 各层是以观察者为中心的嵌套规则网格，近处范围小但分辨率高，远处范围大但分辨率低；
- 最细层绘制完整网格，其他层绘制空心环，以避免重复绘制已经由更细层覆盖的区域；
- 随观察者移动，各层窗口增量平移，只更新新进入窗口的区域；
- 在相邻分辨率层之间设置过渡区域，通过顶点和像素着色器混合几何与法线，减少接缝和跳变。

### 2. GPU 数据组织

GPU 版本把规则网格的 `x、y` 坐标放在固定的顶点数据中，把高度 `z` 存在每层独立的单通道二维浮点纹理中。顶点着色器根据顶点纹理采样高度，从而得到地形顶点的位置。

主要数据包括：

- 少量固定的顶点缓冲区和索引缓冲区，用来描述不同的二维网格块；
- 每个 Clipmap 层的一张高程纹理；
- 每个 Clipmap 层的一张法线纹理；
- 用于缩放、平移和层间过渡的参数。

这种组织方式使网格缓冲区保持不变，避免 CPU 每帧重新生成或修改大量顶点和索引数据。顶点纹理访问是本章方案能够成立的关键硬件能力。

### 3. 地形绘制

为了支持视锥体剔除并减少内存，环形区域被拆分成多个可重复使用的二维网格块。由于不同块和不同层的网格形状相同，只需通过顶点着色器传入缩放和平移参数即可复用同一套顶点和索引缓冲区。

绘制过程大致为：

```text
固定网格块
    ↓
顶点着色器计算世界坐标
    ↓
顶点纹理采样高度
    ↓
混合当前层与更粗层的过渡区域
    ↓
像素着色器采样法线并进行光照
```

CPU 可以在网格块级别进行视锥体剔除。像素着色器则采样当前层和更粗层的法线并进行混合，地形颜色可以通过高度查找纹理得到。

### 4. Clipmap 更新

观察者移动时，每一层的窗口会围绕观察者重新定位。由于观察者通常连续移动，每帧只需要更新一个较小的 L 形区域，而不是重新处理整张纹理。更新通常按照从粗到细的顺序进行：

1. 从更粗层上采样预测当前层的高度；
2. 加入当前层保存的残差细节；
3. 根据更新后的高度重新计算法线；
4. 将结果写回对应的高程纹理和法线纹理。

为了避免移动整张纹理，Clipmap 使用环形寻址。窗口在纹理中循环使用，新增区域通过若干个矩形绘制操作写入；如果更新区域跨越纹理边界，则拆分为多个矩形。

### 5. 结果与限制

书中使用了美国本土的大规模高度图作为测试数据。GPU 几何 Clipmap 能够在相对固定的网格结构下渲染非常大的地形，并把上采样、细节合成和法线更新等工作转移到 GPU。书中测试使用的是当时的 DirectX 9、顶点纹理和 GeForce 6800 GT 硬件，性能数据属于当时的硬件环境。

## 讨论与补充

### 1. Clipmap 更新和地形绘制是两套过程

需要区分：

```text
Clipmap 更新 Pass
    → 只更新高度图中新增的纹素

地形绘制 Pass
    → 每帧绘制当前活跃且可见的地形顶点
```

相机移动后，更新 Pass 通常只处理新进入窗口的条带或矩形区域，原来没有变化的高度纹素保持不变。可以通过渲染目标的 Scissor 区域、有限的 Compute Shader Dispatch 范围等方式限制写入区域。

这并不意味着一个 Draw Call 内只有部分顶点执行顶点 Shader。主渲染时，当前 Clipmap 中所有活跃且通过视锥体剔除的网格块仍会执行顶点 Shader，只是它们读取的是已经更新好的局部高度纹理。

### 2. 材质数据和高度数据分离

地形高度负责决定顶点位置，Albedo、Normal、材质权重等负责决定表面外观。它们可以通过相同的世界坐标分别采样：

```text
世界坐标
   ├─→ 高度图：顶点位移
   ├─→ 法线图：光照
   ├─→ Albedo 图：基础颜色
   └─→ 材质权重图：混合地表材质
```

因此，某个地块使用哪些材质，并不决定哪些高度纹素需要更新。

### 3. 一帧中的大致流程

```text
相机移动
    ↓
计算各级 Clipmap 窗口的偏移
    ↓
只更新新进入窗口的高度区域
    ↓
更新对应法线区域
    ↓
对固定网格块进行视锥体剔除
    ↓
绘制可见网格块
    ↓
顶点 Shader 采样高度并完成顶点位移
    ↓
像素 Shader 采样材质、法线和颜色
```

所以 Clipmap 的“只处理部分区域”主要指高度和法线缓存的增量更新；地形绘制仍然每帧处理当前可见的局部网格，而不是处理整个世界的所有地形顶点。
