# 复杂边界下的流体模拟

## 章节内容

本章在 GPU 上实现基于 Lattice Boltzmann Method 的流体流动模拟，并重点解决静态、移动和可变形复杂边界的处理。模拟、边界体素化、粒子平流和可视化都尽量留在 GPU 上，以避免 CPU-GPU 传输成为瓶颈。

### Lattice Boltzmann Method

LBM 把空间离散为笛卡尔格点，每个格点保存沿若干离散速度方向运动的分布函数。二维示例使用 D2Q9，即每个节点有 9 个分布；三维示例使用 D3Q19，即每个节点有 19 个分布。

每个时间步先根据分布函数计算密度和速度，再计算平衡分布，最后执行碰撞和传播。传播会把每个方向的分布移动到相邻节点，结果作为下一步输入。

### GPU 数据布局

不同速度方向的分布被分别组织成纹理。三维体数据可以存成多张 2D 切片，也可以把切片平铺为一张大 2D Flat Volume，以减少纹理切换。相反方向的分布会打包到同一 RGBA 纹理中，减少纹理数量和需要传递的速度向量参数。

每个 LBM 更新步骤由多个片元程序组成：输入分布纹理生成密度和速度，计算平衡分布，执行碰撞与传播，再应用边界条件并写回新的分布纹理。

### GPU 体素化复杂边界

LBM 的边界必须对齐到离散格点。若边界移动或变形，每帧都要重新体素化。CPU 体素化后再把边界节点上传 GPU，会造成计算和传输瓶颈。

本章使用 GPU 深度剥离思想进行体素化：第一 PASS 得到最近片元层，后续 PASS 与上一层深度纹理比较，逐层得到更远的交点，直到没有新的片元。这样只处理真正与表面相交的稀疏体素，而不必像简单切片法那样为整个体积逐层扫描。

### 边界条件

- 周期边界：把流出一侧的分布复制到另一侧，边界纹理坐标使用取模；
- 出流边界：丢弃流出分布，并从内部节点复制边界需要的入流分布；
- 障碍物边界：使用改进的 bounce-back 规则，根据边界交点位置和边界速度处理被表面截断的分布。

对于移动或变形边界，还需要保存交点位置、表面平面参数和壁面速度。章节通过多次渲染体素并利用顶点偏移，使每个需要更新的边界分布都能得到片元。

### 粒子可视化

为了观察流场，在流体中注入颜色粒子。粒子位置保存在纹理中，由片元程序根据速度场更新，然后复制到显存中的顶点数组进行渲染。流出边界或停滞区域的粒子会被重新放回入口，因此粒子总数保持不变。

### 总结

本章把 LBM 的规则格点更新天然映射为纹理计算，并用 GPU 体素化和深度剥离处理复杂动态边界。真正的性能收益来自“模拟和边界数据都留在 GPU”，避免每帧把大量边界节点传回传出。
