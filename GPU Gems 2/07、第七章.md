# 自适应细分曲面与置换贴图

## 章节内容

本章介绍在 GPU 上对 Catmull-Clark 细分曲面进行视点相关的自适应细分，并结合置换贴图生成高几何细节。它不再对整个模型统一使用固定细分次数，而是根据曲面曲率、距离和屏幕空间误差决定每个区域需要的细分程度。书中的实现将控制网格和中间细分结果存入二维纹理，通过像素着色器执行细分、平坦度测试和顶点属性计算，再生成最终的顶点与索引数据。

### 1. 细分曲面的基本概念

细分曲面使用一个较简单的控制网格和一组细分规则描述平滑曲面。每执行一次细分，就会产生更多面和更平滑的表面。理论上不断细分可以趋近一个极限曲面。

本章使用 Catmull-Clark 细分曲面。相关概念包括：

- **Limit Surface**：无限细分后趋近的理论曲面；
- **Valence**：连接到某个顶点的边数；
- **Extraordinary Point**：Valence 不等于 4 的顶点。对于四边形为主的 Catmull-Clark 方案，这类点是特殊点。

Catmull-Clark 可以处理任意流形拓扑，但本章实现限制控制网格为全四边形网格。一次细分会把每个四边形拆成四个面，并根据面点、边点和原始顶点周围的权重重新计算顶点位置。

### 2. 固定细分的问题

最直接的做法是对整个控制网格统一执行固定次数的细分，然后把生成的多边形全部绘制。这会带来两个问题：

- 平坦区域可能被过度细分；
- 曲率大或距离相机近的区域可能细分不足。

细分不足会产生明显的多边形轮廓和形状误差；过度细分则会产生大量小三角形，使 GPU 受顶点变换或三角形设置限制。特别是只有几个像素大小的微小三角形，会显著降低光栅化效率。

### 3. 基于平坦度的自适应细分

本章使用平坦度测试决定是否继续细分。它把当前多边形近似表面与极限曲面之间的最大距离转换为屏幕像素误差：

- 曲面越弯曲，越需要细分；
- 距离相机越近，屏幕空间误差越明显，越需要细分；
- 平坦且较远的区域可以停止细分。

例如，平坦度为 0.5 表示多边形近似与极限曲面之间的最大距离约为半个像素。当误差低于目标阈值时，就可以将该区域视为足够平坦。

### 4. 将控制网格组织为 Patches

为了便于在 GPU 上处理，控制网格被拆分为较小的 Patch。每个 Patch 可以表示为规则二维网格，并存储在二维数组或纹理中。通过顶点在二维数组中的位置，可以推断相邻顶点的连接关系。

如果一个面单独作为一个 Patch，就需要复制周围的顶点，保证细分时能够访问邻接环。为了减少重复数据，可以在拓扑允许时让一个 Patch 包含多个面。

Patch 的划分通常在预处理阶段完成。对于动画网格，只要拓扑不变，Patch 的结构、尺寸和特殊顶点的 Valence 信息就可以预先保存，运行时只更新顶点位置。

### 5. GPU 细分流程

整体流程可以概括为：

```text
控制网格顶点位置写入 Patch Buffer Texture
    ↓
对每个 Patch 进行平坦度测试
    ↓
足够平坦 → 计算最终位置、法线等属性
不够平坦 → 继续细分并写入下一级 Patch Buffer
    ↓
反复处理新的 Patch Buffer
    ↓
生成最终顶点数组和索引缓冲区
```

书中的实现通过渲染纹理来执行这些步骤：

- 使用 Fragment Program 复制和生成 Patch 数据；
- 使用 Flatness Test Shader 计算边的平坦度；
- 使用 Subdivision Shader 按 Catmull-Clark 权重生成更高分辨率 Patch；
- 使用 Limit Shader 计算最终位置和法线；
- 将结果写入可供绘制调用使用的顶点数组和索引缓冲区。

CPU 不负责逐顶点执行细分，而主要负责缓冲区管理、读取平坦度测试结果、分配 Patch 位置以及生成最终的图元索引列表。

### 6. 保证曲面没有裂缝

自适应细分时，相邻 Patch 可能拥有不同的细分等级，容易出现裂缝或 T-junction。

本章通过以下方法保证输出封闭：

- 对共享边和角点只采用一侧的数据，避免浮点计算顺序不同造成不一致；
- 处理不同细分等级之间的 T-junction；
- 在出现 T-junction 时，调整索引并补充三角形，填平细分等级不一致造成的空隙。

这一步很重要，因为即使裂缝只有极少像素，也可能造成背景穿透或透明表面的错误。

### 7. 在细分曲面上加入置换贴图

置换贴图为每个纹素提供一个标量，表示表面沿法线方向移动的距离。它会改变实际顶点位置，与只改变光照法线的凹凸贴图或法线贴图不同。

细分曲面适合结合置换贴图，因为：

- 控制网格较小，数据紧凑；
- 细分后表面平滑，适合承载位移；
- 顶点法线和切线可以在细分过程中推导，不必全部从模型中存储；
- 可以根据位移的变化区域自适应增加几何。

为了在真正需要的地方增加足够几何，平坦度测试还要考虑位移贴图在边缘附近的最大位移。如果某条边附近的位移变化很大，即使原始曲面较平，也需要继续细分。最终顶点在极限曲面上计算后，再从位移贴图中读取位移并沿法线方向移动。

### 8. 置换后的着色

书中的实现没有在每次自适应细分后重新计算所有顶点法线，而是使用法线贴图辅助着色。这样可以：

- 在像素级提供更细的法线细节；
- 避免细分等级改变时出现明显的法线跳变；
- 让动画过程中几何数量变化不那么容易产生视觉上的 Pop。

## 讨论与补充

### 1. 它不只是按相机距离切换细分等级

本章的细分可以包含距离因素，但更准确地说是根据视点相关的屏幕空间误差进行自适应细分：

```text
先做视锥体剔除
    ↓
计算 Patch 的屏幕空间误差
    ↓
误差大 → 继续细分
误差小 → 停止细分
```

距离只是影响误差的因素之一。相同的世界空间误差在近处会占据更多屏幕像素，因此通常需要更多细分；曲率大的区域即使较远，也可能需要细分；平坦区域即使较近，也可能不需要很多细分。加入置换贴图后，还要把位移变化造成的误差纳入判断。

因此，它比简单的“近处高 LOD、远处低 LOD”更细致，可以理解为基于距离、曲率、位移和屏幕像素误差共同决定细分量。
