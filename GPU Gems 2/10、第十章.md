# 动态辐照环境图

## 章节内容

本章介绍如何在 GPU 上实时生成动态辐照环境图（Irradiance Environment Map）。普通环境图可以表示复杂的光照环境，但如果每个像素都遍历环境图中的大量光源或纹素，计算成本会随环境复杂度增加。辐照环境图则预先把光照环境与漫反射响应进行卷积，并按照表面法线索引结果，使运行时只需一次环境图查询就可以近似得到复杂环境的漫反射光照。

本章进一步使用球谐函数把环境光转换到频域，在频域中完成卷积，再通过逆球谐变换生成新的环境图。这样将直接卷积的 `O(MN)` 成本降低到与少量球谐系数相关的成本，并使用 Pixel Shader 3.0、浮点纹理和 Render-to-Texture 在 GPU 上完成整个过程。

### 1. 辐照环境图的基本概念

假设场景中有多个方向光，它们的方向和强度组成一个光照环境。对于法线方向为 `n` 的漫反射表面，最终光照可以看作所有入射方向的光照强度乘以 Lambert 余弦项后的积分或求和。

普通环境图可以把不同方向的光照强度存储在不同纹素中，纹素位置隐含光照方向。但如果每个表面都遍历整张环境图来计算漫反射，就会产生较高的运行时开销。

注意到所有法线方向相同的表面都会得到相同的漫反射结果，因此可以预先为每个法线方向计算一次结果，并将结果存入另一张环境图：

```text
输入环境图：每个方向的光照
        ↓ 与 Lambert 漫反射响应卷积
辐照环境图：每个法线方向的漫反射光照
```

运行时只需要根据表面法线查询辐照环境图，就能以固定成本近似复杂光照环境。

### 2. 漫反射与高光环境图

对于漫反射，辐照环境图通常以表面法线作为索引，并使用 `max(0, dot(L, N))` 作为响应函数。

对于对称的高光反射函数，也可以建立类似的高光辐照环境图，但索引通常改为视线反射方向 `R`，响应函数可以使用 Phong 一类的：

```text
pow(max(0, dot(R, L)), s)
```

这样可以用环境图近似复杂环境下的漫反射和部分高光反射。

### 3. 直接卷积的问题

如果输入环境图有 `M` 个纹素，输出环境图有 `N` 个纹素，直接为每个输出方向遍历所有输入方向，复杂度约为：

```text
O(MN)
```

即使输入和输出环境图的分辨率并不高，所有方向两两组合也会产生很大的计算量，因此直接用 CPU 或简单 Pixel Shader 循环实时计算并不理想。

### 4. 球谐函数表示环境光

球谐函数可以把球面上的光照函数表示为一组频域系数。对于 `l` 阶球谐表示，总系数数量为：

```text
(l + 1)²
```

球谐基函数具有线性和正交性。更重要的是，空间域中的卷积可以转换为频域中的系数乘法。因此，输入环境光和漫反射响应可以分别投影到球谐空间，再对对应系数进行相乘和累加。

漫反射光照随法线方向变化较慢，低阶球谐已经可以提供较好的近似。书中引用的结果表明，二阶球谐，即 9 个系数，就足以表示漫反射环境光的主要变化。高光函数需要更多系数，所需阶数与高光指数有关。

### 5. 球谐卷积流程

球谐方法的计算可以分为三个步骤：

1. 将输入环境图投影到球谐系数；
2. 将环境光系数与目标反射函数的预计算系数相乘并累加；
3. 对卷积后的系数执行逆球谐变换，重新生成空间域环境图。

复杂度从直接卷积的 `O(MN)` 变为与球谐系数数量 `K` 相关的：

```text
O(KM + KN)
```

当 `K` 远小于输入和输出纹素数量时，计算量会明显下降。

反射函数的球谐系数只由函数本身决定，例如 Lambert 或 Phong，因此可以预先计算并在不同环境图卷积时重复使用。

### 6. GPU 上的实现

书中使用 Pixel Shader 3.0、浮点纹理和 Render-to-Texture，将球谐投影和卷积过程映射到 GPU。

#### 6.1 环境图到球谐系数

输入环境图的每个纹素会乘以对应球谐基函数的权重，再对所有输入纹素求和，得到一个球谐系数。

一种直接实现是每个系数执行一个 Pass。为了减少 Pass 数量，书中将多个球谐系数的权重查找表平铺到纹理中，并在一次 Pass 中把不同系数安排到不同输出像素或纹理区域。Pixel Shader 根据当前输出位置找到对应的球谐基函数权重，然后遍历输入环境图完成投影。

#### 6.2 频域卷积与逆变换

得到环境光球谐系数后，将它们与预计算的反射函数系数相乘。随后，对输出环境图的每个纹素评价逆球谐展开，得到该方向上的卷积结果。

如果输出是立方体贴图，可以逐面设置 Render Target，并使用对应立方体面的权重纹理生成最终结果。通过纹理平铺，同样可以把多个系数组织到一次 Pixel Shader 处理中。

### 7. 动态环境的用途

辐照环境图生成过程完全在 GPU 上进行，因此可以把原本离线的卷积过程变成实时过程。输入环境图本身可以来自：

- 动态光源；
- 动态物体；
- 实时渲染得到的环境立方体贴图；
- 随时间变化的天空或室内环境。

生成后的辐照环境图可以用于动态对象的环境漫反射和部分高光近似。书中的 GeForce 6800 GT 示例能够以很高的速度生成辐照环境图，证明了当时 GPU 已经可以把这一类预计算过程实时化。

### 8. 局限与延伸

辐照环境图假设光照环境具有空间不变性：同一张环境图通常被不同位置的表面共享。因此它不能完整表示场景中每个位置不同的遮挡、反射和间接光照。

主要限制包括：

- 环境图本身难以表达正确的局部阴影；
- 动态对象的环境遮挡不能直接预计算；
- 高光反射需要更多球谐系数，近似误差也更明显；
- 生成和更新环境图仍会占用 GPU 计算和带宽。

为了补偿环境图缺少的遮挡，离线渲染器通常会使用 Ambient Occlusion 项进行衰减。静态物体可以预计算 AO，动态物体则需要使用动态 AO 等方法进行近似。

球谐系数还具有线性组合性质：两个环境的系数可以直接相加或插值，结果等价于空间域中对应环境的相加或插值。这使球谐表示可以用于动态天空、光照过渡和其他全局光照近似。

## 讨论与补充

### 1. 内置球谐系统与自定义球谐系统

使用引擎内置的 Light Probe 或 Ambient Probe 时，通常由引擎或烘焙工具负责生成、保存和插值球谐系数；Shader 只负责用法线评价这些系数。

需要区分三层：

```text
球谐数学函数
    → 根据法线和系数计算光照

Light Probe
    → 提供并管理不同位置的 SH 系数

环境贴图投影
    → 把自定义 Cubemap 转换成 SH 系数
```

因此，内置的 SH 评价函数不会自动把任意 Cubemap 转成 SH。若使用自定义环境图，需要自己或工具完成：

```text
环境图
    → 采样各个方向
    → 投影到球谐基函数
    → 得到 SH 系数
    → 上传给 Shader
```

静态场景可以在编辑器或烘焙阶段完成；动态天空和动态光照则可以在运行时重新捕获环境并更新系数。Unity 的 `SphericalHarmonicsL2` 使用 3 个频带、9 个系数，并将其用于 Light Probe 和环境光；Light Probe 还保存探针位置和空间插值结构。

需要注意，Light Probe 主要提供低频漫反射环境光，而 Reflection Probe 通常保存 Cubemap，主要用于镜面反射。全局天空环境可以由 Ambient Probe 表示，不一定要求手动布置 Light Probe；Light Probe 的价值在于让不同空间位置拥有不同的环境光。
