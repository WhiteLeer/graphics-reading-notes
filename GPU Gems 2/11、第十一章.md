# 近似双向纹理函数

## 章节内容

本章介绍一种用少量采集图像近似 Bidirectional Texture Function（BTF）的方法，用于实时渲染布料、羊毛、皮革、麂皮和木材等具有明显细微结构的材料。完整 BTF 能描述不同表面位置、入射光方向和观察方向下的反射变化，但数据维度和采集成本都很高。本章通过采集少量不同光照角度的图像，将它们组织成一个三维 Shading Map；运行时先用普通 BRDF 估计当前亮度，再用该亮度选择 Shading Map 的层，补充材料的空间细节和局部自阴影。

这种方法不试图完整恢复真实 BRDF 或完整 BTF，而是只捕获细微表面结构对光照变化造成的视觉影响，并把基础 BRDF 参数留给艺术家或程序控制。

### 1. BRDF、BTF 与材料细节

普通 BRDF 描述某个表面位置在不同入射光方向和观察方向下的反射。光照方向和观察方向各需要两个角度，因此 BRDF 可以看作四维函数：

```text
BRDF = f(入射方向、观察方向)
```

如果还要记录表面上不同位置的空间变化，就增加二维纹理位置：

```text
BTF = f(表面位置、入射方向、观察方向)
```

因此 BTF 是六维函数。完整 BTF 可以捕获：

- 纹理和反射率的空间变化；
- 微表面结构；
- 材料内部或表面局部的自阴影；
- Masking 和 Shadowing；
- 材料内部的部分互反射。

但完整 BTF 需要在大量位置、光照方向和观察方向下采集图像，数据量和采集时间都很大。

### 2. 近似方法的基本假设

本章为了降低采集和存储成本，做了几个假设：

- 材料近似各向同性，旋转材料方向不会显著改变外观；
- 材料细节主要是小尺度结构；
- 不需要表现大尺度结构造成的复杂投影阴影；
- 采集时可以只使用少量光照方向；
- 基础 BRDF 可以由普通光照模型近似，并由艺术家调整。

这些假设使方法更适合布料、麂皮、牛仔布、细密羊毛等材料，而不适合强烈各向异性、强镜面或具有大尺度遮挡结构的材料。

### 3. 材料采集

采集时将材料平铺在平面上，用正交相机观察。使用平行光或距离足够远的点光源照射材料，并让光源只沿一个弧线移动，使入射光的高度角发生变化，而不绕表面法线旋转。

典型流程是：

```text
固定相机与材料
    ↓
改变光源入射高度角
    ↓
采集多张材料图像
    ↓
组成图像序列
```

书中大约每隔 10 度采集一张图像，通常得到约 10 张输入图像。光源方向变化会让材料微结构产生不同的亮暗和微小自阴影，从而把材料的细节表现记录下来。

### 4. 构建 Shading Map

采集到的图像按照光照亮度堆叠起来。对每张图像计算平均辐射亮度 `aₖ`，然后重新采样，使 Shading Map 的层级按照平均亮度近似线性分布。

具体过程是：

1. 计算每张采集图像的平均亮度；
2. 预先定义一组线性分布的目标亮度；
3. 在相邻两张原始图像之间插值；
4. 将插值结果组织成图像堆栈。

最终得到一个三维纹理：

```text
X、Y：材料表面位置
Z：目标亮度对应的图像层
```

这个三维纹理就是 Shading Map。它的每个层不是普通 Mipmap，而是同一材料在不同亮度/光照状态下的细节图像。纹理中的值被解释为已经包含 BRDF 与入射角余弦影响的材料响应。

### 5. 运行时渲染流程

对于一个像素，先获得：

- 表面纹理坐标；
- 入射光方向；
- 观察方向；
- 光源强度；
- 普通 BRDF 所需的参数。

然后执行：

1. 使用普通光照模型，例如 Phong 或其他 BRDF，计算当前像素的基础亮度 `r`；
2. 将 `r` 归一化到 Shading Map 的层坐标；
3. 使用 `(u, v, r)` 查询三维 Shading Map；
4. 使用三线性过滤在相邻亮度层之间插值；
5. 将采样结果乘以实际光源强度。

可以写成：

```text
基础 BRDF → 得到当前应该有多亮
       ↓
用亮度选择 Shading Map 的 Z 层
       ↓
查询材料在这个亮度下的空间细节
       ↓
乘以光源强度
```

基础 BRDF 负责确定整体光照响应，Shading Map 负责添加真实材料图像中的细微结构、自阴影和空间变化。

### 6. 三维纹理实现

运行时将 Shading Map 作为三维纹理上传 GPU：

- 顶点着色器可以先计算光照强度和三维纹理坐标；
- 像素着色器执行三维纹理采样并乘以光源强度；
- 如果硬件支持像素级依赖纹理读取，则可以在像素着色器中计算 BRDF 和 Z 坐标，减少顶点级计算造成的欠采样。

三线性过滤很重要，因为它可以在相邻亮度层之间平滑过渡，避免不同层之间出现明显的分段和轮廓线。

### 7. 为什么只采集少量图像也能有效

该方法并没有完整记录所有观察方向和光照方向下的材料反射，而是主要记录：

```text
材料表面细节如何随着入射亮度变化
```

基础 BRDF 由程序或艺术家提供，采集图像只负责补充微结构造成的变化。因此只需要少量光源角度，就可以取得比单张漫反射贴图或普通法线贴图更真实的效果。

这种方法本质上是一个经验近似，而不是严格的物理测量模型。它之所以有效，一部分原因是人眼能够根据细小的亮暗变化识别布料、皮革和羊毛等材料。

### 8. 适用范围与限制

表现较好的材料包括：

- 布料；
- 牛仔布；
- 麂皮；
- 细密羊毛；
- 细小纹理的木材；
- 蜡等具有空间反射变化的材料。

表现较差的材料包括：

- 强镜面材料；
- 大尺度凹凸结构；
- 明显各向异性材料；
- 需要随方位角变化的材料；
- 具有复杂远距离自阴影和互反射的材料。

原因是本章的采集只沿一个光照弧线变化，无法完整记录方位角变化；大尺度结构造成的阴影方向也不能被正确表示。即使不满足这些假设，它仍然可以作为快速预览或比普通纹理更真实的近似方案。

### 9. 与完整 BTF 的区别

完整 BTF：

```text
大量空间位置
× 大量入射方向
× 大量观察方向
→ 高维数据
```

本章的近似方法：

```text
少量采集图像
× 普通 BRDF 亮度估计
× 三维 Shading Map 查表
→ 较低采集与运行时成本
```

它不是完整 BTF 的无损压缩，而是利用基础 BRDF 加一组经验图像来重现材料外观。

## 讨论与补充

### 1. 这不是专门的毛发渲染方案

本章的方法更适合布料、羊毛、牛仔布、麂皮、皮革和细小纹理木材等材料。它主要捕获细微表面结构在不同光照下产生的亮暗变化。

毛发通常需要考虑发丝方向、各向异性高光、发丝之间的遮挡和透射，因此工程上更常使用发片、发束或发丝几何，并配合专门的各向异性着色、多层排序或近似自阴影。不能把本章的 Shading Map 直接理解成通用毛发渲染方案。

### 2. 采集的不是运行时多个光源

预处理阶段是让同一个材料、同一个观察条件下的光源改变入射角，采集多张图像；不是运行时同时采样多个光源的结果。

这些图像按照整体平均亮度重新排列或重采样后，组成 Shading Map 的不同层。每一层记录的是材料在某个亮度状态下的空间细节，而不是一个独立光源的数据。

### 3. 运行时不是简单叠加一张图

更准确的流程是：

```text
当前光照和视线
    ↓
普通 BRDF 计算基础亮度 r
    ↓
用 r 作为 Shading Map 的 Z 坐标
    ↓
采样对应的材料细节
    ↓
结合光源强度得到结果
```

普通 BRDF 先估计当前像素应该有多亮，Shading Map 再补充微结构、自阴影和局部反射变化。因此它通常是替代或细化部分材料响应，而不是把另一张图无条件加到最终颜色上。

### 4. 为什么使用三维纹理而不是纹理数组

Shading Map 的 X、Y 表示表面位置，Z 表示亮度层。使用三维纹理的主要原因是可以直接使用硬件三线性过滤，在相邻亮度层之间连续插值。

纹理数组也可以存放这些图像层，但数组层通常是离散索引，需要手动取相邻两层并插值：

```hlsl
float z = brightness * (layerCount - 1);
float layer0 = floor(z);
float layer1 = min(layer0 + 1, layerCount - 1);
float t = frac(z);

float3 c0 = SampleArray(uv, layer0);
float3 c1 = SampleArray(uv, layer1);
float3 color = lerp(c0, c1, t);
```

所以纹理数组并非不能实现，而是需要自己处理 Z 方向的层间插值；三维纹理更直接地表达“亮度连续变化的图像体”，并能利用硬件过滤。这里的三维纹理仍然只是图像层的容器，不代表真实的三维空间体积。
