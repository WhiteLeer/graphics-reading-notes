# 薄膜干涉与衍射

## 我的理解

薄膜干涉和衍射都会产生随视角变化的彩虹色，但它们不是同一种现象。

```text
薄膜干涉：薄膜上下表面的反射光发生干涉
衍射：微结构不同位置产生的波发生干涉
```

薄膜干涉常见于油膜、肥皂泡和金属氧化层；衍射常见于 CD、DVD、光栅和具有周期性细密纹理的表面。

## 为什么普通 BRDF 不够？

普通的 Cook-Torrance 等 BRDF 通常将光近似成射线，并用颜色、粗糙度、法线等参数描述反射。当表面细节远大于光的波长时，这种近似通常足够。

但 CD 轨道等微结构的尺寸接近可见光波长，光的波动性不能忽略：

```text
光线模型：不同方向的光照贡献直接计算
波动模型：不同路径的光波还要根据相位进行干涉
```

## 薄膜干涉与衍射的区别

### 薄膜干涉

光在薄膜的上表面和下表面发生反射。下表面反射光在薄膜内部多传播了一段距离，因此两束光之间产生相位差。

```text
空气
  ├─ 上表面反射
  └─ 进入薄膜 → 下表面反射 → 离开薄膜
                         ↓
                   两束光干涉
```

相位差大致受以下因素影响：

- 光的波长；
- 薄膜厚度；
- 薄膜折射率；
- 观察角度；
- 两次反射时是否产生额外的半波相位变化。

### 衍射

衍射表面可以理解为由很多周期性、平行的微小反射条纹组成。每个条纹都会产生反射波，不同条纹的反射波在观察方向上相互叠加。

```text
周期性微结构
    ↓
不同位置产生反射波
    ↓
波之间相长或相消
    ↓
某些波长和方向变亮
```

因此，“结构限制了光的传播”可以作为直观理解，但真正形成彩色高光的核心仍然是：

```text
微结构改变传播路径
    ↓
路径差形成相位差
    ↓
不同波长产生不同程度的干涉
```

## 衍射光栅模型

本章把表面简化成一个衍射光栅：许多平行、狭窄、间距为 `d` 的反射条纹。

光源和观察者相对于条纹方向的角度决定了不同条纹之间的路径差。满足特定相位关系的波长会相长干涉，因此形成高亮颜色。

真实的物理模型需要计算所有可见波长，但实时 Shader 通常只选取有限数量的波长，并通过彩虹映射转换为 RGB。

## Shader 输入

本章实现的是一个顶点 Shader，但同样可以放到 Fragment Shader 或现代材质函数中。对于任意表面，至少需要：

- 位置 `P`；
- 法线 `N`；
- 表示条纹方向的切线 `T`；
- 光源方向 `L`；
- 视线方向 `V`；
- 条纹间距 `d`；
- 高光粗糙度 `r`。

这里的切线不是普通的“随便一个切线”，而是表示表面微结构的主方向。例如 CD 上的切线方向可以表示光盘轨道的方向。

## 工程计算流程

```text
变换位置、法线、切线
    ↓
计算光线方向 L 和视线方向 V
    ↓
计算半角向量 H = L + V
    ↓
将 H 投影到切线方向 T
    ↓
根据投影结果和条纹间距 d 计算可能增强的波长
    ↓
用彩虹函数或 1D LUT 将波长转换为颜色
    ↓
叠加各波长的颜色贡献
    ↓
再加上主方向上的各向异性高光
```

书中的关键量可以简化理解为：

```hlsl
float3 H = L + V;
float u = dot(T, H) * spacing;
float w = dot(N, H);
```

`u` 描述半角方向相对于条纹方向的关系，`spacing` 控制微结构间距。随后根据 `u` 和不同的整数阶次 `n`，估计哪些波长会相长干涉。

书中固定循环计算若干个阶次，并将它们的结果相加。由于当时的 Shader 编译器会展开循环，循环次数不能太复杂，所以使用了固定数量的波长贡献。

## 彩虹颜色映射

严格来说，应该根据可见光波长得到光谱反射结果，再转换为 RGB。书中使用了简化的彩虹函数：分别用三个峰值函数近似蓝、绿、红三个区域，然后组合成彩虹色。

现代实现也可以使用一张一维彩虹 LUT：

```hlsl
float3 color = SAMPLE_TEXTURE1D(_RainbowLUT, sampler, wavelength01);
```

这种方式艺术控制更方便，但它仍然是对光谱到 RGB 转换的近似。

## 各向异性高光

当观察方向接近镜面反射方向时，理论上的衍射高光可能非常尖锐。但真实表面的条纹并不完美，因此高光会扩散。

本章额外叠加了一个各向异性高光：

```text
衍射彩色条纹
    +
各向异性白色或有色高光
    ↓
最终反射结果
```

这也是工程实现中常见的做法：物理模型负责产生主要特征，传统 BRDF 负责补足粗糙度、亮度和形状控制。

## 薄膜干涉的实时实现

薄膜干涉通常将薄膜看成：

```text
空气 → 薄膜 → 基底
```

Shader 根据法线和视线计算观察角度，再根据薄膜厚度、折射率和波长估计相位差。

```hlsl
float NoV = saturate(dot(N, V));
float cosThetaFilm = ComputeRefractedAngle(NoV, airIOR, filmIOR);

float3 wavelength = float3(650.0, 510.0, 475.0);
float3 phase = 4.0 * PI * filmIOR * thickness
             * cosThetaFilm / wavelength;

float3 filmFresnel = EvaluateThinFilmInterference(
    phase, airIOR, filmIOR, baseIOR);
```

最后将薄膜反射结果作为 Cook-Torrance 中的 Fresnel 项：

```text
D、G：仍然使用微表面模型
F：使用薄膜干涉计算结果
```

实时工程中常见三种精度：

1. 只根据视角生成彩虹色，成本最低；
2. 用红、绿、蓝三个代表波长计算，效果和成本比较平衡；
3. 预计算观察角度、厚度和折射率对应的 LUT，运行时快速采样。

## 材质中的参数含义

### 油膜

油膜需要变化的厚度，因此通常使用噪声或贴图控制：

```hlsl
thickness = baseThickness + noise * variation;
```

### 高温金属或氧化金属

可以看成：

```text
空气 → 氧化层 → 金属
```

薄膜参数控制角度变色，金属基底仍然负责主要的金属反射。

### 肥皂泡

可以看成：

```text
空气 → 肥皂液薄膜 → 空气
```

肥皂膜厚度通常变化很大，因此颜色会形成大面积流动条纹，同时还需要较强的 Fresnel 边缘反射和透射效果。

## 工程上的近似和限制

实时薄膜或衍射 Shader 通常不会完整模拟所有光谱、偏振、复杂多层材质和真实微结构，而会进行以下近似：

- 只计算 RGB 三个波段；
- 使用固定数量的干涉阶次；
- 用彩虹 LUT 代替完整光谱转换；
- 用噪声或厚度图代替真实微观几何；
- 用各向异性 BRDF 补足高光形状；
- 用参数化强度控制艺术效果。

## 总结

```text
薄膜干涉
    = 多层界面的反射光干涉
    = 厚度 + 折射率 + 观察角度

衍射
    = 周期性微结构产生的反射波干涉
    = 条纹间距 + 切线方向 + 光线和视线方向
```

两者的共同点是光的波动性和相位干涉；区别在于，薄膜干涉主要来自多层界面之间的光程差，衍射主要来自周期性微结构不同位置之间的光程差。
