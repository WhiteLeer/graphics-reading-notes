# 改进 Perlin 噪声的实现

## 我的理解

Perlin Noise 不是给每个像素直接生成一个随机值，也不是对随机图片简单做高斯模糊。它是在连续空间中建立规则网格，在网格角点放置伪随机梯度方向，然后根据角点对当前点的影响进行平滑插值。

```text
规则噪声网格
    ↓
角点伪随机梯度方向
    ↓
梯度与位置偏移做点积
    ↓
使用 Fade 函数平滑插值
    ↓
得到当前空间位置的 Noise 值
```

## 噪声网格不等于像素网格

Perlin Noise 的网格是数学空间中的采样晶格，而不是屏幕像素。像素只是对这个连续函数进行采样：

```text
连续 Noise 函数
    ↓
根据每个像素的 UV / 世界坐标采样
```

一个噪声网格单元可以覆盖许多像素，也可以根据噪声缩放参数覆盖很小或很大的空间范围。

## Perlin Noise 的具体计算

以二维网格为例：

```text
●────────●
│   P    │
●────────●
```

四个角点分别保存一个伪随机梯度方向，而不是直接保存一个随机高度值：

```text
↗────────←
│    P   │
↓────────↖
```

对于每个角点：

1. 计算角点指向 `P` 的位置偏移向量；
2. 将角点的随机梯度方向与这个偏移向量做点积；
3. 得到这个角点对 `P` 的局部贡献；
4. 将四个角点的贡献混合起来。

```hlsl
cornerContribution =
    dot(randomGradient, point - cornerPosition);
```

点积可以直观理解为：

- 梯度方向与位移方向相近：贡献较大；
- 两者相反：贡献为负；
- 两者垂直：贡献接近零。

三维版本完全相同，只是一个立方体有 8 个角点，而二维正方形只有 4 个角点。

## 它为什么是连续的？

当采样点 `P` 缓慢移动时：

```text
P 移动一点
    ↓
P 到角点的偏移只改变一点
    ↓
点积贡献只改变一点
    ↓
最终 Noise 值也只改变一点
```

为了让相邻网格单元在边界处连接得更自然，不能直接使用生硬的线性权重，而要先使用 Fade 函数。

原始 Perlin Noise 常用三次函数：

```text
f(t) = 3t² - 2t³
```

改进版本使用五次函数：

```text
f(t) = 6t⁵ - 15t⁴ + 10t³
```

五次函数在 `t=0` 和 `t=1` 处不仅一阶导数为零，二阶导数也为零，因此用于法线和凹凸时不容易出现网格边界伪影。

典型的二维混合过程是：

```hlsl
float bottom = lerp(value00, value10, fade.x);
float top    = lerp(value01, value11, fade.x);
float result = lerp(bottom, top, fade.y);
```

## 它不是高斯噪声

Perlin Noise 看起来像被平滑过的随机场，但这里的平滑并不是通过高斯函数完成的。

```text
高斯函数：
    常用于高斯分布或高斯模糊

Perlin Noise：
    伪随机梯度
    + 点积
    + 多项式插值
```

如果四个角点直接保存随机标量值，再进行插值，这更接近 Value Noise。Perlin Noise 的特点是角点保存梯度方向，再通过点积计算局部变化。

## 为什么使用少量、分布均匀的梯度？

原始实现中随机梯度方向可能在球面上分布不均匀，某些方向聚集会产生斑点。改进方法使用少量但分布更均匀的方向，例如立方体边中心附近的 12 个方向，实际实现中可以扩展到 16 个索引。

这样做的好处是：

- 减少梯度方向聚集造成的斑点；
- Hash 只需要返回少量索引；
- 某些点积可以简化，例如：

```text
dot((x, y, z), (1, 1, 0)) = x + y
```

因此，伪随机方向不是越多越好，统计分布均匀更重要。

## GPU 中的直接实现

在 Pixel Shader 或 Compute Shader 中，可以对每个采样点执行：

```text
1. 根据坐标计算所在网格 cell；
2. 计算局部坐标 frac(P)；
3. Hash 网格坐标，得到角点梯度；
4. 计算角点到 P 的偏移；
5. 执行点积；
6. 使用 Fade 和多次 lerp；
7. 输出 Noise 值。
```

简单使用方式：

```hlsl
float3 p = worldPosition * _NoiseScale;
float noise = PerlinNoise3D(p);
float3 color = lerp(_ColorA, _ColorB, noise);
```

它可以直接生成云、岩石、火焰、木纹、溶解遮罩和程序化法线。

## 用小体积纹理近似三维 Noise

直接在 Shader 中计算三维 Perlin Noise 会占用不少指令，因此也可以把噪声预先放进小的三维纹理中，并使用三线性采样：

```text
小体积 Noise Texture
    → 三线性插值
    → 连续的三维噪声值
```

但小纹理直接平铺会产生明显重复：

```text
小块 A | 小块 A | 小块 A
```

书中的改进方法是使用两个频率：

```text
高频小纹理
    → 提供细节

低频纹理
    → 改变高频纹理的相位或旋转
```

低频变化会让高频纹理在不同区域产生不同的相位，从而隐藏明显的 Tile 重复。它没有从数学上消除周期性，只是让重复结构不容易被看出来。

## 多层 Noise：FBM 和 Turbulence

一层 Noise 通常只提供一个尺度的起伏。实际项目会叠加多个频率：

```hlsl
float value = 0;
float amplitude = 1;
float frequency = 1;

for (int i = 0; i < Octaves; i++)
{
    value += amplitude * PerlinNoise(p * frequency);
    frequency *= 2;
    amplitude *= 0.5;
}
```

这种多尺度叠加叫 FBM，即 Fractal Brownian Motion。

如果再使用绝对值：

```hlsl
value += amplitude * abs(PerlinNoise(p * frequency));
```

就可以形成 Turbulence 风格的翻卷、破碎结构。

大理石纹理则可以把噪声加入正弦函数：

```hlsl
marble = sin(x * frequency + turbulence * distortion);
```

## Noise 生成 Bump 法线

可以把 Noise 当作高度函数：

```text
height = Noise(P)
```

然后用有限差分估计梯度：

```hlsl
float e = 0.001;

float dx = Noise(P + float3(e, 0, 0)) - Noise(P);
float dy = Noise(P + float3(0, e, 0)) - Noise(P);
float dz = Noise(P + float3(0, 0, e)) - Noise(P);

float3 gradient = float3(dx, dy, dz);
normal = normalize(normal - strength * gradient);
```

本质过程是：

```text
Noise 高度函数
    → 求空间梯度
    → 修改原始法线
    → 得到程序化 Bump
```

这也是本章强调改进插值函数的原因：如果 Noise 在网格边界处导数不平滑，生成的法线和高光也会出现接缝或跳变。

## 与普通贴图的区别

普通 Normal Map 是预先制作好的：

```text
Normal Texture
    → 运行时直接采样
```

程序化 Noise 则是运行时计算的：

```text
坐标 + 时间
    → Noise
    → 高度、颜色、遮罩或法线
```

程序化 Noise 的优点：

- 不需要制作大尺寸纹理；
- 可以无限延展；
- 不依赖 UV；
- 可以用时间参数动画；
- 适合云、火焰、溶解和地形。

缺点：

- Shader 指令和纹理访问可能较多；
- 多层 Noise 会增加成本；
- 高频超过像素采样能力时会产生闪烁和 aliasing；
- 需要根据屏幕尺寸控制频率。

## 总结

```text
Perlin Noise：
    不是随机像素，也不是高斯模糊

它的核心：
    规则网格
    + 伪随机梯度方向
    + 点积
    + 五次 Fade 插值

它的扩展：
    Noise → FBM / Turbulence → 云、火焰、岩石和大理石

它还可以：
    作为高度函数求导
    → 生成程序化 Bump 法线
```
