# 阴影贴图抗锯齿

## 我的理解

阴影贴图相关技术可以分成几个不同层次：

```text
CSM / PSSM：
    决定阴影贴图如何分区、分配分辨率

PCF：
    决定多个 Shadow Map 比较结果如何平均

PCSS：
    根据遮挡物和接收面的关系估计半影，再进行可变范围过滤
```

它们不是互斥方案，而是可以组合使用：

```text
CSM + PCF
CSM + PCSS
```

## Shadow Map 的基本问题

Shadow Map 的基本流程是：

```text
从光源视角渲染遮挡物深度
    ↓
得到 Shadow Map
    ↓
主相机渲染时转换到光源空间
    ↓
比较接收点深度和 Shadow Map 深度
    ↓
判断是否在阴影中
```

最简单的判断只有 0 和 1：

```hlsl
float shadow =
    receiverDepth <= shadowDepth ? 1.0 : 0.0;
```

因此阴影边缘会出现明显锯齿，尤其是 Shadow Map 被投影到较大屏幕区域时。

## Shadow Map 的放大锯齿

当光源空间中的一个 texel 覆盖较大的屏幕区域时，会出现：

```text
一个 Shadow Map texel
    ↓
覆盖多个屏幕像素
    ↓
多个像素得到相同的深度比较结果
    ↓
阴影边缘呈现阶梯状
```

只提高 Shadow Map 分辨率可以缓解问题，但不能完全解决：

- 远处或斜向表面上的投影可能非常严重；
- 大范围太阳光需要覆盖巨大区域；
- 阴影分辨率和显存、渲染时间有限；
- 光线几乎平行于接收面时，投影放大程度可能非常高。

## CSM：Cascaded Shadow Map

CSM 主要用于方向光，例如太阳光。它将相机视锥沿深度方向切分成多个 Cascade：

```text
Cascade 0：近处，高分辨率
Cascade 1：中处
Cascade 2：远处
Cascade 3：更远，低分辨率
```

近处物体距离相机近、占据更多屏幕像素，阴影更容易被观察到，因此应当分配更多 Shadow Map texel。远处区域则可以使用较低分辨率。

CSM 的核心不是单纯减少性能，而是：

> 将有限的阴影贴图分辨率按照相机距离重新分配。

它通常会增加多个 Shadow Map Pass，因此可能增加渲染成本，但能够显著改善近处阴影质量。

CSM 的基本流程：

```text
划分相机视锥
    ↓
为每个 Cascade 计算光源投影矩阵
    ↓
分别渲染各 Cascade 的 Shadow Map
    ↓
主相机根据深度选择对应 Cascade
    ↓
采样和比较阴影
```

CSM 可能遇到：

- Cascade 之间接缝；
- Cascade 切换时阴影抖动；
- 不同区域分辨率不一致；
- 级联数量增加导致 Shadow Pass 增多。

## PCF：Percentage-Closer Filtering

PCF 不直接模糊深度值，而是：

1. 对多个 Shadow Map 样本分别进行深度比较；
2. 对比较结果求平均。

```hlsl
float shadow = 0;

for each sample
{
    shadow += receiverDepth <= sampleDepth
              ? 1.0
              : 0.0;
}

shadow /= sampleCount;
```

例如四个比较结果是：

```text
1、1、0、0
```

平均后得到：

```text
shadow = 0.5
```

这会把阴影边缘从纯黑或纯白变成中间灰度。

### 为什么不能先模糊深度？

深度比较是一个非线性判断：

```text
先平均深度，再比较
    ≠
先比较每个样本，再平均结果
```

正确的 PCF 是：

```text
shadow =
    average(compare(receiverDepth, sampleDepth_i))
```

而不是：

```text
compare(receiverDepth, average(sampleDepth_i))
```

### PCF 的特点

优点：

- 能减轻 Shadow Map 锯齿；
- 可以产生简单的软边；
- 实现直观；
- 可以使用硬件比较采样。

缺点：

- 过滤半径通常固定；
- 不考虑遮挡物和接收面的距离；
- 不能真实模拟面光源；
- 采样次数增加会增加纹理读取成本。

## PCSS：Percentage-Closer Soft Shadows

PCSS 是在 PCF 基础上的改进。它不使用固定的过滤范围，而是先估计半影大小。

基本流程：

```text
1. Blocker Search
   在接收点附近寻找遮挡物

2. 计算平均遮挡深度
   得到 blockerDepth

3. 估计半影大小
   根据光源大小和遮挡关系计算

4. 使用可变半径 PCF
   在估计范围内进行多次比较
```

直观关系是：

```text
遮挡物靠近接收面
    → 半影较小，阴影较硬

遮挡物远离接收面
    → 半影较大，阴影较软
```

理想化地，半影大小与以下关系有关：

```text
半影宽度 ∝
光源尺寸 ×
(接收面距离 - 遮挡物距离)
÷ 遮挡物距离
```

PCSS 比固定半径 PCF 更接近面光源产生的软阴影，但成本也更高：

- 需要额外的 Blocker Search；
- 之后还要执行可变半径 PCF；
- 采样数量可能较多；
- 可能出现噪声和性能波动；
- 仍然是实时近似，不是真正的光线追踪。

## CSM、PCF 和 PCSS 的关系

这三种技术解决的是不同问题：

| 技术 | 解决的问题 |
|---|---|
| CSM | Shadow Map 应该覆盖哪些空间区域 |
| PCF | 多个阴影比较结果如何平滑 |
| PCSS | 阴影过滤半径应该根据什么变化 |

因此：

```text
CSM：
    负责空间分区

PCF：
    负责固定范围过滤

PCSS：
    负责根据遮挡关系估计可变范围过滤
```

## 其他常见阴影技术

### VSM / EVSM / MSM

这类方法改变 Shadow Map 中保存的数据形式，例如保存深度的统计量或矩信息，使 Shadow Map 更容易预过滤。

优点：

- 可以用纹理过滤器快速得到统计结果；
- 过滤范围更灵活；
- 有机会减少逐样本深度比较。

缺点：

- 可能出现 Light Bleeding；
- 需要额外的数学约束；
- 过滤结果不一定严格对应真实可见性。

### Shadow Atlas

将多个光源或多个阴影区域放到同一张大纹理中，减少资源管理开销，但需要处理：

- 图集分配；
- 区域边界；
- 不同分辨率；
- 更新和缓存。

### Virtual Shadow Map

通过分页和虚拟化管理超大范围、高分辨率的阴影贴图，适合现代大型场景。它主要改变 Shadow Map 的存储、分配和更新方式，并不等同于 PCF 或 PCSS。

### Ray-Traced Shadow

从接收点向光源发射光线，可以直接处理遮挡和面光源软阴影，但成本较高，通常需要限制采样并进行降噪。

## 性能关系

```text
CSM：
    Cascade 越多
    → 阴影深度 Pass 越多

PCF：
    样本越多
    → 纹理读取和比较越多

PCSS：
    Blocker Search + 可变 PCF
    → 成本通常高于 PCF

VSM / EVSM：
    采样可能更便宜
    → 但需要处理统计误差和漏光
```

## 总结

```text
CSM：
    级联阴影
    通过分区把分辨率集中给近处

PCF：
    多次深度比较后平均
    减少锯齿并产生固定范围的软边

PCSS：
    先寻找遮挡物
    再根据遮挡关系估计半影
    最后使用可变范围 PCF
```

最重要的理解是：

> CSM、PCF 和 PCSS 不在同一个层次上。CSM 决定阴影贴图怎么分区，PCF 决定怎么过滤，PCSS 决定过滤范围如何随遮挡关系变化。
