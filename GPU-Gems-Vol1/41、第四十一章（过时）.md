# 实时立体图

## 本章主线

本章讨论如何用 GPU 生成单图立体图，尤其是单图随机点立体图。它不是把完整三维模型直接渲染成普通画面，而是把深度信息转换成图案的水平视差，让双眼通过匹配重复图案产生立体感。

## 和普通 3D 游戏画面的区别

最终的游戏画面当然也是二维图像，但普通单屏游戏通常把同一张图同时给左右眼观看：

```text
同一张 2D 画面
    → 左眼
    → 右眼
```

它主要利用透视、遮挡、阴影、纹理和运动视差产生单眼深度感。GPU 内部的深度缓冲主要用于遮挡和深度测试，并不自动代表左右眼之间存在视差。

立体图做的是另一件事：在一张图片内部编码左右眼需要匹配的不同位置。

```text
二维图案 + 水平视差
        → 双眼匹配
        → 大脑推断深度
```

## 立体图如何产生深度

先准备一张重复纹理或随机点图案，再根据深度图对局部图案进行水平位移：

```text
深度图
  ↓
计算水平偏移
  ↓
重复图案局部错位
  ↓
左右眼看到不同的匹配位置
  ↓
产生立体深度感
```

深度值越大，通常对应越大的水平视差。不同的视差方向还可以让凸起和凹陷互换。

## GPU 的实现思路

片元 Shader 可以对每个输出像素执行：

1. 读取当前像素的深度值；
2. 根据深度和深度系数计算水平偏移；
3. 在前一个纹理条带中寻找对应位置；
4. 如果没有对应内容，就使用重复图案填充；
5. 输出最终颜色。

也可以先渲染普通 3D 场景，再把它的 Z-Buffer 当作深度图：

```text
普通 3D 场景
    → 深度缓冲
    → 立体图生成 Shader
    → 动态立体图
```

因此场景移动时，立体图也可以实时更新。

## 这项技术是否只是主观感觉

深度最终确实是视觉系统的感知，但效果是可重复验证的：

- 修改深度图，隐藏形状会发生变化；
- 增大位移系数，感知到的深度会增强；
- 交换左右眼对应关系，凸起和凹陷会反转；
- 单眼观看时，立体效果会明显减弱；
- 随机点图案本身没有明显形状，但双眼融合后能够出现隐藏形状。

## 工程意义

这章不是现代 VR 的主流实现，具体的立体图生成 Shader 也没有广泛用于普通游戏。它更适合作为一个 GPU 图像编码案例：

- 深度图可以转换成水平视差；
- Z-Buffer 可以作为后续图像算法的输入；
- GPU 可以逐像素生成携带空间信息的二维图案。

## 我的理解

本章可以简化为：

> 普通游戏画面是用透视、遮挡和光照暗示深度；立体图则把深度转换成双眼之间的图案视差，依靠双眼匹配恢复深度。

它和普通 3D 渲染都从三维或深度信息得到二维图像，但编码深度的方式不同。
