# 近似 SSS

## 次表面散射是什么

普通表面着色通常假设光线到达表面后立即反射；但皮肤、蜡、玉石、大理石等材质会让光线进入表面，在内部发生吸收和散射，最后从入射点附近甚至另一侧重新出射。

因此次表面散射常表现为：

- 光照向邻近区域扩散；
- 阴影边界变柔和；
- 细小表面细节被软化；
- 薄的区域更容易透光；
- 皮肤背光边缘出现偏红的散射颜色。

完整的 BSSRDF 需要考虑入射位置、出射位置、光线方向、材质内部结构等，实时渲染通常使用近似方法。

## 方案一：Wrap Lighting

普通 Lambert 漫反射是：

```hlsl
diffuse = max(dot(N, L), 0);
```

当光线位于表面侧面或背面时，光照很快变成零。Wrap Lighting 把漫反射函数向法线背面扩展：

```hlsl
wrapDiffuse = max((dot(N, L) + wrap) / (1 + wrap), 0);
```

它可以产生更柔和的边缘光和轻微的透光感，但没有真正模拟光线在物体内部的传播，只是修改了光照曲线，属于低成本视觉近似。

## 方案二：LUT 近似

可以把经验性的皮肤光照曲线预先烘焙到 LUT 中，运行时使用 `N·L`、`N·H` 等量查表：

```text
LUT.X：N·L
LUT.Y：N·H
LUT.RGB：漫反射与散射颜色
LUT.A：高光或其他光照项
```

这样可以将 Wrap Lighting、边缘偏红、漫反射衰减和高光曲线合并到一次纹理采样中。

## 方案三：用深度图估计厚度

次表面散射和透射都受光线在物体内部经过的距离影响。可以从光源视角渲染一张深度/距离图，记录光线进入物体时的距离 `d_i`。

正常渲染物体表面时，计算光线到当前出射点的距离 `d_o`：

```text
物体内部传播距离：s = d_o - d_i
```

然后用 Beer-Lambert 形式估计吸收：

```hlsl
transmittance = exp(-s * sigmaT);
```

厚度较小的耳朵、鼻翼和手指等区域更容易产生背光透射；厚度较大的区域吸收更多，透射更弱。

这张图与 Shadow Map 的生成方式相似，但含义不同：

- Shadow Map：记录光源到第一个遮挡表面的深度，用于判断遮挡；
- SSS 厚度图：估计光线在当前物体内部传播的距离。

### 局限

单层深度主要适合凸物体。对于孔洞、凹陷和复杂内部结构，一层深度无法表示所有进入和离开物体的表面，可能需要 Depth Peeling、多层深度或体积表示。

此外，如果只做吸收而不做空间扩散，可能会看到背面几何细节直接透到正面，缺少真正的柔和散射。

## 方案四：Texture-Space Diffusion

Texture-Space Diffusion 先把模型展开到 UV 空间，在 UV 空间计算光照并模糊，再重新映射回模型：

```text
模型
  ↓ UV 展开
UV 空间光照纹理
  ↓ 空间扩散/卷积
模糊后的散射光照
  ↓ UV 采样
模型最终颜色
```

它不是直接模糊屏幕截图，而是在模型自己的纹理空间中扩散，因此不容易把背景或其他物体混进来。

实现要求：

- UV 尽量不重叠；
- UV 岛接缝需要处理；
- UV 展开尽量均匀，使纹理距离近似表示表面距离；
- 需要额外的 UV 光照 Pass 和模糊 Pass。

GPU 上通常使用可分离卷积：先做横向模糊，再做纵向模糊。为了模拟不同波长的散射，可以给 RGB 通道使用不同的权重和扩散半径：

```text
红光：扩散距离较大
绿光：中等
蓝光：扩散距离较小
```

最终通常只扩散漫反射/非镜面光照，再与保持清晰的镜面反射合成：

```text
最终颜色 = 模糊后的散射漫反射 + 未模糊的镜面反射 + 其他项
```

## 现代 SSS 与本章的关系

现代实时 SSS 仍然沿用本章的总体方向，但把数据和滤波组织得更复杂：

| GPU Gems 思路 | 现代对应 |
| --- | --- |
| Wrap Lighting | 低成本 Subsurface/Two-Sided Wrap |
| 深度图厚度 | Thickness Map、Transmission、光源方向厚度估计 |
| LUT | 散射曲线、预积分函数、材质 Profile |
| Texture-Space Diffusion | UV 空间 SSS |
| 高斯模糊 | Separable Blur、Diffusion Profile 卷积 |
| 单次散射 | 体积或方向上的单次散射近似 |
| 扩散近似 | 皮肤等高散射材料的多次散射近似 |

现代屏幕空间 SSS 通常先提取非镜面光照，再使用带颜色权重、采样位置和世界空间半径的散射 Profile 进行过滤。它本质上仍然是对漫反射进行空间扩散，但还需要处理深度边界、法线、材质 Mask、散射半径和能量守恒等问题。

## 厚度、散射函数和漫反射模糊的区别

这三个概念不能完全等同：

- 厚度图：描述光线在物体内部传播多远，主要影响吸收和透射；
- 散射函数/Profile：描述光从入射点向周围扩散的距离和颜色权重；
- 漫反射模糊：具体执行空间扩散的工程手段，常用卷积或近似滤波实现。

可以粗略理解为：

```text
厚度图决定“能穿多远”
散射 Profile 决定“向周围扩散多少”
模糊/卷积负责“把这个扩散实际算出来”
```

## 工程判断

如果只使用 Wrap Lighting，成本最低但更像柔和漫反射；如果使用厚度图，可以表现薄区域透光，但不等于完整 SSS；如果使用 Texture-Space 或 Screen-Space Diffusion，才能明显表现光照向邻近区域扩散的效果。

因此“SSS 就是模糊漫反射”在工程上是一个有用的第一近似，但完整的实时实现还需要决定：在哪个空间模糊、模糊什么、怎样防止跨物体泄漏、如何根据厚度和 RGB 散射参数控制卷积。
