# GPU 做 3D 渲染

## 本章主线

本章和上一章确实有明显的继承关系：可以把它理解为把二维的网格/纹理处理扩展到三维体积数据，再增加沿视线进行采样和透明度累积的渲染步骤。

但它不只是简单地把 2D Texture 换成 3D Texture。新增的核心问题是：三维空间中的数据如何被观察者看到，以及一条视线穿过体积后应该如何累积颜色和透明度。

## 体积数据

体积被离散成三维网格：

```text
Volume = 一组 3D 网格单元
Voxel  = 一个体积单元
```

每个 Voxel 可以保存密度、温度、颜色、医学扫描值或其他数据。实际通常放在 3D Texture 中，三维纹理坐标对应空间中的位置。

这和普通模型的区别是：

- 三角形模型主要描述物体表面；
- 体积数据描述空间内部每个位置的状态；
- 渲染时不一定需要先提取出明确的表面。

因此，烟雾、云、火焰、雾气以及 CT/超声数据都适合使用体积表示。

## Transfer Function

Voxel 中保存的数值通常不能直接作为最终颜色，需要通过 Transfer Function 将数据映射为颜色和透明度：

```text
密度/温度/扫描值
        ↓
Transfer Function
        ↓
颜色 + Alpha
```

例如：

- 低密度映射为透明；
- 中密度映射为半透明灰色；
- 高温度映射为黄色或红色；
- 医学扫描值映射为特定组织颜色。

Transfer Function 可以是一张 1D LUT，也可以直接由 Shader 中的函数计算。

## 经典纹理切片方案

GPU Gems 1 主要介绍 Texture-Based Volume Rendering，而不是现代意义上的完整 Ray Marching。基本做法是：

```text
准备 3D Texture
    ↓
在体积内部生成许多张切片
    ↓
切片采样 3D Texture
    ↓
Transfer Function 得到颜色和透明度
    ↓
按前后顺序 Alpha Blend
    ↓
得到最终图像
```

切片通常与视线方向垂直。可以把它想象成很多张半透明玻璃片叠在一起：

```text
前方切片 + 后方切片 + 更后方切片 + ... = 体积效果
```

切片越多，沿视线的采样越密，效果通常越平滑，但片元数量和 Overdraw 也会增加。

## 与上一章流体模拟的关系

上一章主要计算流体状态：

```text
速度场、压力场、密度场
```

本章主要讨论如何显示这些三维状态：

```text
密度场/温度场
    → 3D Texture
    → 沿视线采样
    → 颜色与透明度累积
    → 体积画面
```

因此可以组合为：

```text
GPU 流体模拟 → 产生 Volume Data → 体积渲染
```

但体积渲染也可以独立使用，不一定需要实时流体模拟，例如直接显示烘焙好的烟雾缓存、云数据或医学扫描数据。

## 与 Ray Marching 的区别

本章使用的是纹理切片。现代实时体积效果还常使用 Ray Marching：

- 纹理切片：绘制许多代理几何体，让光栅化器产生片元；
- Ray Marching：每个屏幕像素沿视线在 3D Texture 中连续采样多次。

二者都在近似同一个过程：

```text
沿视线采样体积
    → 根据采样值计算颜色和透明度
    → 按顺序累积
```

Ray Marching 更灵活，容易加入体积光、阴影、噪声和视线方向相关效果，但每个像素需要执行多次采样，性能成本通常更高。

## 主要性能问题

体积渲染很容易受到 Fill Rate 和纹理带宽限制：

- 切片数量多；
- 透明切片带来大量 Overdraw；
- 片元需要反复采样 3D Texture；
- 3D Texture 占用显存和带宽；
- 透明累积不能像不透明物体那样充分利用 Early-Z。

常见优化包括：

- 降低体积纹理分辨率；
- 减少切片数量或 Ray Marching 步数；
- 跳过空区域；
- 使用低分辨率体积缓存再上采样；
- 对远处体积降低更新频率；
- 使用更简单的 Transfer Function；
- 采用预积分或时间累积减少采样不足造成的伪影。

## 我的理解

可以用一句话概括：

> 第三十九章确实是把上一章的二维数据处理扩展到三维，但真正新增的是“体积数据的表达方式”和“沿视线进行采样、混合、累积”的渲染过程。

所以它不是单纯换成 3D Texture，而是：

```text
二维局部计算
    → 三维体素数据
    → 视线方向采样
    → 透明度/颜色累积
    → 体积渲染
```
