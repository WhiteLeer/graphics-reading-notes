# 基于物理模型的有效水面模拟

## 章节内容

基于物理的实时水面模拟，结合几何形变和动态法线贴图，适用于从池塘到海洋的各种水体。

**作者**: Mark Finch (Cyan Worlds)

### 核心概念

基于物理的实时水面模拟，结合几何形变和动态法线贴图，适用于从池塘到海洋的各种水体。

### 技术要点

**1. Gerstner波模型**
- 波函数：正弦波叠加，每个波包含波长(L)、振幅(A)、速度(S)、方向(D)
- 物理基础：色散关系 `ω = √(gk)`，g为重力常数，k为波数
- 陡峭参数Q：控制波峰尖锐度（0=光滑，接近1/ωA时形成尖峰）

**2. 双层实现策略**
- **几何波**（4条）：顶点着色器中实现，产生网格起伏
- **纹理波**（~15条）：像素着色器中实现，生成动态法线贴图

**3. 优化技术**
- 基于网格边长的自适应波长过滤
- 深度衰减：波高随水深减小
- 查找表：优化三角函数和插值计算
- 球面环境映射修正：仅5次算术运算

**4. 应用场景**
- 《Uru: Ages Beyond Myst》游戏中的实时水体
- 最低要求：vs_1_0 和 ps_1_0

> [!tip] 关键技巧
> 将波分为几何层和纹理层，前者产生大尺度形变，后者提供细节，避免过度细分网格。

## 讨论与补充


### 我的理解

这一章的基本思路是：在 Shader 中使用正弦波或其他波函数计算水面起伏，同时计算法线、切线等表面信息，再进行反射、透明度和颜色处理。

这个思路本身并不复杂，现代项目中也仍然常见。不过本章真正有价值的地方，不只是“用正弦函数做波浪”，而是如何根据波浪的空间尺度分配计算资源。

### 核心方案：几何波浪 + 纹理波浪

```text
大尺度波浪
    → Vertex Shader 位移顶点

小尺度波纹
    → 离屏生成动态 Normal Map

最终水面材质
    → 采样法线、计算反射与透明度、混合到画面
```

- 大尺度波浪会影响水面的轮廓和遮挡关系，因此使用顶点位移表达。
- 小尺度波纹如果直接增加网格细分，成本较高，而且远处也不一定能分辨，因此使用动态法线贴图表达。
- 水面法线不是简单从一张固定贴图读取，而是可以根据波函数的偏导数直接计算。
- 顶点 Shader 和像素 Shader 分担不同任务：前者处理几何起伏和表面基底，后者处理法线贴图、环境反射和最终颜色。

这套“大尺度几何 + 小尺度法线”的分层方式，比单纯增加网格或单纯使用法线贴图更合理：前者负责真实轮廓，后者负责视觉细节。

### 波函数与法线

波浪由若干个参数描述：

- 波长：波峰之间的距离；
- 振幅：波峰相对基准面的高度；
- 速度：波峰随时间移动的速度；
- 方向：波浪传播方向。

多个波叠加后，可以得到连续的高度函数。因为有明确的函数表达式，所以可以对它在两个水平方向上求偏导，得到切线和副切线，再通过叉乘得到法线：

```text
水面位置函数 P(x, y, t)
    ↓ 对 x、y 求偏导
切线 T、副切线 B
    ↓ B × T
法线 N
```

这比使用有限差分估算法线更直接，也更容易扩展到其他波函数。

Gerstner Wave 相比普通正弦波可以让波峰更尖、波谷更宽，并通过横向移动顶点表现更有立体感的波浪。但陡峭度参数不能无限增大，否则波峰会产生自相交或翻卷。

### 这一章过时了吗？

GPU Gems 1 出版于 2004 年，因此以下内容已经明显过时：

- Shader Model 1.0 的限制；
- 旧式 Vertex Shader / Pixel Shader API；
- 早期显卡的 8 位法线贴图精度与性能假设；
- 立方体环境贴图作为主要反射方案；
- 当时对 GPU 填充率、查找表和常量优化的具体判断。

但以下思想仍然有效：

- 不同尺度的细节应该使用不同的表示方式；
- 几何位移负责轮廓，法线扰动负责细节；
- 法线可以通过程序化表面函数的导数得到；
- 网格采样频率限制了可以表现的最短波长；
- 水深、视角和波长等参数可以同时服务于视觉控制与一定程度的物理合理性。

### 与 FFT 海洋的关系

FFT 可以在频域中表示大量波浪分量，再通过二维逆 FFT 得到规则网格上的高度场和法线。它更适合大面积、连续的开放海洋，通常比手工叠加少量波浪更丰富。

```text
海浪频谱
    → 随时间更新相位
    → 逆 FFT
    → 高度场与法线
```

#### FFT 的工程实现

FFT 海洋不是直接拿两张普通噪声图做变换，而是先在频域中为每个波数生成一个波浪分量。纹理中的一个像素通常代表一个频率、波长和传播方向，而不是水面上的一个空间位置。

```text
随机噪声
    + 海浪频谱
    ↓
频域复数波浪纹理
    ↓
二维 IFFT
    ↓
空间域高度图 / 位移图 / 斜率图
    ↓
顶点偏移与水面着色
```

随机噪声一般提供每个频率分量的随机相位和振幅，海浪频谱则控制不同波长、方向的能量大小。纹理中的实部和虚部可以放在不同通道中，例如：

```text
R：复数实部
G：复数虚部
```

根据时间更新相位后，得到当前时刻的频域波浪数据。之后使用两张 Ping-Pong 纹理执行蝶形运算：

```text
FFTBufferA → FFTBufferB
FFTBufferB → FFTBufferA
FFTBufferA → FFTBufferB
```

这两张纹理通常是 FFT 的工作缓冲区，不是两张最终的噪声图。每个蝶形运算读取一对数据 `a`、`b` 和旋转因子 `w`，计算：

```text
output1 = a + w * b
output2 = a - w * b
```

对于 `N` 个采样点，需要 `log2(N)` 个阶段。例如 `512` 个采样点需要 9 个阶段。二维 FFT 则先对每一行做一维 FFT，再对每一列做一维 FFT：

```text
水平方向 FFT：log2(N) 个 Pass
垂直方向 FFT：log2(N) 个 Pass
```

经过二维 IFFT 后，数据才变成空间域中的高度场：

```text
HeightMap[x, z] = 水面在空间位置 (x, z) 的高度
```

然后顶点 Shader 可以采样位移图：

```hlsl
float3 displacement = SAMPLE_TEXTURE2D(
    DisplacementMap, sampler_DisplacementMap, uv).xyz;
vertexPosition += displacement;
```

法线可以通过高度图的相邻采样计算，也可以在频域中先乘以 `i * kx`、`i * kz` 得到两个方向的斜率，再分别进行 IFFT：

```text
∂h/∂x  ↔  i * kx * H(k)
∂h/∂z  ↔  i * kz * H(k)

N = normalize(float3(-∂h/∂x, 1, -∂h/∂z))
```

因此，工程上完整的 FFT 水面流程是：

```text
生成随机频域波浪
    → 根据时间更新相位
    → 水平蝶形 Pass
    → 垂直蝶形 Pass
    → 得到高度、位移和斜率图
    → 顶点 Shader 采样并偏移水面网格
```

FFT 并不是本章方案的简单替代品：

- FFT 需要规则网格和多次计算 Pass；
- 它通过大量频率分量和随机相位降低了视觉上的重复感，但有限的离散网格仍然具有周期性，铺设较大范围时可能出现 Tile 重复；
- 它不擅长处理池塘、河流、岸边和局部障碍物；
- 船只、角色、爆炸产生的局部扰动仍需要额外方案。

现代水面通常混合使用：

- FFT 或大尺度 Gerstner Wave：表现海洋整体起伏；
- 局部 Gerstner Wave：提供可控的区域波浪；
- Normal Map / Flow Map：表现小尺度波纹和水流；
- 浅水模拟或交互模拟：处理岸边、碰撞和局部扰动。

因此，本章的具体实现较老，但“按波长分层，并把几何、法线贴图和材质效果分开处理”的思想仍然是现代水面渲染的基础。
