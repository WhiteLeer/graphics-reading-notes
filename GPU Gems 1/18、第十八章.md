# SBRDF

## 章节内容

Spatial BRDF (SBRDF) - 将传统纹理映射与BRDF相结合，表面每个点存储不同反射特性。

**作者**: David McAllister

### 核心概念

Spatial BRDF (SBRDF) - 将传统纹理映射与BRDF相结合，表面每个点存储不同反射特性。

### 与传统BRDF的区别

- **传统BRDF**：描述单一点的光学属性
- **SBRDF**：表面各处拥有不同的反射参数
- 处理光线与表面的复杂空间变化交互

### 纹理编码方法

**Lafortune表示法**：
- 漫反射系数 **d** 存储在一张贴图
- 每个镜面叶瓣的反照率 **s** 和形状系数 **C** 分别存储
- 八位纹理：应用缩放和偏移处理坐标范围

### Shader实现

**两种渲染策略**：

**离散光源**：
- 直接计算点光源与表面交互

**环境贴图**：
- 预卷积环境贴图与不同指数的Phong函数
- 通过LOD采样

### 应用优势

- 仅需10个系数
- 比RGB纹理更真实
- 性能开销主要为点积与指数运算
- 适合实时渲染

## 讨论与补充


### 这章在做什么

普通 BRDF 描述一个固定表面点在不同入射方向和观察方向下如何反射光线；但真实物体的材质还会随着表面位置变化。

例如木头、拉丝金属和布料的不同位置可能拥有不同的：

- 漫反射颜色；
- 粗糙度；
- 高光强度；
- 高光方向；
- 高光形状；
- 各向异性方向。

把纹理的空间变化和 BRDF 的角度变化结合起来，就得到 Spatial BRDF（SBRDF）：

```text
表面每个纹理位置都拥有一套自己的 BRDF 参数
```

这里的 Spatial 不是屏幕空间模糊，而是 BRDF 随表面位置变化。

### 最直接的表示

理论上可以在每个纹理像素保存完整 BRDF，但数据量过大。因此本章用少量参数化的高光 Lobe 近似复杂 BRDF：

```text
Diffuse
+ Specular Lobe 1
+ Specular Lobe 2
+ Specular Lobe 3
```

每个 Lobe 大致保存：

- 高光颜色或权重；
- `Cx`、`Cy`、`Cz`：控制高光瓣方向和形状；
- `n`：控制高光集中程度。

一个或多个 Lobe 叠加后，可以近似表示真实测量或艺术家绘制的表面反射。

### 局部坐标和各向异性

SBRDF 通常在表面局部坐标中计算：

```text
X：切线方向
Y：副切线方向
Z：法线方向
```

这样就可以让高光沿着材质方向变化：

- 木纹方向的拉伸高光；
- 拉丝金属沿切线方向延伸的高光；
- 布料纤维方向的反射；
- 偏离镜面方向的高光；
- Retroreflection 回射。

普通 Phong 或基础 Cook-Torrance 通常只能在有限参数范围内改变高光宽度和强度，而 Lafortune Lobe 还可以改变高光峰值方向和形状。

### 与 ID 图分支的关系

可以使用：

```hlsl
if (materialID == 0) EvaluateWood();
else if (materialID == 1) EvaluateMetal();
else if (materialID == 2) EvaluateCloth();
```

但这种方式是把材质模型硬编码到 Shader 中，材质类型一多就会出现：

- Shader 代码膨胀；
- 分支和 Shader Variant 增多；
- 同一 Warp 内不同像素走不同分支；
- 新增材质需要修改和重新编译 Shader。

SBRDF 的改进是把同一类 BRDF 的差异数据化：

```text
Material ID
    ↓
读取对应的 Lobe 参数
    ↓
使用统一的 BRDF 公式
```

运行时可以统一执行：

```hlsl
for (int i = 0; i < MAX_LOBES; i++)
{
    result += EvaluateLobe(lobeParameters[i]);
}
```

因此它不是“用 SBRDF 替代贴图”，而是“让贴图存储更复杂的 BRDF 参数”。

### SBRDF 仍然有硬编码边界

SBRDF 并没有消除所有硬编码。它仍然固定了一套可表达的 BRDF 家族，例如 Lafortune Lobe。

如果材质属于完全不同的模型，例如：

- 皮肤次表面散射；
- 毛发；
- 透明折射；
- 体积材质；
- 特殊布料模型；

就不能只靠原来的几个 Lobe 参数解决，仍然需要额外的 Shader 模型或 Shader Variant。

因此：

```text
固定几种材质模型：ID + 分支可以接受
同一 BRDF 家族内的大量连续变化：参数化 SBRDF 更合适
完全不同的光照模型：仍然需要专门 Shader 逻辑
```

### 离散光源的渲染

对于点光源或方向光：

```text
采样当前 UV 的 SBRDF 参数
        ↓
把光线方向和视线方向转换到局部坐标
        ↓
计算每个 Lobe
        ↓
叠加所有 Lobe 和光源
```

伪代码：

```hlsl
float3 result = diffuseAlbedo;

for each light
{
    float3 L = ToLocalSpace(lightDirection);
    float3 V = ToLocalSpace(viewDirection);

    for each lobe
        result += EvaluateLobe(L, V, lobeParameters);
}
```

与普通材质 Shader 的主要区别是：普通 Shader 通常从 Material 读取统一参数，而 SBRDF 从纹理中按像素读取一套参数。

### 环境光照和预卷积

如果环境贴图照亮复杂 BRDF，理论上需要对整个入射半球积分：

```text
Lo = ∫ BRDF(L, V) × Environment(L) dL
```

如果每个纹理像素都有不同 BRDF，逐像素实时积分非常昂贵。

因此本章预先用不同粗糙度或 Phong 指数对环境贴图进行卷积，并把不同模糊程度保存到 Cube Map 的不同 MIP 层级：

```text
低 MIP：尖锐高光
高 MIP：模糊高光
```

运行时根据每个像素的高光指数或粗糙度选择 MIP：

```text
粗糙度低 → 清晰环境贴图
粗糙度高 → 模糊环境贴图
```

这和现代 PBR 中的 Prefiltered Environment Map + Roughness MIP 是同一类思想。

### 与现代 PBR 的关系

现代 PBR 中的：

```text
Albedo Texture
Normal Map
Roughness Map
Metallic Map
Anisotropy Map
```

本质上已经是简化版的空间变化 BRDF：每个纹理像素拥有不同材质参数。

GPU Gems 的 SBRDF 更进一步，允许每个位置拥有多个高光 Lobe、不同的高光方向和复杂的反射形状。现代游戏通常不会直接完整使用本章的 Lafortune 表示，而是采用更规整的 PBR 参数化，但以下思想仍然常见：

- 材质参数随纹理空间变化；
- 切线控制各向异性方向；
- 粗糙度选择预卷积环境贴图 MIP；
- 复杂 BRDF 用少量参数近似；
- 将材质实例差异放进数据，而不是大量硬编码分支。

### 工程判断

SBRDF 的核心价值不是证明“普通贴图不能做材质”，而是说明：

> 纹理不只能存 BaseColor、Roughness 等常见参数，也可以存一套更完整的、随表面位置变化的 BRDF 参数。

如果只有木头、金属、布料几种固定材质，ID 图和少量分支完全可行；如果希望表达真实测量材质、拉丝方向、多个高光峰和连续变化，参数化的 SBRDF 更有价值。
