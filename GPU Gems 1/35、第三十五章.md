# 实时渲染使用近似模拟

## 章节内容

本章讨论如何利用高质量软件渲染生成实时硬件渲染所需的模型属性和纹理，并建立高模、复杂材质到低模和属性贴图的内容管线。

### 内容管线

- 在 DCC 和高质量软件渲染器中制作高质量内容。
- 创建适合硬件渲染的低分辨率几何和属性数据。
- 将高模细节、法线、漫反射、反射等信息烘焙为实时 Shader 可使用的贴图。
- 讨论几何数据、属性贴图和内容生成中的常见问题。

## 讨论与补充


### 1. 核心思路

本章提出的不是把高质量 DCC 场景直接搬入实时引擎，而是：

> 把高质量模型和离线材质产生的细节，烘焙成实时 Shader 能高效使用的贴图和顶点数据。

典型流程：

```text
高质量版本
    -> 高模、复杂材质、程序纹理、离线光照
    -> 烘焙属性数据
    -> 低模 + 实时材质
```

这就是现代常见的 High Poly -> Low Poly Baking。

### 2. 高模烘低模

高模包含大量几何细节，低模则负责运行时绘制：

```text
高模细节
    -> Normal Map / Height Map
    -> 低模 Shader 恢复表面变化
```

例如高模有几十万三角形，低模可能只有几千三角形，但借助法线贴图仍能表现出褶皱、刻痕和细小结构。

这样可以降低：

- 顶点处理成本；
- 光栅化成本；
- 蒙皮成本；
- 内存占用；
- LOD 成本。

### 3. Normal Map 烘焙

#### 3.1 模型空间法线

把高模法线输出为颜色：

```text
Normal.x -> R
Normal.y -> G
Normal.z -> B
```

编码方式通常是：

```text
encodedNormal = normal * 0.5 + 0.5
```

把 `[-1,1]` 映射到 `[0,1]`。

#### 3.2 投影到低模 UV

以低模 UV 作为纹理参数，把高模表面细节投影到低模纹理空间：

```text
高模表面细节
    -> 低模 UV 空间
    -> Object-Space Normal Map
```

#### 3.3 转换到切线空间

根据低模的 Normal、Tangent、Bitangent 构造 TBN，将模型空间法线转换为切线空间：

```text
N_tangent = transpose(TBN) * N_object
```

游戏中更常使用切线空间 Normal Map，因为它可以随模型表面使用，也更容易复用和铺设。

### 4. 高模和低模不必拓扑一致

高模和低模不需要拥有完全相同的拓扑，但表面形状应该相近：

```text
高模盔甲 -> 低模盔甲
高模布料褶皱 -> 低模布料
```

如果形状差异太大，投影会出现法线错误、细节错位和边缘伪影。

因此：

```text
拓扑可以不同
形状不能相差太大
```

### 5. 材质和属性贴图

复杂 DCC 材质可以拆成实时 Shader 能读取的属性：

```text
复杂程序材质
    -> Base Color
    -> Roughness
    -> Metallic
    -> Normal
    -> AO
    -> Emission
    -> Mask
```

但不是所有材质差异都被压缩成颜色。更合理的做法是尽量共享 Shader 结构，再通过属性和贴图区分：

```text
共享 Shader
    -> Base Color
    -> Roughness
    -> Metallic
    -> Specular
    -> Transmission
    -> Emission
    -> 各种 Mask
```

### 6. Diffuse Map 的注意事项

如果直接把高模渲染结果烘焙成“Diffuse Map”，其中可能混入：

- 光照；
- 阴影；
- 高光；
- 环境反射；
- AO。

这样得到的不一定是真正的物理 Base Color，而是已经包含部分光照的颜色。

为了尽量提取纯表面颜色，可以在烘焙时：

- 关闭高光和环境影响；
- 关闭原始光源；
- 使用均匀光照；
- 再进行必要的颜色修正。

现代 PBR 流程通常区分：

```text
Base Color -> 材质颜色
AO / Roughness / Metallic -> 独立属性
Lighting -> 运行时计算
```

### 7. 可以烘焙什么

适合烘焙的内容包括：

- 高模几何细节；
- Normal；
- AO；
- Curvature；
- Roughness；
- Metallic；
- Emission；
- Thickness；
- SSS 近似；
- 静态 GI；
- 静态阴影；
- 复杂程序纹理；
- 固定环境反射；
- Caustics 等静态效果。

### 8. 不适合直接烘焙的内容

如果效果依赖运行时状态，就不适合简单烘焙：

- 移动光源的动态阴影；
- 随视角变化的高光；
- 动态反射；
- 角色实时变形；
- 动态流体；
- 交互式破坏；
- 视角相关的折射。

这些效果通常要保留实时计算，或者使用烘焙结果作为基础，再叠加实时项。

### 9. UV 是关键基础

烘焙质量高度依赖 UV：

- UV 流向稳定；
- UV 岛合理；
- 重叠受控；
- 接缝位置合理；
- 纹素密度尽量均匀。

UV 不合理会造成：

- 法线接缝；
- 颜色断裂；
- 投影错位；
- Mipmap 边缘污染；
- 贴图利用率低。

因此烘焙错误不一定是 Shader 错误，也可能来自低模形状、UV、切线计算或烘焙 Cage 设置。

### 10. 工程上的结论

- 高模烘低模是本章最核心的实践。
- 凹凸和几何细节通常转为 Normal/Height 等属性贴图。
- 复杂材质不一定只转成颜色，更合理的是拆成 Base Color、Roughness、Metallic、Normal、Emission 和 Mask 等属性。
- 共享 Shader 结构、使用不同材质参数和贴图，通常比为每个物体写一套 Shader 更好。
- 固定条件的 GI、AO、反射和焦散可以考虑烘焙；动态、视角相关、光源相关效果通常保留实时计算。
- 本章描述的是现代游戏资产制作和实时材质制作的基础思路。
