# 光晕

## 章节内容

实时辉光效果通过屏幕空间后处理，模拟强光在视觉系统中的散射。

**作者**: Greg James, John O'Rorke

### 核心概念

实时辉光效果通过屏幕空间后处理，模拟强光在视觉系统中的散射。

### 辉光原理

视觉系统对光强度敏感性有限，区分强光的唯一方式是通过周围的辉光和光晕。

### 三阶段实现流程

**第一阶段 - 提取高亮源**：
- 使用纹理Alpha通道标记发光区域
- 场景渲染至离屏纹理
- 仅保留高亮部分

**第二阶段 - 可分离卷积模糊**：
- 采用二步高斯模糊而非2D卷积
- 复杂度从O(d²)降至O(2d)
- 关键优化：将2D卷积分解为两个1D卷积

**第三阶段 - 加法混合合成**：
- 加法透明混合将辉光叠加至原场景

### 性能优化

**分辨率缩减**：
- 可用1/4分辨率渲染辉光纹理
- 无明显质量损失

**硬件适配**：
- DirectX 7-9多层级实现
- 2纹理采样到8纹理采样

**Render-to-Texture**：
- StretchRect函数快速拷贝和缩放

### 参数动态控制

- 模糊权重按帧变化产生脉动效果
- 渲染风格映射表控制各对象发光行为
- 雾效参数调整缓解采样别名

### 应用场景

- 景深效果（不同聚焦程度）
- 投影纹理阴影柔化
- 辐照度映射近似
- 非真实感渲染

> [!success] 实战案例
> 《Tron 2.0》中实现60fps+性能，证明工程可行性。

## 讨论与补充


### Glow/Bloom 在做什么

现实中的强光源会因为眼睛、镜头或大气散射产生光晕。实时渲染中通常不直接模拟完整的光学过程，而是把亮部扩散到邻近像素：

```text
提取发光源
    ↓
低分辨率处理
    ↓
水平模糊
    ↓
垂直模糊
    ↓
加法混合回原画面
```

最终可以写成：

```text
FinalColor = SceneColor + BlurredGlow
```

它是一种图像空间的后处理近似，不是严格的物理光学模拟。

### 提取 Glow Source

需要先确定哪些像素会产生光晕。

#### 材质或贴图 Mask

材质可以提供：

- Glow Color；
- Glow Intensity；
- Glow Mask。

也可以使用原始贴图的 Alpha 通道：

```hlsl
glowSource = baseColor.rgb * glowMask;
```

这样一个模型可以只有眼睛、灯带、屏幕或装饰线发光，而不是整个模型都发光。

#### HDR 亮度阈值

现代 Bloom 常根据 HDR 亮度提取高亮：

```hlsl
brightness = Luminance(sceneColor);
weight = smoothstep(threshold, threshold + knee, brightness);
glowSource = sceneColor * weight;
```

使用 HDR 很重要，因为高亮值可以大于 1，Bloom 可以根据这些值控制光晕强度。

### 低分辨率处理

光晕是低频效果，不需要始终使用全屏分辨率。例如：

```text
原始画面：1920 × 1080
Glow RT：960 × 540 或 480 × 270
```

低分辨率本身会让效果更柔和，同时减少后处理成本。

但分辨率太低会导致：

- 闪烁；
- 锯齿；
- 发光物体移动时跳动；
- 小型光源消失。

因此通常需要高质量下采样，例如使用双线性过滤或其他重建方法。

### 可分离模糊

直接使用二维模糊核时，半径为 `d` 的滤波器需要大约 `d × d` 个采样。

高斯模糊可以分解成两个一维卷积：

```text
二维高斯模糊 ≈ 水平一维模糊 + 垂直一维模糊
```

成本从：

```text
O(d²)
```

降低到：

```text
O(2d)
```

通常使用两张 RT Ping-Pong：

```text
RT_A → Horizontal Blur → RT_B
RT_B → Vertical Blur   → RT_A
```

### 现代多级 Bloom

现代实现通常不只在一张 RT 上做一次大模糊，而是使用多级 Downsample 和 Upsample：

```text
亮部图
  ↓
Downsample 1 → Blur 1
  ↓
Downsample 2 → Blur 2
  ↓
Downsample 3 → Blur 3
  ↓
逐级 Upsample 并叠加
```

不同级别提供不同范围的光晕：

- 小范围：清晰、强烈的边缘光；
- 中范围：柔和光晕；
- 大范围：宽广的氛围泛光。

### Glow 与 Bloom

两者经常混用：

- Glow：更泛指发光或光晕效果；
- Bloom：通常指从高亮区域提取并向周围扩散的后处理。

GPU Gems 这一章讲的是 Bloom 的基础结构：

```text
提取 → 模糊 → 叠加
```

### 非物理性和常见问题

这种方法可能：

- 穿过物体边界；
- 将屏幕上的亮点扩散到不合理区域；
- 忽略真实遮挡关系；
- 在低分辨率下产生闪烁；
- 产生过强的白色泛光。

因此 Bloom 通常需要配合：

- Soft Threshold；
- Knee；
- HDR 曝光；
- 强度和半径限制；
- TAA 或更好的下采样；
- Lens Dirt、Anamorphic Streak 等艺术效果。

### 工程判断

Glow/Bloom 的核心是对高亮区域进行低频空间扩散：

```text
高亮区域
    ↓
图像提取
    ↓
低分辨率多级滤波
    ↓
叠加到原始场景
```

它不是严格的光学模拟，但成本低、控制直观，对霓虹灯、魔法、火焰、爆炸、太阳和科技界面等效果非常有效。
