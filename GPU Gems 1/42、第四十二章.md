# GPU 顶点变形与重计算

## 章节内容

GPU变形器技术与顶点法线计算的数学方法。

**作者**: Eugene d'Eon

### 核心概念

GPU变形器技术与顶点法线计算的数学方法。

### 变形器定义

**数学形式**：
- "接收顶点集合并生成新坐标的操作"
- 向量函数：**f**(*x*, *y*, *z*) = (*fx*, *fy*, *fz*)

**核心特性**：
- 顶点数量保持不变
- 单个顶点变形独立（不受邻接顶点影响）
- 操作确定性（相同输入→相同输出）

**应用**：
- 平移
- 波形
- 弯曲
- 扭转

### 顶点法线计算方法

**挑战**：
- 传统软件需重新遍历网格计算邻接关系
- GPU顶点着色器无法访问相邻顶点

**两种解决方案**：

**1. 数值近似法**：
- 对每个顶点变形三个点
- 沿切线和副法线轻微偏移
- 通过叉积估算变形后法线

**2. 雅可比矩阵法（推荐）**：
- 计算变形函数的一阶偏导数矩阵
- 两种等价方式变换法线：
  - 使用逆转置矩阵直接变换
  - 变换切线和副法线后计算叉积

### GPU实现

**顶点程序流程**：
1. 将变形函数参数化
2. 通过uniform输入传递控制参数和时间
3. 计算雅可比矩阵
4. 变换切线/副法线
5. 叉积得新法线
6. 重新归一化

**性能优势**：
- 雅可比方法相比变形三个顶点更高效
- 可重复利用计算表达式

### 应用限制

- 面片化网格可能产生不连续结果
- 要求雅可比矩阵可逆（行列式非零）
- 需要解析可微函数
- 顶点程序长度限制（复杂变形可能超出指令预算）

> [!tip] 数学洞察
> 雅可比矩阵方法是计算变形后法线的数学上正确和高效的方法。

## 讨论与补充


### 本章主线

本章本质上讨论的是：把顶点动画或 Deformer 放到 GPU 顶点阶段执行之后，如何得到与新表面匹配的切线和法线。

```text
原始顶点
    → 顶点变形
    → 新顶点位置
    → 重新计算切线/法线
    → 光照和法线贴图
```

这里的 Deformer 可以是 Wave、Bend、Twist、Bulge、Lattice、沿曲线变形，也可以类比到 GPU 蒙皮、Blend Shape、风摆动和海面位移。

### 为什么不能总是直接变换原法线

如果变形是一个统一的线性矩阵：

```text
p' = M p
```

可以使用逆转置矩阵变换法线：

```text
n' = normalize((M^-1)^T n)
```

但波浪、扭曲和晶格变形通常是位置相关的非线性函数：

```text
p' = f(p)
```

不同顶点附近的局部变形不同，不存在一个全局矩阵可以变换整个物体的法线。因此需要根据局部曲面变化重新计算。

### 有限差分法

对原顶点附近的两个点也执行变形：

```text
p
p + εT
p + εB
```

得到：

```text
f(p)
f(p + εT)
f(p + εB)
```

再通过差分近似得到新的切线和副切线，最后叉乘：

```text
T' ≈ f(p + εT) - f(p)
B' ≈ f(p + εB) - f(p)
N' = normalize(cross(T', B'))
```

这种方法容易理解，但每个顶点需要额外计算两个邻近点。`ε` 太大时近似误差明显，太小时又会受到浮点精度影响。

### Jacobian 方法

如果变形函数可微，可以对它求偏导并组成 Jacobian 矩阵：

```text
J = ∂f/∂p
```

它描述变形函数在当前顶点附近的局部线性变化。切线和副切线可以写成：

```text
T' = J T
B' = J B
N' = normalize(cross(T', B'))
```

也可以使用类似逆转置的形式：

```text
N' = normalize(J^-T N)
```

关键区别是：普通模型变换使用整个物体共享的矩阵，而 Jacobian 是每个位置对应的局部变换矩阵。

### FFT 海洋是一个典型案例

FFT 海洋通常把规则网格上的顶点写成：

```text
p(x,z) = (x, h(x,z), z)
```

其中 `h(x,z)` 是 FFT 得到的波高函数。两个切向量可以直接通过偏导得到：

```text
T_x = ∂p/∂x = (1, ∂h/∂x, 0)
T_z = ∂p/∂z = (0, ∂h/∂z, 1)
```

于是法线为：

```text
N = normalize(cross(T_x, T_z))
```

所以 FFT 海洋中的法线和切线从数学上完全可以计算，并不是只能凭经验制作一张法线贴图。

### FFT 中如何求导

FFT 海洋的高度函数可以表示为频域叠加：

```text
h(x,z) = Σ H(k) · exp(i k·x)
```

在频域中求导只需要乘以对应方向的波数：

```text
∂h/∂x  ↔  i kx H(k)
∂h/∂z  ↔  i kz H(k)
```

再对结果做逆 FFT，就能得到海面在 X/Z 方向的斜率。这样通常比在 Shader 中用有限差分采样邻近高度更稳定。

### FFT 海洋的常见工程流程

```text
Compute Shader 执行 FFT
    → 生成高度/位移数据
    → 频域求导得到 X/Z 方向斜率
    → 生成法线或斜率纹理
    → 顶点 Shader 位移规则网格
    → 像素 Shader 采样法线并计算光照
```

因此 FFT 海洋不只是“顶点 Shader 中直接写一个波函数”。通常是 Compute Shader 先生成动态波浪数据，顶点 Shader 应用低频位移，像素 Shader 再使用法线或斜率纹理表现高频细节。

### 法线、切线和法线贴图

如果材质使用切线空间法线贴图，仅仅更新几何法线还不够，还需要更新完整的 TBN 基：

```text
Tangent
Bitangent
Normal
```

否则法线贴图仍然按照变形前的表面方向解释，可能出现高光方向错误、波面光照断裂或细节方向不一致。

### 适用条件和限制

这种方法要求变形尽量满足：

- 顶点可以独立计算；
- 不创建或删除顶点；
- 变形函数确定且最好可微；
- Jacobian 在当前位置不退化，行列式不能为零；
- Shader 指令量和纹理访问量仍在可接受范围内。

如果变形依赖邻居、改变拓扑、产生断裂，或者函数不可导，就不能直接套用 Jacobian 方法，可能需要 Compute Shader、CPU 重建网格或其他近似方案。

### 我的理解

本章可以概括为：

> 顶点动画之后，法线和切线不是不能重算，而是要根据局部变形的导数重新构造。FFT 海洋就是通过计算高度函数的空间导数，得到海面切线、斜率和法线的典型例子。

从工程角度看，常见方案有三种：

1. 对简单矩阵变形使用逆转置矩阵；
2. 对一般变形使用有限差分近似；
3. 对已知且可导的变形函数直接计算解析导数或 Jacobian。
