# IBL

## 章节内容

基于图像的光照（IBL）技术，通过着色器数学将对象放置在特定大小和位置的反射环境中。

**作者**: Kevin Bjorke (NVIDIA)

### 核心概念

基于图像的光照（IBL）技术，通过着色器数学将对象放置在特定大小和位置的反射环境中。

### IBL原理

**突破性创新**：
- 传统立方体贴图：表现"无限远处"环境反射
- 本章技术：通过着色器将对象放置在特定位置的反射环境中
- 仅需少量额外着色器数学

### 立方体贴图技术

**光照空间系统**：
- 半径1.0的单位立方体（范围-1.0到1.0）
- 世界坐标与光照空间的矩阵变换
- 传递顶点法线、切线、副法线数据
- 支持凹凸贴图增强真实感

### 局部反射实现

**核心算法**：
- **球面相交计算**
- 从表面位置沿反射向量与半径1.0球体求交
- 解二次方程获得环境贴图采样位置
- 超出球体范围：红色安全色

### 菲涅尔衰减

- 基于视角的菲涅尔衰减项
- 幂函数逼近
- 推荐指数5.0
- 较低值产生"漆面"效果

### 扩展功能

**漫反射IBL**：
- 预卷积立方体贴图支持漫反射照明

**阴影处理**：
- 投影阴影简化
- 强调"接触阴影"连接角色与环境

**背景渲染**：
- 简化立方体几何
- 直接投影环保贴图作环境

## 讨论与补充


### IBL 是什么

IBL（Image-Based Lighting）不是某一种固定纹理格式，而是一类光照方法：

> 使用代表环境入射光的图像来计算物体受到的环境光照。

环境表示可以是：

- Cube Map；
- 经纬度 HDR 图；
- Reflection Probe；
- Irradiance Map；
- Spherical Harmonics；
- Irradiance Volume；
- 实时捕获的场景图像。

预卷积或预过滤环境立方体贴图是 IBL 的典型工程实现，但 IBL 不等于某一张预卷积 Cube Map。

### 普通环境反射的问题

普通 Cube Map 反射通常只根据反射方向采样：

```hlsl
R = reflect(-V, N);
reflection = SampleCubeMap(R);
```

它默认环境无限远，因为采样没有使用表面位置。物体在房间内移动时，只要反射方向不变，采样结果就不会正确产生位置变化。

例如物体从房间中央移动到窗户附近，窗户在反射中的大小和位置应该发生变化，但普通 Cube Map 可能仍然给出近似相同的反射。

### Localized Cube Map

本章把 Cube Map 绑定到一个有限的房间或盒子中。对于表面点 `P` 和反射方向 `R`，不直接使用 `R` 采样，而是计算反射射线与环境盒子的交点：

```text
P + tR
```

再使用：

```text
交点 - Cube Map 中心
```

作为新的采样方向。

流程如下：

```text
世界坐标 P
    ↓
转换到 Probe/Lighting Space
    ↓
计算反射方向 R
    ↓
求射线与 Probe 盒子的交点
    ↓
得到位置相关的采样方向
    ↓
采样环境 Cube Map
```

GPU Gems 示例使用了球体边界求交，现代引擎更常使用 Box Projection，也就是射线与盒子边界求交。

它可以近似产生：

- 物体靠近窗户时窗户反射变大；
- 物体远离窗户时窗户反射变小；
- 墙壁和灯具随物体位置产生更合理的反射视差。

### 与 Reflection Probe 的关系

现代 Reflection Probe 通常在一个场景位置捕获 Cube Map，再影响周围物体。如果对采样方向做 Box Projection，就得到类似本章的局部化反射。

但它仍然是近似：

- 一个 Probe 只记录一个位置的环境；
- 复杂房间不一定适合一个盒子；
- Probe 之间需要混合；
- 反射物体自身通常不会实时出现在 Probe 中；
- 物体超出 Probe 影响范围后会产生误差。

### 预卷积环境光

真实环境光照需要对整个入射半球积分：

```text
Lo = ∫ Environment(L) × BRDF(L, V) dL
```

运行时逐方向积分成本很高，因此通常预先处理环境图。

#### 漫反射 IBL

对环境图做 Lambert 漫反射卷积：

```text
Environment Map
    ↓
Diffuse Convolution
    ↓
Irradiance Map
```

运行时根据法线采样：

```hlsl
diffuseIBL = SampleIrradiance(N);
```

也可以使用 SH、Light Probe 或 Irradiance Volume 表示低频漫反射环境光。

#### 镜面 IBL

根据不同粗糙度预过滤环境图：

```text
粗糙度低 → 清晰环境图
粗糙度高 → 模糊环境图
```

通常将不同模糊程度放在 Cube Map 的不同 MIP 中：

```hlsl
specularIBL = SamplePrefilteredEnv(R, roughness);
```

现代 PBR 通常还会配合 BRDF LUT：

```text
Prefiltered Environment Map
+ BRDF LUT
```

### 三个概念的区别

#### 原始环境贴图反射

```hlsl
SampleCubeMap(reflectionDirection);
```

这更准确地说是环境反射，通常适合光滑表面。

#### 预卷积环境贴图

环境图已经针对漫反射或某种高光函数完成积分近似，运行时只需要查表。

#### 完整 IBL

完整 IBL 是使用环境图作为入射光源，并结合材质 BRDF 计算环境光照。它不要求一定使用 Cube Map，也不要求一定预卷积。

### 局部化漫反射的困难

镜面反射方向比较集中，使用位置和反射方向做 Box Projection 后效果明显。

漫反射需要整个半球的环境光。预卷积漫反射图已经隐含了 Probe 中心位置的可见半球，当物体离开 Probe 中心时，原先的可见性就不完全正确。

因此通常：

```text
Reflection Probe：主要负责镜面环境反射
Light Probe/SH：主要负责漫反射环境光
```

局部化镜面反射通常比局部化漫反射更可靠。

### IBL 的阴影问题

环境图包含来自整个半球的光线：天空、窗户、灯具、墙面反射等。如果严格计算 IBL 阴影，就需要判断每个入射方向是否被遮挡，成本很高。

因此实际项目通常组合使用：

```text
IBL：提供环境漫反射和镜面反射
主方向光：提供太阳/主灯阴影
AO：提供局部环境遮挡
Contact Shadow：补充接触阴影
```

这不一定严格物理一致，但能提供更稳定且更可控的视觉结果。对角色来说，角色投射到地面的接触阴影往往比完整的 IBL 阴影更重要，因为它能让角色与场景产生空间联系。

### 工程对应关系

| GPU Gems 思路 | 现代实现 |
| --- | --- |
| Localized Cube Map | Box-Projected Reflection Probe |
| 预卷积环境图 | Prefiltered Environment Map |
| 漫反射 Cube Map | Irradiance Map / SH |
| 粗糙度选择 MIP | Roughness → Prefiltered MIP |
| Fresnel 修正 | PBR Fresnel |
| IBL 阴影近似 | 主方向光阴影 + AO + Contact Shadow |

### 工程判断

IBL 的核心不是“使用一张预卷积 Cube Map”，而是：

```text
将环境图像当作入射光源
并用它参与材质光照计算
```

预卷积 Cube Map、Irradiance Map、SH、Prefiltered MIP 和 BRDF LUT，都是为了把这个积分过程变成可实时执行的查表或少量计算。
