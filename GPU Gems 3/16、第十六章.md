# Crysis 中的植被程序化动画与着色

## 章节内容

本章以 Crysis 的植被为例，介绍如何将大量植物的几何、风动画、材质、阴影和 LOD 结合起来。植被通常按距离使用不同表示：近处使用完整树干、枝条和叶片几何，中距离使用简化簇，远处使用公告板或预烘焙表示，并在切换时处理尺度、朝向和视觉连续性。

动画部分在顶点着色器中依据顶点的层级权重、世界位置、时间和风场参数计算弯曲。树干和大枝条使用低频、大范围运动，细枝和叶片使用更高频的小幅扰动；同一套规则还可以用于草、灌木和其他植被。材质需要考虑双面叶片、alpha test、法线、透光、环境遮蔽和阴影，避免大量透明 blended 叶片造成严重 overdraw。

章节强调植被效果来自多个层次的组合，而不是某个单独 shader：合理的几何组织与剔除决定数量上限，程序化动画减少 CPU 更新，材质和阴影决定近景质量，LOD 和 impostor 决定远景成本。不同硬件还需要提供质量等级和替代路径。
