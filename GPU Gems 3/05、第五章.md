# 通用自适应网格细分

## 章节内容

本章提出一种不依赖特定网格拓扑的 GPU 自适应细分方法。输入仍然可以是普通的三角形网格，只需为顶点提供表示局部细分需求的 depth tag。GPU 根据三角形三条边的细分等级，从预先生成并存储在 GPU 中的自适应细分模式池选择模式，在一个顶点程序中把原始三角形替换成更密集的三角形块。

细分模式使用重心坐标和参数空间表示，因此生成的新顶点可以通过重心插值获得位置及其他顶点属性，再叠加用户提供的位移函数。章节将这一框架用于高阶 Bézier 曲面平滑、程序化高频位移、动画自由形变、位移贴图和多级地形渲染。

该方法的特点是只传输粗网格和少量细分标记，细分与位移按帧在 GPU 上完成，不需要 CPU 预先建立半边结构或重新组织任意拓扑。实际应用仍要处理相邻三角形细分等级不一致造成的裂缝、细分模式数量、顶点缓存和过度细分等问题。
