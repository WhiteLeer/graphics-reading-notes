# 使用几何着色器实现紧凑且可变长度的 GPU 反馈

## 章节内容

本章利用 DirectX 10 geometry shader 解决 GPU 上“输入规则但输出长度动态”的问题。顶点着色器和像素着色器通常适合固定结构的并行输入输出，而压缩、搜索、统计和计算机视觉常会产生未知数量的结果。geometry shader 可以根据数据内容，在一个输入 primitive 的处理过程中发出可变数量的顶点或标量。

一种用法是发送一个简单 primitive，让 geometry shader 循环读取输入纹理并把结果写到指定位置；另一种用法是通过 stream-out 把发出的数据连续写入 GPU 缓冲。这样可以在 GPU 上完成局部最大值搜索、数据压缩或 Hough transform，只把少量紧凑结果反馈给 CPU，避免把整张中间图读回系统内存。

章节以图像处理和直线检测说明流程：像素 shader 先计算 Hough map，geometry shader 再查找局部峰值并输出直线参数。为了发挥并行度，昂贵的逐像素处理应先交给像素 shader，geometry shader 负责较小的动态输出阶段；单个 GS 线程承担过多串行扫描会降低 GPU 利用率。

这种方案适合输出很少、数据结构简单、需要减少回读的任务。geometry shader 的输出容量、线程间协作、stream-out 布局、栅格化限制和旧硬件性能会限制通用性；现代项目通常也会用 compute shader、append/consume buffer、原子计数和 indirect draw 实现更灵活的 GPU feedback。
