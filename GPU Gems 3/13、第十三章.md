# 作为后处理的体积光散射

## 章节内容

本章介绍一种屏幕空间的体积光散射后处理，用于表现从云雾、尘埃或大气介质中向观察者方向散射的光束，也就是常见的 god rays。它不在场景中真实追踪所有光线，而是先得到光源在屏幕上的位置，再沿从当前像素指向光源的方向进行多次采样。

对每个采样点，算法依据深度、遮挡或一张光源遮罩估计光是否能到达介质，并按照散射系数、衰减、曝光和距离对样本贡献进行累积。沿屏幕径向的模糊或积分近似把被遮挡区域与光源区域连接起来，最终将散射结果与原始场景颜色合成。可通过采样数、衰减系数、权重和抖动控制质量与性能。

这种方法适合作为廉价的全屏体积光近似，尤其适合太阳、聚光灯或屏幕中明确可见的亮源。它依赖屏幕空间信息，无法可靠处理屏幕外遮挡物、复杂多层介质、真正的体积碰撞和任意方向的光传输，因此通常会与深度、阴影贴图、雾和其他体积效果组合使用。

## 讨论与补充

### 屏幕空间光束与真正的体积雾

本章的方案是屏幕空间体积光后处理，核心流程是：

```text
得到光源的屏幕位置
→ 生成光源或遮挡物的屏幕空间遮罩
→ 从当前像素沿屏幕方向朝光源步进
→ 累计中间样本的亮度或可见性
→ 与原画面混合
```

它并不是在世界空间中沿摄像机射线穿过真实体积，而是使用屏幕空间的径向采样近似光线散射。因此它适合太阳穿过树枝的光柱、云层缝隙中的 God Rays 和聚光灯光束，但无法可靠处理屏幕外遮挡物、房间内部不同位置的尘埃密度或复杂的多层体积关系。

### 与世界空间体积射线步进的区别

更高质量的局部丁达尔效应通常沿摄像机射线在世界空间中步进：

```text
相机射线
→ 采样世界空间位置
→ 查询体积密度
→ 查询光源可见性
→ 计算散射和透射
→ 沿射线累计
```

每个采样点可以使用局部密度、阴影、相位函数和透射率，因此更适合表现窗户、门洞或室内尘埃形成的真实光束。本章的屏幕空间方法可以作为廉价近似，但不能完全替代这种世界空间体积积分。

### Cluster 在体积光中的作用

Cluster 或 Froxel 划分可以用于世界空间体积光的多光源管理。空间被划分成许多三维区域，每个区域保存可能影响它的光源列表。射线步进到某个采样点后，先找到其所在的 Cluster，再遍历该区域的相关光源：

```text
采样点
→ 查找 Cluster
→ 获取相关光源列表
→ 计算光照、可见性和散射
```

Cluster 负责减少光源遍历，不负责产生体积光本身；密度、光源可见性、阴影、相位函数、透射率和沿视线积分仍然需要单独计算。

因此，两种方案可以概括为：

```text
本章：屏幕空间径向采样，快速伪造光束
更高质量方案：世界空间体积步进，可结合 Cluster 管理多光源
```
