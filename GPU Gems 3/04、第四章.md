# 新一代 SpeedTree 渲染

## 章节内容

本章讨论如何利用 DirectX 10 的几何着色器、纹理采样和多重采样能力，提升近距离 SpeedTree 植被的视觉质量。重点不是重新设计植被实例化或风动画系统，而是在低面数树干、树枝和叶片卡片的基础上，补足轮廓、阴影、光照和抗锯齿细节。

树干和枝条使用 Relief Mapping 处理表面内部的凹凸与视差；但 Relief Mapping、法线贴图和 POM 都不能改变低模几何的外轮廓。因此，本章使用 silhouette clipping：通过顶点法线与视线的关系找到轮廓边，由几何着色器挤出 silhouette fins，再沿视线对高度图进行步进，以裁剪出不规则的树皮轮廓。远处树木会逐渐减小或移除这些轮廓几何，以控制成本。

叶片卡片始终朝向相机，直接使用普通阴影贴图会造成阴影拉伸和自阴影错误。本章通过修改叶片阴影贴图的生成和投影过程，并使用偏移系数图在像素着色器中调整用于阴影采样的位置，使叶片卡片能够表现更合理的叶片级自阴影。同时结合级联阴影贴图，并让不同级联以不同频率更新，以降低大范围植被的阴影开销。

叶片光照采用双面和背光近似：根据光线和视线方向模拟叶片透光时的偏色，并降低背面的高光。对于远处叶片，使用更粗糙的高光和较低的法线贴图 Mipmap，减少闪烁和高频细节造成的锯齿。

最后，本章将 HDR、MSAA 和 Alpha-to-Coverage 结合起来，改善 Alpha Test 叶片、silhouette clipping 边缘以及 LOD 交叉淡入淡出的抗锯齿效果。风动画、公告板和一般 LOD 在本章中主要作为 SpeedTree 的既有背景；GPU 生成的程序化风动画将在后续章节进一步讨论。

## 讨论与补充

本章的核心可以概括为：不是单纯增加树木三角形，而是通过高度图步进、几何着色器生成轮廓面、修正叶片阴影投影和 Alpha-to-Coverage，在低模植被上补充近距离最容易暴露的视觉细节。

### 叶片透光与 SSS

树叶的透光通常不等同于皮肤式的完整 SSS 或 BSSRDF。由于叶片很薄，工程上更常使用双面光照、背光项和薄片透射近似：当光线从叶片背面照射时，根据光线方向、视线方向、叶片法线以及透射颜色，向光照结果中加入偏黄或偏绿的背光颜色，并适当降低背面高光。

这类实现可以写成类似的形式：

```hlsl
backLight = saturate(dot(-normal, lightDirection));
transmission = backLight * transmissionColor;
```

它主要模拟“光穿过薄叶片后从背面出来”的方向性颜色，不负责计算光在表面内部的横向扩散。因此，叶片材质可以使用 SSS 或引擎提供的植被次表面模型，但本章的方案本质上是针对薄片植被的轻量近似，而不是完整的皮肤散射模型。
