# 使用 CUDA 成像地球地下结构

## 章节内容

本章以石油勘探中的地震成像为例，说明 CUDA 如何加速工业科学计算。船只发射压缩波，水听器记录地下不同速度和密度层产生的反射波；海量、低信噪比的观测数据经过定位、信号归一化、去噪、波场传播和 migration，最终形成地下三维结构，并迭代更新速度模型。

作者分析了完整工业流水线中最耗时的局部 kernel，把 CPU 例程拆成若干适合 GPU 的网格计算。每个 CUDA block 处理二维 tile，将数据从全局内存加载到 shared memory；局部算子在 tile 上重复使用邻域数据，波传播等路径则可使用纹理读取。这样可以把大部分相关中间数据留在 GPU，减少 PCIe 往返和系统内存通信。

实际迁移需要同时考虑数据规模、集群并行、GPU/CPU 负载、参数变化、显存、容错和整体应用的 Amdahl 限制。局部 kernel 可以获得数量级加速，但如果其他阶段、调度或数据传输仍占主要时间，端到端收益会明显下降；GPU 集群还需要足够 CPU 控制能力和可靠的故障恢复。
