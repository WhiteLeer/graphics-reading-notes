# 用 Relaxed Cone Stepping 实现 Relief Mapping

## 章节内容

本章讨论 relief mapping：把高度图解释为表面起伏，并在像素着色器中沿视线寻找与高度场的交点，从而获得比普通法线贴图和简单视差偏移更强的遮挡、视差和自阴影效果。基本问题是射线步进必须在高度场中找到可靠交点，同时避免每个像素进行过多采样。

Relaxed Cone Stepping 为高度图预计算能够安全跳跃的 cone 信息。对当前射线位置和方向，算法可以根据局部高度变化估计不会穿过表面的区域并进行较大步长跳跃；接近表面后再用较细的线性搜索或二分搜索定位交点。预计算的 cone map 使算法在高频纹理和斜视角下比固定步长更高效。

得到交点后，可以用高度场梯度或邻域采样计算法线，并进行视差遮挡、阴影和材质采样。该方法仍然是纹理空间近似：无法真正改变轮廓，屏幕外信息和极端视角会失败，cone 数据、纹理内存、步进次数和分支发散也需要在质量与性能间平衡。
