# 高速屏外粒子

## 章节内容

本章针对烟雾、火焰、尘埃等粒子造成的巨大 overdraw，提出把粒子先绘制到低分辨率的屏外 render target，再放大合成到主画面。许多体积粒子是低频、柔和的图像，不需要以全屏分辨率计算，因此可以用较少的粒子片元获得近似观感。

为保证粒子与场景正确遮挡，先正常渲染不透明物体并得到深度，再将主深度下采样到屏外分辨率，用它测试粒子。粒子颜色和 alpha 在低分辨率缓冲中累积，最后上采样合成。简单方案可能出现块状边缘、深度 halo 和闪烁，因此章节进一步使用边缘检测、stencil mask、混合分辨率和针对边缘的高分辨率处理，保留重要轮廓。

低分辨率方案能显著减少填充和复杂粒子 shader 的成本，但不是所有粒子都适合：碎石等高频、硬边、细小几何在下采样后会丢失；当粒子系统在屏幕上很小时，额外的 downsample、edge detection 和 composite pass 可能反而超过直接绘制的成本。
