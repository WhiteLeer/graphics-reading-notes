# 在 GPU 上烘焙法线贴图

## 章节内容

本章把传统的高模到低模法线贴图烘焙搬到 GPU。低模作为工作模型，使用其 UV 把目标纹理空间栅格化；对每个纹理像素，从低模表面沿法线或包围笼方向发射射线，与高模三角形求交，得到高模表面法线，再转换到低模切线空间并编码到法线贴图。

为了让像素着色器能够查询高模几何，章节把高模放入均匀三维网格：3D 纹理记录每个体素对应的三角形列表，三角形数据放入纹理中。射线只需要遍历可能经过的网格单元，而不是与整个高模逐三角形求交。GPU 通过纹理采样、并行像素处理和单 pass 或 tiled/multipass 方案加速烘焙。

系统需要处理显存限制、Shader Model 的循环次数限制、空体素、UV 边界、抗锯齿、padding 和 cage。多次抖动射线或多次渲染可以改善边缘质量，但成本会近似随样本数增加。相同思路还可以生成 displacement、relief、AO 或 cavity 等贴图。
