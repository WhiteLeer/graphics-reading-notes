# 基于颜色的 GPU 实时视频目标检测

## 章节内容

本章把 GPU 当作实时视频图像处理器，用颜色信息检测目标。输入视频首先转换到更适合分离色相、饱和度和亮度的颜色空间，再根据颜色范围生成二值 mask。GPU 对每个像素并行完成分类，随后通过缩小、滤波、形态学操作和区域合并去除噪声并连接目标区域。

为了得到目标位置和尺寸，算法可以对 mask 做 reduction，计算非零像素的包围盒、质心或连通区域，并将结果反馈给 CPU 或后续 GPU 阶段。多级 downsample 能减少处理像素，分离不同阶段的纹理和缓冲区能保持流水线效率。时间上的平滑与跟踪可以减少摄像头噪声和检测框抖动。

该方法的优势是实现简单、并行度高、适合颜色明显且背景可控的目标；阴影、反射、白平衡变化、相似背景和光照变化会降低可靠性。它是一个面向特定视觉条件的 GPU 图像处理方案，不是通用的语义目标检测器。
