# 实用的后处理景深

## 章节内容

本章为第一人称游戏设计一种可插入现有引擎的后处理景深。景深来自真实镜头的 circle of confusion：处于焦平面的物体成像为点，前后距离越远离焦平面，成像越扩散。算法先由深度和相机焦距、光圈、焦距距离计算每个像素的 CoC 半径。

为了稳定处理近景和远景，完整流程包括：下采样前景 CoC 图、模糊近景 CoC、由模糊与未模糊结果得到实际前景 CoC，最后在全屏 pass 中根据前景和背景 CoC 对场景做可变半径模糊。章节使用深度预处理，并在旧硬件无法直接读取深度缓冲时把世界空间距离写入浮点颜色目标；透明像素需要 clip，以免它们污染景深深度。

实现中通过分离的水平/垂直 Gaussian blur、双线性采样和低分辨率缓冲降低采样成本，同时处理前景边缘、遮挡、近景无限 CoC、背景上限和 halo。它是视觉上可信的屏幕空间近似，并不模拟真实镜头的完整光学成像；深度错误、透明物体和屏幕外信息仍会限制效果。
