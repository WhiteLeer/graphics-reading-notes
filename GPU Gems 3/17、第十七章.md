# 稳健的多重镜面反射与折射

## 章节内容

本章用分层距离图在 GPU 上近似求解单次和多次镜面反射、折射。由于片元着色器不能直接访问整个场景网格，先从一个参考点把场景渲染到多个 cube map 层中，每个 texel 保存沿该方向可见表面的颜色、法线和距离。多层数据用于表示同一方向上被遮挡的后续表面。

追踪次级射线时，先沿射线进行 ray marching，保证不会轻易跳过交点，再使用 secant search 在符号变化或距离变化区域内精确定位命中点。命中点的颜色用于反射或折射结果，法线用于生成下一条射线；反复执行即可得到更高阶反射和折射。反射强度用 Fresnel 近似，折射还需要折射率，材质类型可以编码到距离图的附加通道中。

这种方法把网格转换成纹理化的场景表示，能在旧式可编程 GPU 上运行并利用纹理采样和动态分支。它在表面平滑、距离图变化连续时效果较好；薄物体、遮挡层数不足、快速变化的距离和屏幕外几何会造成误差，且每增加一个反射/折射阶数都会增加步进和采样成本。

## 讨论与补充

### 实时折射的常见实现

实时渲染通常不会完整追踪折射后的所有光路，而是先根据 Snell 定律计算折射方向，再使用某种场景表示寻找折射射线命中的颜色。表面处还会使用 Fresnel 项，在反射和折射之间分配能量：

```text
最终结果 = Fresnel × 反射 + (1 - Fresnel) × 折射
```

常见的命中结果来源包括：

- 屏幕空间折射：沿折射方向步进深度图，再偏移 UV 采样场景颜色；
- 环境立方体图或 Reflection Probe：根据折射方向直接采样环境；
- 平面反射/折射：从关于水面或镜面的相机重新渲染场景到 RT；
- 硬件光追：对场景几何进行求交，但通常限制射线数量和反射/折射次数。

屏幕空间方法便宜，但无法看到屏幕外或当前不可见的几何；环境图缺乏局部几何和视差；平面 RT 只适合平面或近似平面的表面；实时光追虽然更准确，也通常会与其他近似方案混合使用。

### 本章方案的定位

本章使用分层距离立方体图保存从参考点沿不同方向可见的多层表面，再沿反射或折射射线进行 Ray Marching，并使用 Secant Search 修正交点。它比简单的环境图和屏幕空间 UV 偏移更完整，可以表示同一方向上的多层表面并支持多次反射、折射，但仍然是在纹理化的场景表示上近似追踪，而不是直接对原始场景网格进行完整路径追踪。

### 表面折射与内部散射

反射和折射主要是表面光学事件，而内部散射是光进入材质内部后发生吸收、散射并从其他位置或方向离开的体积传输问题。实时透明材质通常会计算表面反射、折射、Fresnel、厚度和吸收，但经常忽略复杂的内部散射。

对于磨砂玻璃、冰、玉石、蜡和牛奶等内部散射明显的材质，还需要额外使用 SSS、体积吸收、体积散射、厚度图或光线步进等近似。第十七章的重点是多重镜面反射与折射，并没有完整解决透明材质内部的散射。
