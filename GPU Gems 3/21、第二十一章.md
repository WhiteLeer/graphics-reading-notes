# True Impostors

## 章节内容

本章提出一种比普通 billboard 更接近真实几何的 impostor。传统 impostor 只保存某个视角的一张颜色图，视角改变后会出现明显错误；True Impostor 在面向相机的四边形上保存由多个深度层组成的纹理化体积，像素着色器沿视线在该体积中进行 ray casting，求出当前像素对应的表面交点。

交点不仅用于取得颜色，还可以重建深度、法线和穿过体积的距离，因此可以支持自阴影、反射、折射以及不受高度场限制的表面结构。四边形可以始终朝向相机，实际几何复杂度被转化为纹理采样和片元计算，适合同时绘制大量动画、透明或高细节小物体。

方法受填充率和每像素步进成本影响，billboard 之间还可能互相遮挡，因此需要排序和合理的深度处理。视角虽然比普通单张 impostor 灵活，但数据层数、采样分辨率和薄结构仍限制精度；它是几何与光线步进的混合近似，并不等同于完整光线追踪。
