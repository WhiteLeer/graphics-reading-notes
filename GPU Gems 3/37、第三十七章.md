# 使用 CUDA 高效生成随机数及其应用

## 章节内容

本章讨论 Monte Carlo 计算中的 GPU 随机数。Monte Carlo 通过大量独立试验估计复杂问题的结果，试验之间天然适合并行，但随机数发生器必须同时满足速度、统计质量、独立流和可复现性要求。章节重点关注伪随机数，以及金融模拟所需的高斯分布随机数。

一种方案先生成均匀分布随机数，再用 Box-Muller 变换得到高斯分布；另一种方案直接使用 Wallace 方法生成高斯数。CUDA 中为每个线程或线程序列维护独立状态，尽量把状态放在合适的存储层，并通过并行初始化、连续访问和批量生成降低开销。随机数质量、周期、不同线程流之间的相关性和状态保存位置会影响最终估计的偏差与性能。

章节用期权定价等例子展示随机数生成器的实际应用。GPU 加速不只是把一个 CPU RNG 逐线程照搬，还要考虑随机状态占用寄存器/显存、分支和复杂变换的成本。密码学安全随机数、拟随机序列和普通模拟用 PRNG 的要求不同，不能混用。
