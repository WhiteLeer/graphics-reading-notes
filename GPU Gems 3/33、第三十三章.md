# 使用 CUDA 的 LCP 碰撞检测算法

## 章节内容

本章关注碰撞检测管线中的 narrow phase：在宽相得到候选对象对后，使用真实几何计算凸多面体之间的距离、接触点和接触约束。作者把凸体距离问题和接触力求解转化为线性互补问题（LCP），并在 CUDA 上实现 Lemke/互补 pivot 算法。

刚体物理通常分为宽相、窄相和 resolution 三段。宽相给出候选对，窄相建立几何约束和 LCP 矩阵，resolution 阶段求出不互穿所需的约束力。CUDA 中可把每个碰撞对映射到一个 block，block 内线程协作构建矩阵、选择 pivot、求解变量并检查终止条件。共享内存、线程同步和局部存储使这种矩阵式小问题能够并行执行。

惩罚法用弹簧允许少量穿透，简单但需要调参；约束法直接求抵消穿透趋势的力，精度和稳定性更好但求解更复杂。LCP 方法适合大量结构相似的凸体碰撞，但迭代次数、分支、退化情况、摩擦和多个接触点会影响 GPU 效率与数值稳定性。
