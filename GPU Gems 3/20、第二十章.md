# GPU 上的重要性采样

## 章节内容

本章讨论如何用重要性采样减少评价复杂 BRDF 和环境光照时的无效样本。均匀采样会把大量计算浪费在对最终贡献很小的方向上；重要性采样根据 BRDF、光源分布或环境贴图的能量，把更多样本放到可能贡献较大的方向。

实现时需要构造概率密度函数（PDF），按照该分布生成半球或球面方向，并用样本贡献除以对应 PDF 保持估计无偏或近似无偏。GPU 适合并行生成大量样本和执行 BRDF 评价，但随机数、方向变换、分支、纹理访问和样本之间的方差会影响实际效果。可以使用低差异序列、预计算表、分层采样和多重重要性采样降低噪声。

章节的目标是在动态光照环境中减少对昂贵 BRDF 积分和大量预计算数据的依赖。它并不意味着一次采样就能得到完美结果：样本数量不足会产生噪声，PDF 与真实贡献分布不匹配会降低效率，实时应用通常仍需时域累积、滤波或其他近似。

## 讨论与补充

### 重要性采样是什么

重要性采样不是某一个固定算法，而是蒙特卡洛积分的一种降方差策略：把更多样本放到最终贡献可能更大的区域，减少采样落在低贡献区域的浪费。

按照概率密度函数 `p(x)` 采样时，积分估计可以写成：

```text
I ≈ 1 / N × Σ f(xi) / p(xi)
```

除以 `p(xi)` 是为了补偿采样概率不同造成的权重变化。否则改变采样分布后，结果会产生偏差。重要性采样的效率取决于 `p(x)` 是否接近真实贡献分布；如果实际有贡献的区域几乎没有被采样，噪声反而会增加。

### 常见应用

重要性采样通常会用于：

- 路径追踪，根据材质 BRDF 采样反射方向；
- GGX 等微表面 BRDF 采样高光瓣；
- 直接光照和 Next Event Estimation，优先采样贡献更大的光源或面光源；
- IBL 和环境贴图采样，优先采样明亮区域；
- 体积渲染，在高密度、发光或散射贡献大的区域增加采样；
- 光子映射、Path Guiding 等根据已有光能分布调整后续路径。

例如环境贴图中只有太阳区域非常明亮时，均匀采样大部分会落在低亮度天空；重要性采样则提高太阳方向的采样概率。

### 多重重要性采样

单独使用 BRDF 采样或光源采样都可能失效：高光瓣可能没有覆盖小光源，而光源采样也可能没有覆盖很窄的反射方向。多重重要性采样（MIS）会同时使用多种采样策略，再根据各自的 PDF 对结果加权，从而降低某一种采样分布不匹配带来的噪声。

重要性采样并不保证一次采样得到准确结果，实时渲染和路径追踪通常还要结合低差异序列、分层采样、蓝噪声、时域累积、自适应采样和降噪。
