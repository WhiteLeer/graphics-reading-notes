# GPU 上的高速病毒签名匹配

## 章节内容

本章把 GPU 作为网络或文件病毒检测管线中的高速预过滤器。病毒签名可能有不同长度、通配符、范围约束和复杂形式；如果 CPU 对输入数据和数万条签名逐一比较，内存访问和重复处理会成为瓶颈。GPU 擅长同时处理规则、独立的固定大小输入，因此适合先筛出可能匹配的位置。

示例中为每条签名选择两个连续字节作为 key，并建立可被 GPU 直接索引的表；表项还保存 key 前面的若干 tag 字节。GPU 线程遍历输入中连续的字节对，以 key 查表，再比较相邻 tag，输出潜在匹配位置。CPU 负责文件类型识别、解压、跨 buffer 管理以及对少量候选结果进行完整、可靠的签名验证。

这种 CPU/GPU 分工避免把不规则的完整匹配逻辑强行放进 GPU，同时利用 GPU 的大吞吐过滤大量数据。算法适用于规则、可并行的筛选阶段；签名数据库更新、碰撞 key、跨块边界、通配符和误报率都需要额外处理。GPU 预过滤器不能单独证明病毒存在，最终结果仍需完整验证。
