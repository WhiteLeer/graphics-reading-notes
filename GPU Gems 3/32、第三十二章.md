# 使用 CUDA 进行宽相碰撞检测

## 章节内容

本章实现大量三维对象的 broad phase collision detection。宽相阶段只使用包围盒等保守表示，快速排除不可能相交的对象对；剩余候选对再交给 narrow phase 做精确碰撞和接触点计算。暴力方法需要 O(N²) 对象对测试，而 sort-and-sweep 和空间划分通常能把平均复杂度降到 O(N log N)。

章节重点是 CUDA 的并行空间划分实现：根据对象包围盒生成其覆盖的网格 cell ID，把对象 ID 与 cell ID 组成列表，排序后建立索引表，再让线程遍历同一 cell 内的候选对象对。过程中使用并行 reduction、prefix sum 和 radix sort 等基础并行原语。对象在多个 cell 中出现时需要去重或通过后续逻辑避免重复候选对。

这种方法在对象数量大、空间分布稀疏且大多数对象不相撞时收益明显；拥挤场景会使候选对接近 O(N²)，排序、cell 遍历、输出容量和重复处理成为瓶颈。宽相只保证“不漏掉可能碰撞”，不能替代窄相。
