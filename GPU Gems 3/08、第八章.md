# 求和面积方差阴影贴图

## 章节内容

本章从标准阴影贴图的过滤问题出发，介绍方差阴影贴图（VSM）以及求和面积方差阴影贴图（SAVSM）。普通阴影贴图必须对每个样本做深度比较，PCF 的滤波半径变大后采样成本也随之增加；直接对深度做线性过滤又会得到不正确的遮挡结果。

VSM 在光源空间保存深度的一阶矩和二阶矩，即深度与深度平方。过滤后可以得到局部深度分布的均值和方差，再利用 Chebyshev 不等式估计当前片元被遮挡的概率。因此 VSM 可以使用普通纹理的线性过滤、Mipmap 和各向异性过滤。它还可以通过模糊和光源渗漏抑制函数改善阴影边缘与漏光问题。

SAVSM 进一步为矩数据建立 summed-area table。任意矩形过滤区域可以通过表中少量角点的加减在常数时间内求和，过滤宽度不再直接决定采样次数，因此适合动态变化的软阴影。章节还讨论了与 PCF、PCSS 的关系、阴影贴图投影畸变、bias、MSAA 和 mipmap 等问题。VSM/SAVSM 以概率上界换取可过滤性，可能产生 light bleeding；它们不是所有场景中都优于标准阴影贴图。

## 讨论与补充

### VSM 的概率估计与过滤

VSM 不是先生成一张准确的概率阴影图，再对概率图进行降采样，而是保存阴影贴图深度的一阶矩和二阶矩：

```text
M1 = E[z]
M2 = E[z²]
```

由此可以得到深度方差：

```text
variance = M2 - M1²
```

采样时，将当前接收点在光源空间中的深度与过滤后的均值、方差结合，通过 Chebyshev 不等式估计该点被遮挡的概率。因此更准确的流程是：

```text
保存深度矩
→ 对矩进行过滤、降采样或生成 Mipmap
→ 根据过滤后的矩估计遮挡概率
```

由于一阶矩和二阶矩可以线性过滤，VSM 可以使用双线性过滤、高斯模糊和 Mipmap；普通阴影贴图中的深度值则不能简单平均后继续进行可靠的深度比较。

### VSM 的误差与 SAVSM

VSM 的主要问题不是传统 PCF 那种采样噪点，而是 `Light Bleeding`：均值和方差只能描述深度分布的一部分信息，无法完整表示过滤区域内的遮挡结构，因此完全被遮挡的区域也可能被估计出一部分“可见光”。过滤还会抹掉细小遮挡物，并可能带来阴影过度模糊和浮点精度问题。

SAVSM（Summed-Area Variance Shadow Maps）是在 VSM 基础上使用 Summed-Area Table，使大范围矩形过滤可以用固定次数的采样完成。普通 PCF 或局部过滤通常会随着过滤半径增加而增加采样次数，而 SAVSM 的过滤区域变大时采样成本基本不随面积增加。不过它需要额外存储，也仍然继承 VSM 的漏光和精度问题。
