# 在 GPU 上渲染矢量艺术

## 章节内容

本章讨论如何将二维矢量艺术中的路径、曲线、填充和描边交给 GPU 处理。矢量图的优势是分辨率无关，但直接把复杂路径三角化可能产生大量几何、细碎三角形和边缘质量问题。系统需要在 GPU 上高效确定像素是否位于路径内部，并处理填充规则、曲线边界和抗锯齿。

一种思路是把曲线参数化后用覆盖测试、距离或 winding 信息表示，再在片元阶段求路径边界和覆盖率；另一类方案把路径栅格化到中间缓冲，再使用 stencil、距离场或覆盖值完成填充。描边还需要处理线宽、连接点、端点和曲线的局部参数。抗锯齿通常通过解析覆盖率、多重采样、距离函数或后续过滤实现。

GPU 方案可以避免为每个缩放级别重新生成高密度三角网格，但复杂路径仍受片元填充、分支、临时缓冲和曲线交点计算影响。适合 UI、图标和可缩放二维图形，不代表任意矢量场景都能用一个简单 shader 直接完成。

## 讨论与补充

### 矢量图仍然需要抗锯齿

矢量图并不意味着最终显示时不需要抗锯齿。矢量路径是连续的数学表示，但显示器仍由离散像素组成：

```text
连续曲线
→ 像素采样
→ 屏幕显示
```

如果只根据像素中心判断某个像素在路径内部还是外部，斜线和曲线边缘仍然会出现阶梯。更准确的做法是计算路径对像素的覆盖率，例如某个像素被路径覆盖了 30%，就让边缘颜色按约 30% 的比例混合。

矢量图相较于位图的优势是可以在目标分辨率下重新光栅化，而不是直接放大原始像素，因此更容易获得稳定的边缘质量。但重新光栅化本身仍然需要 MSAA、超采样、解析覆盖率、距离场或其他抗锯齿方法。

此外，并不是所有图像都适合转为矢量图。照片、烟雾、云、噪声和高频纹理可能需要极其复杂的路径表示，数据量和计算量反而会超过位图；矢量路径也无法消除纹理采样、摩尔纹等一般采样问题。
