# 高质量实时皮肤渲染

## 章节内容

本章讨论实时渲染真实皮肤所需的两个主要部分：表面高光反射和次表面散射。皮肤的毛孔、皱纹、斑点等细节可以来自扫描数据，但如果只使用普通漫反射，皮肤会显得干硬；光线进入皮肤后散射并从邻近位置离开，形成柔和的外观，因此必须近似这种次表面传输。

高光部分使用接近物理模型但更适合实时计算的解析 BRDF。散射部分用 diffusion profile 描述不同颜色通道随距离衰减的能量，并把 profile 近似为多个 Gaussian 的和。高斯卷积可分离为水平和垂直两个方向，结合纹理空间 diffusion、层次化缩小与放大、stretch texture 和可选的 translucent shadow map，把原本昂贵的二维积分转化为若干 GPU 纹理处理 pass。

章节还讨论厚度、阴影、透光颜色、环境光、法线和纹理空间分辨率对结果的影响，并指出该模型主要处理扩散型散射，不完整处理单次散射。因此它适合皮肤这类材料的实时近似，但玉石、大理石、烟雾等材料可能需要更完整的单次散射模型。
