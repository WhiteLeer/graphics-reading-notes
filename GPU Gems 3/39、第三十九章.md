# 使用 CUDA 实现并行前缀和

## 章节内容

本章详细介绍 parallel prefix sum，也叫 scan。给定一个满足结合律的二元操作，scan 为每个元素计算它之前所有元素的累积结果。它看似具有顺序依赖，但可以用树形 up-sweep/down-sweep 在 GPU 上并行完成，是流压缩、基数排序、空间划分、分配可变长度输出等许多算法的基础。

章节先介绍朴素的 Hillis-Steele 风格实现，再改进为 work-efficient 的 Blelloch scan，使总工作量达到 O(n)。CUDA 实现使用 shared memory、线程同步和 block 内树形访问；大数组通过先扫描每个 block、再扫描 block 总和、最后把偏移量加回各 block 的层次化流程完成。进一步优化包括避免 shared-memory bank conflict、循环展开、每线程处理多个元素、使用 float4 提高计算/访存比，以及区分 inclusive 和 exclusive scan。

scan 的重要性在于它把“每个元素需要一个唯一输出位置”转化为前缀偏移：例如筛选有效元素、构建 radix sort 的位置、生成碰撞候选列表和压缩可变长度数据。性能不仅取决于加法次数，还受同步、shared memory 冲突、全局内存访问、block 边界和不规则输入影响。
