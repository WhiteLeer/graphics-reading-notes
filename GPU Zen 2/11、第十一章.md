# Procedural Stochastic Textures by Tiling and Blending（通过平铺与混合生成程序化随机纹理）

## 章节内容

本章介绍一种从小尺寸样例纹理生成近似无限随机纹理的运行时方法，适用于苔藓、花岗岩、沙地、树皮等自然材质。算法在 Fragment Shader 中执行，目标是使用少量计算和不超过数次纹理采样，同时避免普通平铺产生的明显重复。

作者：Thomas Deliot 和 Eric Heitz

## 核心思路

系统不把输入纹理按照规则矩形网格重复，而是把 UV 空间划分为三角形网格：

1. 找到当前像素所在的三角形以及三个顶点；
2. 使用哈希函数为三个顶点生成随机 UV 偏移；
3. 从输入样例纹理中分别采样三个随机位置；
4. 使用当前像素在三角形内的重心坐标作为混合权重；
5. 将三个样本合成为最终像素。

因此每个像素覆盖三个随机 Tile，Tile 的位置和相邻关系不断变化，能够显著降低规则重复感。

## 为什么使用三角形网格

等边三角形网格可以为每个像素提供三个稳定的重心权重，并且使相邻区域共享顶点。每个网格顶点关联一个随机偏移，相邻三角形共享该顶点的随机选择，因此不会产生明显的矩形拼接结构。

每个像素只需处理三个样本，基础版本大约需要三次纹理读取。输入纹理仍然可以使用 Mipmap 和各向异性过滤，但随机偏移会破坏默认的屏幕空间导数，所以必须在添加随机偏移前计算 UV 导数，再显式传给纹理采样函数。

## 线性混合的问题

最直接的做法是：

```text
I = w1 * I1 + w2 * I2 + w3 * I3
```

但普通线性插值会改变输入纹理的统计分布，常见结果是：

- 对比度不均匀；
- 纹理变得过于模糊；
- 三角形网格结构重新显现；
- 局部颜色和亮度不再符合原始样例。

因此本章重点不是随机平铺本身，而是如何在混合时尽量保持输入纹理的直方图特征。

## 直方图保持混合

处理流程是：

1. 预处理阶段将输入纹理通过直方图变换映射到近似高斯分布；
2. 运行时在高斯空间中做方差保持的加权混合；
3. 通过预计算的逆变换 LUT，把结果映射回原始颜色分布。

这样可以减少线性混合带来的对比度损失和统计特征变化。运行时需要额外采样变换后的输入纹理，并查询逆变换 LUT，但仍保持较低的总体采样成本。

## Tile 尺寸与随机性

Tile 尺寸需要在大尺度结构和重复感之间取平衡：

- Tile 较大：保留更多原始大尺度形状，但更容易看到重复；
- Tile 较小：随机变化更多，但会丢失输入纹理的大尺度特征；
- 哈希函数只需产生足够随机、且相邻顶点之间不出现明显相关性的偏移。

这不是简单地对 UV 做随机抖动，因为三角形网格、重心权重和直方图保持混合共同决定了最终的空间连续性。

## 与 Wang Tiles 的区别

第三章的 Wang Tiles 通过边缘标签约束 Tile 邻接关系，让不同 Tile 按兼容边缘拼接；本章则使用三角形网格和随机顶点偏移，让三个样本在像素级进行混合。

两者都在解决纹理周期性，但侧重点不同：

- Wang Tiles：更强调 Tile 之间的离散邻接合法性；
- 本章方法：更强调 Fragment Shader 中的低采样实时合成和统计分布保持。

## 代价与限制

- 需要预计算直方图变换和逆变换 LUT；
- 运行时比普通单纹理采样需要更多纹理读取和混合计算；
- 直方图保持并不能完全保持原始空间结构；
- Tile 尺寸选取不当时仍可能出现重复或大尺度特征缺失；
- 对需要严格结构对齐的纹理，如规则砖墙或文字图案，不一定适用；
- Mipmap 导数需要手动处理，否则随机 UV 偏移会导致错误的 LOD 和过滤。

## 本章结论

本章把小样例纹理扩展成近似无限的随机纹理，核心不是单纯随机平铺，而是“三角形网格 + 随机顶点偏移 + 三样本混合 + 直方图保持”。

它用少量运行时纹理采样，换取了比普通 UV 平铺更低的重复感，并且不需要为大面积自然材质存储超大唯一纹理。
