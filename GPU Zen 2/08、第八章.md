# Soft Shadow Approximation for Dappled Light Sources（斑驳光源的软阴影近似）

## 章节内容

本章讨论树叶、织物、金属网和家具孔洞等高频遮挡结构产生的斑驳光影。普通 Shadow Map 可以表示这些遮挡，但 PCF、PCSS 等软阴影过滤会把细小孔洞平均掉，使接收面变成过于均匀的半影。

作者：Mariano Merchante

## 核心思路

系统不重新完整求解面积光源的解析软阴影，而是在已有 Shadow Map 上额外识别可能产生光斑的“pinhole”：

1. 生成场景 Shadow Map；
2. 分析每个采样点及其邻域的深度均值和方差；
3. 找出周围深度较稳定、中心却明显偏离的深度异常点；
4. 将这些 pinhole 存入 GPU 的均匀网格缓冲；
5. 阴影接收点查询附近 pinhole，并计算它们投影到当前表面的范围；
6. 采样任意形状的光斑纹理，将局部透光贡献与普通阴影结果合并。

这里的 pinhole 不一定意味着材质透明，它也可以是 Shadow Map 中由几何孔洞或细小遮挡结构形成的可见光通道。

## 与普通阴影和 Alpha Clip 的关系

如果树叶是实体几何，或者使用 Alpha Clip/Alpha Test 在 Shadow Pass 中裁剪像素，普通硬阴影就可以保留树叶孔洞。问题主要出现在软阴影过滤阶段：多个采样被平均后，原本离散的透光孔洞会变成一片平滑半影。

因此本章不是替代普通阴影，而是补充普通软阴影丢失的高频局部光斑：

- 普通 Shadow Map 负责基础遮挡；
- PCF 或 PCSS 负责一般的软阴影边缘；
- pinhole 投影负责恢复细小孔洞产生的斑驳光。

Alpha Clip 可以直接参与 Shadow Map 生成，结果通常是二值遮挡；Alpha Blend 则不能简单地通过普通深度阴影表达半透明透光，需要额外的透射或特殊阴影方案。

## Pinhole 检测

最简单的检测方式是比较中心采样与邻域的深度均值和标准差。一个候选 pinhole 通常具有：

- 外围邻域深度变化较小，说明附近遮挡结构相对稳定；
- 中心采样明显偏离邻域，说明可能存在细小透光通道；
- 中心点与邻域遮挡关系满足预设方向和距离约束。

更稳健的实现会把邻域分为内外两组，并使用方差、比例阈值和距离权重减少误判，例如避免把普通遮挡边缘误识别为 pinhole。

## Scatter 与 Gather

如果每个接收像素都去 Shadow Map 中搜索可能的 pinhole，会产生昂贵且不连续的 Gather。因为同一个 pinhole 投射到接收面上的范围可能很大，搜索半径也会随距离改变。

本章采用相反的思路：

- 先在 Shadow Map 上统一检测 pinhole；
- 将 pinhole 写入按空间划分的均匀网格；
- 阴影接收像素只遍历附近网格单元；
- 对落入投影范围的 pinhole 计算光斑贡献。

GPU 上可以先使用带原子计数器的链表收集结果，再将链表压平成连续数组，并额外保存每个网格单元的数量，减少后续遍历开销。

## 光斑投影

每个 pinhole 可以关联一个任意形状的纹理，用它表示穿过孔洞的光形状。对于远处太阳，可以把投影尺寸近似为光源尺寸与接收面距离、孔洞距离之间的函数；也可以使用多个方向相关的形状纹理，以支持近距离或非规则形状光源。

最终将所有局部光斑贡献与常规阴影过滤结果组合。光斑纹理还可以做动画或 Mipmap，从而表现日食、树叶移动等特殊效果。

## 代价与限制

- 需要额外的 pinhole 检测和 GPU 存储；
- 阈值过宽会把普通遮挡边缘误判为光孔；
- 阴影图分辨率过低时，原始细节已经丢失，无法完全恢复；
- pinhole 数量过多会增加接收像素的遍历成本；
- 它是面积光源斑驳光的近似，并不是完整的光线追踪；
- 主要改善高频局部光斑，不会替代普通阴影、PCF 或 PCSS。

## 本章结论

本章的关键不是重新生成一张更复杂的阴影图，而是识别软阴影过滤中被抹掉的细小透光结构，并把它们作为稀疏的局部光斑重新投影。

因此，普通阴影负责“遮挡”，软阴影负责“平均半影”，pinhole 系统负责“恢复细小孔洞造成的斑驳光”。这种分层组合比单纯提高 Shadow Map 分辨率或增加 PCF 采样更有针对性。
