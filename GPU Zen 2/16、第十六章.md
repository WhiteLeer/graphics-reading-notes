# Adaptive Anti-Aliasing using Conservative Rasterization and GPU Ray Tracing（使用保守光栅化和 GPU 光线追踪的自适应抗锯齿）

## 章节内容

本章提出一种针对复杂几何边缘的自适应抗锯齿方法。它不对所有像素使用高采样率，而是先识别可能只被几何部分覆盖的像素，再使用 GPU 光线追踪提高这些像素内部的可见性分辨率。

作者：Rahul Sathe、Holger Grün、Adam Marrs、Josef Spjut、Morgan McGuire 和 Yury Uralsky

## 核心问题

MSAA 可以通过多个子样本改善几何边缘，但会增加颜色和深度样本的存储、带宽以及压缩失败时的成本。更重要的是，普通单样本光栅化可能完全漏掉细线、远处栅栏、电线和其他没有覆盖像素中心的几何。

理想情况是：

- 完全被前景三角形覆盖的像素，不做额外计算；
- 明显没有几何覆盖的像素，继续使用普通流程；
- 只有部分覆盖或可疑的像素，增加子像素可见性采样。

## 保守光栅化分类

保守光栅化会把部分覆盖像素也提交给 Pixel Shader，因此可以发现标准光栅化可能漏掉的薄几何。Tier 3 硬件还提供 `SV_InnerCoverage`，用于判断像素是否可以保证被三角形完全覆盖。

Pixel Shader 计算当前图元在像素范围内的最小和最大深度：

- 完全覆盖像素输出较远的 `zmax`，并标记为不重要；
- 部分覆盖像素输出较近的 `zmin`，并标记为重要像素。

这种保守深度选择的目标是“不漏掉真正需要处理的像素”。代价是会产生部分 false positive：一些实际上被前景遮挡的像素也可能被标记为重要，后续需要额外光追，但不会漏掉真正可见的细几何。

## 对困难像素使用光追

分类完成后，只有标记为 interesting 的像素才启动额外射线。Ray Generation Shader 在这些像素内部生成多个子像素位置的射线，并与场景几何求交，从而估计：

- 子像素是否被几何覆盖；
- 哪个三角形或表面可见；
- 各个几何区域在像素中的覆盖比例；
- 最终应该使用哪些表面颜色和深度。

完全覆盖的大面积像素仍然沿用普通光栅化结果，因此计算量不会像全屏 MSAA 或全屏光追那样增长。

## 两种覆盖率计算方式

本章讨论了两类提高子像素可见性的方法：

- 使用 DXR/RTX 硬件进行自适应射线求交；
- 在 Pixel Shader 中使用非 DXR 的光线近似方法。

DXR 版本可以根据像素复杂程度增加采样数量，复杂像素使用更多子样本，简单像素使用更少样本。光追结果还可以用于估计像素内的颜色积分，而不只是二值覆盖率。

## 与普通 MSAA 的区别

普通 MSAA 通常对大量像素按照固定采样模式增加深度和颜色样本；本章方法是内容自适应的：

```text
普通像素       → 普通光栅化
部分覆盖像素   → 额外子像素射线
细线/薄几何    → 保守光栅化确保先被发现
```

它把高质量采样集中在真正困难的区域，而不是为整个画面支付同样的采样成本。

## 代价与限制

- 保守光栅化会产生 false positive，导致部分不必要的光追；
- 屏幕上复杂几何很多时，interesting 像素数量会上升；
- 额外 Ray Generation 和求交仍然有较高成本；
- 需要 Tier 3 Conservative Rasterization 和 DXR/RTX 等硬件支持；
- 像素分类本身需要计算深度范围和额外 Render Target；
- 这是可见性抗锯齿方案，不会自动解决纹理、透明度或 Shader 高频细节的所有锯齿。

## 本章结论

本章的核心是“先便宜地找问题，再昂贵地解决问题”：保守光栅化负责保证薄几何不会被漏掉，像素 Shader 负责区分完全覆盖和部分覆盖，GPU 光追只为困难像素提供更高分辨率的子像素可见性。

它不是用光追替代光栅化，而是把光追作为自适应抗锯齿的局部补充，在接近 MSAA 质量的同时减少全画面高采样成本。
