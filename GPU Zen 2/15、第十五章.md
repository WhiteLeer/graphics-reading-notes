# Real-Time Ray-Traced One-Bounce Caustics（实时光线追踪单次反弹焦散）

## 章节内容

本章介绍一种使用 DXR 实时生成单次反弹焦散的方案，主要针对水面、玻璃等折射或反射界面把光能量集中到接收物体上的效果。目标不是执行完整路径追踪，而是专门高效地处理一次折射或反射造成的光能聚集。

作者：Holger Grün

## 核心思路

焦散的难点在于光线经过折射或反射后，可能在接收面上集中到很小的区域。若所有区域均匀采样，会把大量射线浪费在不可见或低能量位置。

本章用四个阶段处理：

1. 计算折射/反射后的网格和光线方向；
2. 为每个三角形计算光能压缩比；
3. 根据压缩比和屏幕覆盖范围进行重要性采样，并追踪射线；
4. 对累积的焦散亮度进行降噪，再用于照亮接收场景。

## 折射网格与压缩比

对于折射或反射界面的每个顶点，系统根据入射光方向和表面法线计算一条折射/反射射线，并将它与接收几何相交，得到对应的折射/反射网格。

每个界面三角形会产生一个压缩比：

```text
compression ratio = interface triangle area / refracted triangle area
```

如果折射后的三角形面积更小，说明光能被集中，焦散更亮，应分配更多样本；如果面积变大，能量被摊开，则可以减少样本。

样本数量还会考虑折射三角形的屏幕空间大小，使接近摄像机、影响较多屏幕像素的区域获得更多采样。

## 光线追踪与屏幕累积

在界面三角形内部生成随机世界空间样本。对于每个样本：

1. 判断该位置是否能被光源看到；
2. 沿插值后的折射或反射方向发射光线；
3. 与接收场景求交；
4. 将交点投影到屏幕空间；
5. 如果交点对应当前像素的前景表面，则使用原子加法累积亮度。

累积值可以根据压缩比、射线在水或玻璃中的传播距离、光线吸收等因素进行修正。这样得到的是一个屏幕空间焦散亮度缓冲，而不是直接修改接收物体的材质纹理。

## 降噪与最终应用

随机射线会产生噪声，因此需要对焦散缓冲进行迭代的 Cross-Bilateral Blur。降噪时考虑：

- 屏幕空间深度；
- 表面法线；
- 视空间位置。

示例中使用半分辨率焦散缓冲来降低降噪成本，再将结果用于接收场景的光照。焦散可以表现为水面下的亮斑、玻璃折射后的局部照明等。

## 与传统焦散方法的区别

传统方法可能使用：

- 屏幕空间 Ray Marching；
- Shadow Map 或深度图近似；
- 体素化接收几何后进行 Ray Marching；
- 单独生成 Caustics Map。

本章方案直接在 DXR 中生成折射/反射射线，不需要额外渲染完整的 Caustics Map，并通过压缩比进行重要性采样，因此更适合实时硬件光追。

## 代价与限制

- 只处理单次折射或反射，不是完整多次反弹路径追踪；
- 需要实时光线追踪硬件和加速结构；
- 焦散亮度仍然依赖随机采样和降噪，可能出现残余噪声；
- 折射/反射界面过于粗糙或三角形过大时，压缩比估计会产生误差；
- 屏幕外但会把光线投射到屏幕内的区域也需要扩大处理范围；
- 半分辨率和降噪会牺牲部分细节。

## 本章结论

本章不是用光追重新渲染所有光照，而是针对焦散最重要的特征——光能压缩——进行采样分配。光能越集中、屏幕影响越大，就投入越多射线；随后通过屏幕空间累积和边缘感知降噪得到稳定的焦散结果。

它用单次反弹、重要性采样和降噪，把原本昂贵的焦散效果缩减为实时光追硬件可以承受的专用效果。
