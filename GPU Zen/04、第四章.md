# Participating Media Using Extruded Light Volumes（使用挤出式光照体积处理参与介质）

## 章节内容

本章介绍一套实时体积光方案：在均匀介质、单次散射等假设下，把沿视线的散射积分改写为若干段累计积分；利用从 shadow map 重建的光照体积，找出光照可见性变化边界，只在这些边界处计算并加减积分，而不对每个像素沿视线密集 ray march。

作者：Nathan Hoobler、Andrei Tatarinov、Alex Dunn

## 物理模型与关键简化

参与介质会吸收并散射光。沿观察射线的最终辐射由场景表面传来的光经过介质透射，加上视线各处散射进来的光组成。一般形式需要沿光路积分，且介质中的点同时可能是遮挡者、接收者和散射光源，直接高质量求解成本很高。

本文主要采用两项假设：

- 介质在局部近似均匀，消光/散射密度不随位置任意变化。
- 只计算单次散射；光源对某点的可见性是二值函数，并在可见性不变的区段内保持不变。

在此模型下，视线可按光照可见性变化切成多个区段。每个区段的积分可由“从眼睛到边界的累计积分”组合得到：穿过光照体积边界的正面时加上累计量，穿过背面时减去累计量。多段相加、相减后，剩下的就是光源可见区段对该像素的散射贡献。

## 从 shadow map 构造光照体积

shadow map 描述光源视角下被遮挡的深度。算法把它用于重建光源可见空间的边界：

1. 为方向光，在光源视锥近平面放置网格；读取 shadow map 深度，将网格顶点重建/挤出到遮挡边界，并封闭体积。
2. 使用硬件曲面细分按目标屏幕特征尺寸自适应增加网格细节，使近处区域较细、远处区域较粗。
3. 从相机视角绘制体积表面；像素着色器计算该表面位置之前的累计散射积分，按正反面符号累加到缓冲区。
4. 使用 stencil 统计体积表面交叉与缺失情况，并做补填，处理 shadow map 精度导致的体积与场景几何相互穿插问题。

这样，算法的主要工作量转为光照体积在屏幕上的覆盖和深度复杂度，而非每个像素固定执行许多采样步。它仍依赖 shadow map 的准确性；shadow map 与实际遮挡几何不一致会造成明显伪影。

## 方向光与局部光

方向光可假设入射方向近似恒定、距离衰减可忽略，因此单段散射积分可以直接计算，是最简单的路径。

点光源和聚光灯的光线方向、距离衰减、相位函数会沿视线变化，积分不再容易解析求解。作者为局部光预计算二维积分 LUT：compute shader 先数值积分每个参数位置的微分贡献，再对每行做前缀和；体积绘制时按视线深度与方向参数采样 LUT。点光体积由围绕光源的立方控制网格重建，聚光灯则使用锥形范围并额外处理角度衰减。

## 优化与性能

体积光可在低于最终分辨率的缓冲区计算，再上采样合成。作者指出，内部半分辨率配合 2× MSAA 可用较低成本保留较多边缘质量；MSAA 深度/累积缓冲能减轻下采样时体积边界与锐利阴影的锯齿。由于下采样会放大抖动和小遮挡物的可见性跳变，文中也讨论在 resolve 阶段使用 TAA。

在 GTX 1080、1440p、内部半分辨率加 2× MSAA 的样例中，方向光约 1.72 ms、聚光灯约 2.24 ms、点光约 2.30 ms。方向光不需要局部光 LUT；表中各阶段时间还包括 resolve/composite。成本会随光体积屏幕覆盖、遮挡体积深度复杂度和灯光类型变化，且依赖视角。

## 限制与讨论补充

- 任意 3D 噪声雾的密度随空间变化，不满足直接使用的均匀介质假设。可以扩展为分区近似、可解析密度模型或额外数值采样，但一般会增加计算，不能再直接享有原方法的简单积分形式。
- 单次散射不包含多次散射；任意尘云、复杂局部密度分布也无法直接由本文的二值可见区间积分表达。
- 本方法并非完全不做积分，而是利用可见性区段边界，把固定步进积分换成边界处的累计积分求值；对于 shadow map 不一致、体积边界复杂或大量重叠的情况，收益可能下降。
- 代价从 ray marching 转向体积网格绘制、shadow map 重建、LUT（局部光）和合成。最终是否更快取决于场景与光照覆盖，不能只凭“减少步数”断言整体性能必然更好。
