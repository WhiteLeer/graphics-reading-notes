# Stable Indirect Illumination（稳定的间接光照）

## 章节内容

本章以 Reflective Shadow Map（RSM）估算一次反弹间接光照，再用去交错采样和分阶段的交叉双边模糊，降低稀疏采样造成的块状噪声与运动闪烁。它关注的是实时近似的稳定性与效率，不是完整的全局光照求解。

作者：Holger Gruen、Louis Bavoil

## 方法基础：RSM 稀疏采样

RSM 中，直接受光的表面可视作许多虚拟小光源。对当前 G-buffer 像素，算法从 RSM 稀疏采样，估算这些表面的一次间接反弹贡献。采样越稀疏，开销越低，但画面会出现噪声、斑块和固定采样结构；相机或动态物体运动时，这些结构会表现为闪烁。

作者采用可见性未感知的近似贡献公式，结合 G-buffer 位置/法线、RSM 表面法线、距离衰减与 RSM 通量累计采样贡献。该近似本身并不显式追踪每个反弹光路的遮挡。

## Deinterleaved Texturing（DT）

将 G-buffer 和 RSM 按 2×2 像素位置拆成四张子纹理。每张子纹理包含原图四分之一的像素，即宽高各减半；每种像素相位有自己对应的 G-buffer 与 RSM 子纹理。

在半分辨率上计算四组间接光照，每组使用固定采样模式访问对应的 RSM 子纹理。作者提出 DT 可以让稀疏采样在原始交错纹理中覆盖更宽的足迹，同时改善采样访问的缓存效率。它是空间重排与采样策略，不是跨帧时间累积。

## 分阶段滤波

原始稀疏结果会保留明显斑块。单纯直接模糊虽能平滑图像，却可能把光照扩散到几何边界另一侧。本文的处理顺序是：

1. 对四张去交错的低分辨率间接光照子图分别做交叉双边模糊。
2. 将四组子结果重组为全分辨率间接光照图。
3. 再对全分辨率结果做一次交叉双边模糊。

滤波权重参考场景深度和逐像素法线，以减弱跨越深度断层、表面方向突变的模糊。它能缓解错误扩散，但不是绝对的漏光保证：低分辨率输入、深度/法线不连续处以及稀疏采样误差仍可能造成错误光照或细节损失。

## 性能与限制

论文报告在 1920×1200 的预渲染数据上，DT 采样耗时约为 GTX 1070 的 3.0 ms、RX 480 的 4.6 ms；不使用 DT 时约为 4.6 ms、7.5 ms。该比较不包含 G-buffer 和 RSM 的生成成本。书中合并 DT 与子图模糊的另一张表，其行标签在当前 PDF 呈现中不清楚，因此不据此归因配置差异。

整体思路可以概括为：RSM + 稀疏采样估算一次间接光照，再通过 DT 和分阶段深度/法线引导模糊压低采样噪声与闪烁。画质与成本仍取决于采样数量、模糊半径和边缘信息质量；它不消除稀疏估算本身的误差，也不能保证没有漏光。

## 讨论补充

- 本章所说的稳定主要来自空间去交错采样与滤波，不是依赖历史帧的时间累积。
- 深度/法线引导的双边模糊是对跨表面光照扩散的抑制，不是物理可见性测试，也不能彻底修复 RSM 稀疏采样带来的错误贡献。
- 简述：RSM + 稀疏采样算间接光，然后以不同阶段的模糊做稳定化；需要区分算法近似误差和滤波伪影。
