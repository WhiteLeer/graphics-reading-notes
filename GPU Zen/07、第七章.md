# High Quality GPU-efficient Image Detail Manipulation（高质量 GPU 高效图像细节操控）

## 章节内容

本章讨论如何在 GPU 上高效增加和控制图像细节，例如局部锐化、纹理细节和多尺度变化。核心不是对整张图统一模糊或锐化，而是先分解不同频率，再根据局部特征重新组合。

## 核心思路

### 基础层与细节层

将图像分解为基础层和细节层：

```text
detail = original - base
```

基础层描述较大范围的颜色和形状，细节层描述边缘、纹理等高频信息。这样可以分别控制低频结构和高频细节。

### 局部自适应

通过局部方差、对比度或纹理强度判断某个区域应该增强还是抑制细节。平坦区域需要避免放大噪声，纹理区域则可以适当提高细节权重。

### GPU 友好的多尺度处理

使用分层降采样、上采样、局部统计和 Summed-area Table 等规则的并行流程，降低大范围滤波的成本。多尺度结构可以让不同大小的细节分别受到控制。

## 为什么不能直接锐化

全屏固定强度锐化会放大噪声、压缩伪影和边缘振铃；固定半径的模糊也无法同时适应平坦区域与高频纹理。因此滤波半径、权重或细节强度需要随局部图像特征变化。

## 代价与限制

- 多尺度处理会增加中间纹理、带宽和采样成本。
- 局部统计窗口越大，得到的结果越稳定，但计算和存储代价也越高。
- GPU 实现应尽量使用规则、可并行的采样流程，避免复杂的逐像素可变循环。
- 细节增强本质上仍是图像处理，不能恢复输入中本来不存在的信息。

## 本章结论

本章的本质是把“整张图统一处理”改成“按频率和局部特征处理”，从而在有限 GPU 成本下获得更高质量的细节控制。
